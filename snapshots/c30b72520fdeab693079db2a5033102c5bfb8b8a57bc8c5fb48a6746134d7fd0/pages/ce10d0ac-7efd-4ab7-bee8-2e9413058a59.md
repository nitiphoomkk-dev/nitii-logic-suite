\*\*EP-02 การเพิ่มวิดีโอรีวิว แสดงหน้า UI ดังต่อไปนี้ \*\*

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=6d206d1f-7b78-42d9-9ed7-63efa31b23b4) ![](https://wiki.infonayoo.co/api/attachments.redirect?id=07399c6b-b717-4510-8676-0101dbb41b7b)

* **การเพิ่มหัวข้อรีวิว (require)**
  * จำกัดข้อความที่ 500 ตัวอักษร
    * ใส่ได้ทั้งทุกตัวอักษร อักขระ และตัวเลข
    * ถ้าใส่ชื่อวิดีโอไว้ก่อนที่จะวาง link จะยังคงชื่อวิดีโอไว้ที่ user ตั้ง
    * ถ้าใส่ link โดยยังไม่ใส่ ชื่อหัวข้อรีวิว จะดึงชื่อวิดีโอมาใส่ที่หัวข้อให้ auto
* **แท็ก(require)**
  * โครงการใหม่
  * รับสร้างบ้าน
  * อสังหามือสอง
  * ไลฟ์สไตล์
  * เมื่อเลือก tag การเชื่อมต่อจึงจะปรากฎ section นี้ขึ้นมา
* **Link URL (ต้องใส่ link 3 ประเภทนี้เท่านั้น)**
  * Youtube
  * Tiktok
  * Short video
  * เมื่อวาง link url แล้วระบบจะต้องดึงรูปปก cover ของวิดีโอนั้นมาทันที และแสดงรูปนั้นที่กรอบตัวอย่างรูปภาพ
  * โดย user สามารถที่จะลบภาพปกที่ดึงมาเผื่ออัพภาพใหม่ได้ ถ้า user อยากได้ภาพปกวิดีโอเดิมหลังลบไปแล้ว ให้วาง link ใหม่
* **รูปปกวิดีโอ**
  * อัพได้ไม่เกิน 3 mb jpg jpeg png เท่านั้น
  * ขนาด 1920 \* 1080 px
* \*\*แหล่งที่มา เลือกได้แค่  1 \*\*
  * สามารถใส่ได้เฉพาะจังหวัดที่แอดมินน่าอยู่ดูแลเท่านั้น (admin จังหวัด)
    * Default เป็นจังหวัดนั้น
  * Super admin สามารถใส่แหล่งที่มาให้ทุกจังหวัดได้
    * Default เป็นส่วนกลาง
* \*\*จังหวัดที่แสดงผล \*\*
  * Super admin สามารถใส่จังหวัดที่แสดงผลได้ทุกจังหวัด	(เลือก 1 : many )

    **เลือกได้มากกว่า 1**
  * Admin จังหวัดสาสามารถติดแท็กจังหวัดที่แสดงผลได้แค่จังหวัดตัวเองเท่านั้น
    * Default เป็นจังหวัดของแอดมินนั้น เพิ่มอีกไม่ได้ ยกเว้นแอดมินอื่นมาขอติดแท็กด้วย \*\* เลือกได้แค่  1 \*\*
* **การเชื่อมต่อ (การแสดงผล depend on การเลือกประเภท tag) ไม่เป็น require file**
  * **เชื่อมใบประกาศเชื่อมได้ทีละ 1 เท่านั้น depend on แหล่งที่มาของวิดีโอ**
  * **การเชื่อมบทความ สามารถเชื่อมบทความได้**
    * **บทคว่ามจะดึงเฉพาะบทความตามประเภท tag**
    * โครงการใหม่ ถ้าเลือก tag โครงการใหม่ บทความที่เลือกได้จะเฉพาะแท็กนี้เท่านั้น
    * รับสร้างบ้าน ถ้าเลือก tag รับสร้างบ้าน ถ้ บทความที่เลือกได้จะเฉพาะแท็กนี้เท่านั้น
    * อสังหามือสองถ้าเลือก tag อสังหามือสอง บทความที่เลือกได้จะเฉพาะแท็กนี้เท่านั้น
    * ไลฟ์สไตล์ถ้าเลือก tag ไลฟ์สไตล์ บทความที่เลือกได้จะเฉพาะแท็กนี้เท่านั้น
    * **ถ้าเลือก tag ของวิดีโอแล้วจึงจะเลือกตรงนี้ได้**

ไลฟ์สไตล์ → บทความไลฟ์สไตล์

**3. dropdown แสดงบทความที่เลือกได้**

แสดงเฉพาะบทความที่ tag ตรงกับวิดีโอเท่านั้น ไม่ข้าม tag

\* admin ไม่ต้องเลือก tag บทความเอง ระบบ filter ให้อัตโนมัติ
