## ต้องตัดสินใจก่อน

### 1. FE-04: prefix ภาษาจีนจะใช้ /zh หรือ /cn

task เขียนให้เปลี่ยนเป็น `/cn` แต่ branch nayoo ตัดสินไปแล้วเมื่อ 2026-10-15 ให้ใช้ `zh` ทุกที่ (prefix `/zh`) และลบ redirect 308 ของ `/cn` ออก (`docs/plans/locale-cn-to-zh-plan.md`) ใน ClickUp ขึ้นว่า dev complete ต้องเลือกว่าจะใช้แบบไหน ถ้าใช้ `/zh` ให้แก้คำอธิบายใน task ถ้าใช้ `/cn` ต้องเปลี่ยนโค้ดทั้งระบบ

### 2. FE-02: skill ยังเป็น contract เก่า

ClickUp ขึ้นว่า dev complete แต่ `.claude/skills/localized-api-compatibility/SKILL.md` (และสำเนาใน `.agents/`) ยังสอนให้รับ `{ th, en, zh }` และให้ขอ BE แก้ endpoint ยังไม่ได้เปลี่ยนเป็น "ส่ง header แล้วรับค่าเดียว"

### 3. FE-12: console ส่งภาษาของหน้า ไม่ได้ตรึงเป็น th

task ให้ส่ง `Accept-Language: th` ทุกครั้ง แต่ console ส่งภาษาตาม URL (หน้า `/en` ส่ง `en`) พอ BE เปิดเลือกภาษาจาก header แอดมินที่อยู่หน้า `/en` จะได้ค่าภาษาอังกฤษ ต้องตกลงว่ารับแบบนี้ได้หรือจะตรึงเป็น `th` ข้อนี้ต้องขึ้น prod ก่อนที่ BE จะเปิด header
