**Functional Requirements** 

หน้าจัดการบริษัทบริษัทรับสร้างบ้าน

แบ่งออกเป็น 2 section ในหน้าคือ 1.section จัดการสาขา 2.section ผู้ดูแลสาขา

**EP-01: การกำหนดสิทธิ์และความสามารถของ Profile แม่ลูกตามตารางดังต่อไปนี้**

**EP-02: สิทธิ์บัญชีแม่** 

● หน้าที่บัญชีแม่

● สร้าง Profile บริษัท

● สร้างบัญชีสาขา

● กำหนดสิทธิ์ Admin ของบัญชีสาขา

● เห็นรายงานของบัญชีสาขา แบบ Real Time

● สร้าง Content ของบริษัท

● แก้ไข Profile จังหวัด

● สร้าง/แก้ไข/จัดการ ใบประกาศ

● ดันใบประกาศ

● สร้าง/จัดการ Content ใน Feed

● จัดการ โปรโมชั่น

● ซื้อ Ads

**EP-03: สิทธิ์บัญชีลูก**

● แก้ไข Profile จังหวัด

● สร้าง/แก้ไข/จัดการ ใบประกาศ

● ดันใบประกาศ

● สร้าง/จัดการ Content ใน Feed

● จัดการ โปรโมชั่น

● ซื้อ Ads

● เห็นรายงานของบัญชีสาขาที่ได้รับสิทธิ์ในการดูแล แบบ Real Time ในหน้าภาพรวม

**EP-04:หน้าจัดการบริษัท ต้องรองรับทั้ง 3 ภาษา**

ในการแปลหน้าที่แสดงผล UI ต้องเปลี่ยนแปลงตามภาษาที่เหลือ ได้ แก่ภาษา TH EN CN

**EP-05:Section  จัดการสาขา**

EP-05.1 แสดง (รายการ & การค้นหา) ช่องการค้นหาสามารถ  ค้นหาชื่อสาขา และค้นหาโดยพิมพ์ชื่อจังหวัด

EP-05.2 มีช่อง “ค้นหาสาขา” (ค้นด้วยชื่อจังหวัด)

EP-05.3 มีปุ่มเพิ่มสาขา เมื่อกดแล้วแสดง modal ช่องทางการติดต่อสื่อสารกับแอดมินน่าอยุ่ให้สามารถเปิดสาขาจาก console น่าอยู่ได้  เมื่อแอดมินอนุมัติ จังหวัดนั้นจะถูกเพิ่มให้บริษัทและกลายเป็นสิทธิ์ที่ใช้งานบนระบบได้ทันที (แจ้งเตือนผล)  (เปิดสาขา เท่ากับสิทธิ์ในการเปิดบัญชีจังหวัดนั้นที่น่าอยู่ให้บริการ)

EP-05.4 มีตารางแสดงคอลัม  ชื่อบริษัท จังหวัด ผู้ดูแลจังหวัด  แก้ไข   

 มีปุ่มไอคอน 3 จุดเมื่อกดไอคอน แสดงปุ่ม แก้ไข แสดง modal เพิ่มผู้แลในจังหวัดนั้นคือให้สิทธิ์แอดมินในการดูแลจังหวัดนั้น โดย แสดง icon “เพิ่ม” สำหรับจังหวัดที่ยังไม่ถูกดูแลโดยผู้ใช้นั้น

แสดง icon “ลบ” สำหรับจังหวัดที่ผู้ใช้รายนั้นถือสิทธิ์อยู่   และปุ่มลบสาขา   และมีปุ่มเพิ่มผู้ดูแลในตาราง คอลัมผู้ดูแลจังหวัด

**EP-06:Section  จัดการสาขา**

EP-06.1 แสดงตารางผู้ใช้: ชื่อผู้ใช้งาน, อีเมล, บทบาท (Super Admin/Admin), จังหวัดที่ดูแล, สถานะ(เปิด/ปิด), ใช้งานล่าสุด

EP-06.2 ค้นหาผู้ใช้ได้ด้วย ชื่อผู้ใช้งาน / อีเมล 

EP-06.3  คอลัมน์ “ใช้งานล่าสุดเมื่อ” ต้องเรียงได้ (ขึ้น/ลง)

**EP-07:  เพิ่มผู้ดูแล (Add Admin)**

EP-07.1  กดปุ่มเพิ่มผู้ดูแล แสดง modal เพิ่มข้อมูลผู้ใช้งานประกอบด้วย

● อีเมลผู้ใช้งาน\*

● ชื่อผู้ใช้งาน\*

● เบอร์โทรผู้ใช้งาน\*

● รหัสผ่าน\*

● ยืนยันรหัสผ่าน\*

และมี check box  ติ๊กเพิ่มสาขาที่ดูแล (เพิ่มสาขาผู้ดูแลต้องเลือกอย่างน้อย 1 จังหวัดในการ บันทึกข้อมูล)

ใน modal ต้องมีปุ่มบันทึกและยกเลิก

EP-07.2 ต้องเลือก “จังหวัดที่ดูแลอย่างน้อย 1 จังหวัด” ก่อนบันทึก (สำหรับผู้ดูแลสาขา)

EP-07.3 หากรหัสผ่านและยืนยันรหัสไม่ตรงกันห้ามบันทึก พร้อมแสดงข้อความเตือน

EP-07.4 การสร้างรหัสผ่าน  

**ต้องทำการยืนยันรหัสผ่าน 2 ชั้น**

สร้างรหัสผ่าน(6 ตัวอักษรขั้นต่ำ)\*

● สีแดง   ระดับความปลอดภัยต่ำ= 6 ตัวอักษร (ขั้นต่ำ)

● สีเหลือง    ระดับความปลอดภัยปานกลาง  =7- 8 ตัวอักษร

● สีเขียว    ระดับความปลอดภัยสูง = 9-10 ตัวอักษร (สูงสุด)

● ไม่จำกัดว่าจะกรอกภาษาไทยหรืออังกฤษหรือตัวเลข ขอแค่ตัวอักษรครบ

**EP-08 เปลี่ยนรหัสผ่านผู้ใช้**

EP-08.1มีทางเลือก “เปลี่ยนรหัสผ่าน” ในเมนูแก้ไขข้อมูล—-> เปลี่ยนรหัสผ่าน  ตามflow การเปลี่ยนรหัสผ่าน 

EP-08.2 หลังบันทึกสำเร็จ แสดง Modal แจ้ง “บันทึกรหัสผ่านใหม่เสร็จสมบูรณ์”

การเปลี่นรรหัสผ่านต้องยืนยัน รหัสผ่าน 2 ครั้ง และสร้างรหัสใหม่ตาม EP-07.4

หากฟิลด์ว่างหรือไม่ตรงกันต้องไม่ให้บันทึก

**EP-09 การป้องกันข้อผิดพลาดด้วย Modal**

EP-09.1 ทุกการ “ลบ/ยกเลิก/เปลี่ยนแปลงสำคัญ” ต้องมี Modal ทวนก่อนเสมอ

EP-09.2 ข้อความใน Modal ต้องสื่อสารผลกระทบชัดเจน

**EP-10 ปุ่มแก้ไขข้อมูลประกอบไปด้วย แก้ไขจังหวัดที่ดูและ แก้ไขข้อมูลผู้ใช้งาน**

EP-10.1ปุ่มแก้ไขจังหวัดที่ดูแล กดแล้วแสดง modal จัดการเพิ่มลดสาขาให้ admin ในสิทธิ์การดูแลสาขาในจังหวัดนั้น

EP10.2 ปุ่มแก้ไขข้อมูลผู้ใช้งาน กดแล้วแสดง modal แก้ไขข้อมูลผู้ใช้งาน สามารถเปลี่ยนรหัสผ่าน ชื่อผู้ใช้งานได้

EP-10.3 ลบผู้ใช้ต้องมี Modal ยืนยันก่อนเสมอ

**EP-11 ข้อกำหนดการตรวจสอบข้อมูล (Validation)**

EP-11.1หากตรวจสอบไม่ผ่าน ให้ไฮไลต์ฟิลด์ที่ผิดและอธิบายเหตุผล

EP-11.2 ตรวจสอบข้อมูลที่ require ที่มีการใส่\* หากไม่กรอก ระบบแสดงฟีลสีแดงที่ช่องกรอกพร้อมอธิบายเหตุผล

**EP-12 Console ต้องทำได้ทั้งหมดตามสิทธิ์ Super Admin บริษัทรับสร้างบ้านมือบนเว็บ**

 โดยใช้กติกา/Validation/Modal/นโยบายเดียวกันทุกประการ  อบเขต: Console ต้องทำได้ เท่ากับ Super Admin บริษัทรับสร้างบ้าน บนเว็บ ตาม EP-02, EP-05–EP-11   ทำทุก action ได้เท่าฝั่งเว็บน่าอยู่

EP-12.1 บทบาท/สิทธิ์ ใน Console

เฉพาะ Super Admin (Nayoo) เท่านั้นที่เข้าถึงเมนู Console ชุดนี้ได้

EP-12.2 ทุกคำสั่งสำคัญมี ข้อความ/Validation/Modal เหมือนเว็บ

EP-12.3 จัดการสิทธิ์ผู้ดูแลระบบ สำหรับ Super Admin บริษัทรับสร้างบ้าน เพิ่มเลือกจังหวัดในการบริการให้

EP12.4 สามารถจัดการสิทธิ์ Admin บริษัทรับสร้างบ้าน  เพิ่ม admin บริษัทรับสร้างบ้าน เพิ่มสิทธิ์ในการดูแลจังหวัดให้ admin บริษัทรับสร้างบ้าน ,แก้ไขข้อมูล,เปิด/ปิดสถานะใช้งาน admin บริษัทรับสร้างบ้าน,ลบ

**EP13-16 เกี่ยวกับ การเพิ่มวิดีโอรีวิว  ใช้ logic เดิมของการเพิ่มวิดีโอรีวิว ของบริษัทรับสร้างบ้าน**

**EP-13 Console มีปุ่มเพิ่มวิดีโอรีวิวที่ คอลัมจัดการ ในไอคอนฟันเฟื่อง** 

เมื่อกดปุ่มเพิ่มวิดีโอรีวิวิ ปุ่มบนหน้าโปรไฟล์บริษัท: “เพิ่มวิดีโอรีวิว”

เมื่อกดแล้วเปิด Modal: จัดการวิดีโอ มี 2 ส่วน

⁠ 1⁠. วิดีโอเดิม – รายการวิดีโอที่มี (ปุ่ม แก้ไข, ลบ)

⁠ 2⁠. เพิ่มวิดีโอใหม่ – แบบฟอร์มเพิ่มวิดีโอ

ช่องกรอกที่ต้องมี (\* = จำเป็น)

1⁠. ลิงก์วิดีโอ (YouTube)\*

2⁠. ชื่อวิดีโอ\*

เมื่อวางลิงก์ YouTube แล้ว ระบบ แสดงตัวอย่าง (Preview) อัตโนมัติ ปุ่ม: บันทึก, ยกเลิก

## **EP-14 รายละเอียด “วิดีโอเดิม”**

1⁠. แสดงรายการ: รูปตัวอย่าง (ถ้ามี), ชื่อวิดีโอ, ลิงก์, ปุ่ม บันทึก, ลบวิดีโอ

2⁠. แก้ไข: เปิดฟอร์มให้แก้ชื่อ/ลิงก์ แล้ว บันทึก หรือ ยกเลิก

3⁠. ลบ: ขึ้น Modal ยืนยันการลบ กดปุ่ม “ตกลง” = ลบสำเร็จ   “ยกเลิก” = ไม่เปลี่ยนแปลง

**EP-15 Validation**

● ต้องกรอก ลิงก์ YouTube และ ชื่อวิดีโอ ครบก่อนบันทึก

ลิงก์ต้องเป็น YouTube ที่เปิดดูได้ (ไม่รับไฟล์อัปโหลดตรงในรุ่นนี้)

**EP-16 ข้อความแจ้งเตือน (Modals)**

1⁠. สำเร็จ

⁠ 1⁠. เพิ่ม: Video added – เพิ่มวิดีโอเรียบร้อยแล้ว

⁠ 2⁠. ลบ: ลบสำเร็จ

2⁠. ผิดพลาด

⁠ 1⁠. ลิงก์ YouTube ไม่ถูกต้องหรือเปิดดูไม่ได้

⁠ 2⁠. มีวิดีโอนี้อยู่แล้ว

⁠ 3⁠. เพิ่มได้ไม่เกิน 2 วิดีโอ

3⁠. ยืนยันการลบ

⁠ 1⁠. ยืนยันลบวิดีโอรีวิวนี้หรือไม่? ปุ่ม ตกลง / ยกเลิก
