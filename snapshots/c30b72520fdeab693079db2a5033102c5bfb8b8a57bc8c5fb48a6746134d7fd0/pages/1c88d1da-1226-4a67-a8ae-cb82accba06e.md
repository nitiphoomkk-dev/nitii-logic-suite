# **1. บทนำและที่มา**

ฟีเจอร์ “ลูกค้ามาแล้ว” บนแพลตฟอร์มน่าอยู่ (Nayoo V2) ทำหน้าที่แสดงรายการลูกค้า/ผู้สนใจที่ได้ติดต่อเข้ามาแล้วในบริบทต่าง ๆ ของหมวดรับสร้างบ้าน, หมวดโครงการมือ 1  เช่น ใบประกาศโครงการ ,โปรไฟล์แบรนด์, ใบประกาศแบบบ้าน และบริษัทรับสร้างบ้าน  เอกสารฉบับนี้กำหนดความต้องการสำหรับการพัฒนาในเวอร์ชัน 2.1 ซึ่งมุ่งเน้นการเพิ่มความสามารถ\*\* “การจัดลำดับการแสดงผล” ของรายการใบประกาศและโปรไฟล์ ตามสถานะโฆษณา (Premium, Super Top Ads, Top Ads) เพิ่มเติมจากการแสดงผลพื้นฐานที่มี\*\*

\*\*2. วัตถุประสงค์ \*\*

ส่งการแจ้งเตือนไลน์ลูกค้ามาแล้ว ให้กับ แอดมินโครงการหรือบริษัทรับสร้างบ้าน เพื่อเป็นการ tigger ให้กับ แอดมินเข้ามาตรวจสอบข้อมูล และติดต่อกลับหาลูกค้าที่ลงทะเบียน

\*\*3. Scope of work \*\*

**Mvp สามารถทำการกดไลค์ กดแชร์ คอมเมนต์ได้ และ จัดกา ลบแก้ไข คอมเมนต์ได้**

* In of  Scope

1\.      การแสดงผลรายการ “ลูกค้ามาแล้ว” บนฟีเจอร์ Line ในหมวดรับสร้างบ้าน (มือ 1)

**2**\*\*.\*\*      **การจัดลำดับการแสดงผลตามสถานะโฆษณา ได้แก่ Premium, Super Top Ads, Top Ads และรายการปกติที่บอกลำดับแบบ real time ลำดับ x หน้า 10**

3\.      การแสดงการ์ด “ลูกค้ามาแล้ว” ครบทั้ง 4 บริบท: (1)ใบประกาศโครงการมือ 1 (2) โปรไฟล์สาขา (3) โปรไฟล์ส่วนกลาง (4) ใบประกาศแบบบ้าน

4\.      ข้อมูลที่แสดงในแต่ละการ์ด: ชื่อ (ใบประกาศ/แบรนด์/บริษัท/แบบบ้าน), รูปปก/โลโก้, ชื่อผู้ติดต่อ, เบอร์โทร, ที่มา (Source), จังหวัด และคำอธิบายก่อนปุ่มติดต่อตาม UI

5\.      รองรับการแสดงที่มา (Source) ตามที่ระบุในแต่ละบริบท: Facebook, Line, ทั่วไป, Map, บทความ, Walk-in, Event Online

6\.การจัดการสิทธิ์ (Permission) ในการเข้าถึง/จำกัดการดูเบอร์ติดต่อ

* Out of Scope
  * 
    1. ```
        การเปลี่ยนแปลง Logic การเก็บ/บันทึกข้อมูลลูกค้า (Lead Capture) — เวอร์ชันนี้เน้นเฉพาะการ “แสดงผล” และ “จัดลำดับ”
       ```
  * 
    2. ```
        การเปลี่ยนแปลงระบบขาย/คิดค่าใช้จ่ายโฆษณา Premium / Super Top Ads / Top Ads (ใช้สถานะโฆษณาที่มีอยู่เดิม)
       ```
  * 
    3. ```
        ฟีเจอร์ Line อื่น ๆ ที่ไม่เกี่ยวข้องกับ “ลูกค้ามาแล้ว”
       ```
  * 
    4. ```
        หมวดหมู่อื่นนอกเหนือจากรับสร้างบ้าน, มือ 1 เช่น มือ 2 หรือหมวดอื่น
       ```
  * 
    5. ```
        ระบบรายงาน/Analytics และ Dashboard ของลูกค้ามาแล้ว
       ```
  * 
    6. ```
        การรองรับภาษาอื่นนอกเหนือจากภาษาไทย
       ```
  * 
    7. ```
        การย้าย/แปลงข้อมูลเดิม (Data Migration)
       ```
