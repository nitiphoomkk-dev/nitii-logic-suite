# **EP-02 Pop-up โฆษณา หน้า Center**

## **Solution รองรับ 3 ภาษาและเลือกหนึ่งภาพต่อ Slot**

## **1 แนวคิดหลัก**

ดึงรายการโฆษณา Product Pop-up จากทุกจังหวัดที่มีรายการมารวมบนหน้า Center รองรับจำนวนจังหวัด N และไม่นำ Pop-up ประเภท **“น่าอยู่”** เข้าชุดแสดงผล จากนั้นตรวจภาษาและไฟล์ของอุปกรณ์แยกแต่ละ Slot แล้ว Shuffle **Slot ต้นทาง** ก่อนเลือกภาพ A หรือ B เพียงหนึ่งภาพภายใน Slot ที่ได้รับเลือก

การเลือกภาษาใช้ลำดับ **ภาษาที่ User ใช้งาน → ภาษาไทยของ Slot เดียวกัน → ตัด Slot ออก** ตาม Top Banner โดยยังเปิด Pop-up เฉพาะเมื่อผ่านเงื่อนไขของหน้า เวลา และ Session ของ Pop-up

**หนึ่ง Slot ต้นทางที่ได้รับเลือก = หนึ่งรายการ Pop-up และหนึ่งภาพที่ใช้แสดงในรอบนั้น** จำนวนภาษาและภาพ A/B ไม่เพิ่มจำนวนรายการที่ User มีสิทธิ์เห็น และไม่เพิ่มน้ำหนักของ Slot ในการ Shuffle

| **ส่วนการทำงาน** | **กฎที่ใช้ใน Solution** |
|--------------|---------------------|
| แหล่งข้อมูล  | ใช้รายการ Pop-up จากทุกจังหวัดที่ผ่านเงื่อนไขเดิม |
| ประเภทที่ไม่แสดง | ตัดประเภท “น่าอยู่” ก่อนจัดชุด |
| ภาษา         | ไทย จีน อังกฤษ โดยใช้ไทยเป็นภาษาสำรองเพียงภาษาเดียว |
| หน่วย Shuffle | Slot ต้นทางหนึ่งรายการเข้า Shuffle หนึ่งครั้ง |
| ภาพที่แสดง   | เลือก A หรือ B หนึ่งภาพจากชุดภาษาที่ได้ภายใน Slot |
| การเปิดแสดง  | ใช้เงื่อนไขหน้า เวลา ความถี่ และ Session ของ Pop-up เดิม |

## **2 ตารางเปรียบเทียบ Logic เดิมกับ Logic ใหม่**

ฐานเปรียบเทียบคือ Pop-up Center ใน NaYoo Center (25).pdf ซึ่งยกเลิก Rotate และ Impression-based ranking แล้ว การปรับครั้งนี้เพิ่มภาษาและทำวิธีเลือกภาพให้ชัดเจน

| **ประเด็น** | **Solution ฉบับนี้** |
|---------|------------------|
| แหล่งข้อมูล | คงเดิม           |
| Phase และ Ranking | คงเดิม ไม่ใช้ Impression จัดลำดับ Slot |
| หน่วย Shuffle | Shuffle Slot ก่อน แล้วเลือกหนึ่งภาพภายใน Slot |
| ภาษา    | ตรวจแยก Slot ตามภาษาของ User แล้วใช้ไทยสำรอง |
| A/B     | A/B แยกตามภาษา แต่เมื่อ Slot ได้รับเลือกแสดงหนึ่งภาพ |
| น้ำหนัก Slot | จำนวนภาษาและ A/B ไม่เพิ่มน้ำหนัก Slot |
| **เวลาและ Session** | **ใช้กฎเปิดเดิมภายในแท็บเดียวกัน การ Refresh หรือเปลี่ยนภาษาไม่รีเซ็ตประวัติ/สิทธิ์ของแท็บนั้น ส่วนการเปิด NaYoo Center ในแท็บใหม่ให้แยกประวัติและคิวจากแท็บเดิม** |
| **Refresh** | **ตรวจข้อมูลและจัดชุด Shuffle ใหม่ตามกฎ Refresh เดิม โดยไม่รีเซ็ตเวลา ความถี่ การปิด หรือ Session และไม่บังคับให้เปิดทันที** |
| **กดเปลี่ยนหน้าผลลัพธ์** | **คงคิว ลำดับ และภาพที่เลือกไว้ ไม่จัดชุดหรือ Shuffle ใหม่เพียงเพราะกดเลขหน้า หน้าถัดไป หน้าก่อนหน้า หรือย้อนกลับ ก่อนเปิดให้ตรวจหน้าปลายทาง เวลา ความถี่ และ Session เดิม** |
| User กดปิด | คงเดิม ตรวจเงื่อนไขการเปิดซ้ำก่อนทุกครั้ง |

## **3 ตารางสรุป Logic และกฎภาษา**

### **3.1 โครงสร้างกราฟิกภายใน Slot**

รองรับชุดกราฟิก **ไทย จีน อังกฤษ** เช่นเดียวกับ Top Banner แต่ละภาษาเก็บ A/B ได้สูงสุดสองภาพ โดยจำนวนภาพและเนื้อหาของแต่ละภาษาไม่จำเป็นต้องเท่ากัน

| **ภาษา** | **ภาพ A** | **ภาพ B** | **จำนวนสูงสุดต่อภาษา** |
|------|-------|-------|--------------------|
| ไทย  | TH-A  | TH-B  | 2                  |
| จีน  | ZH-A  | ZH-B  | 2                  |
| อังกฤษ | EN-A  | EN-B  | 2                  |
| รวมต่อ Slot |       |       | 6 กราฟิกตามชุดภาษา |

**ข้อกำหนดเรื่องอุปกรณ์:** Pop-up ใช้ไฟล์ภาพชุดเดียวกันทั้ง Desktop และ Mobile ระบบ**ไม่ต้องตรวจหรือแยกไฟล์ตามอุปกรณ์** และ**ไม่ตัด Slot ออกเพราะขาดไฟล์ของอุปกรณ์ใด** การตัด Slot พิจารณาจากภาษาเท่านั้น (ภาษาที่ User เลือก → ภาษาไทย → ตัด Slot) ข้อความ ตัวอย่าง และ AC ที่กล่าวถึง Desktop/Mobile ในเอกสารนี้เป็นเพียงตัวอย่างประกอบ ไม่ถือเป็น Requirement หากขัดกับข้อกำหนดนี้ ให้ยึดข้อกำหนดนี้เป็นหลัก

### **3.2 การเลือกภาษาและไฟล์อุปกรณ์**

* ตรวจแต่ละ Slot โดยใช้ภาษาปัจจุบันของ User บนเว็บไซต์และอุปกรณ์ที่กำลังใช้งาน
* ถ้ามีภาพตรงภาษาที่ใช้ได้บนอุปกรณ์นั้นอย่างน้อยหนึ่งภาพ ให้เลือกชุดภาษานั้น
* ถ้าไม่มีภาพตรงภาษาที่ใช้ได้ แต่มีภาพไทยที่ใช้ได้บนอุปกรณ์เดียวกัน ให้เลือกชุดไทยของ Slot เดียวกัน แม้ Slot จะมีภาษาอื่นร่วมอยู่ด้วย
* ถ้าไม่มีทั้งภาพตรงภาษาและภาพไทยที่ใช้ได้ ให้ตัด Slot ก่อน Shuffle และก่อนนับจำนวนรายการที่เลือกได้
* หลังเลือกภาษาแล้ว ให้เก็บ A/B ของภาษานั้นเป็นทางเลือกภายใน Slot ไม่ผสมภาษาเพื่อเติมภาพ และไม่ใช้ไฟล์ข้าม Desktop กับ Mobile

| **ภาษาที่มีภาพใช้ได้ใน Slot** | **User เลือกไทย** | **User เลือกจีน** | **User เลือกอังกฤษ** |
|---------------------------|---------------|---------------|------------------|
| ไทย จีน อังกฤษ            | ไทย           | จีน           | อังกฤษ           |
| ไทย อังกฤษ                | ไทย           | ไทยสำรอง      | อังกฤษ           |
| ไทย จีน                   | ไทย           | จีน           | ไทยสำรอง         |
| จีน อังกฤษ                | ตัด Slot      | จีน           | อังกฤษ           |
| ไทยอย่างเดียว             | ไทย           | ไทยสำรอง      | ไทยสำรอง         |
| จีนอย่างเดียว             | ตัด Slot      | จีน           | ตัด Slot         |
| อังกฤษอย่างเดียว          | ตัด Slot      | ตัด Slot      | อังกฤษ           |
| ไม่มีภาพที่ใช้ได้         | ตัด Slot      | ตัด Slot      | ตัด Slot         |

**ตัวอย่าง:** User เลือกจีน แต่ Slot มีไทยและอังกฤษ ให้ใช้ไทยของ Slot นั้น ไม่ใช้ภาพอังกฤษแทนจีน หากจีนมีเพียงหนึ่งภาพและไทยมีสองภาพ ให้ใช้จีนหนึ่งภาพโดยไม่เติมไทย

**ตัวอย่างตามอุปกรณ์:** User ใช้ Mobile ภาษาอังกฤษ แต่ Slot มีอังกฤษเฉพาะ Desktop และมีไทย Mobile ให้ใช้ไทย Mobile หากไม่มีไทย Mobile ด้วยให้ตัด Slot บน Mobile

### **3.3 การ Shuffle และเลือกภาพ**

* รวม Slot ต้นทางที่ผ่านเงื่อนไขจากทุกจังหวัดเป็นชุดเดียว โดย Slot เดียวกันต้องเข้าชุดเพียงหนึ่งครั้ง ใช้รหัสที่แยกรายการข้ามจังหวัดได้
* Shuffle ชุด Slot ทั้งหมดก่อนเลือกจำนวนรายการที่ Pop-up อนุญาต ไม่แยกเป็นคิวจังหวัด และไม่แยกภาพ A/B เป็นหลาย Slot
* เลือก Slot ตามเพดาน Pop-up เดิม จากนั้นจึงเลือก A หรือ B หนึ่งภาพจากชุดภาษาที่กำหนดไว้ภายในแต่ละ Slot ที่ได้รับเลือก ถ้ามีภาพเดียวให้ใช้ภาพนั้น
* ภาพ A/B ที่ไม่ถูกเลือกยังเป็นทางเลือกภายใน Slot ไม่กลายเป็น Pop-up อีกหนึ่งรายการ และไม่ใช้เติมจำนวนรายการที่ขาด
* จำนวนภาพ ภาษา และการใช้ไทยสำรองไม่เพิ่มน้ำหนักของ Slot ในการ Shuffle ไม่ใช้ Impression เลือก Slot และไม่ผูกการเลือกภาพกับ Phase 1 หรือ Phase 2 ที่ยกเลิกแล้ว
* ระหว่างที่ Pop-up รายการหนึ่งเปิดอยู่ ให้คงภาพที่เลือกไว้ ไม่สลับ A/B อัตโนมัติและไม่เพิ่ม Auto Slide
* เวลาของ center pop up set ไว้ที่ 0 วินาที

กำหนด **S = จำนวน Slot ที่ผ่านเงื่อนไข** และ **K = จำนวนรายการที่เข้ากฎ Pop-up เดิมอนุญาตให้เลือกในรอบจัดชุดนั้น** จำนวน Slot ที่เลือกคือ **min(S, K)** การเลือก K รายการไม่ใช่การอนุญาตให้เปิดทั้งหมดพร้อมกันหรือเปิดต่อเนื่องทันที เงื่อนไขการเปิดแต่ละครั้งยังใช้ตาม Pop-up เดิม

* ระบบเลือกจาก Slot ที่ผ่านเงื่อนไขแล้ว ตามจำนวนที่กฎ Pop-up เดิมอนุญาตในรอบนั้น หากมี Slot ผ่านเงื่อนไขน้อยกว่า ให้เลือกเท่าที่มีจริง

**ตัวอย่าง:** กฎเดิมกำหนดให้เลือกได้ 3 รายการต่อรอบ

* มี Slot ผ่านเงื่อนไข 5 Slot → เลือก 3 Slot
* มี Slot ผ่านเงื่อนไข 2 Slot → เลือกทั้ง 2 Slot

### **3.4 ตาราง Logic ฉบับปรับปรุง**

PPC-01–PPC-11 คงรหัสหัวข้อเดิม โดย PPC-08 เพิ่มโครงสร้างสามภาษา และ PPC-09 ยืนยันการสุ่มสองขั้น ส่วน **PPC-12–PPC-25** เพิ่มกฎภาษา อุปกรณ์ ผลต่อการแสดง และขอบเขตประวัติแยกแท็บ

| **รหัส** | **หัวข้อ** | **Logic การทำงาน** |
|------|--------|----------------|
| PPC-01 | ขอบเขต Product | ใช้กับ Pop-up โฆษณาบนหน้า Center ตามหน้าที่ได้รับอนุญาตเดิม |
| PPC-02 | แหล่งข้อมูล | ดึง Pop-up ที่ผ่านเงื่อนไขเดิมจากทุกจังหวัด รองรับ N จังหวัด |
| PPC-03 | ประเภทที่ไม่แสดง | ตัดประเภท “น่าอยู่” ก่อนจัดชุด Center |
| PPC-04 | วิธีจัดลำดับ | Shuffle Slot ต้นทางที่ผ่านเงื่อนไข |
| PPC-05 | จำนวนที่เลือก | สุ่มลำดับ Slot ที่ผ่านเงื่อนไขทั้งหมด แล้วเลือกตามจำนวนที่กฎ Pop-up เดิมอนุญาต หากมีไม่ครบ ให้เลือกเท่าที่มีจริง |
| PPC-06 | Phase เดิม | ไม่ใช้ Phase 1 Rotate หรือ Phase 2 Impression-based ranking |
| PPC-07 | Impression | ยอด Impression ไม่เพิ่มน้ำหนักและไม่กำหนดว่า Slot ใดแสดงก่อน |
| PPC-08 | โครงสร้างกราฟิก | แยกไทย จีน อังกฤษ แต่ละภาษามี A/B สูงสุดสองภาพ รวมสูงสุดหกกราฟิกตามชุดภาษา |
| PPC-09 | หน่วย Shuffle | ขั้นแรก Shuffle Slot จากนั้นเลือก A/B หนึ่งภาพภายใน Slot ที่ได้รับเลือก |
| PPC-10 | ไม่มีรายการ | ไม่เปิด Pop-up โฆษณาหากไม่มี Slot เหลือหลังคัดเงื่อนไข |
| PPC-11 | เวลาและความถี่ | การ Shuffle ไม่ข้ามหรือรีเซ็ตกฎหน้า เวลา ความถี่ และ Session |
| PPC-12 | ภาษาที่ใช้ | ใช้ภาษาปัจจุบันของ User ตรวจแยกแต่ละ Slot |
| PPC-13 | ภาษาสำรอง | เมื่อไม่มีภาพตรงภาษาที่ใช้ได้ ให้ใช้ไทยใน Slot และอุปกรณ์เดียวกันเท่านั้น |
| PPC-14 | ไม่มีภาษาที่อนุญาต | ถ้าไม่มีทั้งภาษาของ User และไทยที่ใช้ได้ ให้ตัด Slot ก่อน Shuffle |
| PPC-15 | ไม่ผสมภาษา | ใช้ A/B จากภาษาเดียวที่เลือกได้ ไม่เติมภาพต่างภาษา |
| PPC-16 | อุปกรณ์ | ใช้ไฟล์ของ Desktop หรือ Mobile ที่กำลังใช้งาน ไม่ข้ามอุปกรณ์ |
| PPC-17 | หนึ่งภาพต่อ Slot | Slot ที่ได้รับเลือกแสดงหนึ่งภาพ ภาพอีกใบไม่เพิ่มรายการ Pop-up |
| PPC-18 | น้ำหนัก Slot | จำนวนภาษาและภาพ A/B ไม่เพิ่มน้ำหนักในการ Shuffle |
| PPC-19 | คงภาพขณะเปิด | Pop-up ที่เปิดอยู่ใช้ภาพเดิม ไม่เลือก A/B ใหม่หรือสลับภาพอัตโนมัติ |
| **PPC-20** | **Refresh และเปลี่ยนหน้า** | **Refresh ให้จัดชุดและ Shuffle ใหม่ตามกฎเดิม; การกดเปลี่ยนหน้าผลลัพธ์คงคิว ลำดับ และภาพเดิม ไม่ Shuffle ใหม่ ทั้งสองเหตุการณ์ยังต้องตรวจหน้า เวลา ความถี่ การปิด และ Session ก่อนเปิด ไม่รีเซ็ตสิทธิ์** |
| PPC-21 | หลัง User ปิด | ไม่เปิดรายการถัดไปทันทีจากผล Shuffle ต้องผ่านกฎเปิดซ้ำเดิม |
| PPC-22 | ภาษาเว็บไซต์ | ภาพไทยสำรองไม่เปลี่ยนภาษาเว็บไซต์และไม่แปลข้อความในภาพ |
| **PPC-23** | **เปลี่ยนภาษาในแท็บเดิม** | **ประเมินรายการตามภาษาล่าสุดและ Shuffle คิวใหม่ เลือกภาพตามภาษาหรือไทยสำรอง โดยไม่ล้างประวัติและไม่เพิ่มสิทธิ์เปิดซ้ำของแท็บนั้น ผลสุ่มอาจเหมือนเดิม** |
| **PPC-24** | **เปิดแท็บใหม่** | **เปิดหน้า NaYoo Center ที่อนุญาตในแท็บใหม่ ให้ตรวจเงื่อนไขและจัดคิวใหม่ของแท็บนั้น ประวัติการเปิดแยกจากแท็บเดิม จึงอาจแสดง Slot ที่เคยเปิดในอีกแท็บได้เมื่อผ่านกฎ ไม่ยกเว้นหน้า เวลา หรือความถี่** |
| **PPC-25** | **ขอบเขตประวัติและสถิติ** | **ประวัติและคิวของแต่ละแท็บเป็นอิสระ แต่การเปิดแท็บใหม่หรือเปลี่ยนภาษาไม่ลบสถิติ Performance หรือรีเซ็ตข้อมูลคำนวณ A/B ของ Product/Slot และไม่สร้าง Impression จากการเตรียมคิวล้วน** |

## **4 ลำดับการทำงาน**

* User เข้าหน้า Center ที่อนุญาตให้แสดง Pop-up
* ตรวจเงื่อนไขการเปิด เวลา ความถี่ และ Session ตาม Pop-up เดิม หากยังไม่ผ่านให้ไม่เปิด
* ดึงรายการ Pop-up ที่ผ่านเงื่อนไขเดิมจากทุกจังหวัด แล้วตัดประเภท “น่าอยู่”
* ตรวจภาษาและไฟล์อุปกรณ์แยกแต่ละ Slot ตามลำดับภาษาของ User แล้วไทย
* ตัด Slot ที่ไม่มีภาพใช้ได้ หากไม่เหลือรายการให้ไม่เปิด Pop-up โฆษณา
* Shuffle Slot ทั้งชุด แล้วเลือก Slot ตามจำนวนที่ Pop-up เดิมอนุญาต
* เลือก A หรือ B หนึ่งภาพในภาษาที่กำหนดให้แต่ละ Slot ที่ได้รับเลือก
* เปิดรายการตามจังหวะและเงื่อนไขของ Pop-up เดิม การมีรายการถัดไปในชุดไม่ทำให้เปิดต่อทันที

**Flow:** ตรวจสิทธิ์เปิด → ดึง Pop-up ทุกจังหวัด → ตัด “น่าอยู่” → เลือกภาษาและอุปกรณ์ราย Slot → ตัด Slot ที่ไม่มีภาพ → Shuffle Slot → เลือกตามเพดาน Pop-up → เลือกหนึ่งภาพต่อ Slot → เปิดเมื่อกฎ Pop-up อนุญาต

## **5 ตัวอย่างการจัดชุด Pop-up**

### **5.1 ตัวอย่าง Shuffle สองขั้น**

สมมติเลือกภาษาและอุปกรณ์เรียบร้อยแล้ว Slot A มี A1/A2, Slot B มี B1/B2 และ Slot C มี C1 ทั้งหมดเข้าเงื่อนไข

| **Slot ต้นทาง** | **ภาพทางเลือก** | **จำนวนรายการที่เข้า Shuffle** |
|-------------|-------------|----------------------------|
| A           | A1, A2      | 1                          |
| B           | B1, B2      | 1                          |
| C           | C1          | 1                          |

Shuffle Slot ได้ **B → A → C** แล้วเลือกภาพภายใน Slot ได้ **B2 → A1 → C1** ผลคือ **สาม Slot และสามภาพที่เลือกไว้** จากภาพทางเลือกทั้งหมดห้าภาพ

### **5.2 ตัวอย่างภาษาและอุปกรณ์**

สมมติ User เลือก **ภาษาอังกฤษบน Mobile** และภาพในตารางมีไฟล์ Mobile ยกเว้นที่ระบุไว้

| **จังหวัด** | **Slot** | **ข้อมูลภาพ** | **ชุดภาพที่เลือกได้** | **เข้า Shuffle** |
|---------|------|-----------|-------------------|--------------|
| A       | 01   | TH-A, TH-B, EN-A, EN-B | EN-A, EN-B        | 1            |
| B       | 02   | TH-A, TH-B, ZH-A | TH-A, TH-B        | 1            |
| C       | 03   | ZH-A, ZH-B | ไม่มีอังกฤษหรือไทย | 0            |
| D       | 04   | EN-A      | EN-A              | 1            |
| E       | 05 ประเภท “น่าอยู่” | EN-A      | ตัดตามประเภท      | 0            |
| F       | 06   | อังกฤษมีเฉพาะ Desktop; มี TH-A Mobile | TH-A Mobile       | 1            |

ถ้า User เลือกจีนในการประเมินครั้งถัดไป Slot 02 ต้องใช้ ZH-A เพราะมีภาพตรงภาษา ส่วน Slot 03 มีสิทธิ์เข้าชุดแล้ว ระบบจึงต้องประเมินทุก Source Slot ใหม่ ไม่ใช้เฉพาะสี่ Slot ที่ผ่านตอนภาษาอังกฤษ

## **6 ตารางเงื่อนไขและเหตุการณ์สำคัญ**

| **กรณี** | **ผลที่ต้องได้** |
|------|--------------|
| ไม่มี Pop-up ที่เข้าเงื่อนไข | ไม่เปิด Pop-up โฆษณา |
| มีแต่ประเภท “น่าอยู่” | ตัดทั้งหมดและไม่เปิด Pop-up โฆษณา |
| มี Pop-up แต่ยังไม่ผ่านเวลา หรือ Session ไม่อนุญาต | ไม่เปิด แม้มี Slot และภาพที่เลือกได้ |
| มีภาพตรงภาษาและภาพไทย | ใช้ภาพตรงภาษาเท่านั้น |
| ไม่มีภาพตรงภาษา แต่มีไทยและอีกภาษา | ใช้ไทยของ Slot เดียวกัน ไม่ใช้อีกภาษาเป็นสำรอง |
| มีเพียงอีกภาษาและไม่มีไทย | ตัด Slot ก่อน Shuffle |
| ชุดภาษาที่เลือกมีภาพเดียว | ใช้ภาพนั้น ไม่เติมอีกภาษาและไม่ทำซ้ำ |
| Slot มี A/B สองภาพ | เข้า Shuffle หนึ่งรายการ หากได้รับเลือกแสดงหนึ่งภาพ |
| หลายจังหวัดมี Pop-up | รวม Slot ที่ผ่านเงื่อนไขแล้ว Shuffle ไม่แยกคิวจังหวัด |
| มี Slot ผ่านเงื่อนไขมากกว่าจำนวนที่เลือกได้ | สุ่มลำดับ Slot ทั้งหมด แล้วเลือกตามจำนวนที่กฎ Pop-up เดิมอนุญาต |
| มี Slot ผ่านเงื่อนไขน้อยกว่าจำนวนที่เลือกได้ | เลือกเท่าที่มีจริง ไม่ทำ Slot ซ้ำหรือใช้ภาพอีกใบของ Slot เดิมมาเติมให้ครบ |
| **Refresh** | **Shuffle ใหม่ตามกฎ Refresh เดิม ผลอาจซ้ำเดิม แต่ไม่รีเซ็ตเวลา ความถี่ หรือสิทธิ์ Session** |
| **เปลี่ยนหน้า 1 → 2 → 3 แล้วย้อนกลับ** | **คงคิว ลำดับ และภาพเดิม ไม่ Shuffle หรือสุ่ม A/B ใหม่ ไม่เริ่มคิวจากต้นเพียงเพราะย้อนกลับ พิจารณารายการถัดไปในคิวที่ยังมีสิทธิ์ได้เฉพาะเมื่อผ่านกฎเปิดเดิม** |
| User กดปิด | ไม่เปิดรายการถัดไปทันทีจากผล Shuffle |
| ภาพไทยใช้เป็นสำรอง | ภาษาเว็บไซต์และข้อความส่วนอื่นยังเป็นภาษาที่ User เลือก |
| **ประเมินภาษาใหม่** | **เมื่อเปลี่ยนภาษา ให้ตรวจรายการและภาพตามภาษาล่าสุดหรือไทยสำรอง แล้ว Shuffle คิวใหม่ โดยคงประวัติ เวลา ความถี่ การปิด และสิทธิ์ของแท็บเดิม ไม่คืนสิทธิ์ให้ Slot ที่เคยเปิดแล้วในขอบเขตกันซ้ำเดิม** |
| **เปิด NaYoo Center ในแท็บใหม่** | **แท็บใหม่เริ่มตรวจเงื่อนไขและจัดคิวของตัวเอง แยกประวัติจากแท็บเดิม จึงอาจเห็น Slot เดิมได้เมื่อผ่านกฎเปิดของแท็บใหม่ การเปิดแท็บใหม่ไม่ล้างหรือเปลี่ยนคิวและประวัติในแท็บเดิม** |

## **7 Requirement สำหรับคัดลอกใส่เอกสาร**

ระบบต้องดึงรายการ Product Pop-up ที่ผ่านเงื่อนไขเดิมจากทุกจังหวัด รองรับจำนวนจังหวัด N และไม่นำประเภท “น่าอยู่” เข้าชุดแสดงผล Center โดยคงการยกเลิก Phase 1 Rotate และ Phase 2 Impression-based ranking ตามกฎเดิม

สำหรับแต่ละ Slot ต้นทาง ให้ตรวจกราฟิกที่มีไฟล์ใช้ได้บนอุปกรณ์ปัจจุบันตามภาษาที่ User เลือกก่อน หากไม่มีให้ใช้ภาษาไทยของ Slot เดียวกัน หากไม่มีทั้งภาษาที่เลือกและไทยให้ตัด Slot ก่อน Shuffle ห้ามใช้จีนแทนอังกฤษหรืออังกฤษแทนจีน ห้ามผสมภาพต่างภาษาเพื่อเติม A/B และห้ามใช้ไฟล์ข้าม Desktop กับ Mobile

ให้ Shuffle ที่ระดับ Slot ต้นทาง โดย Slot หนึ่งเข้าชุดเพียงหนึ่งครั้ง หลังเลือกตามจำนวนที่ Pop-up เดิมอนุญาตจึงเลือก A หรือ B หนึ่งภาพจากชุดภาษาที่ได้ภายในแต่ละ Slot ที่ได้รับเลือก ภาพอีกใบไม่กลายเป็นรายการเพิ่ม ไม่ใช้เติมจำนวนที่ขาด และไม่สลับแทนภาพที่เปิดอยู่ จำนวนภาษาและ A/B ไม่เพิ่มน้ำหนัก Slot และการเลือกภาพไม่ผูกกับ Phase เดิม

**Refresh ให้ตรวจข้อมูลและจัดชุด Shuffle ใหม่ตามกฎ Pop-up เดิม ผลอาจซ้ำรายการหรือภาพเดิมได้ แต่ไม่รีเซ็ตเวลา ความถี่ หรือสิทธิ์ Session และไม่อนุญาตให้เปิดซ้ำทันที**

**เมื่อเปลี่ยนภาษาภายในแท็บเดิม ให้ตรวจรายการและภาพตามภาษาล่าสุดหรือไทยสำรอง แล้ว Shuffle คิวใหม่ โดยไม่ล้างประวัติ เวลา ความถี่ การปิด หรือสิทธิ์เปิดของแท็บนั้น ไม่คืนสิทธิ์ให้ Slot ที่เคยเปิดแล้วในขอบเขตกันซ้ำเดิม และไม่บังคับเปิด Pop-up ทันทีจากการเปลี่ยนภาษา**

**เมื่อเปิดหน้า NaYoo Center ที่อนุญาตให้แสดง Pop-up ในแท็บใหม่ ให้เริ่มตรวจเงื่อนไขและจัดคิวของแท็บใหม่เอง โดยแยกประวัติจากแท็บเดิม จึงอาจเห็น Slot เดิมที่เคยเปิดในอีกแท็บได้เมื่อผ่านกฎเปิดของแท็บใหม่ ไม่ล้างหรือเขียนทับประวัติ/คิวของแท็บเดิม และไม่รีเซ็ตสถิติ Performance หรือข้อมูลคำนวณ A/B เพียงเพราะเปิดแท็บใหม่ การสลับกลับไปแท็บเดิมให้ใช้ประวัติของแท็บนั้นต่อ**

**การกดเลขหน้า หน้าถัดไป หน้าก่อนหน้า หรือกลับหน้าที่เคยเปิด ไม่เป็นเหตุให้จัดชุดหรือ Shuffle ใหม่ ให้ใช้คิว ลำดับ และภาพที่เลือกไว้เดิม ไม่เริ่มคิวจากต้น ไม่สุ่ม A/B ใหม่ และไม่คืนสิทธิ์ให้รายการที่เคยเปิดแล้วเพียงเพราะเปลี่ยนหน้า ก่อนเปิดรายการถัดไปที่ยังมีสิทธิ์ ต้องตรวจหน้าปลายทาง เวลา ความถี่ การปิด และ Session ตามกฎเดิม หากไม่ผ่านให้ไม่เปิด การเปลี่ยนหน้าไม่ถือเป็น Refresh**

**หลัง User ปิดต้องตรวจเงื่อนไขการเปิดซ้ำเดิม ไม่เปิดรายการถัดไปทันที และหากไม่มีรายการที่เข้าเงื่อนไขให้ไม่เปิด Pop-up โฆษณา**

Pop-up ต้องใช้หน้าที่อนุญาต จำนวนที่เปิดได้ ขนาดภาพ หน้าต่าง ปุ่มปิด ลิงก์ และพฤติกรรมหลังปิดตามข้อกำหนด Pop-up เดิม การใช้ภาษาไทยสำรองไม่เปลี่ยนภาษาเว็บไซต์หรือแปลข้อความในภาพ

## **8 Acceptance Criteria**

กรณีทดสอบต่อไปนี้สมมติว่า Slot ผ่านเงื่อนไขโฆษณาเดิมแล้ว ยกเว้นกรณีที่ระบุให้ทดสอบเวลา Session หรือประเภท

| **รหัส** | **เงื่อนไข** | **ผลที่ต้องได้** |
|------|----------|--------------|
| AC-PPC01 | User เลือกอังกฤษ Slot มีอังกฤษและไทยที่ใช้ได้ | เลือกชุดอังกฤษเท่านั้น |
| AC-PPC02 | User เลือกอังกฤษ Slot มีไทยกับจีนแต่ไม่มีอังกฤษ | เลือกไทยของ Slot เดียวกัน |
| AC-PPC03 | User เลือกจีน Slot มีไทยกับอังกฤษแต่ไม่มีจีน | เลือกไทย ไม่ใช้ภาพอังกฤษ |
| AC-PPC04 | User เลือกไทย Slot มีจีนและอังกฤษแต่ไม่มีไทย | ตัด Slot ก่อน Shuffle |
| AC-PPC05 | ไม่มีทั้งภาษาของ User และไทยที่ใช้ได้ | ตัด Slot ไม่กินจำนวนที่เลือก |
| AC-PPC06 | ภาษาของ User มีหนึ่งภาพ ไทยมีสองภาพ | ใช้ภาพตรงภาษาหนึ่งภาพ ไม่เติมไทย |
| AC-PPC07 | Slot มีเพียงภาพ B ในภาษาที่เลือก | ใช้ B หาก Slot ได้รับเลือก ไม่สร้าง A |
| AC-PPC08 | Slot มี A/B สองภาพ | เข้า Shuffle หนึ่งรายการ และแสดงหนึ่งภาพเมื่อได้รับเลือก |
| AC-PPC09 | สาม Slot มีภาพทางเลือกรวมกันห้าภาพ | สุ่มลำดับ 3 Slot ก่อน แล้วเลือกตามจำนวนที่กฎ Pop-up เดิมอนุญาต จากนั้นสุ่มภาพจาก Slot ที่เลือก Slot ละ 1 ภาพ โดยไม่นับภาพทั้ง 5 เป็น Pop-up 5 รายการ |
| AC-PPC10 | Slot หนึ่งมีสองภาพ อีก Slot มีภาพเดียว | ทั้งสองเข้า Shuffle อย่างละหนึ่งรายการ จำนวนภาพไม่เพิ่มน้ำหนัก |
| AC-PPC11 | Slot ใช้ไทยสำรอง | ร่วม Shuffle กับ Slot ที่มีภาพตรงภาษา ไม่มีลำดับรอง |
| AC-PPC12 | อังกฤษมีเฉพาะ Desktop แต่ User ใช้ Mobile และมีไทย Mobile | ใช้ไทย Mobile ไม่ใช้ไฟล์ Desktop |
| AC-PPC13 | User ใช้ Mobile แต่ไม่มีภาพที่อนุญาตบน Mobile | ตัด Slot บน Mobile |

## **เพิ่มเติม: เปลี่ยนหน้าผลลัพธ์ไม่ Shuffle Pop-up ใหม่**

**ใช้กับการกดเลขหน้า หน้าถัดไป หน้าก่อนหน้า หรือกลับหน้าที่เคยเปิด เช่น หน้า 1 → 2 → 3 → 2 → 1 ภายในบริบทและขอบเขตสิทธิ์เดิม ให้คงคิว ลำดับ และภาพที่เลือกไว้ ไม่จัดชุดหรือ Shuffle ใหม่จากการเปลี่ยนหน้า ไม่สุ่ม A/B ใหม่ และไม่เริ่มคิวจากต้นเมื่อย้อนกลับ**

**ก่อนเปิด Pop-up ต้องตรวจสิทธิ์และหน้าปลายทาง เวลา ความถี่ การปิด และ Session เดิมเสมอ รายการที่ไม่ผ่านเงื่อนไขไม่เปิด การเปลี่ยนหน้าไม่ล้างประวัติ ไม่คืนสิทธิ์ให้รายการที่เคยเปิดแล้ว ไม่เปิดหน้าต่างซ้อน และไม่บังคับเปิดทันที**

**คำตัดสินนี้ยกเลิกเฉพาะกฎ Shuffle เมื่อเปลี่ยนหน้าผลลัพธ์ที่เพิ่มไว้ก่อนหน้า กฎ Refresh การเปลี่ยนภาษา และเงื่อนไขอื่นยังใช้ตามเดิม ไม่ถือว่าการกดเปลี่ยนหน้าเป็น Refresh**

### **ตัวอย่างการทำงาน**

**สมมติคิวเดิม A → B → C และแต่ละรายการมีภาพที่เลือกไว้แล้ว การเปิดในตัวอย่างจะเกิดได้เมื่อผ่านกฎเดิมเท่านั้น**

| **การกระทำ** | **ผลการทำงาน** |
|----------|------------|
| **หน้า 1 เปิด A แล้วผู้ใช้ปิด** | **คง B → C เป็นรายการรอ ไม่เปิด B ต่อทันที** |
| **ไปหน้า 2 และกฎเปิดอนุญาต** | **พิจารณา B ตามคิวเดิม ใช้ภาพเดิม ไม่ Shuffle ใหม่** |
| **ไปหน้า 3 แต่หน้าหรือเวลาไม่อนุญาต** | **ไม่เปิด C ไม่ถือว่าถูกเห็นจากการเปลี่ยนหน้าเพียงอย่างเดียว** |
| **กลับหน้า 2 แล้วหน้า 1** | **ยังพิจารณา C ที่รออยู่เมื่อกฎเปิดครบ ไม่เริ่ม A ใหม่ และไม่สุ่มคิวใหม่** |
| **Refresh** | **จัดชุดใหม่ตามกฎ Refresh เดิม โดยยังคงประวัติและสิทธิ์ตาม Session เดิม** |
