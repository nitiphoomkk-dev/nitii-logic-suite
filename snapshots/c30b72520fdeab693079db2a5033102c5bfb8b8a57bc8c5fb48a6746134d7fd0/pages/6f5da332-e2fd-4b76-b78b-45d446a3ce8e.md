ใช้กับการ์ดตัวเลขบนหน้า Home รวมจังหวัด (Home Center) ใน section **โครงการใหม่** (รวม / บ้าน / ทาวน์โฮม / คอนโด) และ **แบบบ้าน** (9 สไตล์) เป็น public ไม่ต้องใช้ token ใช้แค่ apikey ตามปกติ **ไม่ต้องส่ง header** `**province**` เพราะนับรวมทุกจังหวัดเสมอ

```cs
GET /api/listing/home-page/thailand/count-post-by-category
```

## ตัวอย่าง response

```json
{
  "success": true,
  "message": "get thailand posts by category successfully",
  "data": {
    "province_id": 0,
    "post_new": {
      "total": 3587,
      "by_property_type": { "house": 2604, "condo": 290, "townhouse": 585 }
    },
    "home_builder": {
      "total": 3185,
      "by_post_style": {
        "modern": 1450, "nordic": 420, "minimal": 610, "loft": 160, "luxury": 95,
        "englishcottage": 70, "tropical": 140, "contemporary": 180, "classic": 60
      }
    }
  }
}
```

> ตัวเลขข้างบนเป็นตัวอย่าง ไม่ใช่ข้อมูลจริง

## Field

| Field | ความหมาย | การ์ด → หน้าที่กดไป |
|-------|----------|---------------------|
| `post_new.total` | โครงการใหม่ทั้งหมด (ออนไลน์ + ปิดขาย + เปิดใหม่เฟสใหม่) | `/property-project/properties/thailand` |
| `post_new.by_property_type.house` | บ้าน     | `/property-project/houses/thailand` |
| `post_new.by_property_type.townhouse` | ทาวน์โฮม | `/property-project/townhomes/thailand` |
| `post_new.by_property_type.condo` | คอนโด    | `/property-project/condos/thailand` |
| `home_builder.total` | แบบบ้านทั้งหมด (ออนไลน์เท่านั้น) | หน้าค้นหาแบบบ้าน center |
| `home_builder.by_post_style.<slug>` | แบบบ้านแยกสไตล์ (key ไม่มี `_` เช่น `englishcottage`) | หน้าค้นหาแบบบ้าน center + filter สไตล์ |

* ตัวเลขแต่ละช่องตั้งใจให้ **เท่ากับจำนวนที่หน้าปลายทางแสดง** (ไม่ได้ติ๊ก filter อื่นเพิ่ม)
* `house + townhouse + condo` **ไม่จำเป็นต้องเท่ากับ** `total` และผลรวมของสไตล์ก็ไม่จำเป็นต้องเท่ากับ `home_builder.total` เพราะโครงการหนึ่งมีได้หลายประเภท และแบบบ้านหนึ่งมีได้หลายสไตล์
* `post_new` หรือ `home_builder` เป็น `null` ได้ เมื่อไม่มีใบประกาศเลย ให้แสดง 0
* ตัวเลขถูก cache ไว้ฝั่ง backend 30 นาที เลขอาจไม่เปลี่ยนทันทีหลังมีการลงหรือแก้ประกาศ
