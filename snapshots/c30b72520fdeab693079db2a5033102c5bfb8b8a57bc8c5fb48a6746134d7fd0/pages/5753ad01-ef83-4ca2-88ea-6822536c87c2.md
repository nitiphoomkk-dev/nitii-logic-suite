**Functional Requirements** 

**EP-01:การจะเป็นบริษัทนายหน้าในระดับแต่ละโล่นั้น ต้องสมัครสมาชิกของระบบน่าอยู่ก่อน**

โดนใช้ Logic การเป็นสมาชิกและเข้าสู่ระบบ Logic เว็บน่าอยู่ v.2 จะไม่เหมือนการสมัครสมาชิกของ โครงการมือ 1 และบริษัทรับสร้างบ้าน

**EP-02  การสมัครนายหน้า**

EP-02 .2: ต้องสมัครสมาชิกของน่าอยู่ก่อน ถึงจะสามารถสมัครสมาชิกนายหน้าของบ้านพร้อมบนเว็บน่าอยู่ได้

EP-02 .3:ใช้สามารถเลือกภาษาได้ 3 ภาษา: ไทย (TH) / อังกฤษ (EN) / จีน (ZH)

เมื่อเปลี่ยนภาษา  หน้าตา UI และข้อความแจ้งเตือน/Validation จะเปลี่ยนตามภาษาที่เลือกทัน

EP-02 .4: นายหน้าแบ่งออกเป็น 2 role คือ นายหน้าอิสระและนายหน้าบริษัท

โดยนายหน้าอิสระเกิดจาก เจ้าของทรัพย์มือสอง เจ้าของหอพัก ผู้ใช้ทั่วไป ที่มาสมัคร  โดยแบ่งออกเป็น 3 ระดับ คือ

1\.นายหน้าโล่เทา

2\.นายหน้าโล่เขียว

3\.นายหน้าโล่ฟ้า

และนายหน้าบริษัทจะเป็นนายหน้าแบบนิติบุคคลสามารถแบ่งได้เป็น 3 ระดับเช่นเกัน 

1\.นายหน้าโล่เทา

2\.นายหน้าโล่เขียว

3\.นายหน้าโล่ฟ้า

โดยการจะเป็นนายหน้าแต่ละระดับจะต้องมีการยืนยันตัวตนตามขั้นตอนของบ้านพร้อม 

**หน้าข้อมูลส่วนตัว**

EP-02 .5 ดึงข้อมูลมาแสดงจากหน้าแก้ไขข้อมูลโปรไฟล์จาก user โดยสามารถแก้ไขหน้าข้อมูลส่วนตัวได้ยกเว้น หากสมัครมาด้วย Email แล้วไม่สามารถแก้ไข Email ได้ แต่หากไม่ได้สมัครมาด้วย Email ระบบจะต้องเพิ่มข้อมูลตรงนี้ให้ครบ หากไม่ใส่ระบบจะไม่ทำการให้ไปหน้าถัดไปได้

**หน้าข้อมูลสมัครนายหน้า**

EP-02 .6: จังหวัดติดต่อประสานงาน เลือกได้เฉพาะ จังหวัดที่น่าอยู่เปิดให้บริการ 

         พื้นที่ให้บริการ เลือกได้ 77 จังหวัด เพิ่มพื้นที่ให้บริการได้ตามจังหวัดในประเทศไทย 

           เงื่อนไข ห้ามเลือกจังหวัดซ้ำ หากมีจังหวัดซ้ำให้ปรากฎ modal แจ้งเตือนว่าได้เลือกพื้นที่ให้บริการนี้ไปแล้ว  ให้ผู้ใช้เลือกพื้นที่อื่น

          ที่ตั้งสำนักงาน เลือกได้ 1 จังหวัด จาก 77 จังหวัด

**EP-02 .7: กรณี แผนที่ที่ใช้สำหรับ   ที่ตั้งสำนักงาน                                                                                                          กรณีใส่ Link Google Map**

ผู้ใช้สามารถกรอก ลิงก์ Google Map ของสำนักงานได้

เมื่อมีการใส่ลิงก์แล้ว → ช่องกรอก จังหวัด / อำเภอ / ตำบล / รหัสไปรษณีย์ และช่อง ละติจูด-ลองจิจูด จะถูก disable

หากต้องการแก้ไขพิกัดเอง → ต้อง ลบลิงก์ Google Map ก่อน จึงจะแก้ไขได้

#### **กรณีไม่ใส่ Link (เลือกเองจาก Dropdown)**

ผู้ใช้เลือก จังหวัด → อำเภอ → ตำบล จาก dropdown

ระบบจะแสดงผลแผนที่อ้างอิง จากพิกัดจังหวัดเท่านั้น (map zoom ไปที่จังหวัด)

ผู้ใช้ ไม่สามารถลากหมุดบนแผนที่ได้

แต่สามารถ แก้ไขพิกัดละติจูด-ลองจิจูด ได้เองโดยการกรอกตัวเลข

**EP-02 .8: ทุกช่องที่ผู้ใช้งานสมัครนายหน้าต้องพิมพ์กรอกข้อมูล ต้องให้มีระบบ Translation เพื่อ**

ระบบต้องสามารถแปลข้อความจาก ภาษาไทย (TH) / อังกฤษ (EN) / จีน (ZH) ไปยังภาษาอื่น ๆ ได้ครบทั้ง 3 ภาษา

จุดประสงค์คือเพื่อให้ข้อมูลประกาศที่กรอก มี เวอร์ชันแปลที่ถูกต้องมากขึ้น รองรับผู้ใช้งานหลายภาษา

EP-02 .11: สามารถเชื่อม social media ในหน้านี่ได้เพื่อให้การเข้าสู่ระบบครั้งหน้า สามารถใช้ช่องทางเหล่านี้เข้าสู่ระบบได้

**EP-03: ใช้ การยืนยันตัวตนสมัครนายหน้า**

EP-03.1: นายหน้าแบ่งออกเป็น 2 role คือ นายหน้าอิสระและนายหน้าบริษัท

โดยนายหน้าอิสระเกิดจาก เจ้าของทรัพย์มือสอง เจ้าของหอพัก ผู้ใช้ทั่วไป ที่มาสมัคร  โดยแบ่งออกเป็น 3 ระดับ คือ

1\.นายหน้าโล่เทา

2\.นายหน้าโล่เขียว

3\.นายหน้าโล่ฟ้า

และนายหน้าบริษัทจะเป็นนายหน้าแบบนิติบุคคลสามารถแบ่งได้เป็น 3 ระดับเช่นเกัน 

1\.นายหน้าโล่เทา

2\.นายหน้าโล่เขียว

3\.นายหน้าโล่ฟ้า

โดยการจะเป็นนายหน้าแต่ละระดับจะต้องมีการยืนยันตัวตนตามขั้นตอนของบ้านพร้อม 

EP-03.2 การยืนยันตัวของนายหน้าแต่ละโล่ ใช้การยืนยันแบบเดิม Logic เดิม ที่เกิดขึ้นทั้งบนหน้าเว็บ และ console ของเว็บน่าอยู่  ขั้นตอนการเป็นนายหน้าของนายหน้าอิสระ และนายหน้าบริษัทใช้ ข้อมูลเดียวกัน flow เดียวกัน การแสดงผลเดียวกัน 

EP-03.3: การแจ้งเตือนการยืนยันตัวตนที่หน้าเว็บ สำหรับนายหน้าโล่เทาประกอบไปด้วยหน้าดังต่อไปนี้

**EP-09:Section  จัดการสาขา**

EP-09.1 แสดง (รายการ & การค้นหา) ช่องการค้นหาสามารถ  ค้นหาชื่อสาขา และค้นหาโดยพิมพ์ชื่อจังหวัด

EP-09.2 มีช่อง “ค้นหาสาขา” (ค้นด้วยชื่อจังหวัด)

EP-09.3 มีปุ่มเพิ่มสาขา เมื่อกดแล้วแสดง modal ช่องทางการติดต่อสื่อสารกับแอดมินน่าอยุ่ให้สามารถเปิดสาขาจาก console น่าอยู่ได้  เมื่อแอดมินอนุมัติ จังหวัดนั้นจะถูกเพิ่มให้บริษัทและกลายเป็นสิทธิ์ที่ใช้งานบนระบบได้ทันที (แจ้งเตือนผล)  (เปิดสาขา เท่ากับสิทธิ์ในการเปิดบัญชีจังหวัดนั้นที่น่าอยู่ให้บริการ)

EP-09.4 มีตารางแสดงคอลัม  ชื่อบริษัท จังหวัด ผู้ดูแลจังหวัด  แก้ไข   

 มีปุ่มไอคอน 3 จุดเมื่อกดไอคอน แสดงปุ่ม แก้ไข แสดง modal เพิ่มผู้แลในจังหวัดนั้นคือให้สิทธิ์แอดมินในการดูแลจังหวัดนั้น โดย แสดง icon “เพิ่ม” สำหรับจังหวัดที่ยังไม่ถูกดูแลโดยผู้ใช้นั้น

แสดง icon “ลบ” สำหรับจังหวัดที่ผู้ใช้รายนั้นถือสิทธิ์อยู่   และปุ่มลบสาขา   และมีปุ่มเพิ่มผู้ดูแลในตาราง คอลัมผู้ดูแลจังหวัด

**EP-10:Section  จัดการสาขา**

EP-10.1 แสดงตารางผู้ใช้: ชื่อผู้ใช้งาน, อีเมล, บทบาท (Super Admin/Admin), จังหวัดที่ดูแล, สถานะ(เปิด/ปิด), ใช้งานล่าสุด

EP-10.2 ค้นหาผู้ใช้ได้ด้วย ชื่อผู้ใช้งาน / อีเมล 

EP-10.3  คอลัมน์ “ใช้งานล่าสุดเมื่อ” ต้องเรียงได้ (ขึ้น/ลง)

**EP-11:  เพิ่มผู้ดูแล (Add Admin)**

EP-11.1  กดปุ่มเพิ่มผู้ดูแล แสดง modal เพิ่มข้อมูลผู้ใช้งานประกอบด้วย

● อีเมลผู้ใช้งาน\*

● ชื่อผู้ใช้งาน\*

● เบอร์โทรผู้ใช้งาน\*

● รหัสผ่าน\*

● ยืนยันรหัสผ่าน\*

และมี check box  ติ๊กเพิ่มสาขาที่ดูแล (เพิ่มสาขาผู้ดูแลต้องเลือกอย่างน้อย 1 จังหวัดในการ บันทึกข้อมูล)

ใน modal ต้องมีปุ่มบันทึกและยกเลิก

EP-11.2 ต้องเลือก “จังหวัดที่ดูแลอย่างน้อย 1 จังหวัด” ก่อนบันทึก (สำหรับผู้ดูแลสาขา)

EP-11.3 หากรหัสผ่านและยืนยันรหัสไม่ตรงกันห้ามบันทึก พร้อมแสดงข้อความเตือน

EP-11.4 การสร้างรหัสผ่าน  

**ต้องทำการยืนยันรหัสผ่าน 2 ชั้น**

สร้างรหัสผ่าน(6 ตัวอักษรขั้นต่ำ)\*

● สีแดง   ระดับความปลอดภัยต่ำ= 6 ตัวอักษร (ขั้นต่ำ)

● สีเหลือง    ระดับความปลอดภัยปานกลาง  =7- 8 ตัวอักษร

● สีเขียว    ระดับความปลอดภัยสูง = 9-10 ตัวอักษร (สูงสุด)

● ไม่จำกัดว่าจะกรอกภาษาไทยหรืออังกฤษหรือตัวเลข ขอแค่ตัวอักษรครบ

**EP-15 ข้อกำหนดการตรวจสอบข้อมูล (Validation)**

EP-15.1หากตรวจสอบไม่ผ่าน ให้ไฮไลต์ฟิลด์ที่ผิดและอธิบายเหตุผล

**EP-16 Console ต้องทำได้ทั้งหมดตามสิทธิ์ Super Admin โครงการมือ 1 บนเว็บ**

 โดยใช้กติกา/Validation/Modal/นโยบายเดียวกันทุกประการ  อบเขต: Console ต้องทำได้ เท่ากับ Super Admin โครงการมือ 1 บนเว็บ ตาม EP-02, EP-05–EP-11   ทำทุก action ได้เท่าฝั่งเว็บน่าอยู่

EP-16.1 บทบาท/สิทธิ์ ใน Console

เฉพาะ Super Admin (Nayoo) เท่านั้นที่เข้าถึงเมนู Console ชุดนี้ได้

EP-16.2 ทุกคำสั่งสำคัญมี ข้อความ/Validation/Modal เหมือนเว็บ

EP-16.3 จัดการสิทธิ์ผู้ดูแลระบบ สำหรับ Super Admin โครงการมือ 1 เพิ่มเลือกจังหวัดในการบริการให้
