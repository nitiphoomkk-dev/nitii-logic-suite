# Solution ฟิลเตอร์ที่ตั้ง — Center และจังหวัด


### สรุปกฎในฉบับนี้

* ค่าเริ่มต้นคือ **ทั้งหมด**: ไม่มีตัวเลือกใดถูกติ๊ก และไม่จำกัดผลด้วยที่ตั้ง
* จังหวัดเลือกได้ 1 จังหวัด; การเลือกพื้นที่ 3 Layer ใช้เฉพาะ **โซนยอดนิยม, ตำบล, โซนในสถานศึกษา**
* Layer 1 เลือกหมวดใหญ่ 1 หมวด; Layer 2 เลือกหัวข้อเดียวและเลือก Layer 3 ทุกข้อใต้หัวข้อนั้น; Layer 3 ปรับเลือกได้หลายข้อแต่ห้ามข้ามหัวข้อ Layer 2
* ตัวเลือกที่ตั้งกลุ่มอื่นและ **จัดเรียงตาม** เป็น Radio เลือกได้ครั้งละ 1 ค่าในกลุ่มนั้น
* กด **ล้างข้อมูล** ในฟิลเตอร์ที่ตั้งแล้วล้างจังหวัดและตัวเลือกที่ตั้งทุก Layer กลับเป็น **ทั้งหมด**; ฟิลเตอร์หมวดอื่นคงเดิม
* ค่าใน Full Filter มีผลต่อผลค้นหา ฟิลเตอร์ด้านนอก และ URL เมื่อกด **ค้นหา**
* รายการคำตอบด้านในและรหัสพื้นที่จริงรอ SEO ยืนยัน; ภาพ Prototype เป็นตัวอย่างการจัดวาง ไม่ใช่ทะเบียนคำตอบจริง

## 1 ขอบเขตและคำที่ใช้ใน Solution

| คำ  | ความหมาย |
|-----|----------|
| ทั้งหมด | ค่าเริ่มต้นที่ไม่ติ๊กตัวเลือกที่ตั้งใด ไม่ใช่การบันทึกว่าติ๊กทุกข้อ |
| จังหวัด | ขอบเขตหน้า Center หรือจังหวัด เลือกได้ครั้งละ 1 จังหวัด และอยู่ก่อนการเลือกพื้นที่ภายในจังหวัด |
| Layer 1 | หมวดใหญ่ของตัวเลือกพื้นที่ 3 Layer เลือกได้ 1 หมวด และแสดงสีฟ้าเมื่อเลือก |
| Layer 2 | หัวข้อย่อยภายใน Layer 1 เลือกได้ 1 หัวข้อ การกดหัวข้อเท่ากับเลือก Layer 3 ทุกข้อใต้หัวข้อนั้น |
| Layer 3 | รายการลูกของ Layer 2 เลือกได้ตั้งแต่ 1 ข้อขึ้นไปโดยไม่จำกัดจำนวนภายในหัวข้อเดียว |
| Radio | ตัวเลือกที่เลือกได้ครั้งละ 1 ค่าในกลุ่มนั้น ใช้กับตัวเลือกที่ตั้งอื่นและจัดเรียงตาม |
| ค่าที่กำลังแก้ | ค่าภายใน Full Filter ก่อนกดค้นหา ยังไม่เปลี่ยนชุดผลลัพธ์หรือ URL |
| ค่าที่ใช้ค้นหา | ค่าหลังกดค้นหา ซึ่งต้องตรงกันระหว่างผลลัพธ์ ฟิลเตอร์ด้านนอก Full Filter และ URL |

**ขอบเขตข้อมูลที่ยังรอ:** SEO ต้องยืนยันรายการคำตอบภายในแต่ละ Layer และการผูกกับรหัสพื้นที่จริง Solution นี้ไม่สร้างชื่อโซน ตำบล หรือ URL parameter เพิ่มจากภาพตัวอย่าง

## 2 ตารางสรุป Logic ฟิลเตอร์ที่ตั้ง

| รหัส | เรื่อง | การทำงานและผลแสดง |
|------|--------|-------------------|
| LOC C01 | ค่าเริ่มต้น | “ทั้งหมด” ไม่ติ๊กจังหวัดหรือพื้นที่ใด และไม่จำกัดผลด้วยที่ตั้ง |
| LOC C02 | เลือกจังหวัด | เลือกได้ครั้งละ 1 จังหวัด; แสดงตัวเลือกภายในจังหวัดนั้น |
| LOC C03 | เลือก Layer 1 | เลือกหมวดใหญ่ได้ 1 หมวด; หมวดที่เลือกเป็นสีฟ้า |
| LOC C04 | เลือก Layer 2 | เลือกหัวข้อได้ 1 หัวข้อใน Layer 1; การกดหัวข้อเลือก Layer 3 ทุกข้อใต้หัวข้อนั้น |
| LOC C05 | ปรับ Layer 3 | เลือกหลายข้อได้โดยไม่จำกัดจำนวน แต่ทุกข้ออยู่ภายใต้ Layer 2 เดียวกัน; เลือกไม่ครบให้แสดงสถานะเลือกบางส่วนและจำนวนที่เลือก |
| LOC C06 | ยกเลิก Layer 3 ข้อสุดท้าย | เมื่อไม่เหลือรายการ Layer 3 ที่เลือก ให้ลบค่า Layer 2 ที่เลือกอยู่ |
| LOC C07 | เปลี่ยน Layer 2 | ไม่คงรายการ Layer 3 ของหัวข้อเดิมข้ามไปหัวข้อใหม่; ใช้ชุดลูกของ Layer 2 ใหม่ |
| LOC C08 | หมวดที่ใช้ 3 Layer | ใช้เฉพาะโซนยอดนิยม, ตำบล และโซนในสถานศึกษา |
| LOC C09 | ตัวเลือกที่ตั้งอื่น | ใช้ Radio เลือกได้ครั้งละ 1 ค่าในกลุ่มนั้น |
| LOC C10 | จัดเรียงตาม | ใช้ Radio เลือกได้ครั้งละ 1 ค่า |
| LOC C11 | เปิดเปลี่ยนจังหวัด | การเปิดรายชื่อจังหวัดยังไม่ล้างพื้นที่เดิม; เลือกจังหวัดเดิมแล้วกลับไปเห็นค่าเดิม |
| LOC C12 | ยืนยันจังหวัดใหม่ | ล้างตัวเลือกพื้นที่ที่ผูกกับจังหวัดเดิม แล้วแสดงตัวเลือกของจังหวัดใหม่ |
| LOC C13 | ล้างข้อมูลที่ตั้ง | ล้างจังหวัดและตัวเลือกที่ตั้งทุก Layer กลับ “ทั้งหมด” โดยไม่แตะฟิลเตอร์หมวดอื่น |
| LOC C14 | ใช้ค่าค้นหา | กด “ค้นหา” แล้วจึงให้ผลลัพธ์ ฟิลเตอร์ด้านนอก Full Filter และ URL ใช้ค่าเดียวกัน |
| LOC C15 | เปลี่ยนจังหวัดพร้อมฟิลเตอร์อื่น | คงค่าที่จังหวัดใหม่รองรับ; ล้างเฉพาะค่าที่จังหวัดใหม่ไม่มีในฟิลเตอร์ด้านนอก Full Filter และ URL |
| LOC C16 | ผลลัพธ์เป็นศูนย์ | ถ้าค่าที่ยังคงอยู่ใช้ได้แต่ไม่มีทรัพย์ตรง ให้แสดง 0 ผลลัพธ์ ไม่ล้างค่าเพิ่ม |
| LOC C17 | คำตอบด้านใน | รายการจริงและรหัสพื้นที่รอ SEO ยืนยัน; ตัวอย่าง Prototype ไม่ใช่กฎข้อมูลจริง |

**กฎเลือกข้ามหัวข้อ:** เลือก 1.1.1 และ 1.1.2 พร้อมกันได้หากอยู่ใต้ Layer 2 เดียวกัน แต่เลือก 1.1.1, 1.1.2 และ 1.2.1 พร้อมกันไม่ได้

| ขั้น | ผู้ใช้ทำ | ผลต่อค่าที่กำลังแก้ | ผลต่อหน้าค้นหา |
|------|----------|---------------------|----------------|
| 1    | เปิดฟิลเตอร์ที่ตั้ง | เห็น “ทั้งหมด” หรือค่าที่เคยใช้ค้นหา | ยังไม่เปลี่ยน  |
| 2    | เลือกจังหวัด | แสดงตัวเลือกพื้นที่ของจังหวัดนั้น | ยังไม่เปลี่ยน  |
| 3    | เลือกหมวด Layer 1 และหัวข้อ Layer 2 | Layer 1 เป็นสีฟ้า; Layer 2 เลือก Layer 3 ทุกข้อใต้หัวข้อ | ยังไม่เปลี่ยน  |
| 4    | ติ๊กหรือยกเลิก Layer 3 | คงได้หลายข้อใน Layer 2 เดียว; ยกเลิกข้อสุดท้ายแล้วลบค่า Layer 2 | ยังไม่เปลี่ยน  |
| 5    | เลือก Radio หรือจัดเรียงตาม | ค่าใหม่แทนค่าเดิมในกลุ่มนั้น | ยังไม่เปลี่ยน  |
| 6    | กด “ล้างข้อมูล” ในที่ตั้ง | จังหวัดและ Layer 1–3 กลับ “ทั้งหมด” | ยังไม่เปลี่ยนจนกดค้นหา |
| 7    | กด “ค้นหา” | ใช้ค่าที่กำลังแก้เป็นค่าค้นหา | ผลลัพธ์ ฟิลเตอร์นอก Full Filter และ URL ตรงกัน |

**การเปลี่ยนจังหวัด:** เปิดรายชื่อเฉย ๆ ยังเก็บค่าเดิมไว้ เลือกจังหวัดเดิมก็คืนค่าเดิม เลือกจังหวัดอื่นจึงล้างพื้นที่ของจังหวัดเดิม จากนั้นกดค้นหาเพื่อใช้จังหวัดและค่าอื่นที่ยังรองรับ

## 4 ตัวอย่างการทำงาน

### 4.1 ค่าเริ่มต้นและการล้าง

| เหตุการณ์ | ผล  |
|-----------|-----|
| เปิดหน้าครั้งแรก | “ทั้งหมด”; ไม่มีจังหวัด, Layer หรือ Radio ที่ตั้งถูกติ๊ก |
| เลือกจังหวัดและพื้นที่หลายข้อ แล้วกด “ล้างข้อมูล” | ค่าในฟิลเตอร์ที่ตั้งทุกชั้นถูกล้าง; ฟิลเตอร์หมวดอื่นยังอยู่ |
| กด “ค้นหา” หลังล้าง | กลับผลแบบ “ทั้งหมด” ตามฟิลเตอร์หมวดอื่นที่ยังเลือก |

### 4.2 เลือกหลายข้อใน Layer 3

สมมติ Layer 1 = ตำบล และ Layer 2 = หัวข้อ A ซึ่งมีคำตอบ A1, A2, A3 ชื่อ A ใช้เพื่ออธิบายพฤติกรรมเท่านั้น ไม่ใช่ชื่อพื้นที่จริง

| การกระทำ | ค่าที่เลือก |
|----------|-------------|
| กดหัวข้อ A ใน Layer 2 | A1 + A2 + A3 |
| ยกเลิก A3 | A1 + A2; หัวข้อ A แสดงว่าเลือกบางส่วน |
| ยกเลิก A1 และ A2 | ไม่เหลือ Layer 3; ค่า Layer 2 ถูกลบ |
| เลือกหัวข้อ B แทน A | ใช้ลูกของ B; ลูกของ A ไม่ติดข้ามมา |

### 4.3 เปลี่ยนจังหวัด

เลือกขอนแก่นและพื้นที่ย่อย 2 แห่ง → กด “เปลี่ยนจังหวัด” ยังเก็บสองแห่งไว้ระหว่างดูรายชื่อ → เลือกขอนแก่นเดิม ค่ายังอยู่ → เลือกบุรีรัมย์ พื้นที่ของขอนแก่นถูกล้าง → กด “ค้นหา” แล้วผลและ URL จึงใช้บุรีรัมย์

### 4.4 ค่ายังใช้ได้แต่ไม่มีผลลัพธ์

เปลี่ยนจังหวัดแล้วคงฟิลเตอร์อื่นที่จังหวัดใหม่รองรับ หากค้นหาแล้วไม่มีทรัพย์ตรง ให้แสดง **0 ผลลัพธ์** และคงฟิลเตอร์นั้นไว้ ไม่ล้างต่อเพียงเพราะผลเป็นศูนย์
