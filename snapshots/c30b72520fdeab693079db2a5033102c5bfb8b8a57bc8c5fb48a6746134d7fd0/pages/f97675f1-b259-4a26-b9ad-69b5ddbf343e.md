| Role | สมัคร | เงื่อนไข | ข้อจำกัด |
|------|-------|----------|----------|
| ผู้ใช้ทั่วไป | nayoo | สมัครอย่างเดียว | \-       |
| เจ้าของทรัพย์มือสอง |       | ใบประกาศทั่วไป ≥ 1 | สามารถเป็นนายหน้าได้ |
| เจ้าของหอพัก |       | ใบประกาศหอพัก ≥ 1 | **ไม่สามารถเป็นนายหน้าได้** |
| นายหน้าอิสระ | nayoo | สมัครนายหน้า | ไม่มีประกาศหอพัก |
| นายหน้าบริษัท | nayoo | สมัครนายหน้า | ไม่มีประกาศหอพัก |
| โครงการมือ 1 | Console,Backoffice | Admin สร้างให้ | ไม่มีประกาศหอพัก,ขาย/เช่า |
| บริษัทรับสร้างบ้าน | Console,Backoffice | Admin สร้างให้ | ไม่มีประกาศหอพัก,ขาย/เช่า |
| ทรัพย์ธนาคาร NPA | Console,Backoffice | Admin สร้างให้ | **ไม่สามารถเป็นนายหน้าได้** |
