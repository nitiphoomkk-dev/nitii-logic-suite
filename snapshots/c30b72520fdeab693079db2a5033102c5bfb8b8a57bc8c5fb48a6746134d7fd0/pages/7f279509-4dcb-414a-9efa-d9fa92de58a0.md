 ![](/api/attachments.redirect?id=7ec70ead-c880-450d-b433-affa3a0c27eb " =398x188")

**“แท็บ ‘เหลือขาย / เปิดใหม่–เฟสใหม่ / ขายหมด’ ใช้เปลี่ยนโฟกัสไปยังส่วนของสถานะที่เลือก โดยคงชุดผลการค้นหาและเงื่อนไข Full Filter เดิม ไม่เพิ่มหรือเปลี่ยนเงื่อนไขการกรองข้อมูล”**

**Full Filter เลือกเฉพาะ “เปิดใหม่/เฟสใหม่” แล้ว แท็บ “เหลือขาย” ต้องไม่ดึงรายการที่ถูกกรองออกกลับมาแสดง หากไม่มีข้อมูลสถานะนั้น แนะนำให้แสดง 0 และกดไม่ได้ โดยไม่เปลี่ยน Full Filter ใ**

* * **เหลือขาย** (ตัวเลข ไดนามิกตามจำนวนใบประกาศที่มีสถานะนี้ และไดนามิกตามตัวเลือกประเภทฟีลเตอร์) (เลือกได้มากกว่า 1)
  * **เปิดใหม่/เฟสใหม่** (ตัวเลขไดนามิกตามจำนวนใบประกาศที่มีสถานะนี้ และไดนามิกตามตัวเลือกประเภทฟีลเตอร์) (เลือกได้มากกว่า 1)
  * **ขายหมด** (ตัวเลขไดนามิกตามจำนวนใบประกาศที่มีสถานะนี้ และไดนามิกตามตัวเลือกประเภทฟีลเตอร์) (เลือกได้มากกว่า 1)
* **ถ้าอยู่ในช่วงแคมเปญและมีใบประกาศที่เข้าร่วมในหมวดนั้น**
  * แสดงโลโก้ของแคมเปญนั้นที่ถูกอัพโหลดที่ backoffice เปลี่ยนแปลงตามแคมเปญที่เกิดขึ้นในแต่ละจังหวัด
* **ถ้ามีใบประกาศที่เข้าร่วม walk-in ในหมวดนั้นจะแสดงโลโก้ walk-in เป็น hard code ไอคอนจนกว่าจะมีการเปลี่ยนแปลง**
* **มีการเปลี่ยนแปลง logo น่าอยู่รีวิว จากเดิมเป็นตาม UI ที่แนบมา**

**เมื่อกด full filter แล้วจะแสดง modal ดังต่อไปนี้**

* **ตัวเลือกพิเศษ ถ้าไม่มีใรใบประกาศใดใบประกาศนั้น จะไม่แสดงเลย**
* **เพิ่มฟีลเตอร์เหลือขาย**
