## หน้า: ค้นหาบริษัทรับสร้างบ้านและแบบบ้าน (การ์ด home-builder)

FE ตัด tag ที่ซ้ำกับป้ายหลักของการ์ดออก โดยเทียบ `tags[]` กับข้อความไทย "รับสร้างบ้าน" (`TypeBadges.tsx`) ถ้า BE ส่ง tag เป็นข้อความที่แปลแล้ว การ์ดบน `/en` `/zh` จะโชว์ป้ายซ้ำ

| JSON path | วันนี้ | ขอ  |
|-----------|--------|-----|
| `GET /api/listing/search/home-builder/companies` → `items[].tags[]` | ตรวจไม่ได้ (บน dev คืน 0 รายการ ทั้งมีและไม่มี header `province`) | **ยืนยันว่าเป็น code** `home_builder` / `construction` / `design` เหมือน `profile-company-home-builder/details/:id` (ซึ่งตรวจแล้วเป็น code) ไม่ใช่ข้อความ |
| `GET /api/listing/search/home-builder/posts` → `items[].tags[]` | dev ไม่ส่ง `tags` | ถ้าส่งในอนาคต ขอเป็น code เช่นกัน |
| `GET /api/listing/profile-company-home-builder/:id/nearby-builders` → `tags[]` | ตรวจไม่ได้ (เรียกโดยไม่ส่ง header `province` ได้ `invalid province header`) | ยืนยันเป็น code |

ถ้าเป็น code ทั้งหมด FE ลบการเทียบไทยออกได้เลย ไม่ต้องมี field ใหม่

## หน้า: แคมเปญและอีเวนต์ / คูปองของฉัน (คูปองประเภท น่าอยู่)

FE ต้องรู้ว่าคูปองของ "น่าอยู่" มีชื่อจังหวัดให้โชว์หรือไม่ (`WalkInCouponResultModal.tsx`) ตอนนี้ใช้วิธีดูว่า `owner.name` เท่ากับคำว่า "น่าอยู่" (หรือชื่อแบรนด์ของภาษานั้น) ก็แปลว่าไม่มีชื่อจังหวัด วิธีนี้พังถ้า BE ส่งชื่อแบรนด์ในภาษาอื่นที่ FE ไม่รู้จัก

| JSON path | วันนี้ | ขอ  |
|-----------|--------|-----|
| `owner.name` ของ item ที่ `category` เป็น nayoo (FE อ่านจาก `GET /api/event-campaign/surface` และ `.../summary/location/:location`; หน้า my-coupon ใช้ชื่อแบรนด์จากข้อความฝั่ง FE ไม่ได้อ่านจาก BE) | `{ th, en, zh }` หรือ string — ตรวจค่าจริงไม่ได้ (dev ไม่มีคูปองให้เทส) | ขอ **field แยก** เช่น `owner.province_name` (`{ th, en, zh }`, ว่าง / `null` เมื่อเป็นส่วนกลาง) หรือบอก field ที่มีอยู่แล้วที่ FE ใช้แทนได้ |

## หน้า: แคมเปญและอีเวนต์ (โมดัลวิดีโอโปรโมท)

FE ใช้ประเภททรัพย์ของโพสต์ตัดสินว่าโมดัลแสดงโลเคชันแบบที่ดินหรือไม่ ตอนนี้อ่าน `post.property_type[0].slug` ก่อน แล้ว fallback เทียบชื่อไทย `"ที่ดิน"` ถ้าไม่มี slug

| JSON path | วันนี้ | ขอ  |
|-----------|--------|-----|
| `GET /api/event-campaign/participants/:participantId/promote-video-detail?video_id=` → `post.property_type[]` (และ `post_detail`, `home_builder`, `company_detail` ตามชนิดของ entity) | ตรวจไม่ได้ (ต้องมี participant id ของ Event ซึ่ง FE ไม่มีบน dev) | **ยืนยันว่ามี** `**slug**` ในทุก element เหมือน `reviews/popup/:id` (ตรวจแล้วมี) ถ้าไม่มี ขอเพิ่ม |
