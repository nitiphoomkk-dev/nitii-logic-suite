## 2. Contract

### 2.1 `color_config` (landing + surface)

```jsonc
"color_config": {
  "navbar": { "background": "<gradient>", "text": "<rgba>" },        // แถบแคมเปญ (โลโก้+ชื่อ) + แถบหัวข้อ section บนหน้า NaYoo
  "band_background": "<gradient>",                                   // พื้นหลังแคมเปญ เมื่อ background_type = "campaign_color"
  "sections": {
    "booking_promotion": { "header": "<gradient>", "text": "<rgba>", "background": "<gradient>" }, // โปรโมชันจองบ้าน + tab หัวข้อ
    "articles_videos":   { "header": "<gradient>", "text": "<rgba>", "background": "<gradient>" }, // บทความ วิดีโอแคมเปญ
    "promotion_videos":  { "header": "",           "text": "<rgba>", "background": "<rgba>" }      // วิดีโอโปรโมต — ไม่มีแถบหัวข้อ, header = ""
  },
  "button": { "background": "<gradient>", "text": "<rgba>" }         // ปุ่มของแคมเปญ (tab pill, ปุ่มทึบ, ปุ่มขอบ)
}
```

* รูปแบบค่า (มาจาก color picker ของ BO, BE ไม่ตรวจ ไม่แปลง): solid = `rgba(r,g,b,a)` ไม่มีช่องว่าง · gradient = `linear-gradient(<deg>deg, rgba(..) 0%, rgba(..) 100%)` หรือ `radial-gradient(circle at center, rgba(..) 0%, rgba(..) 100%)` สองจุดพอดี
* **แคมเปญที่ยังไม่เคยตั้ง =** `**null**` → ใช้ `color_preset` (1–5) แบบเดิม · แคมเปญใหม่ที่สร้างหลังถอดตัวเลือกธีมจะมี `color_preset: 0` และ `color_config` มีค่า
* key อยู่เสมอ (ไม่ omit) ทุก phase รวม `expired` · surface discovery ที่ไม่มีแคมเปญ (walk-in เดี่ยว) = `null`

### 2.2 รูปดัก Lead (landing + surface) — ใช้ในหน้าลงทะเบียนเพิ่มเติม

```jsonc
"lead_registration_images": { "new": "<storage key>", "secondhand": "<storage key>", "rent": "", "home_builder": "<storage key>" },
"lead_popup_image_path": "<storage key>"
```

* `lead_registration_images` = รูปปกประกอบฟอร์มลงทะเบียน แยกตามหมวด (3:2, 2400×1600) · **key ใช้** `**new**` **(ไม่ใช่** `**new_project**`**)** · ครบ 4 key เสมอ, `""` = หมวดนั้นไม่มีรูป
* `lead_popup_image_path` = รูป popup ลงทะเบียน (1098×1860) · `""` = ไม่มี
* เป็น storage key แบบเดียวกับ `*_image_path` อื่น · ไม่มีรูป → ใช้รูป default เดิมของ FE

### 2.3 `main_sponsor_promotions` (landing เท่านั้น)

```jsonc
"main_sponsor_promotions": [
  {
    "id": 1,
    "title": "SCG",
    "banners": {                                             // หน้าตาเดียวกับ flash_deal.banners
      "desktop": [{ "id": 1, "alt": "", "image_path": "event-campaign/d1.webp", "link": "https://example.com" }],
      "mobile":  [{ "id": 1, "alt": "", "image_path": "event-campaign/m1.webp", "link": "https://example.com" }]
    },
    "categories": ["new_project", "secondhand"],             // key เดียวกับ tab ของ participants
    "colors": { "header": "<rgba>", "text": "<rgba>", "background": "<gradient>" }
  }
]
```

* แสดง **เหนือรายการประกาศของหมวดใน** `**categories**` (section participants) · คนละอันกับ `sponsors.main_sponsors` (แถวโลโก้ ไม่เปลี่ยน)
* `categories` ∈ `new_project` | `secondhand` | `rent` | `home_builder` = key เดียวกับ `participants.{new_project,secondhand,rent,home_builder}` → เทียบตรงได้เลย ไม่ต้อง map
* เรียงตามลำดับที่แอดมินลากแล้ว · ไม่มีบล็อก = `[]` (ไม่ใช่ `null`)
* banner ที่ไม่มีรูปถูกตัดทิ้ง และ **ไม่มีรูป default** → ฝั่งหนึ่งอาจเป็น `[]` (BO บังคับกรอกอยู่แล้ว เจอได้ยาก แต่ควรกันไว้: ไม่มี banner = ไม่ render carousel)

### 2.4 Flash Deal: `logo_image_path` + `colors`

```jsonc
"flash_deal": {
  "is_visible": true,
  "end_at": "2026-09-30T23:59:59+07:00",
  "banners": { "desktop": [...], "mobile": [...] },
  "logo_image_path": "event-campaign/flash-logo.webp",                 // "" = ไม่ได้ตั้ง → ใช้รูป default ของ FE
  "colors": { "header": "<gradient>", "text": "<rgba>", "background": "<gradient>" }, // null = ไม่ได้ตั้ง → ใช้ธีม default
  "items": [...]
}
```

* ค่าเดียวกันทั้งใน landing (`flash_deal`) และ `/:slug/flash-deal` (สร้างจากฟังก์ชันเดียวกัน)
* section ถูกซ่อน (`is_visible: false`) → `logo_image_path: ""`, `colors: null`

## 3. `background_type` บน landing เปลี่ยนค่า

|     | เดิม | ใหม่ |
|-----|------|------|
| landing `GET /:slug` | `"image"` / `"color"` | `"promote_image"` / `"campaign_color"` |
| surface | `"promote_image"` / `"campaign_color"` | เหมือนเดิม |

* เหตุผล: FE `normalizeEventBackgroundType` (`components/pages/campaign/event-online/adapters/primary-sections.ts` \~บรรทัด 81) เช็คแค่ `=== "promote_image"` ที่เหลือเป็น `"color"` → ค่าเดิม `"image"` ของ landing ถูกอ่านเป็นสี (ยังไม่เห็นผลเพราะธีมถูกล็อกอยู่ แต่จะโผล่ทันทีที่ปลดล็อก)
* ผลกระทบ: ไม่พบโค้ด FE ที่เทียบกับ `"image"` / `"color"` ตรง ๆ → ไม่ต้องแก้อะไร แค่รับรู้
* กติกา: `promote_image` = ใช้ `hero.promote_image_path` เป็นพื้นหลัง · `campaign_color` = ใช้ `color_config.band_background`

### 4.3 ส่ง `registration_source` ตอนลงทะเบียน (BO filter "หน้าที่ลงทะเบียน")

ตอนนี้ FE **ยังไม่ส่ง** → lead ใหม่ไม่มีหน้าที่มา, filter `registration_page` ในรายชื่อผู้สนใจ BO ว่าง · เพิ่มใน body ของ request ลงทะเบียน lead เดิม (body เดียวกับที่ส่ง `type`, `campaign_id`, `conversion_context` อยู่ — listing-service `POST` interested user):

```jsonc
"registration_source": { "page": "search_new", "detail": "โครงการ A" }   // detail = ข้อความแสดงผล ไม่บังคับ
```

* **รับเฉพาะ** `**type: "event"**` — ส่งกับ type อื่น (`post_new` ฯลฯ) = `400` · ไม่ส่ง / ส่งว่าง = ไม่ error
* `page` ต้องเป็นหนึ่งใน (ผิด = `400`):

| `page` | หน้า |
|------|------|
| `home_province` | Home จังหวัด |

| `search_new` | Search รวมโครงการใหม่ |
| `search_secondhand` | Search รวมอสังหาฯ มือสอง |
| `search_rent` | Search รวมเช่า |
| `search_home_builder` | Search รวมรับสร้างบ้าน |
| `search_house_model` | Search รวมแบบบ้าน |
| `post_detail_new` | Section ใต้รายละเอียดใบประกาศโครงการใหม่ |
| `post_detail_secondhand` | Section ใต้รายละเอียดใบประกาศมือสอง |
| `post_detail_rent` | Section ใต้รายละเอียดใบประกาศเช่า |
| `post_detail_house_model` | Section ใต้รายละเอียดใบประกาศแบบบ้าน |
| `brand_project_detail` | Section ใต้รายละเอียดแบรนด์โครงการ |
| `home_builder_detail` | Section ใต้รายละเอียดบริษัทรับสร้างบ้าน |
| `special_campaign` | Section โปรโมชั่นพิเศษจากแคมเปญ |

* ค่า source ของหน้าลงทะเบียนเพิ่มเติม (`s=` / section code ใน `section-code.ts`) → map เป็น `page` ตามตารางนี้

## 7. Checklist ทดสอบ

* ☐ field ใหม่ไปถึง component จริง (ข้อ 4.0) — log ค่า `color_config` / รูปดัก Lead / `main_sponsor_promotions` หลังผ่านตัวแปลงของ FE แล้ว ไม่ใช่ดูแค่ network
* ☐ แคมเปญที่ตั้ง `color_config`: landing + home + search + หน้าประกาศ + profile สีตรงกับที่ตั้งใน BO (navbar, section 3 อัน, ปุ่ม)
* ☐ `background_type = campaign_color` → พื้นหลังเป็น `band_background` · `promote_image` → เป็นภาพโปรโมท (ทั้ง landing และ surface)
* ☐ แคมเปญเก่า (`color_config: null`) หน้าตาเหมือนเดิม
* ☐ Main Sponsor: หลายบล็อกเรียงตาม BO, แต่ละบล็อกขึ้นเฉพาะ tab ใน `categories`, สีตามบล็อก
* ☐ Flash Deal: โลโก้ + สีตาม BO · ไม่ตั้ง → default
* ☐ หน้าลงทะเบียนเพิ่มเติม: รูปปกตามหมวด (รวม `rent` แยกจากมือสอง) + popup ตาม BO · ไม่ตั้ง → default
* ☐ ลงทะเบียน `type=event` จากแต่ละหน้า → BO รายชื่อผู้สนใจ filter "หน้าที่ลงทะเบียน" เจอตรงหน้า
