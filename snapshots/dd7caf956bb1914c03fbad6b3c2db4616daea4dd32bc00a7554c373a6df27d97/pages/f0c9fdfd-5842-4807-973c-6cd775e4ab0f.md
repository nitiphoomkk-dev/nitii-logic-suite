> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/rent/{ประเภท}-detail/{จังหวัด}/{id ประกาศ}` เช่น `/rent/condo-detail/khonkaen/{id ประกาศ}` (หอพักใช้ `/rent/apartment-detail/...`)

**ไฟล์หน้า:** `app/(interface)/(post-and-profile)/detail/rent/[property]/[location]/[uuid]/page.tsx`

**TrackingProvider:** `source_type: rent`, `source_id: {id ประกาศ}`, `entity_id: {id ประกาศ}` (event ที่ไม่ได้ส่ง entity_id เองจะได้ id ประกาศนี้)

หน้านี้มี 2 แบบ: ประกาศเช่าทั่วไป และหอพัก (post_type `apartment`) หอพักแสดง RoomModels กับ CostDetail เพิ่ม, ไม่แสดง RouteDetail และ RegisterInterest, ไม่มีปุ่มลงทะเบียนในการ์ดติดต่อและแถบติดต่อด้านล่าง แต่การ์ดติดต่อมีปุ่ม Google Map

บล็อกคูปอง Walk-in ด้านบน (#5) แสดงเมื่อประกาศมีคูปอง Walk-in แต่ไม่ได้เข้าร่วมแคมเปญ (ยกเว้นขอนแก่น / อุบล / พิษณุโลก) บล็อกแคมเปญด้านล่าง (#20) แสดงเมื่อจังหวัดมีแคมเปญ เปิดจาก BO preview จะไม่ยิง event ใดเลย

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
