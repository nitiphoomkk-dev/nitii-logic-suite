**การเลือกเวลา**

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=404de72c-4cd6-4874-9f96-7051e1608deb)

เป็นตัวเลือกแบบ Calendar ให้เลือกวันที่เริ่มต้น→วันที่สิ้นสุด ตามลำดับ หลังเลือกระบบจะต้องคำนวณระยะเวลาทั้งหมดและแสดง จำนวนวันทั้งหมด พร้อมกับวันที่เริ่มต้น-วันที่สิ้นสุด ในรูปแบบ DD/MM/YYYY ทั้งคู่

1⁠. ตัวเลือกแบบ Calendar ไม่สามารถเลือกวันที่ในอดีตได้  สำหรับวันที่เริ่มต้น

2⁠. การแสดง Calendar จะแสดงเดือนสองเดือนคู่กันเสมอ

3⁠. กดไปทางซ้าย ← จะแสดง เดือนที่ n-1, และเดือน n Ex. กันยายน และ ตุลาคม 

4⁠. กดไปทางขวา → จะแสดงเป็น เดือนที่ n และเดือน n+1 Ex. ตุลาคม ไป พฤศจิกายน

5⁠. กดคลิกเลือกวัน dobleจะเป็นวันที่เลือกเลยทันทีในรูปแบบ DD/MM/YYYY 

6⁠. จะเป็นวันที่เลือกเลยทันทีในรูปแบบ DD/MM/YYYY 

7⁠. เมื่อคลิกครั้งที่ 2และลากคลุม Drag to select จะกำหนดเป็น วันที่สิ้นสุดทันที 

8⁠. เมื่อหลังวันที่ 31 ธันวาคม ให้เริ่มปี ค.ศ.ใหม่ 

9⁠. Filter Calendar สามารถสร้าง insert การ์ด ขึ้นทับวันที่เคยสร้าง insert การ์ด  ช่วงเวลาเดียวกันได้ 

10⁠. แถบสีเขียวด้านล่างปฏิทิน (ระยะเวลาทั้งหมด): ต้อง Auto-calculate ตัวเลขจำนวนวัน และอัปเดตวันที่ในวงเล็บให้ตรงกับ Start Date - End Date ที่ User เพิ่งเลือกใหม่เสมอ

**เพื่อให้ทีมงานหรือ Developer อ่านและเข้าใจ Logic ได้ง่ายขึ้น สามารถแบ่งเป็น 3 ขั้นตอนดังนี้ครับ:**

**Step 1: ตรวจสอบโปรโมชั่นของบริษัท**

1⁠. ระบบทำการเช็คโปรไฟล์ของบริษัทนั้นๆ ว่ามี "ใบประกาศที่ผูกกับโปรโมชั่น" หรือไม่?

⁠ 2⁠. ✅ มี: ดำเนินการต่อใน Step 2

1⁠. เช็คระยะเวลาของโปรโมชั่นบนใบประกาศ ว่ามีการ "ทับซ้อน" กับช่วงเวลาของ Insert Card หรือไม่?

⁠ 1⁠. ❌ ไม่ทับซ้อน: ไม่เข้าเงื่อนไข (ใช้งานไม่ได้)

⁠ 2⁠. ✅ ทับซ้อนกัน: ดำเนินการต่อใน Step 3

Click:  นับเมื่อมีการเกิดการ  Click เสมอ ถึงแม้จะโหลดไม่เสร็จ และนับใหม่ทุกการคลิกเสมอ
