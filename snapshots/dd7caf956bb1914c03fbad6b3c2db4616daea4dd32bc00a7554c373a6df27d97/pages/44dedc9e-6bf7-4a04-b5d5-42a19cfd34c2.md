**Solution การดึงและแสดงบทความ — Center และจังหวัด**

**วัตถุประสงค์:** กำหนดแหล่งบทความที่หน้ารวมบทความ Center และหน้าจังหวัดดึงมาแสดงตามรูปแบบการลงบทความ เพื่อให้ผู้พัฒนาและ Tester ใช้กฎเดียวกัน

**แหล่งอ้างอิง:** [หน้ารวมบทความ Center — EP-01, EP-02 และ AC](https://wiki.infonayoo.co/doc/center-b6TBBBZwwG) revision 32 อ่าน 10 พฤศจิกายน 2569 และ Flow ที่ผู้ใช้ส่งพร้อมคำยืนยันล่าสุดว่า “ลงจังหวัดอย่างเดียวไปหน้ากลางด้วย”

**ขอบเขต:** กฎการดึงบทความที่เผยแพร่เข้าหน้ารวมบทความ Center และหน้าจังหวัด ส่วนการค้นหา การเรียง การ์ด และ Pagination ของหน้า Center ใช้กฎต้นฉบับต่อ เว้นแต่ระบุเปลี่ยนไว้ด้านล่าง กฎจังหวัดนอกเหนือจากขอบเขตการดึงยังยึดเอกสารจังหวัดเดิม

## EP-01 ความหมาย

| คำ  | ความหมาย |
|-----|----------|
| หน้ากลาง / Center | หน้ารวมบทความส่วนกลางที่เป็นปลายทางใน Flow |
| หน้าจังหวัด | หน้าบทความของแต่ละจังหวัดที่เป็นปลายทางใน Flow |

| กลาง + จังหวัด | บทความที่ลงรูปแบบกลางร่วมกับจังหวัด |
| จังหวัดอย่างเดียว | บทความที่ลงรูปแบบจังหวัดโดยไม่มีรูปแบบกลาง |
| เผยแพร่ | บทความอยู่ในสถานะที่ผ่านเกณฑ์เผยแพร่เดิม ไม่ถือว่าบทความที่ยังไม่พร้อมเผยแพร่แสดงได้เพียงเพราะตรง Flow |

## EP-02 ตารางการดึงบทความตาม Flow ที่ยืนยัน

| รหัส | รูปแบบการลง | หน้ารวมบทความ Center | หน้าบทความจังหวัด | Logic |
|------|-------------|----------------------|-------------------|-------|
| ART-S01 | กลางอย่างเดียว | แสดง                 | ไม่อยู่ในเส้นทางแสดงทุกจังหวัดตาม Flow ที่ให้มา | ดึงเข้าหน้ากลางเมื่อบทความผ่านสถานะและสิทธิ์เดิม |
| ART-S02 | กลาง + จังหวัด | แสดง                 | แสดงได้ทุกจังหวัด | นำบทความที่ผ่านเกณฑ์เข้าชุดหน้ากลางและชุดของแต่ละจังหวัด |
| ART-S03 | จังหวัดอย่างเดียว | แสดง                 | แสดงได้ทุกจังหวัด | นำบทความจังหวัดที่ผ่านเกณฑ์เข้าชุดหน้ากลางด้วย และเข้าชุดของแต่ละจังหวัดตาม Flow ที่ผู้ใช้ยืนยัน |
| ART-S04 | ยังไม่ผ่านเงื่อนไขเผยแพร่ / สิทธิ์เดิม | ไม่ดึงมาแสดงจนกว่าจะผ่าน | ไม่ดึงมาแสดงจนกว่าจะผ่าน | ตรวจสถานะและสิทธิ์ก่อนใช้เส้นทางแสดงผล |

**การใช้กฎ:** หน้ากลางใน Solution นี้ดึงบทความจังหวัดอย่างเดียวได้ตามคำยืนยันล่าสุด หากข้อความเก่าที่ตีความว่า Center แสดงเฉพาะบทความกลางขัดกับข้อนี้ ให้ใช้ ART-S03 สำหรับขอบเขต Solution นี้

**หมายเหตุ:** Flow ไม่มีเส้นกลางอย่างเดียวไป “ทุกจังหวัด” ตารางจึงระบุเฉพาะขอบเขตที่ Flow กำหนด ไม่สรุปเพิ่มว่าบทความกลางอย่างเดียวจะแสดงในจังหวัดใดเป็นพิเศษหรือไม่ หากระบบเดิมมีกฎจังหวัดอื่นให้ตรวจร่วมกับเจ้าของ Logic

## EP-03 Flow การทำงาน


1. รับบทความที่ผ่านสถานะและสิทธิ์เผยแพร่ตามกฎเดิม
2. ตรวจรูปแบบการลง: กลาง / กลาง + จังหวัด / จังหวัดอย่างเดียว
3. **หน้ารวม Center:** นำทั้งสามรูปแบบที่ผ่านเงื่อนไขเข้าชุดบทความ
4. **หน้าจังหวัด:** นำรูปแบบกลาง + จังหวัด และจังหวัดอย่างเดียวที่ผ่านเงื่อนไขเข้าชุดของแต่ละจังหวัดตาม Flow
5. หน้ารวม Center จึงนำชุดที่ได้ไปใช้กฎค้นหา หมวด การเรียง และ Pagination ตาม EP-04
6. หากผู้ใช้คลิกบทความ ให้ใช้กฎปลายทางและจังหวัดตามข้อมูลบทความเดิม โดยประเด็นบทความที่มีหลายจังหวัดให้ยืนยันตาม EP-07

## EP-04 กฎหน้ารวมบทความ Center ที่คงจากต้นฉบับ

| รหัส | เรื่อง | Logic |
|------|--------|-------|
| ART-C01 | หมวดเริ่มต้น | เปิดหน้าเลือก “บทความล่าสุด” แสดงจากทุก Tag ในชุดที่ผ่าน EP-02 เรียงวันที่อัปเดตล่าสุดก่อน |
| ART-C02 | เลือกหมวด | แสดงบทความในชุดที่ผ่าน EP-02 และตรงหมวดที่เลือก เรียงวันที่อัปเดตล่าสุดก่อน |
| ART-C03 | ค้นหาชื่อ | พิมพ์มากกว่า 1 ตัวอักษรจึงเริ่มค้นชื่อจากทุกหมวด ไม่จำกัด Tag ที่เลือก และค้นภายในชุดที่ผ่าน EP-02; ช่องรองรับสูงสุด 200 ตัวอักษร |
| ART-C04 | จำนวนต่อหน้า | สูงสุด 24 การ์ดต่อหน้า ไม่รวม Banner และ Pop-up ใช้ทั้ง Desktop และ Mobile |
| ART-C05 | Pagination | เมื่อผลลัพธ์เกิน 24 การ์ด แสดง Pagination ในทุกหมวดและผลค้นหา |
| ART-C06 | การเรียง | ใช้วันที่สร้างเป็นวันที่อัปเดตครั้งแรก; เมื่อมีการอัปเดต ใช้วันที่อัปเดตล่าสุดตามต้นฉบับ |
| ART-C07 | เปิดการ์ด | เปิดแท็บใหม่: บทความส่วนกลางไม่เปลี่ยนจังหวัด; บทความของจังหวัดให้ Navbar ปลายทางแสดงจังหวัดของการ์ดตามต้นฉบับ โดยกรณีจังหวัดต้นทางกำกวมดู EP-07 |
| ART-C08 | Tag / ภาพ | คงกฎ Tag และภาพปกตาม EP-02 ต้นฉบับ: บทความ Center ไม่แสดง Tag จังหวัดต่อท้าย; บทความรีวิวที่มีวิดีโอใช้ภาพปกวิดีโอตามที่ต้นฉบับกำหนด |
| ART-C09 | Banner / Pop-up | คงกฎของเอกสาร Banner 3 ภาษา และ Pop-up 3 ภาษา ที่ต้นฉบับเชื่อมโยง ไม่รวมการแสดงผลเหล่านี้ใน 24 การ์ด |

## EP-05 ตัวอย่างการแสดงผล

สมมติบทความ A ลงกลางอย่างเดียว, B ลงกลาง + จังหวัด, C ลงจังหวัดอย่างเดียว และทั้งสามเผยแพร่พร้อมผ่านสิทธิ์

| หน้า | บทความที่อยู่ในขอบเขตการดึงตาม Flow | ตัวอย่าง |
|------|-------------------------------------|----------|
| หน้ารวม Center | A, B และ C                          | นำเข้าชุดแล้วเรียง/ค้น/แบ่งหน้าตาม EP-04 |
| หน้าจังหวัดขอนแก่น | B และ C                             | ทั้งสองรูปแบบอยู่ในเส้นทางแสดงทุกจังหวัด |
| หน้าจังหวัดอุดรธานี | B และ C                             | ทั้งสองรูปแบบอยู่ในเส้นทางแสดงทุกจังหวัดเช่นกัน |

ตัวอย่างนี้อธิบายเส้นทางการดึง ไม่กำหนดลำดับจริง สิทธิ์ รูปภาพ หรือกรณีกลางอย่างเดียวบนหน้าจังหวัดนอกเหนือจาก Flow

## EP-07 ประเด็นที่ต้องยืนยันก่อนปิดรายละเอียด

| ประเด็น | สิ่งที่ต้องตัดสิน |
|---------|-------------------|
| กลางอย่างเดียวบนหน้าจังหวัด | Flow ระบุเส้นทางไปหน้ากลาง แต่ไม่กำหนดอย่างชัดเจนว่ามีกฎแสดงในจังหวัดบางหน้าหรือไม่ ให้ตรวจ Logic จังหวัดเดิม |
| บทความมีหลายจังหวัด / ลงกลาง + จังหวัด | เมื่อกดการ์ดจาก Center จะใช้จังหวัดใดใน Navbar ปลายทาง และข้อมูลใดเป็นจังหวัดต้นทาง |
| รายการซ้ำ | หากข้อมูลหนึ่งบทความถูกดึงได้จากหลายเส้นทาง ให้กำหนดรหัสที่ใช้ระบุตัวตนและวิธีจัดการซ้ำก่อนกำหนด AC รายละเอียด |
| ตัวกรองจังหวัดบนหน้ารวม | ขอบเขตนี้ไม่ได้กำหนดว่ามีตัวกรองจังหวัดหรือไม่ ให้คงต้นฉบับและยืนยันกับเจ้าของหน้าหากต้องเพิ่ม |
| คำค้นค้างเมื่อเปลี่ยน Tag, Empty State และภาพสำรอง | คงสถานะต้องยืนยันตามต้นฉบับ ไม่สร้างพฤติกรรมใหม่ใน Solution นี้ |
