ใช้กับตัวเลขใต้ 4 ปุ่มบนหน้า Home รวมจังหวัด (Home Center, EP-10) ได้แก่ **ซื้อโครงการใหม่ / อสังหาฯ มือสอง / เช่า-หอพัก / รับสร้างบ้าน** เป็น public ไม่ต้องใช้ token ใช้แค่ apikey ตามปกติ **ไม่ต้องส่ง header** `**province**` เพราะนับรวมทุกจังหวัดเสมอ

```cs
GET /api/listing/home-page/thailand/summary-posts-all-type
```

shape เดียวกับ `/api/listing/home-page/summary-posts-all-type` (ของหน้า Home แยกจังหวัด)

## ตัวอย่าง response

```json
{
  "success": true,
  "message": "get thailand summary posts all type successfully",
  "data": {
    "province_id": 0,
    "summary_posts": {
      "post_new": 3587,
      "secondhand": 12450,
      "apartment": 2310,
      "home_builder": 333
    }
  }
}
```

> ตัวเลขข้างบนเป็นตัวอย่าง ไม่ใช่ข้อมูลจริง

## Field

| Field | ปุ่ม (หน่วย) | ความหมาย | ปุ่ม → หน้าที่กดไป |
|-------|--------------|----------|--------------------|
| `summary_posts.post_new` | ซื้อโครงการใหม่ (โครงการ) | ใบประกาศโครงการใหม่ทั้งหมด (ออนไลน์ + ปิดขาย + เปิดใหม่เฟสใหม่) | หน้าค้นหาโครงการใหม่ center `/property-project/properties/thailand` |
| `summary_posts.secondhand` | อสังหาฯ มือสอง (ใบประกาศ) | ใบประกาศมือสองที่ลงขาย (รวมที่ลงทั้งขายและเช่า, รวม NPA) ออนไลน์ ไม่หมดอายุ | หน้าค้นหามือสอง center |
| `summary_posts.apartment` | เช่า/หอพัก (ใบประกาศ) | หอพัก/อพาร์ทเมนต์ + มือสองที่ลงเช่า ออนไลน์ ไม่หมดอายุ | หน้าค้นหาเช่า center |
| `summary_posts.home_builder` | รับสร้างบ้าน (บริษัท) | จำนวน บริษัท รับสร้างบ้านที่ออนไลน์ (นับที่บริษัทแม่ มีสาขาหรือไม่มีก็นับ) | หน้าค้นหาบริษัทรับสร้างบ้าน center |

* `post_new` / `secondhand` / `apartment` ตั้งใจให้ **เท่ากับจำนวนที่หน้าปลายทางแสดง** (ไม่ได้ติ๊ก filter อื่นเพิ่ม)
* `home_builder` ไม่ได้เช็คสาขา จึง **อาจไม่เท่ากับ** total ของหน้าค้นหาบริษัทรับสร้างบ้าน ถ้าหน้านั้นยังกรองด้วยสาขา
* ใบประกาศมือสองที่ลงทั้งขายและเช่า ถูกนับทั้งใน `secondhand` และ `apartment` (ตั้งใจ เพราะเป็นตัวเลขของแต่ละปุ่ม ไม่ใช่การแบ่งกลุ่ม) ผลรวม 4 ช่องจึงไม่ใช่จำนวนใบประกาศทั้งหมด
* ทุกช่องเป็นตัวเลขเสมอ (ไม่เป็น `null`) ถ้าไม่มีข้อมูลจะเป็น 0 — FE ใส่ comma คั่นหลักพันเอง
* URL ปลายทางของแต่ละปุ่ม FE กำหนดเอง
* ตัวเลขถูก cache ไว้ฝั่ง backend 30 นาที เลขอาจไม่เปลี่ยนทันทีหลังมีการลงหรือแก้ประกาศ
