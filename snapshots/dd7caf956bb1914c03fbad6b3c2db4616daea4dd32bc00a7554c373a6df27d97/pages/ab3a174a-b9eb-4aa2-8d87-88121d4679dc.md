### **เมนูด้านซ้าย (Sidebar)**

| **เมนูย่อย** | **การทำงาน** |
|----------|----------|
| โครงการใหม่ | Navigate ไปหน้ารายชื่อผู้สนใจของโครงการใหม่ทั้งหมด |
| มือสอง   | Navigate ไปหน้ารายชื่อผู้สนใจของทรัพย์มือสอง |
| บริษัทรับสร้างบ้าน | Navigate ไปหน้ารายชื่อผู้สนใจของรับสร้างบ้าน |
| อื่นๆ    | Navigate ไปหน้ารายชื่อผู้สนใจประเภทอื่นๆ |

เมนูที่กำลังใช้งานอยู่จะแสดงพื้นหลังสีเขียวอ่อนกำกับ

**Filter Bar**

 ![](/api/attachments.redirect?id=d039e884-e7be-4ea6-b1bc-706dbc0b583d)

หน้าโครงการใหม่ Back Office มี Filter **2 ปุ่ม** เรียงแนวนอน

**“บริษัท/โครงการ”**    ![](/api/attachments.redirect?id=24a4e48a-5933-4791-98ab-8f6d95aa8df0)

 ![](/api/attachments.redirect?id=11956c2c-8db7-476a-8327-edb03eed20ee)  ![](/api/attachments.redirect?id=44050d42-22c3-44d6-a7df-78030b318cfc)   ![](/api/attachments.redirect?id=6988c967-9590-4a60-874a-fab29b63509e)

**กรณียังไม่กด** ปุ่มแสดงข้อความ "บริษัท/โครงการ" พร้อมลูกศร ▼ ไม่กรองข้อมูล

**กรณีกดเปิด** เปิด Dropdown แสดง 5 ตัวเลือกหลักก่อน ได้แก่

| **ตัวเลือก** | **การทำงาน** |
|----------|----------|
| ทั้งหมด  | ไม่กรอง แสดงข้อมูลทั้งหมด (Default) |
| บริษัททั้งหมด | กรองเฉพาะ Lead ที่มาจากระดับบริษัท |
| บริษัท (ระบุเอง) | ขยาย Search Box และรายชื่อบริษัทให้เลือก |
| โครงการทั้งหมด | กรองเฉพาะ Lead ที่มาจากโครงการทั้งหมด |
| โครงการ (ระบุเอง) | ขยาย Search Box และรายชื่อโครงการให้เลือก |

เมื่อเลือก "บริษัท (ระบุเอง)" หรือ "โครงการ (ระบุเอง)"

* มี Search Box พิมพ์ค้นหาชื่อบริษัท/โครงการได้
* แสดงรายชื่อตามจังหวัดที่เลือกไว้ (ถ้ามี)
* เลือกได้ 1 รายการต่อครั้ง (Single-select)

ด้านล่าง Dropdown มีปุ่ม "ล้างข้อมูล" เพื่อ Reset กลับ Default และปุ่ม "ค้นหา" เพื่อกรองข้อมูลทันที

**กรณีเลือกแล้ว**

ปุ่มแสดงชื่อที่เลือก และกรองรายการเฉพาะ Lead ที่มาจากบริษัทหรือโครงการนั้น

#### **“การลงทะเบียน”**  ![](/api/attachments.redirect?id=4fa23cdf-987d-44dc-be5a-e039cee6207d)

**กรณียังไม่กด** ปุ่มแสดงข้อความ "การลงทะเบียน" พร้อมลูกศร ▼ ไม่กรองข้อมูล

**กรณีกดเปิด**

เปิด Dropdown แสดงตัวเลือกช่องทางที่ Lead ลงทะเบียนเข้ามา แต่ละตัวเลือกแสดงจำนวน Lead ในวงเล็บ เลือกได้มากกว่า 1 ช่องทาง (Multi-select)

ค่าเริ่มต้นจะติ๊กถูกทั้งหมด หากต้องการเลือกเพียงอย่างใดอย่างหนึ่งให้กดที่ "ทั้งหมด" ซ้ำ แล้วเลือกตัวเลือกที่ต้องการกรอง หรือติ๊กออกให้เป็นวงกลมเปล่าทีละอันได้

 ![](/api/attachments.redirect?id=9ee611cb-9e5e-449a-8593-6acbfabf8046)

| **ตัวเลือก** | **จำนวนที่แสดง** |
|----------|--------------|
| ทั้งหมด  | แสดงข้อมูลทั้งหมด |
| ทั่วไป   | หมายถึงข้อมูลการลงทะเบียนประเภท ทั่วไป |
| Facebook | หมายถึงมีข้อมูลการลงทะเบียนประเภท Facebook |

| Map      | หมายถึงมีข้อมูลการลงทะเบียนประเภท Map |
| สินเชื่อ | หมายถึงมีข้อมูลการลงทะเบียนประเภท สินเชื่อ |
| Event Online | หมายถึงมีข้อมูลการลงทะเบียนประเภท Event Online |
| Walk-in  | หมายถึงมีข้อมูลการลงทะเบียนประเภท Walk-in |

| เฟสใหม่  | หมายถึงมีข้อมูลการลงทะเบียนประเภท เฟสใหม่ |

**กรณีเลือกแล้ว**

* กรองตารางเฉพาะ Lead ที่มาจากช่องทางที่เลือก
* กด "ล้างข้อมูล" → กลับ Default
* กด "ค้นหา" → ตารางอัปเดตทันที

**“ตัวกรอง (Advanced Filter)”**   ![](/api/attachments.redirect?id=a0e5a1f5-2868-49ba-ae05-cdbb711bcbd8)

**กรณียังไม่มี Filter ใช้งาน** ปุ่มแสดงไอคอน Filter + ข้อความ "ตัวกรอง" ไม่มีตัวเลข

**กรณีกดเปิด** เปิด Panel ขนาดใหญ่แสดง Filter เพิ่มเติม 3 หมวด

**หมวดที่ 1 — หมวดประเมินลูกค้า**

 ![](/api/attachments.redirect?id=6ff03596-566e-4651-bdd6-4d24500595a8)

แต่ละตัวเลือกได้มากกว่า 1 ตัว (Multi-select) ค่าเริ่มต้นจะติ๊กถูกทั้งหมด หากต้องการเลือกเพียงอย่างใดอย่างหนึ่งให้กดที่ปุ่ม "ทั้งหมด" ซ้ำ แล้วเลือกตัวเลือกที่ต้องการกรอง หรือติ๊กออกให้เป็นวงกลมเปล่าทีละอันได้

| **ตัวเลือก** | **ความหมาย** | **การแสดงจำนวน** |
|----------|----------|--------------|
| ทั้งหมด  | ไม่กรองข้อมูล | รวมทุกประเภท |
| Hot      | ลูกค้าสนใจสูงแสดง | แสดงจำนวน<br>หมายถึง มีชุดข้อมูลลูกค้าสนใจสูง |
| Warm     | ลูกค้าสนใจปานกลาง | แสดงจำนวน<br>หมายถึง มีชุดข้อมูลลูกค้าสนใจปานกลาง |
| Cold     | ลูกค้าสนใจน้อย | แสดงจำนวน<br>หมายถึง มีชุดข้อมูลลูกค้าสนใจน้อย |
| Red      | ลูกค้ามีปัญหา | แสดงจำนวน<br>หมายถึง มีชุดข้อมูลลูกค้ามีปัญหา |
| ไม่ระบุ  | ยังไม่ได้ประเมิน | แสดงจำนวน<br>หมายถึง มีชุดข้อมูลลูกค้ายังไม่ได้ประเมิน |

**หมวดที่ 2 — หมวดการติดตาม**

 ![](/api/attachments.redirect?id=46973b2d-8912-4440-9cc7-ae515de96ac0)

แต่ละตัวเลือกเลือกได้มากกว่า 1 ตัว (Multi-select)ค่าเริ่มต้นจะติ๊กถูกทั้งหมด หากต้องการเลือกเพียงอย่างใดอย่างหนึ่งให้กดที่ปุ่ม "ทั้งหมด" ซ้ำ แล้วเลือกตัวเลือกที่ต้องการกรอง หรือติ๊กออกให้เป็นวงกลมเปล่าทีละอันได้

| **ตัวเลือก** | **ความหมาย** |
|----------|----------|
| ทั้งหมด  | ไม่กรอง แสดงข้อความทั้งหมด |
| ติดต่อไม่ได้ | โทรไม่ติด<br>หมายถึง ติดต่อไม่สำเร็จ |

**หมวดที่ 3 — หมวด Walk-in**

 ![](/api/attachments.redirect?id=ce44c6a8-4c32-45a2-ad77-4204521eb1f8)

| **ตัวเลือก** | **ความหมาย** |
|----------|----------|
| ทั้งหมด  | ไม่กรอง แสดงข้อมูลทั้งหมดโดยไม่กรอง |

ด้านล่าง Panel มีปุ่ม "ล้างข้อมูลการค้นหา" เพื่อ Reset ทุก Filter ใน Panel นี้ทั้งหมด และปุ่ม "ค้นหา" เพื่อกรองข้อมูลทันที

**ปุ่มด้านล่าง Modal ตัวกรอง**

* "ล้างข้อมูล" → Reset ทุก Filter ใน Modal นี้ทั้งหมดกลับสู่ค่า Default
* "ค้นหา" → ยืนยันการเลือก กรองข้อมูลในรายการทันที และอัปเดต Summary Cards

**กรณีมี Filter ใช้งานอยู่**

ปุ่มตัวกรองแสดงตัวเลขนับรวม Filter ที่ Active อยู่ทั้งหมด เช่น 🔴1

### **Edge Cases ที่ต้องจัดการ**

| **กรณี** | **การจัดการ** |
|------|-----------|
| ไม่มีข้อมูลในตาราง | แสดงสถานะว่าง "ไม่พบรายชื่อผู้สนใจ" |
| ค้นหาแล้วไม่พบ | แสดง "ไม่พบรายชื่อที่ค้นหา" พร้อมปุ่ม "ล้างการค้นหา" |
| ข้อผิดพลาดเครือข่าย | แสดง Toast แจ้งเตือน "เกิดข้อผิดพลาด กรุณาลองใหม่" |
| กด "บันทึก" สำเร็จ | แสดง Popup สีเขียว ✔ พร้อมข้อความยืนยัน แล้วปิดอัตโนมัติ |
| Note เกิน 200 ตัวอักษร | ไม่สามารถพิมพ์เพิ่มได้ แสดง Counter สีแดง |
| กด "ยกเลิก" ใน Popup | ปิด Popup ทันที ไม่บันทึกการเปลี่ยนแปลงใด ๆ |
| ราคาต่ำสุด > ราคาสูงสุด | แสดงข้อผิดพลาด "ราคาต่ำสุดต้องเผชิญราคาสูงสุด" บันทึกบันทึก Disabled |
