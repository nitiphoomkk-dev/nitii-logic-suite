ต้องสามารถสลับการกดปุ่มข้อความในการแปลภาษาได้ 3 ภาษา ไทย อังกฤษ จีน เป็นต้น

การแปลภาษา user ต้องกรอกแปลภาษา ยึดภาษาของหน้าเว็บไซต์ที่ user เลือกเป็นภาษาหลัก

**กรณีกดแปล logic การแปล**

1\.กรอกภาษาหลัก

2\.กดภาษารองที่ต้องการแปล

3\.กดปุ่มแปลจากภาษาหลัก

4\.แปลสำเร็จ user ตรวจสอบคำแปล

5\.แก้ไขคำแปลในภาษารอง แต่ภาษาหลักจะไม่เปลี่ยนข้อความตาม

● ตัวอักษร (300 ตัวอักษรรวมเว้นวรรค= 15คะแนน ของการกรอกรายละเอียดเพิ่มเติม)

● ขนาดที่ดิน\* กรอกอย่างน้อย 1 ช่อง

● ราคาขาย และราคาส่วนกลาง/เดือน (ใส่จุดหากเป็นตัวเลขหลักพันขึ้นไป)
