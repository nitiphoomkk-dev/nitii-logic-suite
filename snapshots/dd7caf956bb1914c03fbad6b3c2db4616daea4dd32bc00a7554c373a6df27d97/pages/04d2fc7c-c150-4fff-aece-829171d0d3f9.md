\n**EP-01 Filter เลือกอ่านบทความจากน่าอยู่**

* มีช่องค้นหา
  * ค้นหาชื่อบทความ
    * การค้นหาชื่อบทความจะค้นจาก **ทุกหมวดเสมอ** โดยไม่จำกัดตาม Tag ที่เลือกอยู่
  * ช่องค้นหาจำกัด 200 ตัวอักษร
  * พิมพ์มากกว่า 1 ตัวอักษรแล้วค้นหาเลย

 ![](/api/attachments.redirect?id=13fea1b6-89c3-4387-a1ec-846d33df9686)

* มี tag ให้สามารถ กด filter ตาม หมวดหมู่ได้
  * บทความล่าสุด
  * สาระอสังหาฯ
  * ไลฟ์สไตล์
  * อัปเดตข่าวสาร
  * รีวิว
  * Trend อสังหาฯ
  * วัสดุและนวัตกรรมบ้าน
  * ไอเดียแบบบ้านและฟังก์ชัน
  * โดยจะ Default บทความล่าสุด
    * ดึงบทความทุก tag เรียงตามล่าสุด
  * คลิกที่ tag อื่นๆ จะ filter บทความตามหมวดนั้นๆมา

**EP-02 การ์ดบทความ**

* แสดง 24 slot ตาม tag ที่ filter ไว้  เรียงตามการอัพเดทล่าสุด
  * Default ที่บทความล่าสุด
  * การเปลี่ยน tag ก็ยังเรียงตามบทความล่าสุด (บทความล่าสุด)
* มี Pagination แสดงเมื่อรีวิว > 24 ใบ
  * แสดงการ์ดบทความสูงสุด **24 ใบต่อหน้า ไม่รวม Banner และ Pop-up** หากผลลัพธ์เกิน 24 ใบ ให้แสดง Pagination โดยใช้กับทุกหมวดและผลการค้นหา

* **รายละเอียดการ์ดบทความ center**
  * มีรูปปก
    * ถ้าเป็น tag รีวิว และ บทความนั้นมีวิดีโอ รูปปกจะต้องดึงรูปปกจากวิดีโิอมา (จะไม่ดึงตัวที่บอกว่า play ได้มาแสดง)
    * ถ้าไม่มีวิดีโอ รูปปกจะดึงจากภาพปกบทความ
  * **Tag สาระเรื่องบ้าน, ไลฟ์สไตล์, อัปเดตข่าวสาร, รีวิว, Trend อสังหา, วัสดุและนวัตกรรมบ้าน, ไอเดียวแบบบ้านและฟังก์ชัน + จังหวัดในพื้นที่ให้บริการของน่าอยู่**
    * **ถ้าบทความ center จะไม่มี tag จังหวัดต่อท้ายในการแสดงผล**
    * เฉพาะรีวิวเท่านั้นที่จะติ**ดแท็ก โครงการใหม่ อสังหามือสอง รับสร้างบ้าน ไลฟ์สไตล์ได้**
      * **รีวิว โครงการใหม่ ขอนแก่น**

**ยกตัวอย่าง**

| ชั้น | Tag ที่ใช้ได้ | เงื่อนไข |
|------|---------------|----------|
| **ชั้น 1**<br>หมวดเนื้อหา | บทความล่าสุด<br>สาระอสังหาฯ<br>ไลฟ์สไตล์<br>อัปเดตข่าวสาร<br>รีวิว<br>Trend อสังหาฯ<br>วัสดุและนวัตกรรมบ้าน<br>ไอเดียแบบบ้านและฟังก์ชัน<br> | เลือกได้ทุกบทความ — required อย่างน้อย 1<br>→ เลือก**รีวิว** |
| **ชั้น 2**<br>พื้นที่ | ขอนแก่น ✓ อุดรธานี ... จังหวัดอื่นๆ | เลือกได้ทุกบทความ — ไม่ required อย่างน้อย 1 จังหวัด<br>ตัวอย่าง: ขอนแก่น, อุดรธานี ฯลฯ<br>→ เลือก**ขอนแก่น** |
| **ชั้น 3**<br>ประเภทรีวิว | โครงการใหม่ ✓ อสังหามือสอง รับสร้างบ้าน ไลฟ์สไตล์ | **เฉพาะบทความที่ติด tag "รีวิว" (ชั้น 1) แล้วเท่านั้น**<br>ถ้าไม่มี tag รีวิว — ชั้น 3 จะไม่แสดงบนแท็ก |

* วันที่อัปเดต = วันที่สร้างในครั้งแรก ถ้าอัพเดทหลังจากนั้นค่อยอัพเดท
* จำนวนการเข้าชม
  * **ช่วง 0 - 999:** ให้แสดงตัวเลขจริงทั้งหมด (เช่น 123, 999)
  * **ช่วง 1,000 ขึ้นไป (K):** หารด้วย 1,000 และแสดงทศนิยม 1 ตำแหน่งเสมอ
  * **ช่วง 1,000,000 ขึ้นไป (M):** หารด้วย 1,000,000 และแสดงทศนิยม 1 ตำแหน่งเสมอ
  * **การปัดเศษ:** ห้ามปัดขึ้น (Floor) หรือตัดเศษทศนิยมทิ้งจนกว่าจะถึงตำแหน่งที่กำหนด **(No rounding until 1 decimal place)**

## Acceptance Criteria — หน้ารวมบทความ Center

เกณฑ์ต่อไปนี้อ้างอิง Functional Requirements ในหน้านี้ ใช้ตรวจทั้ง Desktop และ Mobile ตาม UI และเอกสาร Banner / Pop-up ที่เชื่อมโยง

### EP-01: ค้นหาและเลือกหมวดบทความ

| รหัส | เงื่อนไข / การกระทำ | ผลลัพธ์ที่คาดหวัง |
|------|---------------------|-------------------|
| AC-01 | เปิดหน้ารวมบทความ Center ครั้งแรก | แสดงช่องค้นหาและตัวเลือกหมวด โดยเลือก “บทความล่าสุด” เป็นค่าเริ่มต้น |
| AC-02 | อยู่ที่หมวดเริ่มต้น “บทความล่าสุด” | แสดงบทความจากทุก Tag เรียงตามวันที่อัปเดตล่าสุดไปเก่าสุด |
| AC-03 | เลือกหมวดสาระอสังหาฯ ไลฟ์สไตล์ อัปเดตข่าวสาร รีวิว Trend อสังหาฯ วัสดุและนวัตกรรมบ้าน หรือไอเดียแบบบ้านและฟังก์ชัน | แสดงบทความที่ตรงกับหมวดที่เลือก และเรียงตามวันที่อัปเดตล่าสุดไปเก่าสุด |
| AC-04 | พิมพ์ชื่อบทความมากกว่า 1 ตัวอักษรในช่องค้นหา | ระบบเริ่มค้นหาชื่อบทความ โดยค้นจากทุกหมวด ไม่จำกัดเฉพาะ Tag ที่เลือกอยู่ |
| AC-05 | ค้นหาชื่อที่ตรงกับบทความซึ่งอยู่คนละหมวดกับ Tag ที่เลือก | บทความที่ชื่อตรงกับคำค้นยังอยู่ในผลการค้นหา แม้ไม่อยู่ในหมวดที่เลือก |
| AC-06 | พิมพ์ 1 ตัวอักษรในช่องค้นหา | ยังไม่เริ่มค้นหาตามเกณฑ์การพิมพ์มากกว่า 1 ตัวอักษร |
| AC-07 | กรอกคำค้น           | ช่องค้นหารองรับข้อความสูงสุด 200 ตัวอักษร |

### EP-02: การแสดงผลและ Pagination

| รหัส | เงื่อนไข / การกระทำ | ผลลัพธ์ที่คาดหวัง |
|------|---------------------|-------------------|
| AC-08 | แสดงรายการบทความในหมวดหรือผลการค้นหา | แสดงการ์ดบทความสูงสุด 24 ใบต่อหน้า โดยไม่นับ Banner และ Pop-up รวมใน 24 ใบ |
| AC-09 | มีบทความที่ตรงเงื่อนไข 1–24 ใบ | แสดงการ์ดตามจำนวนจริงในหน้าเดียว และไม่แสดง Pagination |
| AC-10 | มีบทความที่ตรงเงื่อนไข 25 ใบ | แสดง Pagination; หน้าแรกแสดงสูงสุด 24 ใบ และหน้าถัดไปแสดงใบที่เหลือ |
| AC-11 | มีผลลัพธ์มากกว่า 24 ใบในหมวดใดหมวดหนึ่งหรือผลการค้นหา | แสดง Pagination ให้เปลี่ยนหน้าได้ทั้งในหมวดและผลการค้นหา |
| AC-12 | ผู้ใช้กดเปลี่ยนหน้าจาก Pagination | แสดงการ์ดของหน้าที่เลือกตามชุดผลลัพธ์และลำดับปัจจุบัน โดยไม่แสดงการ์ดของหน้าก่อนซ้ำเพื่อเติมจำนวน |
| AC-13 | เปิดหน้ารวมบทความบน Desktop และ Mobile | แสดงการ์ดและ Pagination ตาม UI ของอุปกรณ์ โดยใช้เพดานการ์ด 24 ใบต่อหน้าเหมือนกัน |
| AC-14 | บทความมีรูปปกบทความ | แสดงรูปปกในการ์ด  |
| AC-15 | บทความติด Tag รีวิวและมีวิดีโอ | ใช้ภาพปกจากวิดีโอเป็นภาพปกการ์ด โดยไม่ใช้ภาพที่แสดงปุ่ม Play มาเป็นภาพปก |
| AC-16 | บทความไม่มีวิดีโอ   | ใช้ภาพปกบทความในการ์ด |
| AC-17 | การ์ดเป็นบทความ Center | ไม่แสดง Tag จังหวัดต่อท้ายบนการ์ด |
| AC-18 | บทความติด Tag รีวิว | สามารถแสดง Tag ประเภทรีวิวที่กำหนด ได้แก่ โครงการใหม่ อสังหามือสอง รับสร้างบ้าน หรือไลฟ์สไตล์ ตามข้อมูลบทความ |
| AC-19 | บทความไม่ได้ติด Tag รีวิว | ไม่แสดง Tag ชั้นประเภทรีวิว |
| AC-20 | บทความถูกสร้างและยังไม่เคยอัปเดต | วันที่อัปเดตของบทความใช้วันที่สร้างครั้งแรก |
| AC-21 | บทความถูกอัปเดตหลังสร้าง | ใช้วันที่อัปเดตล่าสุด และใช้วันที่นั้นในการเรียงรายการ |
| AC-22 | บทความมียอดเข้าชม 0–999 | แสดงจำนวนเข้าชมเป็นตัวเลขจริง เช่น 123 หรือ 999 |
| AC-23 | บทความมียอดเข้าชมตั้งแต่ 1,000 ถึงต่ำกว่า 1,000,000 | แสดงจำนวนหารด้วย 1,000 ตามด้วย K และทศนิยม 1 ตำแหน่ง โดยตัดเศษไม่ปัดขึ้น เช่น 1,000 → 1.0K และ 1,999 → 1.9K |
| AC-24 | บทความมียอดเข้าชมตั้งแต่ 1,000,000 ขึ้นไป | แสดงจำนวนหารด้วย 1,000,000 ตามด้วย M และทศนิยม 1 ตำแหน่ง โดยตัดเศษไม่ปัดขึ้น เช่น 1,000,000 → 1.0M |
| AC-25 | กดการ์ดบทความส่วนกลาง | เปิดหน้ารายละเอียดบทความในแท็บใหม่ โดยไม่เปลี่ยนจังหวัด |
| AC-26 | กดการ์ดบทความของจังหวัด | เปิดหน้ารายละเอียดบทความในแท็บใหม่ และ Navbar ในหน้าปลายทางแสดงจังหวัดของการ์ดที่กด |

### EP-03 และ EP-04: Banner / Pop-up

| รหัส | เงื่อนไข / การกระทำ | ผลลัพธ์ที่คาดหวัง |
|------|---------------------|-------------------|
| AC-27 | แสดง Banner บนหน้ารวมบทความ Center | ใช้เงื่อนไขการคัดเลือก Slot ภาษา รูปภาพ อุปกรณ์ และตำแหน่งตามเอกสาร Banner 3 ภาษา ที่หน้านี้อ้างอิง |
| AC-28 | Banner ที่แสดงมีลิงก์และผู้ใช้กด | เปิดลิงก์ของ Banner นั้นในแท็บใหม่ |
| AC-29 | หน้ารวมบทความผ่านเงื่อนไขแสดง Pop-up | ใช้เงื่อนไข Slot ภาษา อุปกรณ์ เวลา ความถี่ และ Session ตามเอกสาร Pop-up 3 ภาษา ที่หน้านี้อ้างอิง |
| AC-30 | ไม่เหลือ Pop-up ที่ผ่านเงื่อนไขหลังคัดเลือก | ไม่เปิด Pop-up โฆษณา |

### ประเด็นที่ต้องยืนยันเพิ่มเติม

| ประเด็น | รายละเอียด |
|---------|------------|
| คำค้นและการเปลี่ยนหมวด | เอกสารระบุว่าค้นหาชื่อจากทุกหมวด แต่ยังไม่ระบุผลเมื่อเปลี่ยน Tag ขณะที่มีคำค้นค้างอยู่ |
| ไม่มีผลการค้นหา | ยังไม่ระบุข้อความหรือหน้าตา Empty State |
| ข้อมูลและลำดับหลังเปลี่ยนหน้า | ตำแหน่งหน้าจอหลังเปลี่ยนหน้าและรูปแบบ URL ให้ยึด Logic กลางที่ได้รับยืนยันเพิ่มเติม |
| ภาพปกกรณีไม่มีทั้งวิดีโอและภาพปกบทความ | ยังไม่ระบุภาพสำรอง |
| Banner และ Pop-up | เงื่อนไขโดยละเอียดให้ตรวจร่วมกับเอกสาร Banner 3 ภาษา และ Pop-up 3 ภาษา ที่ลิงก์ไว้ใน EP-03 และ EP-04 |
