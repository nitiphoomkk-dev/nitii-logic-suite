**EP-03 การเก็บประวัติการแก้ไข (Change History/Audit Log)**

ระบบ Back Office ต้องมีการจัดเก็บ ประวัติการแก้ไข (Change History / Audit Log) สำหรับข้อมูลโปรไฟล์แม่และโปรไฟล์ลูกทั้งหมด (ข้อมูลอื่นๆที่ dev เห็นสมควร)

1⁠. โปรไฟล์แม่ (Master Profile): ต้องเก็บประวัติการแก้ไขทุกส่วนของโปรไฟล์แม่

2⁠. โปรไฟล์ลูก/สาขา (Branch Profile): ต้องเก็บประวัติการแก้ไขทุกส่วนของโปรไฟล์ลูก/สาขา

**ข้อมูลที่ต้องการเก็บ** 

● วันที่และเวลาการแก้ไข

● ผู้ที่ทำการแก้ไข

ปุ่มจะ disable ไว้จนกว่าจะพิมพ์อีเมลครบตามฟอร์มของอีเมล หรือ  เมื่อเลือกอีเมลแล้วเท่านั้น

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=d61e2dce-76bf-4286-8385-e0231264ed44)

1\.ไม่เคยมีในระบบ จะไม่ขึ้นอีเมลมาให้เลือกในช่องเสิร์จ โดยต้องพิมพ์อีเมลให้สำเร็จ (เช็คจากฟอร์มอีเมล)

เมื่อพิมพ์สำเร็จครบแล้ว ระบบจะแสดง ข้อมูลดังต่อไปนี้คือ ไม่พบผู้ใช้งานในระบบ  user ต้องทำการกดเลือกอีเมลนั้น แล้วแสดง ดังต่อไปนี้ (การกดปิดกากบาทเท่ากับยังทำไม่สำเร็จ) 

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=c09a28fd-5ff5-4bef-8a58-25fab4f7c59c)

เมื่อเลือกอีเมลนั้นแล้ว อีเมลนั้นจะเข้ามาอยู่ในช่องมีสถานะเป็นเลือก เมื่อกดปุ่มถัดไปแสดง modal ดังต่อไปนี้  

**step ที่ 2 เลือกสาขาให้อีเมลที่ดูแลอีเมลแม่นั้น ดังต่อไปนี้** 

เงื่อนไข ใน step นี้ไม่บังคับให้ superadmin หรือ admin เลือก สามารถกดปุ่มยืนยันผู้ดูแลได้เลย 

หาก superadmin หรือ admin ไม่ได้เลือกจะเท่ากับว่าอีเมลนั้นจะไม่สามารถเข้าสู่ระบบ console ได้ และถูกดีดออกจากระบบการทำงานในที่สุด แต่สามารถเข้าใช้งานได้ปรกติใน role user ทั่วไปบนเว็บน่าอยู่ หากเลือกสาขาที่ลง(โปรไฟล์สาขา) เท่ากับ สามารถเข้าใช้งานได้ตามปรกติ แต่อยุ่ใน role admin ที่ดูแลจังหวัดใน console เท่านั้น

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=230b3b18-3cf0-4ad4-a554-dc1fbe7810b4)

เมื่อกดปุ่มยืนยันผู้ดูแล แสดง modal ดังต่อไปนี้ 

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=018004da-b2fc-4256-98ee-79ee07c33487)

**แสดง modal ดังต่อไปนี้เมื่อเข้าเงื่อนไขหลังกดปุ่มยืนยันผู้ดูแล**

**เงื่อนไขพิเศษ ข้อจำการเชิญอีเมล  กรณีต้องการเลือกอีเมลที่ไม่เคยมีอยู่ในระบบของบริษัทนี้แล้ว กดเลือก**

การเชิญอีเมลจากทั้งสองที่ ไม่สามารถเชิญอีเมลข้ามบริษัทของคนที่ดูแลได้ จะมีการดัก logic คือ ถ้าเพิ่มอีเมลที่แอดมินบริษัท A ดูแล เพิ่มเข้าไปดูแลบริษัท B ไม่สามารถทำได้ เพื่อป้องกันการเพิ่มแอดมินข้ามบริษัทซึ่งอาจจจะเกิดจาก human error ของมนุษย์ เมื่อกดเพิ่มจะแสดง modal ดังต่อไปนี้

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=238e6b0a-dd56-495a-a6ab-8dd250719ddd)

**การแสดงลำดับ default คำตอบไว้ที่ 10** 

ใน ตัวเลือกมีแค่ 10,20  การเลือกการแสดงมีผลต่อจำนวนการแสดงแบบบ้านในใบประกาศนั้น

ถ้าเลือก 20 การแสดงผลจะแสดงแบบบ้าน 20 แบบบ้านในหน้าที่ 1  ส่งผลต่อการแสดงผลปุ่มตัวเลข หน้าที่มีอยู่ลดลงเนื่องจาก แสดงผลต่อหน้ามากขึ้น  

**การกดปุ่มเปลี่ยนหน้า จะเป็นดังต่อไปนี้** 

● กดต่อไป เท่ากับไปทีละหน้า

● กดก่อนหน้า เท่ากับ กลับไปทีละหน้า

● กดเลข 2 ตัวเลขเพจจิเนทจะเปลี่ยนเป็น 2 3 4 เป็นต้น

● ถ้ามีแค่ 3 หน้า เลข 4 จะไม่ปรากฎ 

Disabled ถ้าอยู่ที่ หน้า 1  ปุ่ม "ก่อนหน้า" ต้องถูก Disable (กดไม่ได้/เป็นสีเทา)

ถ้าอยู่ที่ หน้าสุดท้าย ปุ่ม "ต่อไป" ต้องถูก Disable
