## EP-01 วัตถุประสงค์และขอบเขต

Solution นี้ใช้แทน [Solution ก่อนหน้าที่ห้ามซ้ำข้ามจุดวาง](https://wiki.infonayoo.co/doc/solution-banner-center-DyR6xbjlZ7) สำหรับการตัดสินใจเรื่องชุด Banner บนหน้าเดียวกัน โดยยังไม่แก้เอกสารก่อนหน้า

| คำ  | ความหมาย |
|-----|----------|
| Source Slot | Banner ต้นทางหนึ่งรายการ ระบุด้วย ID จำนวนภาษาและรูป A/B ไม่เพิ่มจำนวน Source |
| ชุดของหน้า | Source Slot ที่เลือกไว้ร่วมกันเพื่อใช้ในทุกจุดวางของหน้าปัจจุบัน |
| จุดวาง | Carousel บน กลาง หรือล่างตามหน้าที่กำหนด หนึ่งจุดวางรองรับสูงสุด 3 Source Slot |

## EP-02 Logic การแสดงผล

ในตารางนี้ **Source** หมายถึง Banner ต้นทาง 1 รายการ และ **จุดวาง** หมายถึงตำแหน่ง Carousel บนหน้า Center

| รหัส | กรณี | การแสดงผล |
|------|------|-----------|
| BN-SAME-01 | เลือก Banner ที่ใช้ได้ | ตรวจ Banner จากทุกจังหวัดว่าเปิดใช้งาน อยู่ในช่วงเวลา มีสิทธิ์แสดงครบทุกจุด และมีภาพสำหรับภาษาและอุปกรณ์ที่ใช้ ตัด Banner ประเภทน่าอยู่ออก |
| BN-SAME-02 | เลือกชุด Banner ของหน้า | สุ่มเลือก Source ที่ผ่านเงื่อนไขสูงสุด 3 รายการเป็นชุดของหน้านั้น Source ที่มีหลายภาษาหรือภาพ A/B ยังนับเป็น 1 รายการ |
| BN-SAME-03 | แสดงหลายจุดบนหน้าเดียวกัน | ทุกจุดใช้ Source ชุดเดียวกัน เช่น จุดบนและจุดล่างต่างแสดง A, B, C ครบชุด |
| BN-SAME-04 | เรียง Banner ในแต่ละจุด | สุ่มลำดับ Source แยกแต่ละจุด ลำดับอาจต่างกันหรือบังเอิญเหมือนกันได้ |
| BN-SAME-05 | มี Banner ไม่ครบ 3 รายการ | มี 2 รายการก็แสดง 2; มี 1 ก็แสดง 1; ไม่มีเลยก็ไม่แสดง Carousel ไม่เพิ่มรายการซ้ำเพื่อให้ครบ 3 |
| BN-SAME-06 | เลือกภาพตามภาษาและอุปกรณ์ | ใช้ภาพภาษาที่ผู้ใช้เลือกสำหรับอุปกรณ์ที่ใช้อยู่ ถ้าไม่มีให้ใช้ภาพไทยของอุปกรณ์เดียวกัน ถ้าไม่มีทั้งคู่เพราะข้อมูลผิดปกติ จะไม่เลือก Source นั้นและใช้ Source อื่นที่ผ่านเงื่อนไขแทน |
| BN-SAME-07 | Source มีภาพ A/B | สุ่มเลือกภาพ A หรือ B หนึ่งภาพต่อ Source ตามกฎ A/B เดิม แล้วใช้ภาพนั้นเหมือนกันทุกจุด การสุ่มภาพนี้แยกจากการ Shuffle ลำดับ Source |
| BN-SAME-08 | Banner เลื่อนเองหรือวนกลับ | เลื่อนไปภาพถัดไปทุก 4 วินาที เมื่อวนกลับให้ใช้ชุด ลำดับ และภาพเดิมของจุดนั้น ไม่สุ่มใหม่ |
| BN-SAME-09 | ผู้ใช้ Refresh หน้า | ตรวจ Banner และเลือกชุดของหน้าใหม่ แล้วสุ่มลำดับแยกจุด ผลอาจบังเอิญเหมือนก่อน Refresh |
| BN-SAME-10 | ผู้ใช้เปลี่ยนภาษา | ตรวจ Source และภาพของภาษาใหม่ตาม AC-BN17 จัดชุดของหน้าใหม่ แล้วสุ่มลำดับแยกจุด ทุกจุดยังใช้ชุดเดียวกัน |
| BN-SAME-11 | ผู้ใช้เปลี่ยนหน้าผลลัพธ์ | ถ้าเงื่อนไขไม่เปลี่ยน ให้ใช้ Source ชุดที่จัดไว้ของหน้าที่ไป แล้วสุ่มลำดับใหม่แยกแต่ละจุด ผลอาจบังเอิญเหมือนเดิม |
| BN-SAME-12 | ขนาดภาพและลิงก์ | ใช้ภาพ Desktop 2544×636 px หรือ Mobile 900×378 px ถ้า Banner มีลิงก์ เมื่อคลิกให้เปิดในแท็บใหม่ |
| BN-SAME-13 | ผู้ใช้เปลี่ยน Filter / Sort | คงชุด Source ลำดับ และภาพ Banner เดิม ไม่จัดชุดหรือ Shuffle ใหม่เพราะ Filter / Sort เพียงอย่างเดียว; หากกดเปลี่ยนหน้าผลลัพธ์ ให้ใช้ BN-SAME-11 |

## EP-06 ข้อสรุปที่ยืนยันแล้ว

1\. หากสิทธิ์ Banner ต่างกันแต่ละจุด ให้ใช้เฉพาะ Source ที่มีสิทธิ์แสดงได้ครบทุกจุดวางของหน้าปัจจุบันเป็นชุดร่วม จำนวน Source ที่แสดงจึงอาจเหลือน้อยกว่า 3 รายการ

## EP-07 Logic การจัดชุดและการแสดงผลแต่ละจุดอย่างละเอียด

**หลักที่ยืนยันแล้ว:** ในหนึ่งหน้าผลลัพธ์ ทุกจุดวางใช้ **ชุด Source Slot เดียวกัน** ส่วนลำดับภายใน Carousel ของแต่ละจุดให้ Shuffle แยกกัน โดยสามารถได้ลำดับเหมือนกันได้

| ลำดับ | ขั้นตอน | การทำงาน |
|-------|---------|----------|
| 1     | คัด Banner ต้นทาง | ตรวจประเภท จังหวัด สถานะ ระยะเวลา ภาษาและไฟล์ของอุปกรณ์ ตามเงื่อนไข Banner Center เดิม แล้วคัดเฉพาะ Source ที่มีสิทธิ์ครบทุกจุดวางของหน้านั้น |
| 2     | เลือกชุดของหน้า | Shuffle รายการที่ผ่านเงื่อนไขและเลือกสูงสุด 3 Source Slot เป็นชุดร่วมของหน้าปัจจุบัน |
| 3     | กระจายชุด | ส่งชุด Source Slot เดียวกันไปยังทุกจุดวางของหน้านั้น |
| 4     | Shuffle ลำดับ | แต่ละจุด Shuffle ลำดับ Source ภายในชุดของตัวเองอย่างอิสระ ผลอาจเหมือนกันหรือต่างกัน |
| 5     | เลือกภาพ | แสดงภาพตามภาษาและอุปกรณ์ เลือกภาพ A หรือ B หนึ่งภาพต่อ Source ตามกลไกเดิม แล้วใช้ภาพนั้นเหมือนกันทุกจุดวาง |
| 6     | เลื่อน Carousel | เลื่อนทุก 4 วินาทีและวนด้วยลำดับและภาพที่จุดนั้นเลือกไว้ ไม่สุ่มใหม่เพราะ Auto Slide |

**กฎสิทธิ์ข้ามจุดวาง:** หากสิทธิ์ต่างกันตามจุด ให้คัด Source ที่แสดงได้ครบทุกจุดวางของหน้านั้นก่อนเลือกชุดร่วม Source ที่แสดงได้เพียงบางจุดไม่เข้าชุด จึงอาจมีไม่ครบ 3 รายการ

### 7.1 จำลองหน้าเดียวกันมี 2 จุดวาง

สมมติหน้าปัจจุบันคัด Banner ต้นทางได้ **Source A และ Source B** และทั้งคู่ผ่านสิทธิ์ทุกจุด:

| จุดวาง | ผล Shuffle ที่เป็นไปได้ | ลำดับ Carousel |
|--------|-------------------------|----------------|
| จุดบน  | A → B                   | แสดง A แล้วเลื่อนไป B |
| จุดล่าง | B → A                   | แสดง B แล้วเลื่อนไป A |

เมื่อครบวงรอบ แต่ละจุดกลับไปภาพแรกของ **ลำดับเดิมของจุดนั้น** โดยไม่สุ่มชุดใหม่ ลำดับบน A → B และล่าง A → B ก็เป็นผล Shuffle ที่ถูกต้องเช่นกัน

| เวลาตัวอย่าง | จุดบน | จุดล่าง |
|--------------|-------|---------|
| 0 วินาที     | A     | B       |
| 4 วินาที     | B     | A       |
| 8 วินาที     | A ภาพเดิมของจุดบน | B ภาพเดิมของจุดล่าง |

ตารางเวลาเป็นตัวอย่างกรณีเริ่ม Carousel พร้อมกัน ไม่ได้กำหนดให้ทุกจุดต้องเริ่มหรือเลื่อนพร้อมกัน

### 7.2 จำนวน Source ที่ใช้ได้

| Source ที่เข้าเงื่อนไข | ชุดที่ใช้ในหน้า | การแสดงผลแต่ละจุด |
|------------------------|-----------------|-------------------|
| 5 รายการ A B C D E     | ตัวอย่างสุ่มได้ A C E | ทุกจุดใช้ A C E แล้ว Shuffle ลำดับแยกกัน |
| 2 รายการ A B           | A B             | ทุกจุดใช้ A และ B |
| 1 รายการ A             | A               | ทุกจุดใช้ A หนึ่งรายการ |
| 0 รายการ               | ไม่มี           | ไม่แสดง Carousel  |

ชุดหนึ่งจุดวางสูงสุด 3 Source; ไม่แปลว่าภาพจาก 3 Source ต้องแสดงเต็มพร้อมกัน ให้ยึด UI เดิม

## EP-08 ภาษา อุปกรณ์ และภาพสำรอง

ตรวจภาษาและไฟล์ **แยกตาม Source Slot และอุปกรณ์ที่ผู้ใช้กำลังใช้งาน** ก่อนนำ Source เข้าชุดของหน้า

| ภาษาหน้าเว็บ | ภาพที่ Source มีสำหรับอุปกรณ์นั้น | ภาพที่ใช้ได้ |
|--------------|-----------------------------------|--------------|
| ไทย          | ไทย A/B                           | ไทย A หรือไทย B ตามกลไกเลือกภาพเดิม |
| อังกฤษ       | อังกฤษ A/B และไทย A/B             | อังกฤษ A หรืออังกฤษ B |
| อังกฤษ       | ไม่มีอังกฤษ แต่มีไทย A/B          | ไทย A หรือไทย B ของ Source เดิม |
| จีน          | ไม่มีจีน แต่มีไทย A/B             | ไทย A หรือไทย B ของ Source เดิม |
| จีน          | มีจีน A เพียงภาพเดียว และไทย A/B  | ใช้จีน A ภาพเดียว ไม่ดึงภาพไทยมาเติม B |
| อังกฤษ       | มีจีนและไทย แต่ไม่มีอังกฤษ        | ใช้ภาพไทยสำรอง ไม่ใช้ภาพจีนแทนอังกฤษ |
| ภาษาใดก็ได้  | มีแต่ไฟล์ Desktop แต่กำลังใช้ Mobile | ไม่ใช้ไฟล์ Desktop แทน ต้องตรวจไฟล์ภาษาและไทยสำรองของ Mobile |

ภาพไทยสำรองเป็นภาพของ **Source เดิม** ไม่เปลี่ยนภาษาเว็บไซต์ ไม่เพิ่มจำนวน Source และไม่ใช้ภาษาอังกฤษแทนจีนหรือจีนแทนอังกฤษ ภาพ A/B เป็นทางเลือกภายใน Source ไม่ใช่ Source ใหม่

### 8.1 จำลองผู้ใช้เลือกภาษาอังกฤษบน Mobile

สมมติ Source ทุกแถวมีสิทธิ์ใช้ในทุกจุดวาง และตรวจเฉพาะไฟล์ Mobile:

| Source | ไฟล์ Mobile ที่มี | ภาพที่ใช้ได้ | เข้าชุด |
|--------|-------------------|--------------|---------|
| A      | ไทย A/B และอังกฤษ A/B | อังกฤษ A หรือ B | ได้     |
| B      | ไทย A/B ไม่มีอังกฤษ | ไทย A หรือ B สำรอง | ได้     |
| C      | อังกฤษ A ภาพเดียว และไทย A/B | อังกฤษ A     | ได้     |
| D      | ไทย A/B และจีน A/B ไม่มีอังกฤษ | ไทย A หรือ B สำรอง | ได้     |

หากเลือกชุดหน้าเป็น A B C ตัวอย่างลำดับจุดบน **A → B → C** และจุดล่าง **C → A → B**: A ใช้ภาพอังกฤษ, B ใช้ภาพไทยสำรอง, C ใช้อังกฤษ A ดังนั้นหน้าเว็บภาษาอังกฤษอาจแสดงทั้งภาพอังกฤษและภาพไทยสำรองใน Carousel เดียวกันได้ เพราะตรวจภาษาภาพแยกตาม Source การ Shuffle เลือกและเรียง Source ไม่ได้สุ่มภาษาไทยหรืออังกฤษของ Source นั้น ทุกจุดมี Source ชุดเดียวกันและใช้ภาพ A/B เดียวกันต่อ Source แม้ลำดับ Source ต่างกัน

### 8.2 เมื่อเปลี่ยนภาษา

| เหตุการณ์ | การทำงาน |
|-----------|----------|
| ไทย → อังกฤษ | ประเมินภาพอังกฤษหรือไทยสำรองของทุก Source อีกครั้ง แล้วจัดชุดหน้ากับ Shuffle แต่ละจุดใหม่ |
| อังกฤษ → จีน | ประเมินภาพจีนหรือไทยสำรองอีกครั้ง แล้วจัดชุดหน้ากับ Shuffle แต่ละจุดใหม่ |
| ผล Shuffle ใหม่ | ชุดหรือลำดับอาจเหมือนเดิมหรือต่างจากเดิมได้ แต่ทุกจุดในชุดใหม่ต้องใช้ Source ชุดเดียวกัน |
| ระหว่างภาษาใหม่กำลังโหลด | ผลที่แสดงต้องตรงภาษาล่าสุดหรือไทยสำรองตามกฎ ไม่ให้ผลคำขอภาษาเก่าทับภาษาใหม่ |

การเปลี่ยนภาษาไม่ใช่การเพิ่ม Source ตามจำนวนภาษา และไม่ถือว่าต้องรีเซ็ตสถิติหรือข้อมูลต้นทางของ Banner

## EP-11 ตารางเลือกภาพตามภาษาและอุปกรณ์

ตรวจ **ทีละ Source** โดยดูเฉพาะภาพที่ใช้ได้บนอุปกรณ์ของผู้ใช้ในขณะนั้น เช่น ใช้ Mobile ก็ตรวจภาพ Mobile เท่านั้น

| ขั้น | ตรวจภาพของ Source บนอุปกรณ์ที่ใช้ | ผล  |
|-----:|-----------------------------------|-----|
| 1    | มีภาพภาษาที่ผู้ใช้เลือกหรือไม่    | ถ้ามี ให้ใช้ภาษานั้น แล้วเลือกภาพ A หรือ B จากภาพที่มี |
| 2    | ถ้าไม่มีภาพภาษาที่เลือก มีภาพไทยหรือไม่ | ถ้ามี ให้ใช้ภาพไทยสำรองของ Source เดิม แล้วเลือก A หรือ B จากภาพที่มี |
| 3    | ถ้าไม่มีทั้งภาพภาษาที่เลือกและภาพไทย (กรณีข้อมูลผิดปกติ) | ไม่เลือก Source นี้มาแสดง แล้วเลือก Source อื่นที่ผ่านเงื่อนไขแทนถ้ามี |

| กรณีที่อาจสับสน | วิธีแสดง |
|-----------------|----------|
| ภาษาที่เลือกมีภาพเดียว เช่น มีแค่ A | ใช้ภาพ A ทุกครั้ง ไม่ดึงภาพไทย B หรือภาษาอื่นมาเติม |
| มีภาพภาษาที่เลือกเฉพาะอุปกรณ์อีกชนิด เช่น มี Desktop แต่ผู้ใช้เปิด Mobile | ไม่ข้ามไปใช้ภาพ Desktop ให้ตรวจภาพไทย Mobile ตามขั้น 2 |
| ไม่มีภาษาที่เลือก แต่มีภาษาอื่น เช่น เลือกจีนแต่ Source มีอังกฤษกับไทย | ไม่ใช้ภาพอังกฤษแทนจีน ให้ใช้ภาพไทยสำรองตามขั้น 2 |

**ข้อมูลที่ยืนยันแล้ว:** การอัปโหลด Banner บังคับภาพภาษาไทยทั้ง Desktop และ Mobile กรณีไม่มีภาพไทยในขั้น 3 จึงเป็นการรองรับข้อมูลผิดปกติ ไม่ใช่กรณีปกติของการสร้าง Banner

**ตัวอย่าง:** หน้าเว็บภาษาอังกฤษอาจแสดงภาพอังกฤษของ Source A และภาพไทยสำรองของ Source B ใน Carousel เดียวกันได้ เพราะตรวจภาษาแยกทีละ Source การ Shuffle เลือกและเรียง Source ไม่ได้สุ่มเลือกภาษาภาพ


### 11.1 ตัวอย่างเปลี่ยนภาษา

สมมติ A มีไทย/อังกฤษ, B มีไทยอย่างเดียว และ C มีไทย/จีน โดยทุกภาพที่กล่าวถึงมีไฟล์ตรงอุปกรณ์:

**เมื่อกดเปลี่ยนหน้าผลลัพธ์ ให้คงสมาชิก Banner Source ที่จัดไว้ของหน้าปลายทางเมื่อเงื่อนไขไม่เปลี่ยน แล้ว Shuffle ลำดับใหม่แยกแต่ละจุดวาง ทุกจุดในหน้าปลายทางยังใช้ Source ชุดเดียวกันและภาพ A/B เดียวกันต่อ Source ผลลำดับอาจเหมือนเดิมได้ ไม่ถือว่าการเปลี่ยนหน้าเป็น Refresh ทั้งระบบ**
