**EP-05 การใช้ปุ่ม pageginate** 

 ![](/api/attachments.redirect?id=bb58bb75-f590-4bfa-9330-2ec86fbc814b)

**การแสดงลำดับ default คำตอบไว้ที่ 10** 

ใน ตัวเลือกมีแค่ 10,15,20  การเลือกการแสดงมีผลต่อจำนวนการแสดงแบบบ้านในใบประกาศนั้น

ถ้าเลือก 20 การแสดงผลจะแสดงแบบบ้าน 20 แบบบ้านในหน้าที่ 1  ส่งผลต่อการแสดงผลปุ่มตัวเลข หน้าที่มีอยู่ลดลงเนื่องจาก แสดงผลต่อหน้ามากขึ้น  

**การกดปุ่มเปลี่ยนหน้า จะเป็นดังต่อไปนี้** 

● กดต่อไป เท่ากับไปทีละหน้า

● กดก่อนหน้า เท่ากับ กลับไปทีละหน้า

● กดเลข 2 ตัวเลขเพจจิเนทจะเปลี่ยนเป็น 2 3 4 เป็นต้น

● ถ้ามีแค่ 3 หน้า เลข 4 จะไม่ปรากฎ 

Disabled ถ้าอยู่ที่ หน้า 1  ปุ่ม "ก่อนหน้า" ต้องถูก Disable (กดไม่ได้/เป็นสีเทา)

ถ้าอยู่ที่ หน้าสุดท้าย ปุ่ม "ต่อไป" ต้องถูก Disable

**EP-06 export ข้อมูล**

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=32bfb595-41dc-4bf2-9b81-fdabb4ee98fe)

**เมื่อกดปุ่ม export  แสดง modal ดังต่อไปนี้** 

 ![](/api/attachments.redirect?id=c4cf9530-7559-47fd-ae77-81bf1801f133)

แสดงค่าเริ่มต้น เป็น ทั้งหมด disable ช่องเลือกวันที่เริ่มต้นและสิ้นสุด ไม่สามารถเลือกช่องเลขกำหนดวันในปฎิทินได้ 

⁠ user super admin,admin สามารถกดปุ่ม export ได้เลยเมื่อกดแล้วจะดาวน์โหลดอัตโนมัติ 

หากเลือกตามวันที่อัปเดต จะ default วันที่สิ้นสุดให้เป็นวันที่ปัจจุบัน ไม่สามารถเลือกเกินวันที่ปัจจุบันได้ จะ disable ปุ่มการเลือกวันที่เกินไว้  และ user กำหนดวันที่เริ่มต้นเอง

 เงื่อนไข ถ้าไม่เลือกวันที่เริ่มต้นและสิ้นสุดจะไม่สามารถกดปุ่ม export ได้ disable ปุ่ม

**Export ข้อมูลเป็น.csv ชื่อไฟล์ตั้งตามหัวข้อฟีเจอร์นั้น พร้อมวันที่ดาวน์โหลด(DD/MM/YYYY)**

**โดยดึงข้อมูลแต่ละอย่างออกมาเป็น column ดังต่อไปนี้**

\- ชื่อทรัพย์

\- ID 

\- ชื่อเจ้าของทรัพย์

\- ประเภทผู้ใช้ของเจ้าของทรัพย์ (นายหน้าอิสระ, ผู้ใช้ทั่วไป, นายหน้าบริษัท, NPA)

\- ราคาขาย

\- ราคาเช่า \*กรณีเลือกเช่าด้วย

\- วันที่ create

\- วันที่ update

\- วันที่หมดอายุประกาศ

\- สถานะประกาศ

การ export ข้อมูล เมื่อกดปุ่มแล้วจะทำการดาวโหลน์อัตโนมัติ ในการดาวน์โหลดและแสดง modal ดังต่อไปนี้ 4 วินาทีแล้วหายไปอัตโนมัติ
