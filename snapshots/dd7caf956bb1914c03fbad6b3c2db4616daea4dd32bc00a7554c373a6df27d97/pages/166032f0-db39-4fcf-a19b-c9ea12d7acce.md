> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/property-for-sale/agent-detail/{จังหวัด}/{uuid}` เช่น `/property-for-sale/agent-detail/khonkaen/{ชื่อ}-{id}`

**ไฟล์หน้า:** `app/(interface)/(post-and-profile)/detail/property-for-sale/agent-detail/[location]/[uuid]/page.tsx` (TrackingProvider อยู่ใน `layout.tsx` ระดับเดียวกัน)

**TrackingProvider:** `source_type: agent`, `source_id` = id ตัวแทน (ตัวเลขท้าย uuid) และตั้ง `entity_id` = id ตัวแทน เป็นค่าเริ่มต้นของทุก event ที่ไม่ได้ใส่ entity_id เอง

หน้าย่อยใช้ layout เดียวกัน จึงได้ `page_view` และ provider ชุดเดียวกัน

* `/page/{N}` = หน้าถัดไปของแท็บประกาศขาย tracking เหมือนหน้าหลัก ต่างแค่ position ของการ์ดใน #11 นับต่อจากหน้าก่อน
* `/portfolio` และ `/review` (และ `/page/{N}` ของทั้งสอง) แสดงแค่ #1, #3, #4, รายการผลงานหรือรีวิว (ไม่มี tracking) และ #13 ต่างจากหน้าหลักคือ #4 ไม่มีปุ่มแชร์ จึงไม่มี `share` และเมนูแชร์, ⚠️ ลิงก์ที่ 2 ของ breadcrumb เป็น `#` (destination = `#`)

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
