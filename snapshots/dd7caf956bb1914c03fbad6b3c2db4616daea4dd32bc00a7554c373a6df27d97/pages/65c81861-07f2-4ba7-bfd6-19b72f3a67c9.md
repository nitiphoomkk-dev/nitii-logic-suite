## ฟิลด์ attribution ใน Lead body

ทุก Lead request แนบฟิลด์เหล่านี้มาด้วย ฟิลด์ไหนไม่มีค่าก็ไม่ส่ง และไม่ทำให้ lead fail

| field | ค่า |
|-------|-----|
| `section` | `section_name` ของจุดที่เปิดหรือถือฟอร์ม ใช้ชุดค่าเดียวกับ tracking (`TRACKING_SECTION` ใน `constant/tracking.ts`) |
| `button_label` | text ของปุ่มที่เปิดฟอร์ม ถ้าเป็นฟอร์มในหน้า ใช้ text ปุ่มส่งของฟอร์ม |
| `url` | `window.location.pathname` ตอนส่ง ค่าเดียวกับ tracking `page.source` — ยกเว้นหน้า `/register-interest` ส่ง path + query ทั้งหมด (ดูด้านล่าง) |
| `marketing_link_key` | Link Studio key ที่ active อยู่ตอนส่ง |

ลำดับการเลือก `section`: ใช้ค่าจากปุ่มที่เปิดฟอร์มก่อน ถ้าไม่มีจึงใช้ section ของฟอร์มเอง ทุกฟอร์มบนหน้าแคมเปญ Landing จึงส่ง `section` เสมอ ไม่มีกรณีว่าง

> Lead body ไม่ใช่ tracking event — event ของฟอร์ม (`campaign_registration_form` / `_start` / `_consent` / `_submit` / `_success` / `_error`) ใช้ section ของฟอร์มเอง จึงอาจไม่ตรงกับ `section` ใน lead body ดูคอลัมน์ "event ฟอร์ม"

## หน้า `/register-interest` 🕒

**Query ที่ปุ่มทางเข้าแนบมา**

| query | ค่า |
|-------|-----|
| `source` | `LeadSource` ของปุ่ม เช่น `campaignLanding`, `direct` |
| `from` | path ของหน้าที่มีปุ่ม โดยแทน `/` ด้วย `_` เช่น `/property-project/properties/phitsanulok` → `property-project_properties_phitsanulok` (ลิงก์เก่าที่ส่ง `LeadSource` ใน `from` ยังใช้ได้) |
| `section` | section ของปุ่ม → ใช้เป็น lead `section` |
| `back` | path ที่ปุ่มกลับในหน้าสำเร็จจะพากลับไป |
| `campaign_id`, `category`, `deal_*` | context ของ lead |

**Lead body**

* `section` = `?section=` — รับเฉพาะค่าที่มีใน `TRACKING_SECTION` ค่าอื่น (เช่นแก้ URL เอง) จะถูกทิ้ง ไม่มี `?section=` → `register_interest_lead_section`
* `url` = path + query ทั้งหมด เช่น `/register-interest/phitsanulok?from=…&section=…&source=campaignLanding&campaign_id=…&back=…`
* tracking event ของฟอร์มในหน้านี้ยังเป็น `register_interest_lead_section` ทั้งหมด

**ทางเข้าจากหน้าอื่น** — ปุ่มแบนเนอร์แคมเปญ (`CampaignRegisterInterestButton`) แนบ `sectionName` ของปุ่มเป็น `?section=` ด้วย เช่น หน้า Home → `home_campaign_section`, หน้ารายละเอียดใบประกาศ → `post_campaign_recommendations_section`, แบนเนอร์หน้าค้นหา → `search_campaign_section` (ค่าเริ่มต้น)
