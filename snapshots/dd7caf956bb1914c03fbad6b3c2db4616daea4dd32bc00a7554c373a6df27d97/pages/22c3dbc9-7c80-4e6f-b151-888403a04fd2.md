### **EP-01.1 Filter Bar**

หน้ามือสอง Back Office มี Filter **5 ปุ่ม** เรียงแนวนอน ต่างจากโครงการใหม่ที่ไม่มีปุ่ม "จังหวัด" แยกต่างหาก แต่เพิ่ม "นายหน้า/ทรัพย์" และ "ประเภททรัพย์" และ "ราคา" เข้ามาแทน

 ![](/api/attachments.redirect?id=054f5eb4-4e9a-491c-8903-179379406bc4)

**“นายหน้า/ทรัพย์”**  ![](/api/attachments.redirect?id=e935d3f8-1ed7-4436-9a66-431dbd9d3571)

**กรณียังไม่กด** ปุ่มแสดงข้อความ "นายหน้า/ทรัพย์" พร้อมลูกศร ▼ ไม่กรองข้อมูล

**กรณีกดเปิด** เปิด Drop Down แสดงตัวเลือกหลัก ได้แก่

 ![](/api/attachments.redirect?id=b45ce474-43ae-4f83-b9dd-1146d0c99f1a) ![](/api/attachments.redirect?id=847b84e2-3517-4c87-91c1-7e6bf07f336c) ![](/api/attachments.redirect?id=30905ad4-86d8-4110-836e-ee6604a00045) ![](/api/attachments.redirect?id=c276693a-367a-45d8-a2c0-b8245a500ff9)

| **ตัวเลือก** | **การทำงาน** |
|----------|----------|
| ทั้งหมด  | ไม่กรอง แสดงข้อมูลทั้งหมด (Default) |
| สถาบันทั้งหมด | กรองเฉพาะ Lead ที่มาจากโปรไฟล์สถาบัน |
| สถาบัน (ระบุเอง) | ขยาย Search Box และรายชื่อสถาบันให้เลือก พร้อมปุ่มค้นหา เลือกได้ 1 รายการ (Single-select) |
| นายหน้าทั้งหมด | กรองเฉพาะ Lead ที่มาจากโปรไฟล์นายหน้า ไม่ใช่ทรัพย์เฉพาะเจาะจง |
| นายหน้า (ระบุเอง) | ขยาย Search Box และรายชื่อนายหน้าให้เลือก พร้อมปุ่มค้นหา เลือกได้ 1 รายการ (Single-select) |
| ทรัพย์ทั้งหมด | กรองเฉพาะ Lead ที่มาจากทรัพย์ที่ลงประกาศไว้ |
| ทรัพย์ (ระบุเอง) | ขยาย Search Box และรายชื่อทรัพย์ให้เลือก พร้อมปุ่มค้นหา เลือกได้ 1 รายการ (Single-select) |

ค่าเริ่มต้นจะเลือก "ทั้งหมด" หากต้องการกรองให้เลือกตัวเลือกที่ต้องการ ด้านล่าง Dropdown มีปุ่ม "ล้างข้อมูล" เพื่อ Reset กลับ Default และปุ่ม "ค้นหา" เพื่อกรองข้อมูลทันที

**กรณีเลือกแล้ว**

ปุ่มแสดงชื่อที่เลือก เช่น "โปรไฟล์นายหน้า" หรือ "โปรไฟล์สถาบัน" หรือชื่อทรัพย์ และกรองรายการเฉพาะ Lead ที่มาจากนายหน้า สถาบัน หรือทรัพย์นั้น

**EP-01.2 “ประเภททรัพย์”**\nกรณีที่ยังไม่กดตัวกรอง แสดงข้อความ "ประเภททรัพย์" เป็น Placeholder ไม่กรองข้อมูล

 ![](/api/attachments.redirect?id=5cb9e1d9-6312-4674-9ece-99f305070dcc)

#### **Dropdown "ประเภททรัพย์" (มีเฉพาะมือ 2)**

**กรณียังไม่กด** ปุ่มแสดงข้อความ "ประเภททรัพย์" ไม่กรองข้อมูล

**กรณีกดเปิด** เปิด Dropdown แสดงรายการประเภททรัพย์ที่มีในระบบ แต่ละตัวแสดงจำนวนในวงเล็บ เลือกได้มากกว่า 1 ตัว (Multi-select)

| **ตัวเลือก** | **จำนวนที่แสดง** |
|----------|--------------|
| ทั้งหมด  | รวมทุกประเภท (Default) |
| บ้าน     | มีสินทรัทย์ประเภทบ้านที่จะแสดง |
| ที่ดิน   | มีสินทรัทย์ประเภทที่ดินที่จะแสดง |
| คอนโด    | มีสินทรัทย์ประเภทคอนโดที่จะแสดง |
| ทาวน์โฮม | มีสินทรัทย์ประเภททาวน์โฮมที่จะแสดง |
| อาคารพาณิชย์/สำนักงาน | มีสินทรัทย์ประเภทอาคารพาณิชย์/สำนักงานที่จะแสดง |
| หอพัก/อพาร์ทเม้นท์ | มีสินทรัทย์ประเภทหอพัก/อพาร์ทเม้นท์ที่จะแสดง |
| อื่นๆ    | มีสินทรัทย์ประเภทอื่นๆที่จะแสดง |

ด้านล่าง Dropdown มีปุ่ม "ล้างข้อมูล" และ "ค้นหา"

**กรณีเลือกแล้ว**

* กรองตารางเฉพาะ Lead ที่สนใจทรัพย์ประเภทนั้น
* กด "ล้างข้อมูล" → กลับ Default
* กด "ค้นหา" → ตารางอัปเดตทันที

#### **EP-01.3 การฟีลเตอร์ราคา**

 ![](/api/attachments.redirect?id=14089f69-18a4-495c-aba2-62cae0f58718)

กรณีกดเปิด เปิด Dropdown แสดง 2 ส่วน ได้แก่

**ส่วนที่ 1 — Input ราคา**

 ![](/api/attachments.redirect?id=0c809749-96ea-4909-b2f5-d9ee5eaf2fad) ![](/api/attachments.redirect?id=eee8fc3c-ad98-4f08-b751-28b3acb68db3) ![](/api/attachments.redirect?id=42fadf45-3e52-4759-9aa4-fe749fbe57c2)

| **ช่อง** | **การทำงาน** |
|------|----------|
| ราคาต่ำสุด (บาท) | กรองข้อมูลที่ราคา >= ค่าที่กรอก |
| ราคาสูงสุด (บาท) | กรองข้อมูลที่ราคา <= ค่าที่กรอก |

* กรอกเฉพาะราคาต่ำสุด → กรองข้อมูลที่ราคามากกว่าหรือเท่ากับค่าที่กรอก
* กรอกเฉพาะราคาสูงสุด → กรองข้อมูลที่ราคาน้อยกว่าหรือเท่ากับค่าที่กรอก
* กรอกทั้งสองช่อง → กรองเฉพาะข้อมูลที่ราคาอยู่ในช่วงนั้น
* ไม่กรอกเลย → ไม่กรองราคา
* หากราคาต่ำสุดมากกว่าราคาสูงสุด → แสดง Error

 ![](/api/attachments.redirect?id=8c457da9-8b43-47ac-bf88-97665745560c)

  * Walk - in เช่น Walk - in
  * Note เช่น ลูกค้ารับปากแล้วว่าจองแน่ ๆ 100%
  * รายละเอียดสถานะ เช่น โทร
  * ชื่อผู้บันทึก เช่น น้องแพนเค้ก
