1\.แบบบ้านในโครงการ

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=2f6f839e-2da8-4f48-9ca1-a88d70d9517e)

Default ค่าแบบบ้านในการแสดงผลของมือ 1 ที่ แบบบ้านในโครงการ

มีทั้งหมด 3 แท็บ 

● แบบบ้านในโครงการ

⁠ ○ สามารถกดดูรูปภาพแล้วแสดงเป็น modal ของแบบบ้านนั้น

⁠ ○ สามารถกดเลื่อนภาพซ้ายได้ เมื่อเลื่อนภาพขวาไปแล้ว ภาพจะค้างไว้ตามภาพที่ user เลื่อน

● มือสองในโครงการ

● ปล่อยเช่าในโครงการ

● Default 4 แบบบ้าน และหากต้องการแบบบ้านอื่นๆ ให้กด take แบบบ้านออกมาดูเพิ่มเติมได้ take หมดใน1 ครั้ง 

● จะแสดงทั้ง 3 แท็บให้ user เห็น หากไม่มีข้อมูลที่อ้างอิงมาจากใบประกาศอื่นๆ จะเป็นสีเทาพร้อมเลข 0 disable แท็บการแสดงผล ไม่สามารถกดได้

● การ์ดแบบบ้าน แสดงผลตามการเรียงลำดับโดย user หากแบบบ้านนั้น ขายหมด จะแสดงในลำดับท้ายสุด คือมุมขวาล่างไล่ไปทางซ้ายมือ
