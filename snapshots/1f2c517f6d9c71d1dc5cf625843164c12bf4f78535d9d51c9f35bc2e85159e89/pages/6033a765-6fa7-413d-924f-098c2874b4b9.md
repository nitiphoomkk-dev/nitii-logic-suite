## ผลตรวจ dev API ทุก endpoint (บ่าย 2026-10-19)

ยิง `GET` ทุกเส้นที่อยู่ในไฟล์หลักกับ dev ([`https://dev-api.np-nayoo.co`](https://dev-api.np-nayoo.co), header `province: 6` ขอนแก่น ถ้าไม่ระบุอื่น) และกวาดทุก response หาฟิลด์ข้อความที่ยังส่งเป็น string ไทย เส้น `POST` / `PATCH` และเส้นที่ต้อง login ไม่ได้ยิง หัวข้อนี้บอกว่า **endpoint ไหนยังค้าง และต้องส่งเป็นอะไร**

### สรุป

* **ทุกฟิลด์ข้อความที่ผู้ใช้เห็นต้องส่งเป็น** `**{ th, en, zh }**` ห้ามส่ง string ตรง ๆ ตารางข้อ B คือฟิลด์ที่ยังเป็น string ทั้งหมดที่ตรวจเจอ ขอให้เปลี่ยนทุกแถว
* เกือบทุกฟิลด์อื่นเป็น object แล้ว แต่ส่วนใหญ่ `en` / `zh` เป็นข้อความไทยที่ copy มาจาก `th` หน้า `/en` `/zh` จึงยังแสดงไทย
* แบ่ง 4 กลุ่ม เรียงตามลำดับที่ขอให้ทำ
  * **A. ข้อมูลผิด:** แก้ก่อน เพราะ `/zh` แสดงคำผิด หรือ FE กรองข้อมูลผิด
  * **B. ยังส่งเป็น string:** ต้องเปลี่ยนเป็น `{ th, en, zh }` ทุกแถว ดูคอลัมน์ "FE รองรับแล้ว" ว่า deploy ได้เมื่อไหร่
  * **C. object ที่ขาด key:** เติม `en` / `zh` ที่ขาด
  * **D. key ครบแต่** `**en**` **/** `**zh**` **เป็นไทยที่ copy มา:** ต้องเติมคำแปลจริง
* **ผ่านครบทุกฟิลด์:** `GET /api/blog/tags`, `GET /api/locations/tree` (label หมวด)
* **ผ่านแล้วบางฟิลด์:** `price_range`, `update` / `update_str` ของการ์ดแบรนด์ นายหน้า NPA และแคมเปญ, `price_display` / `launch_date` ของ `/api/listing/coming-soon` และ `/api/coming-soon/{id}/detail`, `updated_at_th` ของบทความ, `owner.type_label` และ `available_date` ของแคมเปญ, `slot.redirect_url` ของแบนเนอร์, `province.name` ของบทความ, `tags.expenses.*.text` ของหน้าเช่า, `post.price` ของ `promote-video-detail`
