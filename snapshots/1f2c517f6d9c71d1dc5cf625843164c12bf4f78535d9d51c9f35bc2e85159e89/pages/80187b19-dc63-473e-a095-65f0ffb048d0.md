ปุ่ม "รายชื่อผู้สนใจ" แสดงอยู่บนการ์ดโครงการแต่ละใบ โดยมีรายละเอียดดังนี้

| **ส่วน** | **รายละเอียด** |
|------|------------|
| ไอคอน | ไอคอนรูปคน |
| ข้อความ | “รายชื่อผู้สนใจ” |
| ตัวเลข | แสดงจำนวน Lead ทั้งหมดที่ผูกกับโครงการนั้น เช่น 15 |
| จุดสีแดง | แสดงเมื่อมี Lead ใหม่ที่ยังไม่มีการ Action เช่น 🔴+1 |

กรณีที่ยังไม่มี Lead เลย ตัวเลขแสดงเป็น 0 แต่ปุ่มยังคงแสดงอยู่

กรณีมีจุดแดง +1 หรือมากกว่า หมายถึงมี Lead ใหม่เข้ามาที่ยังไม่ได้รับการ Action ใดๆ ตัวเลขจะอัปเดตอัตโนมัติเมื่อมี Lead ใหม่เข้ามา

**กรณีกดปุ่ม "รายชื่อผู้สนใจ"**

เมื่อกดปุ่มนี้ ระบบจะ Navigate ไปยังหน้ารายชื่อผู้สนใจ โดยส่ง project_id ของโครงการนั้นไปด้วย เพื่อให้หน้ารายชื่อผู้สนใจกรองข้อมูลเฉพาะ Lead ของโครงการนั้นทันที ในหน้ารายชื่อ

**ความสัมพันธ์ระหว่างตัวเลขกับหน้ารายชื่อผู้สนใจ**

| **สถานการณ์** | **ผลที่เกิดขึ้น** |
|-----------|---------------|
| มี Lead ใหม่เข้ามา | ตัวเลขบนปุ่มเพิ่มขึ้นอัตโนมัติ + แสดงจุดแดง |
| เข้าไปดูหน้ารายชื่อผู้สนใจแล้ว | จุดแดงหายไป แต่ตัวเลขยังคงอยู่ |
| กด Action กับ Lead แล้ว (จัดการ/บันทึก) | จุดแดงของ Lead นั้นหายไป |

ปุ่ม Filter ในการกรองข้อมูลมีทั้งหมด 4 ประเภท ประกอบไปด้วย จังหวัด, บริษัท/โครงการ,การลงทะเบียน และ ตัวกรอง หากไม่กดตัวกรองทั้ง 4 ประเภท ข้อมูลจะขึ้นข้อมูลล่าสุดของผู้ลงทะเบียนเข้ามาทังหมด

ตัวเลขทั้งหมดอัปเดตอัตโนมัติตาม Filter ที่เลือก ไม่ใช่ตัวเลขคงที่

**"จังหวัด"** ระบบจะแสดง Dropdown รายชื่อจังหวัดที่มีในระบบ โดยมีรายละเอียดดังนี้

**กรณีเปิด Dropdown**

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=f16b2189-17b5-453b-9725-e499a19b6852)

* ตัวเลือกแรกสุดคือ "ทั้งหมด" ซึ่งเป็นค่า Default ที่ถูกเลือกไว้อยู่แล้ว
* รายชื่อจังหวัดที่แสดง เป็นเฉพาะจังหวัดที่มีโครงการในระบบเท่านั้น ไม่ใช่ทุกจังหวัดในไทย
* ผู้ใช้สามารถ เลือกได้มากกว่า 1 จังหวัดพร้อมกัน (Multi-select) โดยตัวที่เลือกจะแสดงเครื่องหมายถูกและพื้นหลังเป็นสีฟ้า
* หากเลือก "ทั้งหมด" จะเป็นการยกเลิกตัวเลือกอื่นทั้งหมดและกลับสู่ค่า Default
* ด้านล่าง Dropdown มีปุ่ม 2 ปุ่มคือ
  * "ล้างข้อมูล" → ยกเลิกตัวเลือกทั้งหมด กลับเป็น "ทั้งหมด"
  * "ค้นหา" → ยืนยันการเลือกและกรองข้อมูลในตารางทันที
* ข้อมูลในตาราง จะยังไม่ถูกกรองจนกว่าจะกดปุ่ม "ค้นหา"

\*\*กรณีเลือกแล้ว \*\*

* แสดงชื่อจังหวัดที่เลือกบนปุ่ม
* ถ้าเลือกหลายจังหวัด แสดงจำนวน เช่น ชื่อจังหวัด
* กด "ล้างข้อมูล" → กลับ Default และ Reset Dropdown
* กด "ค้นหา" → ตารางอัปเดตทันที

ค่าเริ่มต้นจะติ๊กถูกทั้งหมดหากต้องการเลือกเพียงอย่างใดอย่างหนึ่งให้กดที่ทั้งหมดซ้ำ แล้วเลือกตัวเลือกที่ต้องการกรอง หรือติ๊กออกให้เป็นวงกลมเปล่าทีละอันได้

**Dropdown "บริษัท/โครงการ" จะกรองให้เหลือเฉพาะโครงการในจังหวัดที่เลือก**

**"บริษัท/โครงการ"**  กรณีที่ยังไม่กดตัวกรอง แสดงข้อความ "บริษัท/โครงการ" เป็น Placeholder ไม่กรองข้อมูล

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=9c89ca23-03d7-4355-8432-317b690c8f80)

\*\*กรณีกดเปิด Dropdown \*\*แสดง 4 ตัวเลือกหลักก่อน ได้แก่

* ทั้งหมด
* บริษัททั้งหมด
* โครงการทั้งหมด
* โครงการ (ระบุชื่อ) → เมื่อเลือกตัวนี้จะขยายแสดง Search Box และรายชื่อโครงการให้เลือก

เมื่อเลือก "โครงการ (ระบุชื่อ)"

* มี Search Box พิมพ์ค้นหาชื่อโครงการได้
* แสดงรายชื่อโครงการตาม จังหวัดที่เลือกไว้ (ถ้ามี)
* เลือกได้ 1 โครงการต่อครั้ง (Single-select)

**กรณีเลือกแล้ว:**

* แสดงชื่อบริษัทหรือโครงการบนปุ่ม
* กรองตารางเฉพาะ Lead ของบริษัท/โครงการนั้น
* กด "ล้างข้อมูล" → กลับ Default

\*\*"การลงทะเบียน" \*\*กรณีที่ยังไม่กด แสดงข้อความการลงทะเบียน ไม่กรองข้อมูล ก็จะแสดงข้อมูลทั้งหมด

**กรณีกดเปิด Dropdown** แสดงตัวเลือกช่องทางที่ Lead ลงทะเบียนเข้ามา ได้แก่

* ทั้งหมด (Default)
* ทั่วไป

* กรองตารางเฉพาะ Lead ที่มาจากช่องทางที่เลือก

\- ไม่มีรายการใดถูกเลือก

\- ปุ่ม "ลบรายชื่อ" ยังไม่แสดงด้านล่าง

**กรณีกด Checkbox บน Header \*\*\*\* ยังไม่ทำในเฟดนี้**

\- Checkbox เปลี่ยนเป็น ✔ สีฟ้า

\- รายการทุกอันในหน้านั้นถูกเลือกพร้อมกันทั้งหมด

### **Header แถบรายการ**

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=a6f9c2fe-07cc-4ca9-8375-3efab45cdab0)

แถบ Header แสดงอยู่เหนือรายการ Card ทั้งหมด ประกอบด้วย 3 ส่วน ได้แก่

**Logic การทำงานของ Checkbox บน Header**

| **ส่วน** | **ตำแหน่ง** | **รายละเอียด** |
|------|---------|------------|
| Checkbox | ซ้ายสุด | กดเพื่อเลือกรายการทั้งหมดในหน้านั้น |
| ลำดับ + ชื่อ | ตรงกลางซ้าย | หัวข้อคอลัมน์แสดงเป็นข้อความ ไม่สามารถกดได้ |
| จัดการ | ขวาสุด  | หัวข้อคอลัมน์แสดงเป็นข้อความ ไม่สามารถกดได้ |

**กรณียังไม่ติ๊ก**

\- Checkbox แสดงเป็นวงสี่เหลี่ยมเปล่า

\- ไม่มีรายการใดถูกเลือก

\- ปุ่ม "ลบรายชื่อ" ยังไม่แสดงด้านล่าง

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=f4f0c7f2-8ba8-49c2-be20-68b539541973)  ![](https://wiki.infonayoo.co/api/attachments.redirect?id=3053dd74-c451-41e2-9fb0-567387028288) ![](https://wiki.infonayoo.co/api/attachments.redirect?id=f3bb5b17-567d-449f-a4db-6655d1861af4)

**กรณีกด Checkbox บน Header**

\- Checkbox เปลี่ยนเป็น ✔ สีฟ้า

\- รายการทุกอันในหน้านั้นถูกเลือกพร้อมกันทั้งหมด

\- Checkbox ของแต่ละ Card เปลี่ยนเป็น ✔ ตามทั้งหมด

\- ปุ่ม "ลบรายชื่อ" สีแดง Fixed ด้านล่างโผล่ขึ้นมาทันที

**กรณีกด Checkbox บน Header ซ้ำอีกครั้ง**

\- Checkbox กลับเป็นวงสี่เหลี่ยมเปล่า

\- ยกเลิกการเลือกทุกรายการพร้อมกัน

\- ปุ่ม "ลบรายชื่อ" หายไป

* คุณสามารถแสดงชื่อ- ชื่อนามสกุลของลูกค้า, เบอร์โทรศัพท์, วันที่- เวลาแสดงความคิดเห็น, ลูกค้า, เพิ่มเติม, Walk-in, หมายเหตุ, คำอธิบายสถานะ, ชื่อผู้บันทึก
* ประวัติความเป็นมาที่แสดงชื่อ-นามสกุลของลูกค้า, เบอร์โทรศัพท์ และข้อความ "คุณสามารถใช้ประวัติส่วนตัว"
* ปิด X ถัดไปบน

**“การจัดการ”**

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=fc75771c-7f75-42a6-9d56-955b45418860)

กดแล้วเปิดป๊อปอัป "รายการรายชื่อลูกค้า" ส่วน 4 ส่วน

ส่วน 1 — ประเมินลูกค้า (เลือกได้ 1 คน)

แสดงเป็น Card 2 สิ่งที่พวกเขาเลือกในสีฟ้า

* Hot → ติดต่อซ้ำภายใน 3 เดือน
* Warm → ติดต่อซ้ำภายใน 6 เดือน
* Cold → ติดต่อซ้ำภายใน 12 เดือน
* Red → มีปัญหา

มือถือไม่มีทางเลือก "ไม่รับ" แตกต่างจากเดสก์ท็อป

ส่วน 2 — การติดตาม (Dropdown เลือกได้ 1 คน)

ยังไม่ติดต่อ / ติดต่อได้ / ติดต่อไม่ได้ / ติดต่อโดยตรง / รอจอง / จองแล้ว / โอนแล้ว / ปฏิเสธ

ส่วน 3 — Walk-in (ปุ่มกดสามารถเลือกได้ 1 คน)

ไม่ระบุ / รอ Walk-in / Walk-in ไว้แล้ว

ตอนที่ 4 — Note

* Text Area ความละเอียดสูงสุด 200 อักษร
* แสดงเคาน์เตอร์ที่เหลือ
* เขียนเสร็จเรียบร้อย ก็จะถูดบันทึก หมายเหตุ ที่เขียนบันทึกบันทึกใน "อ่าน Note"

อยู่ด้านล่าง

* "ยกเลิก" → ปิดป๊อปอัปโดยไม่ต้องบันทึก
* " บันทึก" → บันทึกข้อมูลแสดงป๊อปอัป สำเร็จ "บันทึกรายการเสร็จสิ้น" แล้วปิดอัตโนมัติอัปเดตข้อมูลในการ์ดทันที

**"อ่าน Note"**

* แสดงเฉพาะหมายเหตุในตอนนั้นเท่านั้น
* แล้วเปิด Popup แสดงข้อมูล Lead (ชื่อ, เบอร์, รายการ, จังหวัด) และ Note ที่ เขียนไว้
* ไอคอนโทรศัพท์สามารถกดโทรออกได้
* มีปุ่ม "ยกเลิก" อีกครั้งเพื่อแสดงการพิมพ์มา
* มีปุ่ม "บันทึก" เพื่อเพิ่มข้อมูลของลูกค้าเมื่อกดบันทึกจะเป็นเครื่องหมายว่า "บันทึก Note สำเร็จ"

หากไม่มีปุ่ม "อ่าน Note" แสดงขึ้นโดยไม่มีข้อมูลการเขียนข้อมูลเพิ่มเติมเกี่ยวกับลูกค้า

### **Edge Cases ที่ต้องจัดการ**

| **กรณี** | **การจัดการ** |
|------|-----------|
| ไม่มีข้อมูลในตาราง | แสดงสถานะว่าง "ไม่พบรายชื่อผู้สนใจ" |
| ค้นหาแล้วไม่พบ | แสดง "ไม่พบรายชื่อที่ค้นหา" พร้อมปุ่ม "ล้างการค้นหา" |
| ข้อผิดพลาดเครือข่าย | แสดง Toast แจ้งเตือน "เกิดข้อผิดพลาด กรุณาลองใหม่" |
| กด "บันทึก" สำเร็จ | แสดง Popup สีเขียว ✔ พร้อมข้อความยืนยัน แล้วปิดอัตโนมัติ |
| Note เกิน 200 ตัวอักษร | ไม่สามารถพิมพ์เพิ่มได้ แสดง Counter สีแดง |
| กด "ยกเลิก" ใน Popup | ปิด Popup ทันที ไม่บันทึกการเปลี่ยนแปลงใด ๆ |
| ราคาต่ำสุด > ราคาสูงสุด | แสดงข้อผิดพลาด "ราคาต่ำสุดต้องเผชิญราคาสูงสุด" บันทึกบันทึก Disabled |
| X บน Modal จังหวัด/บริษัท | ปิด Modal โดยไม่บันทึกบันทึก ตัวกรองที่คาดว่าจะเห็นเซสชันนี้ |
