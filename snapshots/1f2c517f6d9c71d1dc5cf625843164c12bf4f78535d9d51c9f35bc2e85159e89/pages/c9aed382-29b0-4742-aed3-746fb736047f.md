หน้า Home กลาง (ทั้งประเทศ) ไม่ได้เลือกจังหวัด

* **Route:** `/` (`/en`, `/zh` สำหรับภาษาอื่น)
* **ไฟล์:** `app/(public)/[locale]/(interface)/(homepage)/page.tsx`
* **ข้อมูล ณ วันที่:** 2026-10-26 (branch `feature/setup-project-3-languages`)

> ถ้า `GATE_HOME_UNTIL_PROVINCE` ใน `constant/feature-flags.ts` เป็น `true` หน้านี้จะแสดงแค่ `ProvinceVisitGridSection` และเรียก API แค่ `support-provinces` ตอนนี้ค่าเป็น `false` จึงแสดงครบทุก section

## API ที่ใช้ (7 เส้น)

| \#  | Endpoint | Section | เรียกจาก |
|-----|----------|---------|----------|
| 1   | `GET /api/support-provinces` | ProvinceVisitGridSection, ReviewsSection, CTABottomSection | SSR + client |
| 2   | `GET /api/listing/home-page/count-post-by-category` | SearchNewProjectsSection, HouseDesigeAndCompanySection | SSR + client |
| 3   | `GET /api/listing/home-page/secondhand-posts` | CollectionSecondhandSection | client   |
| 4   | `GET /api/listing/home-page/rent-posts` | HousesApartmentsForRentSection | client   |
| 5   | `GET /api/listing/home-page/nayoo-reviews` | ReviewsSection | client   |
| 6   | `GET /api/blog/interest/thailand` | ArticlesInteresSection | SSR และ client ตอนเปลี่ยนแท็บ (`?tag=`) |
| 7   | `GET /api/listing/home-page/summary-posts-all-type` | CTABottomSection | client   |

ทุกเส้นเรียกไปที่ `NEXT_PUBLIC_API_URL`

## Request ตอนโหลดหน้า (ประมาณ 9 ครั้ง)

**SSR (3 ครั้ง)**

* `support-provinces` (cache `revalidate: 60`)
* `count-post-by-category`
* `blog/interest/thailand`

**Client (6 ครั้ง)**

* `count-post-by-category`
* `secondhand-posts`
* `rent-posts`
* `support-provinces` (ReviewsSection กับ CTABottomSection เรียกพร้อมกัน แต่ใช้ in-flight cache 60 วินาทีร่วมกัน จึงออกไปจริงแค่ 1 ครั้ง)
* `nayoo-reviews`
* `summary-posts-all-type`

## Section ที่ไม่เรียก API

* CTATopCenterSection (รวม HomeSearchInput)
* SupportersAndPartnershipSection

ทั้งสองใช้ข้อมูล static และข้อความจาก i18n

## ข้อสังเกต

* `count-post-by-category` ถูกเรียก 2 ครั้ง (SSR ที่ SearchNewProjectsSection และ client ที่ HouseDesigeAndCompanySection) และไม่ได้ส่ง province ทั้งคู่ ถ้าส่งข้อมูลจาก server ลงไปให้ client จะลดได้ 1 request
* ArticlesInteresSection ดึงแท็บ "แนะนำ" ตอน SSR แล้วจะเรียกใหม่ฝั่ง client ก็ต่อเมื่อผู้ใช้เปลี่ยนแท็บ

## ไม่ได้นับรวม

Navbar, footer, popup ระดับ layout และ tracking / page-view
