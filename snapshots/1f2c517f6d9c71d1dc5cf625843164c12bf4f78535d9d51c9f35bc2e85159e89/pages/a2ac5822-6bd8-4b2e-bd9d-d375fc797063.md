**Account linking B2C**

**Functional Requirements** 

**FR01 B2C มีการเชื่อม link บัญชี  account ทุก Role ผู้ใช้ทั่วไป เจ้าของทรัพย์มือสอง เจ้าขอหอพัก นายหน้าอิสระ   ได้เฉพาะนายหน้าบริษัท(master เพราะมีมุมองว่าเป็น B2C)**

Logic การเชื่อมบัญชี 

1⁠. User สามารถเชื่อมบัญชีได้ที่หน้า Edit profile ใน Role ที่ user เป็น Role นั้น

2⁠. User สามารถมี 1 บัญชีของน่าอยู่แล้วเชื่อมช่องทางการเข้าสู่ระบบได้หลายช่องทางเช่น 

สามารถเชื่อมต่อกับ บัญชีอื่นๆ ได้มากกว่า 1 บัญชี เช่น Google, Facebook, LINE, Email/เบอร์โทร

3⁠. การสมัครสมาชิกน่าอยู่ในช่องทางใดช่องทางหนึ่งครั้งแรก นับบัญชีนั้นเป็นบัญชีหลัก (Primary account) ไม่สามารถยกเลิกการเชื่อมบัญชีไ

4⁠. ด้ หากมีบัญชีหลัก (Primary account)เพียง 1 บัญชี

5⁠. การลบบัญชีจะเกิดขึ้นในอนาคตหากปรึกษากับทีมที่ทำ PDPA แล้ว ณ ที่กำลังจะพัฒนา Nayoo v.2 

ยังไม่มีการทำการลบบัญชี

6⁠.  User เมื่อมีการเชื่อมบัญชีมากกว่า 1 บัญชี (Google, Facebook, LINE, Email/เบอร์โทร) สามารถยกเลิกการเชื่อมบัญชีได้ สวิตส์การทำงานโดยสามารถ ยกเลิกการใช้การเชื่อมครั้งแรกเมื่อสมัครสมาชิกเข้ามา และใช้ช่องทางอื่นที่เชื่อมแล้วในการเข้าสู่ระบบครั้งถัดไป

7⁠. สำหรับการเชื่อม social media ในหน้า edit profile ใน Role ที่ user เป็น Role นั้น จะต้องยืนยันตัวตนยืนด้วย provider ของช่องทางนั้น (facebook, line, google)

8⁠. สำหรับการเชื่อมอีเมลหรือ เบอร์โทรศัพท์ ในหน้า edit profile ใน Role ที่ user เป็น Role นั้น จะต้องสร้างรหัสผ่านและยืนยันตัวตนยืนด้วย OTP(สำหรับมือถือมีอายุการใช้งาน 2 นาที) และจะต้องสร้างรหัสผ่านและยืนยันตัวตนด้วยรหัสผ่านอีเมลหรือ link ผ่านอีเมลเท่านั้น                                                   (มีอายุการใช้งาน 2 นาที) จึงจะถือว่าการเชื่อมสำเร็จ

9⁠. เมื่อเชื่อมแล้วจะสามารถใช้บัญชีที่เชื่อมแล้วนั้นไปใช้ในการเข้าสู่ระบบในครั้งถัดไปได้

10⁠. กรณีที่ user นำเบอร์โทรศัพท์หรืออีเมลที่มีการเชื่อมไปสมัครสมาชิกน่าอยู่ใหม่อีกครั้งจะไม่สามารถทำได้จนกว่าจะยกเลิกการเชื่อม

11⁠. กรณีที่ user นำ social media นั้นไปสมัครสมาชิกน่าอยู่ใหม่อีกครั้งจะไม่สามารถทำได้จนกว่าจะยกเลิกการเชื่อม

12⁠. ทุกครั้งในการ เชื่อม/ยกเลิกการเชื่อมบัญชี จะต้องแสดง modal เตือนผู้ใช้งานเสมอในการเชื่อม/ยกเลิกการเชื่อมต่อ 

13⁠. ปุ่ม unlink แสดงเมื่อมีช่องทางการเชื่อมบัญชี >= 2 

14⁠. disable ปุ่ม unlink  เมื่อมีการเชื่อม 1 บัญชี อาจจะใส่ tooltip อธิบาย

15⁠. ไม่มี flow ในการ megre บัญชี A และบัญชี ฺB เนื่องจากข้อกังวลในการ role ที่แตกต่างกัน

16⁠. กรณีที่เคยเชื่อม Google, Facebook, LINE, Email/เบอร์โทร ของบัญชีน่าอยู่แล้ว หากมีการสมัครสมาชิกด้วย   Google, Facebook, LINE, Email/เบอร์โทร ที่มีการเชื่อมไปแล้วจะไม่สามารถนำบัญชีนั้นไปสมัครสมาชิกน่าอยู่ใหม่ได้

17⁠. แสดง modal หากเชื่อมแล้วชนกับบัญชีที่เคยเชื่อมไปแล้วในกรณีของ Email/เบอร์โทร Google, Facebook, LINE ที่หน้า edit profile
