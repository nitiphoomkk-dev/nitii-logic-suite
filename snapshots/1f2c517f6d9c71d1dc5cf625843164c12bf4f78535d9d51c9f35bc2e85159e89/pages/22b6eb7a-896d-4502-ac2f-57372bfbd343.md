## EP-04 การนับเลข — ต้องแยก “จำนวนพื้นที่” กับ “จำนวนตัวกรอง”

| ตัวเลข | นับอะไร | วิธีคิด | สิ่งที่ไม่นับเพิ่ม |
|--------|---------|---------|--------------------|
| `(2)` ในหัวข้อกลุ่ม | ลูกที่เลือกจริงภายในกลุ่มนั้น | จำนวน ID พื้นที่ย่อยที่ไม่ซ้ำและถูกเลือกในกลุ่ม | Checkbox แม่, แถวอำเภอที่ใช้เปิดกลุ่ม, Radio ทั้งจังหวัด |
| `ขอนแก่น (2)` ในหน้าเปลี่ยนจังหวัด | พื้นที่ย่อยที่ยังเลือกของจังหวัดปัจจุบัน | รวม ID พื้นที่ย่อยที่เลือกของจังหวัดนั้นโดยไม่ซ้ำ | ชื่อจังหวัดอีก 1, จำนวนใบประกาศที่ค้นเจอ |
| จังหวัดบนปุ่ม Full Filter ของหน้าโปรไฟล์ | เงื่อนไขขอบเขตจังหวัด | ทุกจังหวัด = 1; จังหวัดเฉพาะ = 1 | ไม่บวกทุกจังหวัดกับขอนแก่นพร้อมกัน |
| ที่ตั้งบนปุ่ม Full Filter ของหน้าโปรไฟล์ | เงื่อนไขที่ตั้งภายในจังหวัด | มีค่าที่ตั้งเฉพาะอย่างน้อยหนึ่งค่าให้นับรวม 1 ไม่ว่าจะเลือกลึกหรือหลายข้อเพียงใด | ไม่เอา `(2)` ภายในกลุ่มมาบวกเป็นที่ตั้ง 2 |
| ตัวกรองเดียวกันด้านนอกกับ Full Filter | ค่าเดียวที่แสดงสองตำแหน่ง | นับครั้งเดียวจาก state เดียวกัน | จำนวน control หรือตำแหน่งที่แสดงซ้ำ |

**ขอบเขตปุ่ม Full Filter:** กฎจังหวัด/ที่ตั้ง/จัดเรียงด้านบนเป็นคำยืนยัน U ของหน้าโปรไฟล์ การยกสูตรนี้ไปใช้ Home/Search Center ต้องอ้างกฎของหน้าที่เรียกฟีลเตอร์ประกอบ เนื่องจาก Prototype ชุดนี้ไม่มีปุ่ม Full Filter ภายนอกให้ตรวจ จึงไม่ระบุว่า Prototype ยืนยันยอดรวมภายนอกแล้ว

## EP-07 Logic ข้อมูลสำหรับ Dev และ QA

ตารางนี้อธิบายข้อมูลเชิงตรรกะ ไม่ใช่ชื่อ API, parameter หรือ table ฐานข้อมูลที่ยืนยันแล้ว

| หัวข้อ | Logic ที่ต้องรักษา | สถานะ |
|--------|--------------------|-------|
| ขอบเขตจังหวัด | หนึ่งชุดค่าที่ตั้งเป็นทุกจังหวัด หรือจังหวัดเดียว ห้ามส่งจังหวัดเฉพาะสองค่าพร้อมกันหาก UI รองรับหนึ่งค่า | W1/W2 |
| ขอบเขตพื้นที่ย่อย | ID ลูกต้องสัมพันธ์กับจังหวัดและแม่ตามข้อมูล SEO ที่เลือกอยู่ | ข้อกำหนดความสอดคล้องจาก W1/W2; SA/Backend ตรวจกับข้อมูลจริง |
| โหมดทั้งจังหวัด | ใช้ขอบเขตจังหวัดโดยไม่มีรายการลูกเฉพาะ ไม่จำลองว่าเลือกทุก ID ลูกในฐานข้อมูล | คำอธิบายจากกฎทั้งจังหวัด/ล้างลูก |
| จำนวนที่เลือก | คำนวณจาก ID ที่เลือกจริงแบบไม่ซ้ำ ไม่คำนวณจากข้อความชื่อหรือจำนวน control | แนวทางเทคนิคเพื่อให้ผลตามกฎการนับ |
| สถานะแม่ | 0 ลูก = ไม่เลือก; บางลูก = `−`; ครบทุกลูกในกลุ่ม = เลือกครบ โดยไม่บวกแม่ในจำนวน | W2 และวิธีคำนวณ |
| เปลี่ยนจังหวัดใหม่ | ส่งค่าใหม่พร้อมล้างพื้นที่ของจังหวัดเก่าในชุดเดียวกัน เพื่อไม่ให้ UI/ค่าค้นหาคนละจังหวัด | W1 LF-06; ไม่ระบุวิธี transaction หรือ endpoint |
| การใช้ค่าค้นหา | ค่าที่แสดงบน UI, ค่าที่ใช้ค้น, จำนวนที่แสดง และ URL ที่ยืนยันแล้วต้องอ้างชุดเดียวกัน | W2; ต้องตรวจเมื่อเชื่อมเว็บจริง |
| ความผิดพลาดจากข้อมูลอ้างอิง | กรณี ID ลูกไม่อยู่ในจังหวัด/แม่ หรือถูกยกเลิกจาก SEO ให้ Dev/SA กำหนด validation และ UX ก่อนเขียน Expected Response | งานออกแบบทางเทคนิคที่ยังไม่ปรากฏใน Prototype ไม่สร้าง HTTP code/ข้อความ error ขึ้นเอง |
