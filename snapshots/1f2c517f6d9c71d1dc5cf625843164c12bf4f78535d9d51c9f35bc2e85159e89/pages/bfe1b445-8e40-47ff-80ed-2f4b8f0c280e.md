ใช้กับ section น่าอยู่รีวิวบนหน้า Home รวมจังหวัด (Home Center, EP-08) logic ตาม wiki "รีวิว center" หัวข้อ การแสดงวิดีโอแนะนำ (EP-01.2 / EP-02) เป็น public ไม่ต้องใช้ token ใช้แค่ apikey ตามปกติ **ไม่ต้องส่ง header** `**province**` เพราะเลือกจากรีวิวทุกจังหวัดรวมกันเสมอ

```
GET /api/listing/home-page/thailand/nayoo-reviews
```

shape ของการ์ดเหมือน `/api/listing/home-page/nayoo-reviews` (ของหน้า Home จังหวัด) ใช้ component เดิมได้

## ตัวอย่าง response

```json
{
  "success": true,
  "message": "get thailand nayoo reviews successfully",
  "data": [
    {
      "id": 234,
      "slug": "review-the-palm-khonkaen",
      "title": { "th": "รีวิวโครงการ เดอะปาล์ม ขอนแก่น" },
      "tag": "new_project",
      "video_type": "youtube",
      "video_url": "https://www.youtube.com/watch?v=xxxxxxxxxxx",
      "cover_image": "https://.../cover.webp",
      "is_blog_connected": true,
      "updated_at": "2026-10-30T08:33:47.14Z",
      "visitor_count": 1250,
      "position": 1
    },
    { "id": 150, "position": 2 },
    { "id": 182, "position": 3 }
  ]
}
```

> ค่าข้างบนเป็นตัวอย่าง ไม่ใช่ข้อมูลจริง การ์ดที่ 2–3 ย่อไว้ ของจริงมีทุก field เหมือนการ์ดแรก

## Field

| Field | ความหมาย |
|-------|----------|
| `id`  | review id |
| `slug` | slug ของรีวิว |
| `title.th` | ชื่อรีวิว (`en` / `cn` ส่งมาเฉพาะเมื่อมีค่า) |
| `tag` | หมวด: `new_project` / `home_builder` / `secondhand` / `lifestyle` |
| `video_type` | `youtube` / `shorts` / `tiktok` |
| `video_url` | ลิงก์วิดีโอ |
| `cover_image` | รูปปก    |
| `is_blog_connected` | `true` = เชื่อมบทความแล้ว (กดไปหน้ารายละเอียดรีวิวได้) |
| `updated_at` | เวลาอัปเดตล่าสุดของรีวิว |
| `visitor_count` | จำนวนการเข้าชม (จาก report-service) |
| `position` | ลำดับการ์ด 1–3 `**position: 1**` **= การ์ดใหญ่** |

## วิธีเลือกการ์ด (ฝั่ง backend)


1. รวมรีวิว online จากทุกจังหวัด
2. รีวิวที่ปักหมุดหรือติดดาว (จากหน้าจัดการปักหมุดรีวิวของหน้าจังหวัด) รวมเป็นกลุ่มเดียว รีวิวที่มีทั้งสองสถานะนับเป็น 1
3. กลุ่มนี้มีเกิน 3 → สุ่มแล้วเลือก 3 / มีไม่ถึง 3 → เติมด้วยรีวิวที่อัปเดตล่าสุด
4. สุ่มลำดับทั้ง 3 ใบรวมกัน ติดดาว **ไม่ได้ล็อกตำแหน่ง** เหมือนหน้าจังหวัด การ์ดใหญ่จึงเป็นใบไหนก็ได้

## ข้อควรรู้

* **สุ่มใหม่ทุก request** การ์ดและลำดับเปลี่ยนได้ทุกครั้งที่โหลด ถ้า render ฝั่ง server แล้ว fetch ซ้ำฝั่ง client จะได้ชุดไม่ตรงกัน ให้ fetch ที่เดียว
* ได้ **0–3 การ์ด** ถ้ารีวิวในระบบมีน้อยกว่า 3 จะได้เท่าที่มี ถ้าไม่มีเลยได้ `data: []`
* `data` เรียงตาม `position` แล้ว (1, 2, 3)
* การ์ดไม่มี field จังหวัด (เหมือนการ์ดหน้า Home จังหวัด) ถ้าต้องแสดงชื่อจังหวัด แจ้ง backend
* **ใช้กับหน้า Home รวมจังหวัดเท่านั้น** หน้ารวมรีวิว center ต้องกันไม่ให้รายการด้านล่างซ้ำกับรีวิวแนะนำ (RV-C11) ซึ่งเส้นนี้ไม่รองรับ
* ปลายทาง backend: product-service `GET /system/review/home-page/thailand`
