**Functional Requirements version 1**

FR 0 ระบบจะสร้าง Profile บริษัทเอาไว้ หลังจากการสร้าง Profile เอาไว้แล้วทางทีมหน้าบ้าน จะนำการขออีเมลจริง ของบริษัท/โครงการนั้น เพื่อทำการเชิญให้เข้าสู่ระบบผ่านการส่งอีเมลพร้อมลิ้งที่จะนำพาไปสู่Flow การเปลี่ยนรหัส  กรณีในการเข้าใช้งานครั้งแรก

FR01 กรณีในการเข้าใช้งานครั้งแรก ระบบจะต้องสามารถนำพา User ที่เราได้การเชิญไปนั้นด้วย link URL เมื่อ user กด link URL จะนำพาเข้าสู่เว็บน่าอยู่ แล้วแสดง modal ดังต่อไปนี้

**FR02 การทำงานของ modal เปลี่ยนรหัสผ่าน**

\-สามารถเปลี่ยน 3 ภาษาได้ที่ modal นี้หากเปลี่ยนภาษาตรงนี้เท่ากับเปลี่ยนภาษาทั้งเว็บ

\-รหัสผ่านตั้งตามนโยบาย Policy ที่ Dev คิด 2 ขั้นตอนในการยืนยัน

\-ปุ่มตา สามารถกดดูรหัสผ่านที่พิมพ์ไปได้ จากจุดๆ เมื่อกดรูปตาแล้วจะมองเห็นเป็นตัวอักษร

\- user ไม่สามารถกดปิด modal นี้ได้ หากปิดเว็บน่าอยู่ไปเลยจะเท่ากับยังไม่สามารถเข้าสู่ระบบได้

\-เมื่อกดปุ่มยืนยัน แสดงmodal ดังต่อไปนี้

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=cd5b59ec-2be0-4da2-a70d-d13f0304f0a2)

แสดง modal เป็นเวลา 2 วินาทีแล้ว หายไปอัตโนมัติ  สามารถใช้งานเว็บไซต์น่าอยู่ได้

**FR03 เมื่อผู้ใช้เข้าสู่ระบบสำเร็จหลังจากเปลี่ยนรหัสผ่าน จะเข้าสู่หน้า default ที่หน้า home center**

**FR04 เงื่อนไขการเข้าสู่ระบบในครั้งถัดไป**

เมื่อ user เข้ามาที่เว็บน่าอยู่ user สามารถกดเลือกลงใบประกาศฟรีหรือเข้าสู่ระบบ ทั้งสองปุ่ม default
