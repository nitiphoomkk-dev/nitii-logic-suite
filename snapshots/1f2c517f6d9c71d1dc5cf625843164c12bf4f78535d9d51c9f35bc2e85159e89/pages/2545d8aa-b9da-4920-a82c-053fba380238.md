1\. **การ์ดใบประกาศ**

 ![](/api/attachments.redirect?id=e25681e7-d96f-4d73-a39a-23dcc4b4fb68) ![](/api/attachments.redirect?id=695647c4-d5b6-4b77-828f-019259721e36)

ใบประกาศที่เข้าร่วม/บริษัทที่เข้าร่วม (เป็น Top Event และแสดงแบบสุ่ม หากแต่ละหมวดมีไม่ถึง 4 การ์ด จะดึงใบประกาศทั่วไปที่เข้าร่วม  แสดงสูงสุด 12 slot

  a. การวางสนใจแต่ top event ไม่มีการคำนึงถึง top ads ranking model

  b. ดึงใบประกาศที่เข้าร่วมแคมเปญมาแสดงด้วยหากไม่เต็ม slot

  c. ถ้าใบประกาศ 1-2 ใบจะแสดงกึ่งกลาง , ใบประกาศ =<4 ใบประกาศจะชิดซ้าย

  d. จะมีปุ่มเลื่อนซ้าย ขวา เลื่อนซ้ายได้เมื่อเลื่อนขวา เลื่อนเป็นชุด

  e. กดแล้วเปิด new tab ไปหน้าใบประกาศนั้น

| **หัวข้อ** | **รายละเอียด** |
|--------|------------|
| **ประเภทการ์ด** | ใบประกาศ/บริษัทที่เข้าร่วม โดยเป็น Top Event |
| **เงื่อนไขเติมการ์ด** | หากแต่ละหมวดมีการ์ดไม่ถึง 4 ใบ จะดึง "ใบประกาศทั่วไปที่เข้าร่วม" มาเติม |
| **จำนวน slot สูงสุด** | แสดงสูงสุด 12 slot |
| **โมเดลจัดอันดับ** | คำนึงถึงเฉพาะ Top Event เท่านั้น **ไม่** คำนึงถึง Top Ads Ranking Model |
| **การจัดวาง: 1–2 ใบ** | แสดงกึ่งกลาง (center) |
| **การจัดวาง: ≤ 4 ใบ** | ชิดซ้าย (left-aligned) |
| **ปุ่มเลื่อน** | จะมีปุ่มเลื่อนซ้าย ขวา เลื่อนซ้ายได้เมื่อเลื่อนขวา เลื่อนเป็นชุด |

|-----|------|-----------------|-----------------|---------|
| 1   | Top event | 1               | ไม่สลับ เพราะมีรายการเดียว | คงที่ตำแหน่งเดิม |
|     | Top event | 2+              | วนตำแหน่งเฉพาะภายในกลุ่ม Top event แบบเก้าอี้ดนตรี | Top event ยังอยู่ด้านหน้าก่อนเสมอ และรายการในกลุ่ม Top event จะค่อย ๆ วนตำแหน่งกันจนครบทุกตำแหน่ง |
| 2   | ใบประกาศ | 1               | ไม่สลับ เพราะมีรายการเดียว | คงที่ตำแหน่งเดิม |
|     | ใบประกาศ | 2+              | วนตำแหน่งเฉพาะภายในกลุ่มใบประกาศแบบเก้าอี้ดนตรี | ใบประกาศยังอยู่หลัง Top event เสมอ และรายการในกลุ่มใบประกาศจะค่อย ๆ วนตำแหน่งกันจนครบทุกตำแหน่ง |

### **Logic การแสดงผล**

| **Logic** | **ช่วงเวลา** | **เงื่อนไขการดึงข้อมูล** | **ลำดับการแสดง** |
|-------|----------|----------------------|--------------|
| **โปรจอง** | **Pre-event** | ดึงเฉพาะโครงการ/บริษัทที่กรอกโปรใหม่เข้ามาในช่วงนั้น แสดงทั้งหมด | Top event แสดงก่อน → ตามด้วยใบประกาศที่เข้าร่วมแคมเปญ |
| **โปรจอง** | **Event** | ขึ้นหมดทุกโครงการ/บริษัทรับสร้างบ้าน (ทั้งที่เป็นและไม่เป็น top event) | Top event แสดงก่อน → ตามด้วยใบประกาศที่เข้าร่วมแคมเปญ |
|       |          | • ดึงโปรเก่าที่ยังไม่หมดอายุ โดยเวลาคาบเกี่ยวกับช่วง event มาแสดง |              |
|       |          | • ถ้าโปรใหม่ของแคมเปญหมดอายุก่อนถึงช่วง event → ดึงโปรเก่าที่ยังไม่หมดอายุและคาบเกี่ยวเวลาของ event มาแสดงแทน |              |

**โครงการใหม่**

```
- ดึงโปรโมชั่นโครงการใหม่มาแสดงผล
  - **Top event แสดงก่อน \(random เฉพาะในชนชั้นนั้น\) → ตามด้วยใบประกาศที่เข้าร่วมแคมเปญ \(random เฉพาะในชนชั้นนั้น\)**
```

  * **ถ้ามีมากกว่า 4 <8 แสดงการ์ดอื่นชิดซ้าย**
  * **เลื่อนซ้ายได้เมื่อเลื่อนขวา เลื่อนแล้วชน**

#### **ชั้นที่ 2  — สลับลำดับวิดีโอ (Round-robin)**

| **#** | **จำนวนวิดีโอใน tab (N)** | **ตำแหน่งที่ใช้** | **กฎครั้งแรกที่ User เข้ามา** | **กฎต่อ 1 refresh** | **ผลลัพธ์** |
|-----|-----------------------|---------------|---------------------------|-----------------|---------|
| **N** | **1**                 | **[1]**       | มีวิดีโอเพียงตัวเดียว จึงไม่ต้องจัดลำดับใหม่ | ไม่สลับตำแหน่ง  | วิดีโอคงอยู่ตำแหน่งที่ 1 |
|     | **2**                 | **[1, 2]**    | ระบบกำหนดลำดับเริ่มต้นให้แต่ละ User/Session ได้ โดยแต่ละคนอาจเห็นลำดับแรกไม่เหมือนกัน | เมื่อ refresh ให้สลับตำแหน่งวนไปทีละรอบ | วิดีโอทั้ง 2 ตัวได้สลับตำแหน่งกัน และจะกลับมาตำแหน่งเดิมเมื่อวนครบ 2 รอบ |
|     | **3**                 | **[1, 2, 3]** | ระบบกำหนดลำดับเริ่มต้นให้แต่ละ User/Session ได้ โดยแต่ละคนอาจเห็นลำดับแรกไม่เหมือนกัน | เมื่อ refresh ให้เลื่อนตำแหน่งของวิดีโอทุกตัวไป 1 ตำแหน่ง | วิดีโอทุกตัวได้แสดงครบทุกตำแหน่ง ก่อนจะกลับมาตำแหน่งเดิม |
|     | **N**                 | **[1 … N]**   | ระบบกำหนดลำดับเริ่มต้นให้แต่ละ User/Session ได้ โดยแต่ละคนอาจเห็นลำดับแรกไม่เหมือนกัน | เมื่อ refresh ให้เลื่อนตำแหน่งของวิดีโอทุกตัวไป 1 ตำแหน่ง และวนไปเรื่อย ๆ จนครบทุกตำแหน่ง | วิดีโอทุกตัวได้แสดงครบทุกตำแหน่งอย่างเป็นรอบ ก่อนเริ่มวนใหม่อีกครั้ง |
