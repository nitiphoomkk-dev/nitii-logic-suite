2\. **การ์ดใบประกาศ**

 ![](/api/attachments.redirect?id=aa4ea0bb-4655-45fe-97e4-8d963b16e0cb)

ใบประกาศที่เข้าร่วม/บริษัทที่เข้าร่วม (เป็น Top Event และแสดงแบบสุ่ม หากแต่ละหมวดมีไม่ถึง 4 การ์ด จะดึงใบประกาศทั่วไปที่เข้าร่วม  แสดงสูงสุด 12 slot

  a. การวางสนใจแต่ top event ไม่มีการคำนึงถึง top ads ranking model

  b. ดึงใบประกาศที่เข้าร่วมแคมเปญมาแสดงด้วยหากไม่เต็ม slot

  c. ถ้าใบประกาศ 1-2 ใบจะแสดงกึ่งกลาง , ใบประกาศ =<4 ใบประกาศจะชิดซ้าย

  d. จะมีปุ่มเลื่อนซ้าย ขวา เลื่อนซ้ายได้เมื่อเลื่อนขวา เลื่อนเป็นชุด

  e. กดแล้วเปิด new tab ไปหน้าใบประกาศนั้น

| **หัวข้อ** | **รายละเอียด** |
|--------|------------|
| **ประเภทการ์ด** | ใบประกาศ/บริษัทที่เข้าร่วม โดยเป็น Top Event แสดงแบบสุ่ม |
| **เงื่อนไขเติมการ์ด** | หากแต่ละหมวดมีการ์ดไม่ถึง 4 ใบ จะดึง "ใบประกาศทั่วไปที่เข้าร่วม" มาเติม |
| **จำนวน slot สูงสุด** | แสดงสูงสุด 12 slot |
| **โมเดลจัดอันดับ** | คำนึงถึงเฉพาะ Top Event เท่านั้น **ไม่** คำนึงถึง Top Ads Ranking Model |
| **การจัดวาง: 1–2 ใบ** | แสดงกึ่งกลาง (center) |
| **การจัดวาง: ≤ 4 ใบ** | ชิดซ้าย (left-aligned) |
| **ปุ่มเลื่อน** | จะมีปุ่มเลื่อนซ้าย ขวา เลื่อนซ้ายได้เมื่อเลื่อนขวา เลื่อนเป็นชุด |
