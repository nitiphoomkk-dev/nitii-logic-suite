## **EP-01 รายการที่แสดง**

| **รหัส** | **เงื่อนไข** | **การแสดงผล** |
|------|----------|-----------|
| **LOC-01** | **เปิดเมนูเลือกจังหวัด** | **แสดงตัวเลือก “ทุกจังหวัด เป็น default กรณีเข้า url thailand ” และจังหวัดที่เว็บไซต์เปิดให้บริการ** |
| **LOC-02** | **แสดงตัวเลือกแต่ละจังหวัด** | **แสดงรูปประจำจังหวัด พร้อมชื่อใต้รูป โดยรูปและชื่ออ้างอิงพื้นที่เดียวกัน** |
| **LOC-03** | **แสดงตัวเลือก “ทุกจังหวัด”** | **ใช้ภาพแผนที่ประเทศไทย(รอกราฟฟิค) พร้อมข้อความ “ทุกจังหวัด”** |
| **LOC-04** | **มีพื้นที่ที่เลือกอยู่** | **แสดงชื่อพื้นที่นั้นเป็นสีฟ้าตาม UI เพื่อให้แยกจากรายการอื่น** |
| **LOC-05** | **แสดงรายการบน Desktop และ Mobile** | **ใช้ข้อมูลจังหวัดและลำดับเดียวกัน ปรับการจัดวางให้เหมาะกับขนาดหน้** |

## **EP-03 การเลือกพื้นที่**

| **การกระทำ** | **ผลลัพธ์ที่เสนอ** |
|----------|----------------|
| **กดปุ่มเลือกจังหวัดบน Header** | เปิดเมนูรายการจังหวัด |
| **กดรูปหรือชื่อจังหวัด** | เลือกจังหวัดนั้น โดยรูปและชื่อกดได้ผลลัพธ์เดียวกัน |
| **เลือกจังหวัดสำเร็จ** | ปิดเมนู เปลี่ยนชื่อพื้นที่บน Header และนำผู้ใช้ไปยังหน้าของจังหวัดที่เลือก |
| **เลือก “ทุกจังหวัด”** | ปิดเมนู และนำผู้ใช้ไปหน้า Center |
| **เปิดเมนูอีกครั้ง** | แสดงสถานะพื้นที่ที่เลือกอยู่ล่าสุด |
| **ปิดเมนูโดยไม่ได้เลือก** | คงพื้นที่เดิม  |

**การเปิดเมนูด้วยการคลิกหรือ Hover รวมถึงปลายทางเมื่อเปลี่ยนจังหวัดจากหน้ารายละเอียดยังต้องยืนยันเพิ่มเติม เพราะภาพนิ่งไม่ได้ระบุพฤติกรรมส่วนนี้**
