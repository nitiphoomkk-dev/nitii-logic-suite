**\*\*EP-02 หน้าเพิ่ม Top banner \*\***


 ![](/api/attachments.redirect?id=70c02372-4e4a-4d2d-acce-038874a69050)


\*\*Trigger  \*\*เมื่อ  User กดปุ่ม เพิ่ม  Banner  ให้มีการพา user ไปอีกหน้าในการลง banner รูปแบบการออกแบบ UI ตาม Figma

**\*\*Conditions: \*\*การแสดงในหน้านี้ เป็นไปตามที่ออกแบบ <u>Figma</u> ให้มี 4 หัวข้อในการเพิ่มรายละเอียด คือ**

1\. ประเภท 2.ชื่อแบนเนอร์ 3. ระยะเวลาแสดงผล 4. Slot A/ Slot B

\*\*Logic: \*\*

* **Default การแสดงผลไว้ที่เฉพาะ slot A slot B จะเป็นไม่แสดงผล ในค่าเริ่มแรกของการเพิ่ม**
* **หัวข้อประเภท banner** เป็นตัวเลือกแบบ Single Choice และ มีตัวเลือกให้เลือก 4 หมวดหมู่ คือ 1.โครงการใหม่ 2. บริษัทรับสร้างบ้าน 3.น่าอยู่ 4.อื่นๆ เป็น require\*\*  default เป็น โครงการใหม่ \*\*
* **\*\*หัวข้อชื่อของแบนเนอร์ \*\***สามารถพิมพ์ได้ทั้ง TH/EN ตัวเลขและเครื่องหมาย เป็น require
* **\*\*หัวข้อ ระยะเวลาแสดงผล \*\***ให้เลือกวันที่เริ่มต้น - วันที่สิ้นสุด เป็นตัวเลือกแบบ Calendar ให้เลือกวันที่เริ่มต้น→วันที่สิ้นสุด ตามลำดับ หลังเลือกระบบจะต้องคำนวณระยะเวลาทั้งหมดและแสดง จำนวนวันทั้งหมด พร้อมกับวันที่เริ่มต้น-วันที่สิ้นสุด ในรูปแบบ DD/MM/YYYY ทั้งคู่ เป็น require
  * ตัวเลือกแบบ Calendar **ไม่สามารถเลือกวันที่ในอดีตได้  สำหรับวันที่เริ่มต้น**


 ![](/api/attachments.redirect?id=ca52618c-c99e-4016-ad78-388a087ba6d4 " =452x381")

```
- การแสดง Calendar จะแสดงเดือนสองเดือนคู่กันเสมอ
- กดไปทางซ้าย ← จะแสดง เดือนที่ n\-1, และเดือน n <u>Ex</u>\. กันยายน และ ตุลาคม

- เมื่อหมดเดือนธันวาคม ให้เริ่มปี ค\.ศ\.ใหม่

```

**EP-05 การนับสถิติของ Slot A และ Slot B**

ระบบเก็บสถิติ 2 ระดับ ได้แก่ **ยอดสะสมของแต่ละ Slot** และ **สถิติรายกราฟฟิก** โดยใช้เหตุการณ์ Click และ Impression ชุดเดียวกันมาสรุปผล ไม่สร้างเหตุการณ์ซ้ำเพื่อเพิ่มยอดแต่ละระดับ

**05.1 สถิติภาพรวมของ Slot ที่หน้าจัดการ Top Banner**

| หัวข้อ | Logic การทำงาน |
|--------|----------------|
| ขอบเขต | แสดงสถิติ Slot A และ Slot B แยกกัน โดยแต่ละ Slot รวมทุกภาษา ทุกอุปกรณ์ และทุกเวอร์ชันภาพของ Slot นั้น |
| Click  | รวม Click ที่ผ่านเงื่อนไขทั้งหมดของ Slot นับสะสมต่อเมื่อเปลี่ยนหรือเพิ่มกราฟฟิก |
| Impression — IMP | รวม IMP ที่ผ่านเงื่อนไขทั้งหมดของ Slot นับสะสมต่อเมื่อเปลี่ยนหรือเพิ่มกราฟฟิก |
| CTR    | คำนวณจาก **Click สะสม ÷ IMP สะสม × 100** ไม่บวกหรือเฉลี่ยค่า CTR ของแต่ละภาพ |
| เปลี่ยนกราฟฟิก | ไม่รีเซ็ตยอดสะสมของ Slot แต่ภาพใหม่มีสถิติรายกราฟฟิกของตนเองตามข้อ 05.2 |
| รอเริ่มแสดงผล | ยังไม่นับสถิติ |
| ปิดแสดงผล / ออฟไลน์ | ไม่นับสถิติใหม่ เมื่อเปิดอีกครั้งและยังอยู่ในช่วงแสดงผล ให้นับต่อจากยอดเดิม |
| หมดอายุ | ไม่นับเหตุการณ์ที่เกิดหลังสิ้นสุดการแสดงผล โดยเก็บสถิติที่ผ่านมาไว้ดูย้อนหลัง |

**05.2 สถิติรายกราฟฟิก แยกภาษา อุปกรณ์ และเวอร์ชัน**

| หัวข้อ | Logic การทำงาน |
|--------|----------------|
| การเปลี่ยนภาพ | บันทึกภาพใหม่เป็น Record หรือ Version ใหม่ ไม่เขียนทับภาพเดิมและสถิติเดิม |
| การผูกสถิติ | แต่ละเหตุการณ์ต้องระบุรายการ Banner, Slot A/B, Graphic_ID หรือ Version, ภาษากราฟฟิก และอุปกรณ์ |
| แยกภาษา | เก็บภาษาไทย `TH` อังกฤษ `EN` และจีน `CN` แยกกัน |
| แยกอุปกรณ์ | เก็บ Desktop และ Mobile แยกกันภายในแต่ละภาษา |
| ภาพใหม่ | เริ่ม Click และ IMP ของภาพเวอร์ชันใหม่ที่ 0 แล้วนับเมื่อภาพนั้นเกิดเหตุการณ์จริง |
| ภาพเดิม | เก็บ Record และสถิติเดิมไว้สำหรับเรียกดูย้อนหลัง |
| แก้เฉพาะบางภาพ | เช่น เปลี่ยน EN Desktop ของ Slot A ให้สร้างเวอร์ชันใหม่เฉพาะภาพนั้น ส่วน EN Mobile และภาพภาษาอื่นคง Record และสถิติเดิม |
| CTR รายกราฟฟิก | คำนวณจาก Click และ IMP ของ **Graphic_ID/Version นั้นเท่านั้น** |
| สรุปรายภาษา | รวม Click และ IMP ของภาษานั้นตามขอบเขตรายงาน แล้วคำนวณ CTR ใหม่ ไม่เฉลี่ย CTR ของ Desktop/Mobile หรือแต่ละเวอร์ชัน |
| ใช้ไทยสำรอง | นับตาม **ภาษาของภาพที่แสดงจริง** เช่น เว็บอังกฤษแสดงไทยสำรอง ให้นับเข้า Graphic_ID ภาษาไทย ไม่เพิ่มยอดให้ภาพอังกฤษ |

หากต้องการวิเคราะห์ว่าภาพไทยถูกแสดงบนเว็บภาษาใด ให้เก็บ **ภาษาหน้าเว็บ** แยกจาก **ภาษากราฟฟิกที่แสดงจริง** เพื่อไม่ให้สถิติปะปนกัน

**05.4 สูตรและรูปแบบการแสดงตัวเลข**

ฐานข้อมูลต้องเก็บ **จำนวนจริงเต็มจำนวน** แล้วจึงย่อเฉพาะตอนแสดงผล

| จำนวนจริงของ Click / IMP | วิธีแสดง | ตัวอย่าง |
|--------------------------|----------|----------|
| 0–999                    | แสดงจำนวนเต็มตามจริง | `0`, `123`, `999` |
| 1,000–999,999            | หาร 1,000 แสดงทศนิยม 1 ตำแหน่ง ตัดเศษไม่ปัดขึ้น | `1,000 → 1.0K`, `1,999 → 1.9K` |
| ตั้งแต่ 1,000,000        | หาร 1,000,000 แสดงทศนิยม 1 ตำแหน่ง ตัดเศษไม่ปัดขึ้น | `1,000,000 → 1.0M`, `1,299,999 → 1.2M` |

**สูตร CTR**

`CTR = (Click จริง ÷ IMP จริง) × 100`

* คำนวณจากจำนวนจริงก่อนย่อเป็น K/M
* แสดงทศนิยม 1 ตำแหน่ง โดยตัดเศษไม่ปัดขึ้น เช่น `3.39% → 3.3%`
* หาก IMP เท่ากับ 0 ให้แสดง `—` เพราะยังคำนวณ CTR ไม่ได้
