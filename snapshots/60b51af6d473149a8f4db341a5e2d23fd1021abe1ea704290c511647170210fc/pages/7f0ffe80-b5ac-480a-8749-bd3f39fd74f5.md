* วันที่เริ่มต้น - วันที่สิ้นสุด

เป็นตัวเลือกแบบ Calendar ให้เลือกวันที่เริ่มต้น→วันที่สิ้นสุด ตามลำดับ หลังเลือกระบบจะต้องคำนวณระยะเวลาทั้งหมดและแสดง จำนวนวันทั้งหมด พร้อมกับวันที่เริ่มต้น-วันที่สิ้นสุด ในรูปแบบ DD/MM/YYYY ทั้งคู่

```
- ตัวเลือกแบบ Calendar **ไม่สามารถเลือกวันที่ในอดีตได้**
- การแสดง Calendar จะแสดงเดือนสองเดือนคู่กันเสมอ
- กดไปทางซ้าย ← จะแสดง เดือนที่ n\-1, และเดือน n Ex\. กันยายน และ ตุลาคม 
- กดไปทางขวา → จะแสดงเป็น เดือนที่ n และเดือน n\+1 Ex\. ตุลาคม ไป พฤศจิกายน
- กดคลิกเลือกวันครั้งแรกจะเป็นวันที่เลือกเลยทันทีในรูปแบบ DD/MM/YYYY และเมื่อคลิกครั้งที่ 2 จะกำหนดเป็น วันที่สิ้นสุดทันที 
- เมื่อครบเดือนธันวาคม ให้เริ่มปีค\.ศ\.ใหม่ 
- สามารถเลือกซ้ำได้กับที่มีอยู่
```
