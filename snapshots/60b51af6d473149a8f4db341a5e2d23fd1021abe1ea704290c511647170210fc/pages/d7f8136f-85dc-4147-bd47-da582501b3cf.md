**EP-02 สถานะใบประกาศออนไลน์มือสอง**

 ![](/api/attachments.redirect?id=44ab60db-4692-493b-99ed-9acd92211744)

* **ใบประกาศที่ user ลงสำเร็จหลังจากลงใบประกาศแล้วนั้น** จะแสดงอยู่ในจัดการใบประกาศสถานะออนไลน์ ตามเงื่อนไขของ logic ที่นำเสนอ   default หน้าสถานะใบประกาศออนไลน์เลยเมื่อ user กดเข้ามาในหน้านี่
* **มีแท็กแสดงกรณีเข้าร่วมแคมเปญ**
  * แสดงแท็ก Campaign + ระยะเวลา เริ่มต้นนับจากวันพรี-วันสิ้นสุดแคมเปญ
    * ปุ่มสร้างโปรโมชั่น และ เพิ่มวิดีโอ (กรณียังไม่สร้าง)
    * ปุ่มดูโปรโมชั่นและดูวิดีโอโปรโมท (กรณีเพิ่มแล้ว)

**กรณีมีแคมเปญ การเพิ่มมี logic ดังต่อไปนี้**

**EP-02.1 การเพิ่มวิดีโอโปรโมทและโปรแคมเปญของใบประกาศแต่ละหมวด มี logic ดังต่อไปนี้**

1\. ปุ่มเพิ่มวิดีโอโปรโมทและโปรแคมเปญ จะเริ่มแสดงให้ input เมื่อเพิ่มใบประกาศเหล่านั้นเข้ารวมแคมเปญ user ฝั่ง console สามารถเข้ามา input ได้ เมื่อ แคมเปญนั้นสร้างสำเร็จ แต่โปรโมชั่นและวิดีโอจะแสดงเมื่อถึงช่วง pre event —> end เมื่อหมดแล้วจะไม่แสดง ทั้งการแสดงผลฝั่งหน้าบ้านและฝั่ง console (แสดงเฉพาะใบประกาศ/โปรไฟล์บริษัทที่เข้าร่วม)

 ![](/api/attachments.redirect?id=587c35a7-dc7e-4e6a-8797-d59c432c15e0)

2\. การเพิ่ม/แก้ไข/ลบ จากฝั่ง backoffice และ console มีผลต่อการใช้งาน หากเพิ่มแก้ไขลบ จากทางใดทางนึง จะส่งผลกระทบต่ออีกระบบ

3\. สร้าง= ยังไม่มีโปรโมชั่นหรือวิดีโอนั้น

4\. ดู= สร้างไปแล้ว สามารถเข้าไปแก้ไขข้อมูลหรือลบได้

**การเพิ่มโปรโมชั่นช่วงแคมเปญ**

การออกแบบเป็นไปตาม Figma  Modal จะขึ้นเมื่อกดเพิ่มโปรโมชั่น**ช่วงแคมเปญ**

ข้อมูลที่ให้กรอกจำเป็นต้องกรอกทุกช่อง โดยมี่ข้อมูลดังนี้

1\. วันที่เริ่มต้น - วันที่สิ้นสุดยึดตามแคมเปญ   2. หัวข้อโปรโมชั่น 3.รูปภาพโปรโมชั่น 4.รายละเอียดโปรโมชั่น

* Backoffice สามารถเพิ่ม โปรโมชั่นได้ และ console ฝั่ง user ก็สามารถเพิ่มได้เช่นกัน หากเพิ่มจากที่ใดที่นึง อีกที่จะเห็นข้อมูลในการเพิ่มนั้นด้วย
* Logic การเพิ่มโปรโมชั่นมีดังต่อไปนี้ในช่วงอีเว้น
  * สามารถเลือกวันที่เริ่มต้นก่อน prevent หรือ เลือกหลังวันที่ pre event —> ก่อนวันสิ้นสุด eventได้
* ให้เลือกวันที่เริ่มต้นก่อน แล้วจึงเลือกวันที่สิ้นสุด อีกครั้ง
