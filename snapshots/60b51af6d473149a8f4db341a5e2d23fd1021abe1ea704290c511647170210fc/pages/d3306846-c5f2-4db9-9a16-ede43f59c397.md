**4. Logic blacklist user** 

● เมื่อแอดมินพบการลงใบประกาศที่แปลกปลอมในระบบมากกว่าเท่ากับ 3 ใบประกาศ แล้วได้มีการทำการ rejects ใบประกาศ(ให้ไปอยู่ในหมวดรออนุมัติ) ระบบต้องตรวจสอบได้ว่ามี user ใดบ้างที่ทำการลงใบประกาศแปลกปลอมแล้วถูกให้รออนุมัติใบประกาศ มากกว่าเท่ากับ 3 ใบประกาศ  เมื่อตรวจสอบแล้ว เข้าเงื่อนไขจะสามารถใช้ logic blacklist user ได้  (แปลกปลอม=ลงใบประกาศไม่เหมาะสม)

● โดยหากทำการ blacklist user ที่เกี่ยวข้องกับการลงใบประกาศไปแล้วนั้น  user นั้นจะยังทำการลงใบประกาศ แต่ใบประกาศที่ลงจะถูกเข้าไปอยู่ในหมวดรออนุมัติ อัตโนมัติ และใบประกาศนั้นจะไม่แสดงบนเว็บน่าอยู่
