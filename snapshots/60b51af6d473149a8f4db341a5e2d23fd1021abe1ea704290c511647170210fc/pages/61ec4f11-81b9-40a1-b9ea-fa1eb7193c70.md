ใช้กับผลค้นหาตอนพิมพ์ในช่อง Search Navbar บนหน้า Center (ซื้อใหม่ / ซื้อมือสอง / เช่า-หอพัก / รับสร้างบ้าน) ค้นจากทุกจังหวัดที่เปิดแล้ว เป็น public ไม่ต้องใช้ token ใช้แค่ apikey ตามปกติ **ไม่ต้องส่ง header** `**province**`

```cs
GET /api/listing/nav-search/thailand/all?search={คำค้น}
```

shape เดียวกับ `/api/listing/nav-search/all` (ของหน้าแยกจังหวัด) แต่มี field เพิ่มตามหัวข้อด้านล่าง

## Field ที่เพิ่มจากเส้นแยกจังหวัด

| Field | ความหมาย |
|-------|----------|
| `<section>.location.province[]` | จังหวัดที่ตรงคำค้น ไม่ส่ง key นี้เมื่อไม่มีผล |
| `<section>.location.*[].province` | จังหวัดของแถวนั้น `{id, slug, name}` มีทุกแถว ใช้กำกับชื่อที่ซ้ำกันและพาไปหน้าจังหวัด |
| `<section>.count.province` | จำนวนจังหวัดที่ตรงคำค้น ไม่ส่ง key นี้เมื่อเป็น 0 |
| `home_builders.home_builder[].service_type` | ประเภทบริการของบริษัท |
| `home_builders.style[].count` | จำนวนแบบบ้านของสไตล์นั้น (หน่วย แบบ) อาจไม่มี key นี้ถ้าดึงตัวเลขไม่สำเร็จ |

## รายการในแต่ละ section

| Field | ค้นจาก | กดรายการ → ไปที่ | กดดูทั้งหมด → ไปที่ |
|-------|--------|------------------|---------------------|
| `projects.location` และ section อื่น | จังหวัด, สถานที่ใกล้เคียง, โซน, อำเภอ, ตำบล | หน้าเสิร์ชของ `province.slug` พร้อมใช้ที่ตั้งนั้นเป็น filter | ไม่มี               |
| `projects.project` | ใบประกาศโครงการใหม่ | หน้ารายละเอียดใบประกาศ | `/property-project/properties/thailand` |
| `projects.brand` | ชื่อแบรนด์โครงการ นับที่บริษัทแม่ ไม่แยกสาขา | หน้าโปรไฟล์แบรนด์ | `/property-project/developers/thailand` |
| `secondhands.secondhand` | ใบประกาศมือสองที่ลงขาย ไม่รวม NPA | หน้ารายละเอียดใบประกาศ | `/property-for-sale/properties/thailand` |
| `secondhands.agent` | ชื่อนายหน้าที่มีใบประกาศออนไลน์ | หน้าโปรไฟล์นายหน้า | `/property-for-sale/agents/thailand` |
| `secondhands.npa` | ใบประกาศมือสองของ NPA | ตาม FE เดิม      | `/property-for-sale/npa-banks/thailand` |
| `apartments.apartment` | หอพัก/อพาร์ทเมนต์ + มือสองที่ลงเช่า (`price` เป็นราคาเช่า) | หน้ารายละเอียดใบประกาศ | `/rent/properties/thailand` |
| `home_builders.style` | ชื่อสไตล์ | หน้าค้นหาแบบบ้าน center + filter สไตล์ | ไม่มี               |
| `home_builders.home_design` | แบบบ้านของบริษัทแม่ที่ออนไลน์ | หน้ารายละเอียดแบบบ้าน | `/home-design/styles/thailand` |
| `home_builders.home_builder` | ชื่อบริษัทแม่ที่ออนไลน์ | หน้าโปรไฟล์บริษัท | `/home-builder/companies/thailand` |

* ที่ตั้งแสดงเฉพาะจังหวัดที่เปิดแล้วและไม่ใช่ soft launch เพราะจังหวัดอื่นไม่มีหน้าปลายทาง
* แต่ละกลุ่มส่งมาไม่เกิน 50 แถว ส่วน `count` เป็นจำนวนที่ค้นเจอจริง จึงอาจมากกว่าจำนวนแถว
* `count.total` รวมทุกกลุ่มของ section นั้นแล้ว รวมที่ตั้งด้วย
* `search` ว่าง จะได้โครงสร้างเปล่าและทุก count เป็น 0 โดยไม่ค้นหา
* แบรนด์ค้นแบบตรงบางส่วนของชื่อ เหมือนหน้าค้นหาแบรนด์ จึงไม่รองรับคำที่พิมพ์ผิด และ `name_en` ว่าง
* `name.en` ของจังหวัดมาจากข้อมูล `support_provinces` ซึ่งตอนนี้เป็นค่าแบบ slug เช่น `khonkaen` ส่วน `name.en` ของใบประกาศและสไตล์อาจไม่มี ควร fallback เป็น `th`
* บน env ที่เปิดงานหลายภาษา `name` ของที่ตั้งและสไตล์ รวมถึง `province.name` จะเป็นค่าเดียวตาม `Accept-Language`
* ควรยกเลิก request เดิมเมื่อพิมพ์ต่อ (AbortController) เส้นนี้ถูกเรียกทุก keystroke ที่ผ่าน debounce
