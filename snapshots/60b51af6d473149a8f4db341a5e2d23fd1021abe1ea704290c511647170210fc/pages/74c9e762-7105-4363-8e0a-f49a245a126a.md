section "บทความน่าสนใจ" บนหน้า Home กลาง (ทั้งประเทศ): chip ที่ 2 (จังหวัด / center) และ link ของการ์ด

* **หน้า:** Home กลาง `/` (`/en`, `/zh`) ใช้ logic นี้ทั้งกรณี location เป็น `center` และ `thailand` (`resolveMenuLocation` map `thailand` → `center` แล้ว `isCenter` เป็นจริง) ส่วน `/thailand` จริงๆ ถูก redirect ไป `/` ใน `next.config.ts` จึงไม่มีหน้า `/thailand` แยก
* **Section:** `ArticlesInteresSection` → `ArticlesInteresClient` → `ArticlesInteresBox` → `ArticleBox`
* **ข้อมูล ณ วันที่:** 2026-11-12 (branch `feature/setup-project-3-languages`)

## API

`GET {NEXT_PUBLIC_API_URL}/api/blog/interest/center` (เพิ่ม `?tag=<slug>` ตอนเปลี่ยนแท็บ)

* ฟีด center ส่งบทความของทุกจังหวัดรวมกัน ไม่ใช่เฉพาะบทความระดับประเทศ
* แต่ละบทความมี `tags[]` เป็น `{ id, name, slug }` ไม่มี field `province` แยก
* `name` เป็นข้อความที่ BE ส่งมา (string หรือ `{ th, en, zh }`) FE แสดงตามที่ส่ง ไม่แต่งข้อความเอง

## กฎ chip ที่ 2

การ์ดแสดง chip 2 ตัว: ตัวแรกคือหมวด (`tags[0]`) ตัวที่ 2 คือจังหวัดหรือ center


1. **แสดงเฉพาะหน้า Home กลาง** หน้า Home จังหวัดไม่แสดง เพราะซ้ำกับจังหวัดของหน้าอยู่แล้ว
2. หา tag ที่ **slug** อยู่ใน location slugs ของ blog (`BLOG_LOCATION_SLUGS` = `center` + จังหวัดที่เปิด) รวม `thailand` ซึ่งเป็น tag เก่าของบทความระดับประเทศ หาจากทุก tag ตามลำดับใน `tags` และไม่ใช้ `tags[1]` ตรงๆ เพราะลำดับ tag ไม่การันตี
3. ถ้าเจอหลายตัว (เช่น 2 จังหวัด หรือ center + จังหวัด) ใช้ **ตัวแรกตามลำดับ** ใน `tags` ตัวเดียว จังหวัดที่เหลือไม่แสดง chip และ link ใช้ tag ตัวเดียวกับ chip เสมอ จึงไม่ชี้คนละจังหวัด
4. ถ้า tag ที่เจอเป็น `tags[0]` แปลว่าแสดงเป็น chip หมวดอยู่แล้ว จึงไม่แสดง chip ที่ 2 ซ้ำ
5. ข้อความ chip = `name` ของ tag นั้น (ผ่าน `pickI18n` ตามภาษา)
6. **ไม่เจอ tag ที่ตรง = ไม่แสดง chip ที่ 2** ไม่มีข้อความ fallback
7. หา tag ด้วย slug เท่านั้น ไม่เทียบจากชื่อ tag

tag อื่นที่ไม่ใช่ slug จังหวัด (เช่น `naa-yuuriiwiw`, `_project_80705`) ไม่แสดง

## กฎ link ของการ์ด

ทุกการ์ดเคยชี้ `/blogs/center/<slug>` ทั้งหมด แต่หน้า detail `/blogs/<location>/<slug>` ตรวจว่า **บทความต้องมี tag ที่ slug ตรงกับ** `<location>` (`getBlogDetail`) บทความที่ติด tag แค่จังหวัดจึง 404 ที่ `/blogs/center/...`

ตอนนี้บน Home กลาง:

| บทความมี tag | link |
|--------------|------|
| จังหวัด (เช่น `khonkaen`) | `/blogs/khonkaen/<slug>` |
| `center` หรือ `thailand` | `/blogs/center/<slug>` (`thailand` ถูก map เป็น `center` ด้วย `resolveMenuLocation`) |
| ไม่มี tag location เลย | `/blogs/center/<slug>` (ซึ่งจะ 404 ถ้าไม่มี tag `center`) |

* link กับ chip ใช้ tag location ตัวเดียวกัน (ตัวแรกตามลำดับใน `tags`) ต่างกันแค่ chip ไม่แสดงถ้า tag นั้นเป็น `tags[0]` เพราะเป็น chip หมวดอยู่แล้ว ส่วน link ยังใช้ tag นั้นสร้าง `/blogs/<จังหวัด>/<slug>` ตามปกติ
* หน้า Home จังหวัดใช้ link เดิม (`/blogs/<จังหวัดของหน้า>/<slug>`)

## ข้อควรระวัง

* `ArticleBox` มี JSX การ์ด 2 ชุด (ชุดตอนมี `onVideoClick` กับชุดที่ห่อ `<Link>` ซึ่ง Home ใช้) แก้ส่วนแสดงผลต้องแก้ทั้งสองชุด
