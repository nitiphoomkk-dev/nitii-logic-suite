ใช้กับ section **ประกาศขายอสังหาฯ มือสองล่าสุด** บนหน้า Home รวมจังหวัด (Home Center, EP-06) เป็น public ไม่ต้องใช้ token ใช้แค่ apikey ตามปกติ **ไม่ต้องส่ง header** `**province**` เพราะดึงจากทุกจังหวัดเสมอ

```cs
GET /api/listing/home-page/thailand/secondhand-posts
```

shape เดียวกับ `/api/listing/home-page/secondhand-posts` (ของหน้า Home แยกจังหวัด) ใช้ component การ์ดเดิมได้เลย

## ตัวอย่าง response

```json
{
  "success": true,
  "message": "get thailand secondhand posts successfully",
  "data": {
    "province_id": 0,
    "posts": [
      {
        "id": 90369,
        "slug": "ขายบ้านเดี่ยว-...-90369",
        "project_name": { "th": "บ้านเดี่ยว ...", "en": "..." },
        "post_type": "secondhand",
        "listing_types": ["sale"],
        "is_new": true,
        "update": "อัพเดท 2 ชั่วโมงที่แล้ว",
        "...": "field อื่นเหมือนการ์ดหน้า Home แยกจังหวัด"
      }
    ]
  }
}
```

> ข้อมูลข้างบนเป็นตัวอย่าง ไม่ใช่ข้อมูลจริง

## Field

| Field | ความหมาย |
|-------|----------|
| `province_id` | เป็น `0` เสมอ (หมายถึงรวมทุกจังหวัด) |
| `posts` | การ์ดใบประกาศ สูงสุด **12 ใบ** เรียงมาให้แล้ว FE แสดงตามลำดับได้เลย (ซ้าย → ขวา) |
| `posts[].is_new` | `true` = ติดป้าย NEW (ลงประกาศมาไม่เกิน 6 ชั่วโมง) |
| `posts[].listing_types` | section นี้เป็น `["sale"]` เสมอ |

## วิธีเลือกและเรียงการ์ด


1. ใบประกาศที่ติด **NEW** มาก่อน
2. ถ้ายังไม่ครบ 12 ใบ เติมด้วยใบประกาศธรรมดา
3. ในแต่ละกลุ่ม เรียงจาก **ลงใหม่ / ดันล่าสุด** ก่อน (ดูเวลาที่ใหม่กว่าระหว่างวันลงกับวันดัน) กลุ่มธรรมดาไม่แทรกขึ้นก่อนกลุ่ม NEW

ตัวอย่าง: มีใบ NEW 10 ใบ → แสดงทั้ง 10 ใบ แล้วเติมใบธรรมดาอีก 2 ใบ รวม 12 ใบ

* แสดงเฉพาะใบประกาศมือสองที่ **ลงขาย** ออนไลน์ ไม่หมดอายุ ไม่ใช่ฉบับร่าง และ **ไม่รวม NPA** (เหมือน section เดียวกันของหน้า Home แยกจังหวัด)
* ใบประกาศที่ลง **ทั้งขายและเช่า** ขึ้นได้ทั้ง section นี้ (เป็นการ์ดขาย) และ section ประกาศเช่าล่าสุด (เป็นการ์ดเช่า) ตามสเปก EP-06
* ถ้าไม่มีใบประกาศเลย `posts` จะเป็น `[]` (ไม่เป็น `null`)
* ปุ่ม "ดูทั้งหมด" → หน้าค้นหามือสอง center (FE กำหนด URL เอง) จำนวนในหน้านั้นอาจมากกว่า เพราะหน้าค้นหารวม NPA
* ไม่มี cache ข้อมูลเป็นปัจจุบันทุกครั้งที่เรียก
