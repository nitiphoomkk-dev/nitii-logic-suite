### **รูปภาพปก (Section ข้อมูลบริษัท) — รองรับ 3 ภาษา (Console,bakcoffice)**

ภาพปกแต่ละภาษาใช้ **ไฟล์ชุดเดียวกันร่วมกันทั้ง Desktop และ Mobile** อัปโหลดได้สูงสุด **3 ภาพต่อภาษา** (รับไฟล์ตรงๆ ไม่มี Modal ครอปภาพ, `JPG/JPEG/PNG` ≤ `3 MB`, แนะนำสัดส่วน `21:9`, drag & drop และเรียงลำดับภาพได้) โดย **ภาษาไทย (TH) บังคับ ≥ 1 ภาพทุก Role** ส่วน **ภาษาอังกฤษ (EN) และภาษาจีน (CN) ไม่บังคับ**

#### **1. Logic การทำงาน**

| หัวข้อ | เงื่อนไข / การกระทำ | Logic การทำงาน |
|--------|---------------------|----------------|
| ช่องอัปโหลด 3 ภาษา | เลือกแท็บภาษาไทย (TH), อังกฤษ (EN) หรือจีน (CN) | แสดงช่องอัปโหลดภาพปกของภาษาที่เลือก **สูงสุด 3 ภาพต่อภาษา** โดยไม่แยกช่อง Desktop และ Mobile; drag & drop และเรียงลำดับภาพแยกกันในแต่ละภาษาได้ |
| รูปภาพปกภาษาไทย (TH) | เพิ่มหรือแก้ไขภาพปกในแท็บภาษาไทย | **บังคับอย่างน้อย 1 ภาพทุก Role** (ทั้งโปรไฟล์ส่วนกลาง และสาขาพรีเมี่ยมที่ปิดใช้ข้อมูลแม่); ใช้เป็น **ภาพหลัก** และเป็น **ภาพสำรอง (Fallback)** สำหรับ EN/CN ที่ไม่ได้อัปโหลด |
| ภาษาอังกฤษ (EN) / จีน (CN) | ไม่อัปโหลดภาพภาษาอังกฤษหรือภาษาจีน | **ไม่บังคับ** บันทึกได้เมื่อข้อมูลบังคับอื่นและภาพไทยผ่านเงื่อนไข โดยไม่แจ้ง Error ว่าต้องใส่ภาพ EN/CN |
| อัปโหลดอังกฤษหรือจีน | ผู้ใช้อัปโหลดภาพปกของภาษานั้น (1–3 ภาพ) | เก็บชุดภาพและลำดับภาพแยกตามภาษา ใช้ไฟล์ชุดเดียวกันทั้ง Desktop และ Mobile |
| การแสดงผล Desktop / Mobile | ผู้ใช้งานเปิดหน้าโปรไฟล์บน Desktop หรือ Mobile | แสดงชุดภาพปกของภาษาที่เลือกโดยใช้ไฟล์เดียวกันทั้งสองอุปกรณ์ และปรับขนาดตามพื้นที่แสดงผล (1 ภาพไม่เลื่อน; 2–3 ภาพ auto-slide ทุก 10 วินาที) |
| ไม่มีภาพของภาษาที่เลือก | เว็บไซต์เป็นภาษาอังกฤษหรือจีน แต่โปรไฟล์ไม่มีภาพปกของภาษานั้น | ใช้ **ชุดภาพปกภาษาไทยสำรองของโปรไฟล์เดียวกัน** ทั้ง Desktop และ Mobile |
| มีภาพของภาษาที่เลือกไม่ครบ 3 ภาพ | เช่น ภาษาอังกฤษมีภาพปก 1 ภาพ (แต่ภาษาไทยมี 3 ภาพ) | แสดงเฉพาะภาพภาษาอังกฤษที่มีอยู่ (1 ภาพ) **ไม่ดึงภาพไทยมาเติมเพิ่ม** |
| โปรไฟล์ส่วนกลาง (แม่) | Super Admin หรือ Admin แก้ไขโปรไฟล์ส่วนกลาง | อัปโหลด แก้ไข และเรียงลำดับภาพปกได้ครบทั้ง 3 ภาษา (สูงสุด 3 ภาพ/ภาษา, TH บังคับ ≥ 1 ภาพ) |
| โปรไฟล์สาขา — **ธรรมดา** | เปิดหน้าแก้ไขโปรไฟล์สาขาที่ไม่ได้ซื้อพรีเมี่ยม | แสดงแท็บ TH/EN/CN และภาพปกจากแม่แบบ **อ่านอย่างเดียว** (กดสลับดูได้แต่**แก้ไข/อัปโหลดไม่ได้** และ**ปิดสวิตช์ใช้ข้อมูลแม่ไว้**); ไม่ตรวจ Error ช่องภาพปกเมื่อกดบันทึก; **ยกเว้น** หาก BO จังหวัดเปิดสิทธิ์ฟีเจอร์ **"การแสดงผลพิเศษ + ตกแต่ง" เป็น** `**ทุกคน**` **ให้ปลดล็อกใช้งานได้เหมือนสาขาพรีเมี่ยมทันที** |
| โปรไฟล์สาขา — **พรีเมี่ยม** *(เปิดใช้ข้อมูลกับแม่)* | เปิดสวิตช์ "ใช้ข้อมูลกับบริษัทแม่" (`EP-11`) | ดึงชุดภาพปก 3 ภาษาจากโปรไฟล์แม่มาทับตามภาษาเดียวกัน (ไม่เก็บฉบับเก่าของสาขาแยกไว้) และ **disable ช่องแก้ไขทุกภาษา**; เมื่อแม่แก้ภาพภาษาใด สาขาเปลี่ยนตาม; หากแม่ไม่มี EN/CN ใช้ภาพไทยของแม่แทน |
| โปรไฟล์สาขา — **พรีเมี่ยม** *(ปิดใช้ข้อมูลกับแม่)* | ปิดสวิตช์ "ใช้ข้อมูลกับบริษัทแม่" | **คัดลอกชุดภาพปก 3 ภาษาปัจจุบันจากแม่** มาให้สาขาแก้ไข/อัปโหลด/เรียงลำดับต่อได้ทันที (TH บังคับ ≥ 1 ภาพ, สูงสุด 3 ภาพ/ภาษา) โดยไม่ดึงจากแม่มาทับอีก; หากสาขาไม่มี EN/CN ใช้ภาพไทยของสาขาสำรอง |
| สาขาพรีเมี่ยมหมดอายุกลับเป็นธรรมดา | แพ็กเกจพรีเมี่ยมหมดอายุ (หรือ BO ปรับสิทธิ์จังหวัดกลับเป็น `Premium`) | **เก็บชุดภาพปก 3 ภาษาเดิมของสาขาไว้ในระบบ** (ซ่อนไม่แสดงผลหน้าเว็บและล็อกอ่านอย่างเดียวใน Console) เพื่อกลับมาใช้งานต่อได้ทันทีเมื่อต่ออายุพรีเมี่ยม |
| ประเภทและขนาดไฟล์ | อัปโหลดภาพในภาษาใดก็ได้ | **ไม่มี Modal ครอปภาพ** รับไฟล์ตรงๆ โดยตรวจเฉพาะชนิดไฟล์ `JPG`, `JPEG`, `PNG` และขนาดไม่เกิน **3 MB** ต่อภาพ (สัดส่วน `21:9` เป็นคำแนะนำ ไม่บล็อกการอัปโหลด) |
| ตรวจสอบก่อนบันทึก (Validation) | กดบันทึกข้อมูล (รวมกรณีลบภาพไทยออกหมดขณะเปิดแท็บ EN/CN) | ตรวจทุกภาษาเมื่อกดบันทึก — หาก TH ว่าง (ไม่มีภาพไทย) แม้ผู้ใช้เปิดแท็บ EN/CN อยู่ ให้ **สลับกลับไปแท็บ TH อัตโนมัติ** เลื่อนจอไปที่ช่อง พร้อมกรอบแดง ข้อความแจ้งเตือน และจุดเตือนบนแท็บที่มีปัญหา; ไม่แจ้ง Error เพราะเว้นภาพ EN/CN |

**ตัวอย่าง:** โปรไฟล์สาขาพรีเมี่ยม (ปิดใช้ข้อมูลกับแม่) อัปโหลดภาพปกไทย 3 ภาพ และอังกฤษ 2 ภาพ โดยเว้นจีน — หน้าเว็บภาษาอังกฤษจะแสดงภาพปกอังกฤษ 2 ภาพ (ไฟล์ชุดเดียวกันทั้ง Desktop และ Mobile) ไม่ดึงภาพไทยมาเติมเป็นภาพที่ 3 ส่วนหน้าเว็บภาษาจีนจะแสดงภาพปกไทยสำรองทั้ง 3 ภาพ และหากพรีเมี่ยมหมดอายุ ระบบจะซ่อนภาพปกบนหน้าเว็บแต่เก็บชุดภาพทั้ง 3 ภาษานี้ไว้ให้เมื่อต่ออายุครับ
