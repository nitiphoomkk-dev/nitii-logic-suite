\*\*Trigger  \*\*เมื่อ  User กดปุ่ม เพิ่ม Top Ads (Userต้องการเพิ่ม Top ads) ขั้นตอนจะตามลำดับไปตาม Figma

\*\*Conditions: \*\*การแสดงในหน้านี้ เป็นไปตามที่ออกแบบ Figma ให้มี 4 หัวข้อในการเพิ่มรายละเอียด คือ

* **หัวข้อเลือกบริษัท** เป็นแถบให้ค้นหาโดยจะมี 2 Features คือ พิมพ์ค้นหา และ
  * \*\*เลือก Drop Down \*\* สามารถเลือกดูบริษัทรับสร้างบ้าน(สาขา)ที่อยู่ในระบบได้  สามารถเลื่อนแถบข้างโดยโชว์จนกว่าจะครบรายการในระบบ→เลื่อนจนสิ้นสุด **เรียงตามเลขไอดีบริษัท แสดงโลโก้บริษัทรับสร้างบ้าน**
  * **ดึงเฉพาะโปรไฟล์สาขาที่ออนไลน์ และออฟไลน์**
  * **Features พิมพ์ค้นหา** พิมพ์ได้ทั้ง TH/EN ตัวเลขและเครื่องหมาย  โดยสามารถ Match กับข้อมูลบริษัทรับสร้างบ้าน (โปรไฟล์สาขาในจังหวัดนั้นได้)ในระบบที่มีชื่อเหมือนและแสดงรายการบริษัทรับสร้างบ้านที่มีชื่อเหมือนกันขึ้นมาให้ User เห็นได้ทันที**แสดงโลโก้บริษัทรับสร้างบ้าน**
  * การพิมพ์จะแสดงชื่อบริษัทภาษาไทย-ภาษาอังกฤษ\*\* เรียงตามเลขไอดีบริษัท\*\*
* \*\*หัวข้อหมวดหมู่ \*\*เป็นตัวเลือกแบบ Single Choice และ มีตัวเลือกให้เลือก 2 หมวดหมู่ คือ
  * 1.บริษัทรับสร้างบ้าน 2. แบบบ้าน

เมื่อกดปุ่มบันทึกข้อมูลโดยยังไม่กรอกข้อมูลให้ครบ จะแสดงกรอบสีแดง และขึ้นกรุณาระบุข้อมูลตาม UI\nและข้อมูลจะไม่สามารถบันทึกได้

**Logic:**

* กรณีที่ไม่เลือกวันที่เริ่มต้น วันที่สิ้นสุด ระบบต้องขึ้นกรอบสีแดง พร้อมแสดงข้อความแจ้งเตือน “กรุณาระบุข้อมูล”
* กรณีไม่เลือกบริษัท หาก user ไม่เลือกข้อมูลในช่องค้นหา ระบบต้องขึ้นกรอบสีแดง พร้อมแสดงข้อความแจ้งเตือน “กรุณาระบุข้อมูล”
* กรณีไม่เลือกหมวดหมู่ บริษัทไม่เลือกรับสร้างบ้าน  หรือ แบบบ้าน ระบบต้องขึ้นกรอบสีแดง พร้อมแสดงข้อความแจ้งเตือน “กรุณาระบุข้อมูล”
* กรณีหากไม่เลือกข้อมูล (รวม) หากมี Field ใด Field หนึ่งไม่ครบ ไม่บันทึกข้อมูล แสดง Error ตามจุดที่ไม่กรอกข้อมูล
