> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/property-for-sale/agents/{จังหวัด}` เช่น `/property-for-sale/agents/khonkaen`, หน้า 2 ขึ้นไป `/property-for-sale/agents/{จังหวัด}/page/{N}`

**ไฟล์หน้า:** `app/(interface)/(search)/search/[main_service]/agents/[location]/page.tsx` และ `.../agents/[location]/page/[page]/page.tsx` (ทั้งคู่ render ผ่าน `agents-listing.tsx` → `AgentSearchPage`)

**TrackingProvider:** `source_type: search`

ใช้ได้เฉพาะ `property-for-sale` ถ้า `{main_service}` เป็นค่าอื่นจะโยน error 404 ไม่แสดงหน้านี้

หน้า 2 ขึ้นไปใช้ component และ tracking ชุดเดียวกัน position นับใหม่จาก 1 ทุกหน้า (ไม่บวก offset ตามเลขหน้า)

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก

## 3. AgentContainner

| Component | Event | ประเภท | ยิงเมื่อ | section_name | section_number | หมายเหตุ |
|-----------|-------|--------|----------|--------------|----------------|----------|
| AgentCard | `agent_recommend` | impression, click | การ์ดเข้าจอ / กด | `agent_recommend_section` | ⚠️ 0           | entity_id = id นายหน้า, ไม่มี position / destination, ⚠️ ไม่เคยได้ `agent_recommend_ad` เพราะข้อมูลถูก map เป็น `is_top_ads` แต่โค้ดเช็ก `is_top_ad` |
| ปุ่มดูทั้งหมด | `all_agent_recommend` | click  | กด "ดูทั้งหมด" | `agent_recommend_section` | 0              | action_id = 0, ไม่มี destination |

⚠️ section_number เป็น 0 เพราะหน้านี้ไม่ได้ส่ง `sectionPosition` ให้ AgentContainner

⚠️ impression เสี่ยงไม่ยิง: การ์ดถูกผูก observer ผ่าน ref ก่อน observer ตัวใหม่ถูกสร้าง และ observer ถูกสร้างใหม่ทุก render ควรเช็กใน network

⚠️ ทุก event ในส่วนนี้ยิงผ่าน `track` ตรง ไม่ผ่าน `useTracker` จึงไม่มี `source_type` และ `user_id` (`is_logged_in` เป็น false เสมอ)

ปุ่มบันทึกบนการ์ดไม่แสดง เพราะ flag `SHOW_BOOKMARK = false` event `_save` จึงไม่ยิง
