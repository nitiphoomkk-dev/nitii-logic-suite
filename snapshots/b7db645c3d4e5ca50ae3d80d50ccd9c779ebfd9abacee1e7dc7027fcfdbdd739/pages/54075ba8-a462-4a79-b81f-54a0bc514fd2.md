ใช้กับตัวเลขในแต่ละแถวตอนกดช่อง Search Navbar โดยยังไม่พิมพ์ บนหน้า Center เป็น public ไม่ต้องใช้ token ใช้แค่ apikey ตามปกติ **ไม่ต้องส่ง header** `**province**` เพราะนับรวมทุกจังหวัดเสมอ

```cs
GET /api/listing/nav-search/thailand
```

shape เดียวกับ `/api/listing/nav-search` (ของหน้าแยกจังหวัด) ให้เรียกเส้นนี้เมื่อ province เป็น `thailand`

## ตัวอย่าง response

```json
{
  "success": true,
  "data": {
    "new_projects": { "projects": 3582, "companies": 2543 },
    "second_hand": { "announcements": 1411, "real_estate_agents": 70, "npa": 9412 },
    "rent": { "announcements": 3620 },
    "house_construction": {
      "styles": {
        "classic": 291, "contemporary": 973, "englishcottage": 70, "loft": 14, "luxury": 143,
        "minimal": 250, "modern": 941, "nordic": 136, "tropical": 137
      },
      "total_designs": 3197,
      "construction_companies": 301,
      "design_companies": 183
    }
  }
}
```

> ตัวอย่างจาก uat วันที่ 4 พ.ย. 2569 ตัวเลขเปลี่ยนตามข้อมูล

## Field

| Field | ความหมาย | แถว → หน้าที่กดไป |
|-------|----------|-------------------|
| `new_projects.projects` | โครงการใหม่ทั้งหมด (ออนไลน์ + ปิดขาย + เปิดใหม่เฟสใหม่) | `/property-project/properties/thailand` |
| `new_projects.companies` | แบรนด์โครงการ นับที่บริษัทแม่ ไม่แยกสาขา | `/property-project/developers/thailand` |
| `second_hand.announcements` | มือสองที่ลงขาย ออนไลน์ ไม่หมดอายุ ไม่รวม NPA | `/property-for-sale/properties/thailand` |
| `second_hand.real_estate_agents` | นายหน้าที่มีใบประกาศมือสองออนไลน์อย่างน้อย 1 ใบ | `/property-for-sale/agents/thailand` |
| `second_hand.npa` | ใบประกาศมือสองของ NPA ออนไลน์ ไม่หมดอายุ | `/property-for-sale/npa-banks/thailand` |
| `rent.announcements` | หอพัก/อพาร์ทเมนต์ + มือสองที่ลงเช่า ออนไลน์ ไม่หมดอายุ | `/rent/properties/thailand` |
| `house_construction.total_designs` | แบบบ้านทั้งหมด (ออนไลน์เท่านั้น) ของบริษัทแม่ที่ออนไลน์ | `/home-design/styles/thailand` |
| `house_construction.styles.<slug>` | แบบบ้านแยกสไตล์ (key ไม่มี `_` เช่น `englishcottage`) | หน้าค้นหาแบบบ้าน center + filter สไตล์ |
| `house_construction.construction_companies` | บริษัทที่ให้บริการรับสร้างบ้าน นับที่บริษัทแม่ที่ออนไลน์ | `/home-builder/construction/thailand` |
| `house_construction.design_companies` | บริษัทที่ให้บริการรับออกแบบ นับที่บริษัทแม่ที่ออนไลน์ | `/home-builder/home-designer/thailand` |

* `new_projects.projects`, `new_projects.companies`, `real_estate_agents` และ `rent.announcements` **เท่ากับจำนวนที่หน้าปลายทางแสดง** (เทียบบน uat แล้ว โดยไม่ติ๊ก filter อื่น)
* `second_hand.announcements` ไม่รวม NPA เพราะ NPA มีแถวของตัวเอง ส่วนหน้ามือสอง center รวม NPA ตัวเลขจึงต่างกันมาก เพราะใบประกาศมือสองส่วนใหญ่เป็น NPA (uat: 1,411 เทียบกับ 10,822)
* `second_hand.npa` นับเป็น **ใบประกาศ** ส่วนปลายทางคือหน้าค้นหาทรัพย์สถาบัน
* `total_designs`, `construction_companies` และ `design_companies` นับตามบริษัทแม่ที่ออนไลน์ ไม่ได้เช็คสาขา จึง **อาจไม่เท่ากับ** total ของหน้าปลายทางถ้าหน้านั้นยังกรองด้วยสาขา (uat: รับสร้างบ้าน 301 เทียบกับ 1,858)
* `construction_companies` และ `design_companies` นับซ้ำกันได้ ถ้าบริษัทให้บริการทั้งสองอย่าง
* ทุกช่องเป็นตัวเลขเสมอ (ไม่เป็น `null`) ถ้าไม่มีข้อมูลจะเป็น 0 และทุก key ของ `styles` มีครบเสมอ
* `new_projects.projects`, `total_designs` และ `styles` ใช้ตัวเลขชุดเดียวกับการ์ดหน้า Home center ซึ่ง cache ไว้ฝั่ง backend 30 นาที เลขอาจไม่เปลี่ยนทันทีหลังมีการลงหรือแก้ประกาศ
* URL ปลายทางของแต่ละแถว FE กำหนดเอง
