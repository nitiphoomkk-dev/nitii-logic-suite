> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/property-for-sale/npa-detail/{ธนาคาร}/{จังหวัด}` หรือ `/property-for-sale/npa-{ธนาคาร}-detail/{จังหวัด}` เช่น `/property-for-sale/npa-detail/{ธนาคาร}/khonkaen` และหน้าถัดไปของรายการ `.../page/{N}` (N ตั้งแต่ 2)

**ไฟล์หน้า:** `app/(interface)/(post-and-profile)/detail/property-for-sale/npa-detail/[bank_acronym]/[location]/page.tsx` (`page/[page]/page.tsx` ใช้ไฟล์เดียวกัน)

**TrackingProvider:** `source_type: npa`, `entity_id: {bank_acronym}` (event ที่ไม่ได้ส่ง entity_id เองจะได้รหัสธนาคารนี้)

เป็นหน้าโปรไฟล์ธนาคาร (รวมทรัพย์ NPA ของธนาคารในจังหวัดนั้น) ไม่ใช่ประกาศเดี่ยว ถ้าธนาคารไม่มีทรัพย์ในจังหวัดนี้ จะ redirect ไป `/property-for-sale/npa-banks/{จังหวัด}`

`PostCampaignSection` มีในโค้ด component แต่ไม่แสดง เพราะหน้านี้ไม่ได้ส่ง `campaignModel`

`/page/{N}` ยิง event ชุดเดียวกับหน้าแรก ต่างกันแค่ `position` ของการ์ดใน ProfileListingSection ที่นับต่อจากหน้าก่อน (หน้า N เริ่มที่ (N−1)×24+1) ส่วน section_name / section_number ของการ์ดนับใหม่ทุกหน้า กดเลขหน้าในรายการ (เปลี่ยนในที่ ไม่โหลดหน้าใหม่) ไม่ยิง `page_view` ใหม่

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
