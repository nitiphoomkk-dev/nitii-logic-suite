1\. **การ์ดใบประกาศ**

 ![](/api/attachments.redirect?id=2a622ac8-e344-4931-9a3d-2f0317a4edd8) ![](/api/attachments.redirect?id=5cac70b5-266a-4323-ad67-220d2ee404ae)

ใบประกาศที่เข้าร่วม/บริษัทที่เข้าร่วม (เป็น Top Event และแสดงแบบสุ่ม หากแต่ละหมวดมีไม่ถึง 4 การ์ด จะดึงใบประกาศทั่วไปที่เข้าร่วม  แสดงสูงสุด 12 slot

  a. การวางสนใจแต่ top event ไม่มีการคำนึงถึง top ads ranking model

  b. ดึงใบประกาศที่เข้าร่วมแคมเปญมาแสดงด้วยหากไม่เต็ม slot

  c. ถ้าใบประกาศ 1-2 ใบจะแสดงกึ่งกลาง , ใบประกาศ =<4 ใบประกาศจะชิดซ้าย

  d. จะมีปุ่มเลื่อนซ้าย ขวา เลื่อนซ้ายได้เมื่อเลื่อนขวา เลื่อนเป็นชุด

  e. กดแล้วเปิด new tab ไปหน้าใบประกาศนั้น

| **หัวข้อ** | **รายละเอียด** |
|--------|------------|
| **ประเภทการ์ด** | ใบประกาศ/บริษัทที่เข้าร่วม โดยเป็น Top Event แสดงแบบสุ่ม |
| **เงื่อนไขเติมการ์ด** | หากแต่ละหมวดมีการ์ดไม่ถึง 4 ใบ จะดึง "ใบประกาศทั่วไปที่เข้าร่วม" มาเติม |
| **จำนวน slot สูงสุด** | แสดงสูงสุด 12 slot |
| **โมเดลจัดอันดับ** | คำนึงถึงเฉพาะ Top Event เท่านั้น **ไม่** คำนึงถึง Top Ads Ranking Model |
| **การจัดวาง: 1–2 ใบ** | แสดงกึ่งกลาง (center) |
| **การจัดวาง: ≤ 4 ใบ** | ชิดซ้าย (left-aligned) |
| **ปุ่มเลื่อน** | จะมีปุ่มเลื่อนซ้าย ขวา เลื่อนซ้ายได้เมื่อเลื่อนขวา เลื่อนเป็นชุด |

### **Logic การแสดงผล**

| **Logic** | **ช่วงเวลา** | **เงื่อนไขการดึงข้อมูล** | **ลำดับการแสดง** |
|-------|----------|----------------------|--------------|
| **โปรจอง** | **Pre-event** | ดึงเฉพาะโครงการ/บริษัทที่กรอกโปรใหม่เข้ามาในช่วงนั้น แสดงทั้งหมด | Top event แสดงก่อน → ตามด้วยใบประกาศที่เข้าร่วมแคมเปญ |
| **โปรจอง** | **Event** | ขึ้นหมดทุกโครงการ/บริษัทรับสร้างบ้าน (ทั้งที่เป็นและไม่เป็น top event) | Top event แสดงก่อน → ตามด้วยใบประกาศที่เข้าร่วมแคมเปญ |
|       |          | • ดึงโปรเก่าที่ยังไม่หมดอายุ โดยเวลาคาบเกี่ยวกับช่วง event มาแสดง |              |
|       |          | • ถ้าโปรใหม่ของแคมเปญหมดอายุก่อนถึงช่วง event → ดึงโปรเก่าที่ยังไม่หมดอายุและคาบเกี่ยวเวลาของ event มาแสดงแทน |              |

**โครงการใหม่**

```
- ดึงโปรโมชั่นโครงการใหม่มาแสดงผล
  - **Top event แสดงก่อน \(random เฉพาะในชนชั้นนั้น\) → ตามด้วยใบประกาศที่เข้าร่วมแคมเปญ \(random เฉพาะในชนชั้นนั้น\)**
```

* **โปรจองแสดงสูงสุดไม่จำกัด แสดงทีละ 4 ใบ กดสไลด์แล้วเลื่อนเป็นชุด**
  * **ถ้ามีมากกว่า 4 <8 แสดงการ์ดอื่นชิดซ้าย**
  * **เลื่อนซ้ายได้เมื่อเลื่อนขวา เลื่อนแล้วชน**

| **หมวด** | **ดึงข้อมูลอะไร** | **logic การแสดง** |
|------|---------------|---------------|
| **โครงการใหม่** | เฉพาะรับสร้างบ้าน | Top event (สับในชั้น) → ใบประกาศ (สับในชั้น) |

|-----|------|-----------------|--------------------|---------|
| **1** | **โปรจอง Top event** | **1**           | ไม่สลับ เพราะมีรายการเดียว | คงที่   |
|     | **โปรจอง Top event** | **2+**          | วนตำแหน่งเฉพาะภายในกลุ่มโปรจอง Top event แบบเก้าอี้ดนตรี | โปรจอง Top event อยู่ด้านหน้าก่อนเสมอ และรายการในกลุ่ม Top event จะค่อย ๆ วนตำแหน่งกันจนครบทุกตำแหน่ง ก่อนกลับมาตำแหน่งเดิม |

|     | **โปรจองใบประกาศที่เข้าร่วม** | **2+**          | วนตำแหน่งเฉพาะภายในกลุ่มโปรจองใบประกาศที่เข้าร่วมแบบเก้าอี้ดนตรี | โปรจองใบประกาศที่เข้าร่วมจะแสดงตามหลังโปรจอง Top event เสมอ และรายการในกลุ่มนี้จะค่อย ๆ วนตำแหน่งกันจนครบทุกตำแหน่ง ก่อนกลับมาตำแหน่งเดิม |

* **แสดงชื่อบริษัทรับสร้างบ้าน ภาษาไทยและภาษาอังกฤษ ถ้าไม่พอแสดงเป็นจุด**

* ราคาเริ่มต้นดึงราคาแบบบ้านที่ต่ำที่สุดมาแสดงของแบบบ้านและสูงสุดของแบบบ้าน บริษัทนั้นมาแสดง
