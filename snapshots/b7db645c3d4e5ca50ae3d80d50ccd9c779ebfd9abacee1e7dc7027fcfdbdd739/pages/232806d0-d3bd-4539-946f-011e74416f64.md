ใช้กับตัวเลขบนการ์ดทางลัด 4 ชุด ด้านล่างของ Search Navbar บนหน้า Center เป็น public ไม่ต้องใช้ token ใช้แค่ apikey ตามปกติ **ไม่ต้องส่ง header** `**province**` เพราะนับรวมทุกจังหวัดเสมอ

```cs
GET /api/listing/nav-search/thailand/count
```

shape เดียวกับ `/api/listing/nav-search/count` (ของหน้าแยกจังหวัด)

## ตัวอย่าง response

```json
{
  "success": true,
  "data": {
    "province_id": 0,
    "project": { "coming": 25, "home": 2601, "condo": 288, "townhome": 584 },
    "secondhand": { "secondhand": 1411, "home": 467, "land": 500, "condo": 88, "townhome": 87, "npa": 9412 },
    "apartment": { "apartment": 3002, "home": 340, "condo": 165, "townhome": 71 },
    "home_builder": { "one_million": 3156, "three_million": 1582, "five_million": 850, "ten_million": 318 }
  }
}
```

> ตัวอย่างจาก uat วันที่ 4 พ.ย. 2569 ตัวเลขเปลี่ยนตามข้อมูล

## Field

| Field | การ์ดใน spec (หน่วย) | ความหมาย | การ์ด → หน้าที่กดไป |
|-------|----------------------|----------|---------------------|
| `project.coming` | 1\.1 โครงการเปิดตัวเร็วๆ นี้ (โครงการ) | โครงการเปิดตัวเร็วๆ นี้ที่ยัง active | `/property-project/properties/thailand?other=comingsoon` |
| `project.home` | 1\.2 ค้นหาบ้านใหม่ (โครงการ) | โครงการใหม่ประเภทบ้าน | `/property-project/houses/thailand` |
| `project.condo` | 1\.3 ค้นหาคอนโดใหม่ (โครงการ) | โครงการใหม่ประเภทคอนโด | `/property-project/condo/thailand` |
| `project.townhome` | 1\.4 ค้นหาทาวน์โฮมใหม่ (โครงการ) | โครงการใหม่ประเภททาวน์โฮม | `/property-project/townhomes/thailand` |
| `secondhand.home` | 2\.1 ค้นหาบ้านมือสอง (ใบประกาศ) | มือสองลงขาย ประเภทบ้าน | `/property-for-sale/houses/thailand` |
| `secondhand.land` | 2\.2 ค้นหาที่ดิน (ใบประกาศ) | มือสองลงขาย ประเภทที่ดิน | `/property-for-sale/lands/thailand` |
| `secondhand.condo` | 2\.3 ค้นหาคอนโดมือสอง (ใบประกาศ) | มือสองลงขาย ประเภทคอนโด | `/property-for-sale/condos/thailand` |
| `secondhand.townhome` | 2\.4 ค้นหาทาวน์โฮมมือสอง (ใบประกาศ) | มือสองลงขาย ประเภททาวน์โฮม | `/property-for-sale/townhomes/thailand` |
| `apartment.apartment` | 3\.1 ค้นหาหอพัก/อพาร์ทเม้นให้เช่า (ใบประกาศ) | หอพัก/อพาร์ทเมนต์ให้เช่า | `/rent/apartments/thailand` |
| `apartment.condo` | 3\.2 ค้นหาคอนโดให้เช่า (ใบประกาศ) | คอนโดให้เช่า | `/rent/condos/thailand` |
| `apartment.home` | 3\.3 ค้นหาบ้านให้เช่า (ใบประกาศ) | บ้านให้เช่า | `/rent/houses/thailand` |
| `apartment.townhome` | 3\.4 ค้นหาทาวน์โฮมให้เช่า (ใบประกาศ) | ทาวน์โฮมให้เช่า | `/rent/townhomes/thailand` |
| `home_builder.one_million` | 4\.1 บ้านราคามากกว่า 1 ล้าน (แบบ) | แบบบ้านราคาเริ่มต้นตั้งแต่ 1 ล้าน | หน้าค้นหาแบบบ้าน center + filter ราคา |
| `home_builder.three_million` | 4\.2 บ้านราคามากกว่า 3 ล้าน (แบบ) | แบบบ้านราคาเริ่มต้นตั้งแต่ 3 ล้าน | หน้าค้นหาแบบบ้าน center + filter ราคา |
| `home_builder.five_million` | 4\.3 บ้านราคามากกว่า 5 ล้าน (แบบ) | แบบบ้านราคาเริ่มต้นตั้งแต่ 5 ล้าน | หน้าค้นหาแบบบ้าน center + filter ราคา |
| `home_builder.ten_million` | 4\.4 บ้านราคามากกว่า 10 ล้าน (แบบ) | แบบบ้านราคาเริ่มต้นตั้งแต่ 10 ล้าน | หน้าค้นหาแบบบ้าน center + filter ราคา |

`secondhand.secondhand` (ยอดมือสองลงขายทั้งหมด ไม่รวม NPA) และ `secondhand.npa` ไม่ได้ใช้กับการ์ด 4 ชุดนี้ แต่ส่งมาเพื่อให้ shape เหมือนเส้นแยกจังหวัด

* `project.home/condo/townhome` และ `apartment.*` **เท่ากับจำนวนที่หน้าปลายทางแสดง** (เทียบบน uat แล้ว โดยไม่ติ๊ก filter อื่น)
* การ์ดมือสอง (`secondhand.*`) ไม่รวม NPA ส่วนหน้าปลายทางรวม NPA ตัวเลขจึงต่างกันมาก เพราะใบประกาศมือสองส่วนใหญ่เป็น NPA (uat: บ้าน 467 เทียบกับ 3,459)
* `project.coming` นับจากรายการ coming soon ที่ active จึง **อาจมากกว่า** ยอดหน้าปลายทาง (uat: 25 เทียบกับ 21)
* `home_builder` นับเฉพาะแบบบ้านของบริษัทแม่ที่ออนไลน์ ไม่ได้เช็คสาขา จึงอาจไม่เท่ากับหน้าปลายทางถ้าหน้านั้นยังกรองด้วยสาขา
* ใบประกาศหนึ่งมีได้หลายประเภท ผลรวมของการ์ดแต่ละชุดจึงไม่จำเป็นต้องเท่ากับยอดรวม
* มือสองที่ลงทั้งขายและเช่า ถูกนับทั้งการ์ดชุดมือสองและชุดเช่า (ตั้งใจ เพราะเป็นตัวเลขของแต่ละการ์ด)
* `home_builder` เป็นยอดสะสม แบบบ้าน 10 ล้านถูกนับในทั้ง 4 ช่อง
* การ์ด "บ้าน" นับ `property_types=1` ตามที่หน้าปลายทางใช้
* ทุกช่องเป็นตัวเลขเสมอ (ไม่เป็น `null`) ถ้าไม่มีข้อมูลจะเป็น 0
* `project.home`, `project.condo` และ `project.townhome` ใช้ตัวเลขชุดเดียวกับการ์ดหน้า Home center ซึ่ง cache ไว้ฝั่ง backend 30 นาที เลขอาจไม่เปลี่ยนทันทีหลังมีการลงหรือแก้ประกาศ
* URL ปลายทางของแต่ละการ์ด FE กำหนดเอง
