**EP-03 หน้าเพิ่ม Pop up  กรณีเลือก 4 หมวดที่ไม่ใช่ event online**

 ![](https://wiki.infonayoo.co/api/attachments.redirect?id=ff527002-de7c-4ec2-88fc-a44852505522)

\*\*Trigger  \*\*เมื่อ  User กดปุ่ม เพิ่ม  Pop up ให้มีการพา user ไปอีกหน้าในการลง banner รูปแบบการออกแบบ UI ตาม Figma

\*\*Conditions: \*\*การแสดงในหน้านี้ เป็นไปตามที่ออกแบบ <u>Figma</u> ให้มี 4 หัวข้อในการเพิ่มรายละเอียด คือ

1\. ประเภท 2.ชื่อ pop up 3. ระยะเวลาแสดงผล 4. Slot A/ Slot B

\*\*Logic: \*\*

* **Default การแสดงผลไว้ที่เฉพาะ slot A slot B จะเป็นไม่แสดงผล ในค่าเริ่มแรกของการเพิ่ม**
* **หัวข้อประเภท pop up** เป็นตัวเลือกแบบ Single Choice และ มีตัวเลือกให้เลือก 5 หมวดหมู่ คือ 1.โครงการใหม่ 2. บริษัทรับสร้างบ้าน 3.น่าอยู่ 4.อื่นๆ 5.event online เป็น require  default เป็น โครงการใหม่
* **หัวข้อชื่อของ pop up**สามารถพิมพ์ได้ทั้ง TH/EN ตัวเลขและเครื่องหมาย เป็น require
* \*\*หัวข้อ ระยะเวลาแสดงผล \*\*ให้เลือกวันที่เริ่มต้น - วันที่สิ้นสุด เป็นตัวเลือกแบบ Calendar ให้เลือกวันที่เริ่มต้น→วันที่สิ้นสุด ตามลำดับ หลังเลือกระบบจะต้องคำนวณระยะเวลาทั้งหมดและแสดง จำนวนวันทั้งหมด พร้อมกับวันที่เริ่มต้น-วันที่สิ้นสุด ในรูปแบบ DD/MM/YYYY ทั้งคู่ เป็น require
  * ตัวเลือกแบบ Calendar **ไม่สามารถเลือกวันที่ในอดีตได้  สำหรับวันที่เริ่มต้น**

 ![](/api/attachments.redirect?id=ec2a962b-0d36-42ef-a6d7-22324b94799d)

```
- การแสดง Calendar จะแสดงเดือนสองเดือนคู่กันเสมอ
```
