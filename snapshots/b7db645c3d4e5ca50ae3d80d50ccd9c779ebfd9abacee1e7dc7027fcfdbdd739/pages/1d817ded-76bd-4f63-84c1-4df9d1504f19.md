ถ้าหากว่าไปที่ขั้นตอนที่มากว่า 1 สามารถกดย้อนกลับมาขั้นตอนที่น้อยกว่าได้ เช่น 3 -1 3-2 4-2 4-1\nย้อนกลับไปแล้ว เช่น จาก 4-1 1-4 หากไม่มีการแก้ไข สามารถกดตัวเลขได้เลย ไม่ต้องกดปุ่มถัดไปข้างล่าง\nหากกดตัวเลขต้องเช็คเงื่อนไขว่าไม่มีการลบข้อมูลที่เป็น requirefild ถ้าเช็คแล้วผ่าน สามารถกดตัวเลขจาก 1-4 ได้เลย ใช้กับทุกขั้นตอนทุกการลงใบประกาศ

**เงื่อนไขการเลือกประเภทประกาศ**

* สามารถเลือกได้เพียง 1 ตัวเลือก  และข้อมูลการแสดงผลในช่องการกรอกข้อมูลต้องเปลี่ยนตามที่เลือก ประเภทประกาศ = ขาย, เช่า, ขายและเช่า, หอพัก/อภาร์ทเมนต์ในประเภทอสังหา
* ประเภทประกาศ ขาย เช่า ขายและเช่า ไม่รีเซตคำตอบหากรอกข้อมูลตามประเภทประการแล้ว
* รีเซ็ตคำตอบฟีลอื่นๆ กรณีเลือกหอพักอภาร์ทเมนต์ ข้อมูลที่ถูกอัพมาจะถูกรีเซ็ต
* หากเป็นนายหน้า จะไม่มีตัวเลือก หอพัก/อพาร์ทเม้นท์สำหรับเจ้าของตึก

จังหวัดจะถูก default จาก location ที่ user เล่นมาบนเว็บไซต์จากการเล่น เมื่อเลือกในการแสดงผล → อำเภอ → เมื่อเลือกตำบล จาก dropdownระบบจะแสดงผล แผนที่ที่ให้ลากหมุดแสดงผลขึ้นมา และ แสดงผลรหัสไปรษณีย์ในตำบลนั้น อัตโนมัติ   User สามารถลากหมุดแผนที่ ได้แค่ในกรอบการเลือกข้อมูลที่ท่านเลือก จังหวัด อำเภอ ตำบลในเขตนั้น

**กรณีที่ 2 มาจากหน้ากลางในการลงใบประกาศหรือ Link URL**
