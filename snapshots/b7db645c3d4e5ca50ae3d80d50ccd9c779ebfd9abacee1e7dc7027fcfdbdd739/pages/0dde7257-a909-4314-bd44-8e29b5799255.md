# **1. บทนำและที่มา**

ฟีเจอร์การจัดการฟีดเปิดให้ Admin (ทั้งส่วนกลางและสาขา) สร้าง/แก้ไข/ลบ และเผยแพร่ฟีดในรูปแบบข้อความ รูปภาพ หรือวิดีโอ เพื่อแสดงบนหน้าโปรไฟล์ หน้าเสิร์ช และหน้าใบประกาศของแพลตฟอร์มน่าอยู่ พร้อมกลไกให้แต้มดันใบประกาศ (Hook) เป็นแรงจูงใจในการลงคอนเทนต์ เพื่อต่อยอดจาก ฟีดเจอร์ 2.0 ที่เป็น MVP ของการทำงาน

**2.. วัตถุประสงค์ทางธุรกิจ**

ให้ Admin เผยแพร่คอนเทนต์ฟีด (โปรโมชั่น/ผลงาน/ข่าวสาร) ได้สะดวกและสม่ำเสมอ โดยมีการจูงใจโดยใช้ Hook model

**3. Scope of work**

**Mvp สามารถทำการกดไลค์ กดแชร์ คอมเมนต์ได้ และ จัดการ ลบแก้ไข คอมเมนต์ได้**

* **In of  Scope**
  * ฟีเจอร์สามารถทำได้เทียบเท่าฟีด 2.0
  * มีไลค์ในฟังก์ชั่นการทำงาน
  * มีการคอมเมนต์ในฟังชั่นการทำงาน
    * สามารถตอบกลับในคอมเมนต์ได้
  * มีหน้าฟีดรวมเฉพาะโครงการ
  * มีหน้าฟีดรวมเฉพาะโปรไฟล์โครงการ
  * มีหน้าฟีดรวมเฉพาะโปรไฟล์บริษัท
  * มีหน้าฟีดทั้งหมดของรับสร้างบ้าน และ โครงการ
  * Tag มาแรง (ืnote แล้วมาคุย)
  * มี notification ในการแจ้งเตือน มีการกดไลค์ คอมเมนต์ และแชร์
    * จับคนที่ไม่ล็อคอินได้
  * ระบจัดการคอมเมนต์
    * ลบคอมเมนต์
  * รายงานสถิติการมีส่วนร่วมฟีดเข้าไปอยู่ใน full report พรีเมี่ยม , report ธรรมดา
  * **1.ปุ่มไลค์ด้านนอก โดดเด่น**
  * **2.คอมเมนต์โดยไม่ล็อคอินได้**
  * **3. สื่อสารให้คนรู้ว่าโครงการลงเอง**
  * **4.hook ที่รอข้อมูลจาก data**
  * **หน้าจัดการฟีดฝั่ง nayoo มุมมอง แอดมินโครงการ**
  * การโพสรูปแบบ lay out custom ได้ \*\*(ถาม dev ก่อนว่าทำได้ยากไหม ถ้าทำได้ขอเวลาเพิ่ม เขาเอา)
  * สามารถ track คอมเมนต์ว่า user กับโครงการ/รับสร้างบ้านคุยอะไรกันได้บ้าง
  * \
* **Out of Scope**
  * ระบบจัดการฟีดที่ backoffice
  * การ save draft
  * การโพสวิดีโอแบบอัพโหลดโดยใช้ไฟล์วิดีโอ
  * การแนบประเภทไฟล์อื่นที่ไม่รองรับในฟีด 2.0
  * ไม่มีระบบ รีพอร์ตคอมเมนต์
  * การเพิ่มฟีดบริษัทรับสร้างบ้าน แบบแยกสาขา

**4.** **Requirement เพิ่มเติมที่ต้องการ**

**4.1. การ**มีส่วนร่วม (Interaction) — Priority สูง

* ปุ่มไลค์ให้อยู่ด้านนอก โดดเด่น เห็นชัด (ปัจจุบันไลค์น้อย + กดพลาดบ่อย → ออกแบบลด mis-tap)
* ให้คอมเมนต์ได้โดยไม่ต้องล็อกอิน
* ทำ flow คอมเมนต์ให้ง่าย เร็ว ลดขั้นตอน

**4.2. หน้าใบประกาศ (Announcement page)**

* แก้ปัญหา user หลุด/ออกเมื่อเข้ามาหน้านี้
* แสดงคอมเมนต์ในหน้านี้และกระตุ้นให้คอมเมนต์
* แสดงเวลาในการโพส
* มี section สื่อสารว่า "โครงการกำลังรอการตอบกลับ"

**4.3. Hook / Flow การลงฟีด**

* แทรกสเต็ปในขั้นตอนการลง (hook) เพื่อช่วยให้ลงฟีดได้มากขึ้น
* ออกแบบ hook ที่สร้าง impact ทันที
* ใช้ hook / message ต่างกันตามกลุ่มและพฤติกรรมผู้ใช้
* สื่อสารชัดเจนว่า "ลงฟีดแล้วดีกับเขายังไง\*\*"\*\*

**4.4. รางวัล (Rewards)**

* ทบทวนกลไกรางวัล (เช่น tag มาแรง) ที่ปัจจุบันไม่เวิร์ก
* สื่อสาร value ของรางวัลให้ชัด และทำให้รางวัล impact มากขึ้น

**4.5. สถิติ / Impact / Report**

* เพิ่มการแสดงสถิติเพื่อให้เห็น impact ของโครงการ
* ใน report ควรแสดง reach/การเข้าถึง ไม่ใช่ดูแค่ยอดไลค์ (ไลค์ไม่ใช่ตัวชี้วัดทั้งหมด)
* ลูกค้าควรเห็นว่า impact มาจากการมีส่วนร่วมของตัวเองใน full

**4.6. การสื่อสารคุณค่าโครงการ**

* สื่อสารให้ผู้ใช้รู้ว่าโครงการคืออะไร ได้ประโยชน์อะไร
* แสดงความคืบหน้าของโครงการ

**Pain คนเข้ามาหน้าเว้บเกิดปัญหา 2 อย่างลูกค้าเองไม่รุ้ว่าหรือเชื่อว่ามันอัพเดท ลูกค้าไม่จบที่เว็บเรา หรือหาข้อมูลที่มากกว่า ไปติดต่อนอกแพลตฟอร์มเรา ไม่สามารถบอกได้ว่าลูกค้าอยุ่กับเราจริงๆ เจ้าของโครงการจะไม่ใช้เราเพราะ ไม่รุ้่ามาจากเว็บเรา**

## **BR-3 สถานะออนไลน์/ออฟไลน์ (อิง Last log-in)**

•     ออนไลน์: (เวลาปัจจุบัน − Last log-in) ≤ 120 นาที → แสดง “ออนไลน์” (เช่น จุดสีเขียว)

•     ออฟไลน์: (เวลาปัจจุบัน − Last log-in) > 120 นาที → แสดง “ออฟไลน์” พร้อมเวลาตามรูปแบบ BR-2

## **BR-4  tag New**

•     แสดงป้าย New เมื่อมีการลงโพส และนับต่อไปอีก 6 ชั่วโมง จึงหายไป

## **BR-5 รูปแบบตัวเลขโพสอัปเดต**

| **ช่วง** | **การแสดงผล** |
|------|-----------|
| 0 – 999 | แสดงตัวเลขจริงทั้งหมด (เช่น 123, 999) |
| 1,000 ขึ้นไป (K) | หารด้วย 1,000 แสดงทศนิยม 1 ตำแหน่งเสมอ |
| 1,000,000 ขึ้นไป (M) | หารด้วย 1,000,000 แสดงทศนิยม 1 ตำแหน่งเสมอ |
| การปัดเศษ | ใช้ floor ห้ามปัดขึ้น (No rounding until 1 decimal) |
