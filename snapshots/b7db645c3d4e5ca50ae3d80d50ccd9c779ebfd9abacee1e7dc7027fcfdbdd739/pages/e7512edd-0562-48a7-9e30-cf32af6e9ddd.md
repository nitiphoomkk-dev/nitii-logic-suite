> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/{จังหวัด}/campaign/landing/{slug แคมเปญ}` เช่น `/khonkaen/campaign/landing/{slug}` (ไม่มี rewrite ใน `proxy.ts`)

**ไฟล์หน้า:** `app/[location]/campaign/landing/[slug]/page.tsx` → template `components/pages/campaign/event-online/EventOnlineLanding.tsx`

**TrackingProvider:** `source: campaign_landing`, `source_id` = id แคมเปญ, `source_type: campaign` (ไม่มี `category`)

ทุก event ในหน้านี้ได้ค่าเริ่มต้นจาก `CampaignLandingTrackingProvider`: `entity_id` = id แคมเปญ (ถ้า component ไม่ได้ส่ง entity_id เอง) และ extra_data `page_view_id`, `campaign_slug`, `campaign_phase`

Template นี้ใช้กับทุกจังหวัด ยกเว้น `buriram` (ดูเอกสาร "หน้าแคมเปญ Landing บุรีรัมย์") และ `phitsanulok` + slug `home-expo2026` (ดูเอกสาร "หน้าแคมเปญ Landing พิษณุโลก home-expo2026")

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
