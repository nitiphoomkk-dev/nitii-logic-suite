**Backoffice หน้าฟอร์มลงทะเบียน (Enroll)** การเพิ่มภาพแยกภาษา

| หัวข้อ | เงื่อนไข / การกระทำ | Logic การทำงาน |
|--------|---------------------|----------------|
| รูปภาพภาษาไทย (TH) | เพิ่มภาพในแท็บ `TH` | ใช้ภาพไทยเป็นภาพหลักและภาพสำรอง บังคับอัปโหลดครบทั้ง **3 ตำแหน่ง** (แบนเนอร์ Desktop, แนวตั้ง Desktop, แบนเนอร์ Mobile) |
| ภาษาอังกฤษ (EN) | ไม่อัปโหลดภาพภาษาอังกฤษ | บันทึกได้เมื่อภาพไทยครบ 3 ตำแหน่ง และข้อมูลบังคับอื่นผ่านเงื่อนไข |
| ภาษาจีน (CN) | ไม่อัปโหลดภาพภาษาจีน | บันทึกได้เมื่อภาพไทยครบ 3 ตำแหน่ง และข้อมูลบังคับอื่นผ่านเงื่อนไข |
| อัปโหลดอังกฤษหรือจีน | ผู้ใช้อัปโหลดภาพของภาษานั้น | อัปโหลดได้สูงสุด **3 ภาพต่อภาษา** แยกตามตำแหน่ง (แบนเนอร์ Desktop, แนวตั้ง Desktop, แบนเนอร์ Mobile) จะใส่ครบทั้ง 3 ช่องหรือใส่เฉพาะบางช่องก็ได้ |
| ช่องอัปโหลด | เลือกแท็บภาษาไทย (`TH`), อังกฤษ (`EN`) หรือจีน (`CN`) | แสดงช่องอัปโหลด 3 ตำแหน่งของภาษาที่เลือก พร้อมตัวอย่างรูปภาพและปุ่มลบ (ถังขยะ) โดยคงรูปที่อัปโหลดค้างไว้เมื่อสลับแท็บ |
| เปิดบน Desktop | ผู้ใช้งานเปิดหน้าลงทะเบียนบน Desktop | แสดง **แบนเนอร์ Desktop** และ **รูปแนวตั้ง Desktop** ของภาษาที่เลือก |
| เปิดบน Mobile | ผู้ใช้งานเปิดหน้าลงทะเบียนบน Mobile | แสดง **แบนเนอร์ Mobile** ของภาษาที่เลือก |
| ไม่มีภาพภาษาที่เลือก | เว็บไซต์เป็นอังกฤษหรือจีน แต่ไม่มีภาพภาษานั้นในตำแหน่งที่ต้องแสดง | ใช้ **ภาพภาษาไทย (**`**TH**`**) สำรองในตำแหน่งและอุปกรณ์เดียวกัน** ของหน้าลงทะเบียนรายการเดียวกัน (ไม่ใช้ภาพข้ามอุปกรณ์) |
| มีภาพภาษาที่เลือกเพียงบางตำแหน่ง | เช่น ภาษาอังกฤษอัปโหลดเฉพาะแบนเนอร์ Desktop แต่ไม่ได้ใส่แนวตั้ง Desktop และแบนเนอร์ Mobile | ตำแหน่งที่มีภาพอังกฤษแสดงภาพอังกฤษ ส่วนตำแหน่งที่ว่างใช้ภาพไทยสำรองของตำแหน่งนั้นแทน |
| ดูตัวอย่าง (Preview) | กดปุ่ม `ดูตัวอย่าง Desktop`, `Tablet` หรือ `Mobile` | แสดงตัวอย่างตามอุปกรณ์ที่เลือก โดยอิงภาษาของแท็บที่กำลังเปิดอยู่ (หากแท็บ `EN`/`CN` ช่องไหนว่าง ให้แสดงภาพ `TH` สำรองแทน) |
| ตรวจสอบก่อนบันทึก | กดบันทึกข้อมูล      | ตรวจภาพไทยทั้ง 3 ตำแหน่งและข้อมูลบังคับตามเงื่อนไขที่กำหนด ไม่แจ้ง Error เพราะไม่ได้อัปโหลดอังกฤษหรือจีน |
| ประเภทและขนาดไฟล์ | อัปโหลดภาพ (คลิกหรือลากวาง) | รองรับ `JPG`, `JPEG`, `PNG` ขนาดไม่เกิน **3 MB** ต่อไฟล์; ขนาดแนะนำ แบนเนอร์ Desktop `4038×1440 px`, รูปแนวตั้ง Desktop `1080×1920 px`, แบนเนอร์ Mobile `1074×603 px` |

**ตัวอย่าง:** ใส่ภาพไทยครบ 3 ตำแหน่ง และใส่ภาพอังกฤษเฉพาะแบนเนอร์ Desktop แต่ไม่ใส่จีน เมื่อเปิดเว็บภาษาอังกฤษบน Desktop จะแสดงแบนเนอร์เป็นภาพอังกฤษ ส่วนรูปแนวตั้งใช้ภาพไทยสำรอง และบน Mobile ใช้แบนเนอร์ Mobile ภาษาไทยสำรอง ส่วนเว็บภาษาจีนใช้ภาพไทยสำรองทั้งหมดครับ
