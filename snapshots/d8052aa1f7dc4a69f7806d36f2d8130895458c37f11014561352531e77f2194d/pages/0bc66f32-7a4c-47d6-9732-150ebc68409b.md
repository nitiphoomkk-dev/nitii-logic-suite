เป็นตัวเลือกแบบ Calendar ให้เลือกวันที่เริ่มต้น→วันที่สิ้นสุด ตามลำดับ หลังเลือกระบบจะต้องคำนวณระยะเวลาทั้งหมดและแสดง จำนวนวันทั้งหมด พร้อมกับวันที่เริ่มต้น-วันที่สิ้นสุด ในรูปแบบ DD/MM/YYYY ทั้งคู่

1⁠. ตัวเลือกแบบ Calendar ไม่สามารถเลือกวันที่ในอดีตได้  สำหรับวันที่เริ่มต้น

2⁠. การแสดง Calendar จะแสดงเดือนสองเดือนคู่กันเสมอ

3⁠. กดไปทางซ้าย ← จะแสดง เดือนที่ n-1, และเดือน n Ex. กันยายน และ ตุลาคม 

4⁠. กดไปทางขวา → จะแสดงเป็น เดือนที่ n และเดือน n+1 Ex. ตุลาคม ไป พฤศจิกายน

5⁠. กดคลิกเลือกวันครั้งแรกจะเป็นวันที่เลือกเลยทันทีในรูปแบบ DD/MM/YYYY 

6⁠. เมื่อคลิกครั้งที่ 2และลากคลุม Drag to select จะกำหนดเป็น วันที่สิ้นสุดทันที 

7⁠. เมื่อหลังวันที่ 31 ธันวาคม ให้เริ่มปี ค.ศ.ใหม่ 

8⁠. Filter Calendar สามารถสร้าง insert การ์ด ขึ้นทับวันที่เคยสร้าง insert การ์ด  ช่วงเวลาเดียวกันได้ 

9⁠. แถบสีเขียวด้านล่างปฏิทิน (ระยะเวลาทั้งหมด): ต้อง Auto-calculate ตัวเลขจำนวนวัน และอัปเดตวันที่ในวงเล็บให้ตรงกับ Start Date - End Date ที่ User เพิ่งเลือกใหม่เสมอ

### **EP-01.1 หมวดของ insert card ที่สามารถเพิ่มรูปภาพแบบ 3 ภาษา**

| **หมวด / ผู้ใช้งาน** | **รูปแบบ Insert Card** | **กรณีที่เพิ่มภาพ** |
|------------------|--------------------|-----------------|
| โครงการใหม่ — Backoffice และ Console | Free Text          | เชื่อมโครงการ หรือแนบลิงก์ |
| โครงการใหม่ — Backoffice และ Console | Promotion          | เชื่อมโครงการ หรือแนบลิงก์ |
| น่าอยู่ — Backoffice | Free Text          | แนบลิงก์        |
| อื่น ๆ — Backoffice | Free Text          | แนบลิงก์        |
| รับสร้างบ้าน — Backoffice และ Console | Free Text          | เชื่อมบริษัท เลือกแบบบ้าน หรือแนบลิงก์ |
| รับสร้างบ้าน — Backoffice และ Console | Promotion          | เชื่อมบริษัท เชื่อมใบประกาศแบบบ้าน หรือแนบลิงก์ |
| รับสร้างบ้าน — Backoffice และ Console | แบบบ้านซีรีส์ใหม่  | เลือกแบบบ้านที่เข้าเงื่อนไขและเพิ่มภาพ |
| รับสร้างบ้าน — Backoffice และ Console | แบบบ้านยอดนิยม     | เลือกแบบบ้านที่เข้าเงื่อนไขและเพิ่มภาพ |


ตารางนี้นำ Flow **ตรวจทุกแท็บ → จุดแดง → พาไปยัง Slot/ภาษาที่ผิด → แสดง Error ตรงช่อง** มาใช้กับ Insert Card โดยใช้ **ภาพเดียวต่อภาษา ร่วมกันทั้ง Desktop/Mobile** 

**Solution — การอัปโหลดภาพ Insert Card**

 ![Flow อัปโหลดภาพ Insert Card: กดบันทึก จุดแดง สลับแท็บภาษา และเลื่อนไปช่องภาพที่ต้องแก้](https://wiki.infonayoo.co/api/attachments.redirect?id=6796bf3d-61c3-4dba-979a-ac29359d2462)

ขอบเขต: ใช้กับ Slot A/B ที่เลือกรูปแบบรองรับภาพ 3 ภาษาเท่านั้น

| รหัส | หัวข้อ | เงื่อนไข / การกระทำ | Logic การทำงาน |
|------|--------|---------------------|----------------|
| **IC-IMG01** | โครงสร้างช่องภาพ | เปิดส่วนเพิ่มภาพของ Slot A หรือ B | แสดงแท็บ **TH / EN / CN** แต่ละภาษามีช่องภาพ **1 ช่อง** ใช้ร่วมกันทุกอุปกรณ์ ไม่มีช่องแยก Desktop/Mobile |
| **IC-IMG02** | ภาพภาษาไทย | Slot เปิดการแสดงผลและเป็นรูปแบบที่ต้องใส่ภาพ | **บังคับมีภาพไทยที่อัปโหลดสำเร็จและผ่านเงื่อนไขไฟล์** แม้ใส่ภาพอังกฤษหรือจีนแล้ว ก็ใช้แทนภาพไทยไม่ได้ |
| **IC-IMG03** | ภาพอังกฤษ / จีน | ไม่อัปโหลดภาพภาษานั้น | เว้นว่างได้ ไม่แสดง Required Error และไม่บังคับให้ครบ 3 ภาษา โดยการแสดงผลใช้ไทยสำรองตามกฎเดิม |
| **IC-IMG04** | อัปโหลดภาพ | เลือกไฟล์ในภาษาใด   | ตรวจชนิดและขนาดไฟล์ตามสเปก Insert Card ของช่องนั้น เมื่อสำเร็จแสดงภาพตัวอย่างใน **Slot และภาษาที่เลือก** ภาพหนึ่งไฟล์ถือว่าครบสำหรับภาษานั้น ไม่ตรวจหาไฟล์อีกอุปกรณ์ |
| **IC-IMG05** | สลับแท็บภาษา | อัปโหลดภาพแล้วเปลี่ยนไปภาษาอื่น | สลับแท็บได้ และคงภาพกับข้อมูลที่กรอกไว้ การสลับแท็บไม่ล้างภาพหรือ Error ที่ยังไม่ได้แก้ |
| **IC-IMG06** | กดบันทึก | ผู้ใช้อยู่แท็บภาษาใดก็ได้ | ตรวจภาพ **ทุกภาษาในทุก Slot ที่เปิดการแสดงผล** รวมแท็บที่ไม่ได้เปิดอยู่ หากภาพที่ต้องใช้ยังอัปโหลดไม่เสร็จ ยังไม่บันทึกสำเร็จ |
| **IC-IMG07** | พบข้อผิดพลาด | ไม่มีภาพไทยที่บังคับ หรือมีข้อผิดพลาดไฟล์/การอัปโหลดค้างอยู่ | ไม่บันทึกสำเร็จ แสดง **จุดสีแดงบนแท็บภาษาที่มีปัญหาใน Slot นั้น** พร้อมคงภาพที่ผ่านแล้วทั้งหมด |
| **IC-IMG08** | พาไปแก้ไข | ข้อผิดพลาดอยู่ในส่วนที่ผู้ใช้ไม่ได้เปิดดู | **เลื่อนไปยังส่วนภาพของ Slot ที่มีปัญหา → เปิดแท็บภาษานั้นอัตโนมัติ → แสดงกรอบแดงและข้อความใต้ช่องภาพที่ผิด** หากมีหลายจุด ให้พาไปจุดแรกตามลำดับฟอร์ม โดยภายใน Slot ตรวจ TH → EN → CN |
| **IC-IMG09** | ข้อความ Error | เปิดแท็บที่มีปัญหา  | ระบุสาเหตุให้ตรง เช่น **“กรุณาใส่รูปภาพตามที่กำหนด”** Desktop/Mobile ใช้คำตาม UI  |
| **IC-IMG10** | แก้ไขหรือลบภาพ | อัปโหลดภาพใหม่สำเร็จ หรือยกเลิกไฟล์ EN/CN ที่มีปัญหาจนภาษานั้นว่าง | ตรวจใหม่และล้าง Error ของช่องที่แก้แล้ว หากภาษานั้นไม่มีปัญหาเหลือจึงนำจุดแดงออก **EN/CN ว่างกลับเป็น Optional ได้ แต่ลบ TH จนว่างยังไม่ผ่าน** ผู้ใช้กดบันทึกอีกครั้งเพื่อยืนยัน |
| **IC-IMG11** | Slot ปิดการแสดงผล | ปิด Slot A หรือ B ก่อนบันทึก | ใช้ข้อยกเว้นตาม Flow ต้นทาง: **ไม่ตรวจ Required ภาพของ Slot ที่ปิด และไม่นำภาพไม่ครบของ Slot นั้นมาขัดขวางการบันทึก** หากปิดทั้งสอง Slot ยังต้องตรวจข้อมูลบังคับส่วนอื่นตามเดิม การปิดไม่ใช่คำสั่งลบภาพ |

**กรณีที่ต่างจาก Flow ตัวอย่าง:** เมื่อ Insert Card อัปโหลดภาพ EN สำเร็จ 1 ภาพ ถือว่า EN ครบแล้ว จึงไม่มีกรณี “EN ขาดภาพ Mobile” การพาไปแท็บ EN จะเกิดเมื่อ **ไฟล์หรือการอัปโหลดของ EN มีข้อผิดพลาด** ไม่ใช่เพราะไม่ได้ใส่ภาพแยกอุปกรณ์
