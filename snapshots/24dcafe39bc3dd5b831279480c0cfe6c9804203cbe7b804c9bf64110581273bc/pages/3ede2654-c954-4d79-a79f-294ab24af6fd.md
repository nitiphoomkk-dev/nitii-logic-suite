> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/property-project/developer-detail/{แบรนด์}/{จังหวัด}` เช่น `/property-project/developer-detail/{ชื่อแบรนด์}-{id}/khonkaen`

**ไฟล์หน้า:** `app/(interface)/(post-and-profile)/detail/property-project/developer-detail/[brand_id]/[location]/page.tsx`

**TrackingProvider:** `source_type: developer`, `source_id` = company_id ของแบรนด์ และตั้ง `entity_id` = company_id เป็นค่าเริ่มต้นของทุก event ที่ไม่ได้ใส่ entity_id เอง

* `/thailand` = หน้าหลักแบรนด์, จังหวัดอื่น = หน้าสาขา แสดง section ต่างกันตามวงเล็บในตารางสรุป ลำดับในตารางเป็นของหน้าสาขา (หน้า thailand มี #14 อยู่ก่อน #13)
* แบรนด์ premium ซ่อนบางส่วนตามวงเล็บ และถ้าปิดโฆษณา (`blockAds`) จะไม่มี #19 และ #20, ถ้าปิด Line / Facebook ปุ่มนั้นใน #3 และ #4 จะไม่แสดง
* แคมเปญ: แสดง #6 เมื่อบริษัทร่วมแคมเปญและมีเนื้อหา ถ้าไม่มีจะแสดง #7 (hero) หรือ #8 (Walk-in) แทน
* FeedSection ถูกวางไว้ในหน้าสาขาแต่ไม่แสดง เพราะหน้าไม่ได้ส่งข้อมูลฟีดให้
* `/page/{N}` = หน้าถัดไปของรายการโครงการ (#15) tracking เหมือนหน้าหลัก ต่างแค่ position ของการ์ดนับต่อจากหน้าก่อน

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
