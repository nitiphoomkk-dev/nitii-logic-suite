  * Tab โครงการใหม่
    * ดึงโปรโมชั่นโครงการใหม่มาแสดงผล
      * **Top event แสดงก่อน (random เฉพาะในชนชั้นนั้น) → ตามด้วยใบประกาศที่เข้าร่วมแคมเปญ (random เฉพาะในชนชั้นนั้น)**
  * Tab รับสร้างบ้าน
    * ดึงโปรโมชั่นรับสร้างบ้าน มาแสดงผลแบบ สลับการแสดงผล
      * **Top event แสดงก่อน (random เฉพาะในชนชั้นนั้น) → ตามด้วยใบประกาศที่เข้าร่วมแคมเปญ (random เฉพาะในชนชั้นนั้น)**

**แบ่งออกเป็น 3 ช่วง**

**1.ช่วง pre event**

* แสดงตัวเลขนับถอยหลังกิจกรรมจะเริ่มในอีก เป็น วัน ชั่วโมง นาที วินาที
  * ตัวเลขแสดงตั้งแต่สร้าง event เสร็จในหน้า landing page
  * ถ้าหมดวันจะแสดงง เป็น 00 วัน ชั่วโมง นาที วินาที ถ้าหมดจะแสดงเป็น 00 เหมือนกัน
  * ถ้าเริ่ม event แล้วจะไม่มีตัวเลขนับเวลาถอยหลัง

**2.ช่วง event**

* ตัวเลขนับเวลาถอยหลังจะหายไปจากการแสดงผล

**3.ช่วง end of event**

* แสดงข้อความว่า กิจกรรมได้จบลงแล้ว และจะหายไปก็ต่อเมื่อถึงวันที่สิ้นสุดอีเว้น online เท่านั้น
  * เมื่อครบแล้วจะไม่แสดงหน้า landing page นี้
