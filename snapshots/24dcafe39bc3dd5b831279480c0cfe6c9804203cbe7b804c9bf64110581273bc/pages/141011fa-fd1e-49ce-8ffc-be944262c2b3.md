# **EP-02 Solution: EP-09 Section บทความหน้า Home Center และหน้าเสิร์ช**

**สูตรการเลือกข้อมูล**

**[ล่าสุดไม่เกิน 5 เรื่อง × แต่ละจังหวัด] + [ล่าสุดไม่เกิน 5 เรื่องของส่วนกลาง]**

**→ รวมรายการโดยไม่รวมบทความที่เนื้อหาเหมือนกันแต่คนละ article_id**

**→ Shuffle ทั้งชุด**

**→ แสดงสูงสุด 5 การ์ด**

## **2) ตารางสรุป Logic — บทความ Center**

| **รหัส** | **หัวข้อ** | **Logic การทำงาน** |
|------|--------|----------------|
| ART-C01 | บทความที่เข้าเงื่อนไข | ใช้บทความที่เผยแพร่และแสดงบนเว็บได้ บทความจังหวัดมีแท็กจังหวัดชั้น 2 หนึ่งจังหวัดพอดี บทความส่วนกลางไม่มีแท็กจังหวัดและมีประเภทข้อมูลระบุชัดเจน |
| ART-C02 | การเลือกหมวด | “บทความแนะนำ” ใช้ทุกหมวด; แท็บอื่นใช้เฉพาะบทความที่มีแท็กหมวดชั้น 1 ตรงกับแท็บ โดยกรองก่อนคัดล่าสุด |
| ART-C03 | คัดล่าสุดรายจังหวัดและส่วนกลาง | แต่ละจังหวัดเรียงตามวันที่อัปเดตบทความที่แสดงบนการ์ด จากใหม่ไปเก่า แล้วเลือกไม่เกิน 5 เรื่อง |
| ART-C04 | เนื้อหาซ้ำข้ามจังหวัด | บทความเนื้อหาเดียวกันที่สร้างเป็นคนละ article_id และติดคนละจังหวัด ให้คงทั้งสองรายการไว้ ไม่ตัดซ้ำจากชื่อ เนื้อหา หรือภาพปก |
| ART-C05 | การ Shuffle | รวมชุดรายจังหวัดกับชุดส่วนกลาง แล้ว Shuffle ทั้งชุด เลือก 5 รายการแรกโดยไม่เลือก article_id เดิมซ้ำในหนึ่งผลลัพธ์ |
| ART-C06 | จำนวนแสดงผล | สูงสุด 5 การ์ด **รวมทั้ง Section** ไม่ใช่จังหวัดละ 5 การ์ด |
| ART-C07 | ตำแหน่งการ์ด | ผล Shuffle ลำดับ 1 เป็นการ์ดใหญ่; ลำดับ 2–5 เป็นการ์ดเล็ก ไม่มีจังหวัด หมวด หรือบทความส่วนกลางล็อกตำแหน่ง |
| ART-C08 | ข้อมูลไม่ครบ 5 | แสดงเท่าที่มี ไม่ดึงบทความที่เก่ากว่าอันดับ 5 ของจังหวัดหรือส่วนกลางมาเติม และไม่ทำรายการซ้ำให้ครบช่อง |
| ART-C09 | ไม่มีข้อมูล | เมื่อแท็บที่เลือกไม่มีบทความเข้าเงื่อนไข แสดง “ยังไม่มีบทความในหมวดนี้” แทนการ์ด |
| ART-C10 | จังหวะสุ่ม | สุ่มหนึ่งครั้งเมื่อโหลด Section หรือเปลี่ยนแท็บ ผลลัพธ์ต้องนิ่งระหว่างการแสดงครั้งนั้น; โหลดใหม่จึงสุ่มใหม่ |
| ART-C11 | บทความส่วนกลาง | เรียงบทความส่วนกลางตามวันที่อัปเดตล่าสุด แล้วเลือกไม่เกิน 5 เรื่องเข้าสู่ชุด Shuffle เดียวกัน |
| ART-C12 | แท็กบนการ์ด | บทความจังหวัดแสดงแท็กหมวดและจังหวัด **หนึ่งชื่อ**; บทความส่วนกลางไม่แสดงจังหวัด แท็กประเภทรีวิวชั้น 3 แสดงเฉพาะบทความหมวด “รีวิว” |
| ART-C13 | การคลิกการ์ด | บทความจังหวัดเปิดหน้ารายละเอียดโดยเปลี่ยนบริบท Navbar เป็นจังหวัดของการ์ด; บทความส่วนกลางเปิดรายละเอียดโดยคงบริบทส่วนกลาง เปิดแท็บใหม่ตามกฎเดิม |
| ART-C14 | บทความปักหมุด | กฎ Section ฉบับนี้ไม่ให้สถานะปักหมุดแทรกหรือล็อกตำแหน่งในขั้น “ล่าสุด → Shuffle” |

**การตัดซ้ำที่ ART-C05 หมายถึง:** ป้องกันแถวข้อมูล article_id เดิมเข้าผลสุ่มสองครั้งจากการดึงข้อมูลหรือการเชื่อมตารางเท่านั้น **ไม่ตัดบทความคนละ ID ที่มีเนื้อหาเหมือนกัน**

## **4) ตัวอย่างการคัดและแสดงผล**

สมมติเลือกแท็บ **บทความแนะนำ** และมีข้อมูลดังนี้

| **แหล่งบทความ** | **รายการที่ผ่านการคัดล่าสุด** |
|-------------|---------------------------|
| ขอนแก่น     | A-KK, B, C, D, E          |
| อุดรธานี    | A-UD, F, G, H, I          |
| อุบลราชธานี | J, K, L                   |
| ส่วนกลาง    | M, N                      |

ชุด Shuffle มี **15 รายการ** A-KK และ A-UD เป็นคนละ article_id แม้ใช้เนื้อหาเดียวกัน จึงคงไว้ทั้งคู่

ตัวอย่างผลหลัง Shuffle: A-UD, M, J, B, A-KK

| **ตำแหน่ง** | **การ์ด** | **แท็กจังหวัด** |
|---------|-------|-------------|
| การ์ดใหญ่ | A-UD  | อุดรธานี    |
| การ์ดเล็ก 1 | M     | ไม่แสดงแท็กจังหวัด |
| การ์ดเล็ก 2 | J     | อุบลราชธานี |
| การ์ดเล็ก 3 | B     | ขอนแก่น     |
| การ์ดเล็ก 4 | A-KK  | ขอนแก่น     |

ดังนั้นเนื้อหา A อาจเห็นสองการ์ดพร้อมกัน แต่แท็กจังหวัดทำให้ทราบว่าเป็น **คนละบทความจังหวัด**

## **5) ตัวอย่างเมื่อมี N จังหวัดจำนวนมาก**

หากเปิดให้บริการ **10 จังหวัด** และทุกจังหวัดมีบทความในหมวดที่เลือกอย่างน้อย 5 เรื่อง พร้อมบทความส่วนกลางอีก 5 เรื่อง:

* จังหวัดส่งเข้าชุดผู้สมัคร 10 × 5 = 50 รายการ
* ส่วนกลางส่งอีก 5 รายการ
* Shuffle รวม 55 รายการ แล้วแสดง **5 รายการ**
* ไม่มีการรับประกันว่าแต่ละจังหวัดหรือส่วนกลางต้องติดผลลัพธ์ในรอบนั้น

การคัด 5 ต่อแหล่งช่วยจำกัดบทความเก่าที่เข้าสุ่ม แต่ **ไม่ได้เป็นโควตาการแสดงผลต่อจังหวัด** หากต้องการการันตีจังหวัดละอย่างน้อยหนึ่งการ์ด จะต้องเปลี่ยนวิธีเลือกผลลัพธ์

## **6) ตารางจำลอง 8 กรณี**

| **กรณี** | **ผลที่คาดหวัง** |
|------|--------------|
| 1\. จังหวัดหนึ่งมีบทความ 8 เรื่อง | เฉพาะ 5 เรื่องล่าสุดของจังหวัดนั้นเข้าสุ่ม |
| 2\. จังหวัดหนึ่งมี 2 เรื่อง | ส่ง 2 เรื่องเข้าสุ่ม ไม่เติมเรื่องเก่าหรือรายการซ้ำ |
| 3\. มีเฉพาะบทความส่วนกลาง | คัดล่าสุดไม่เกิน 5 เรื่อง แล้ว Shuffle แสดงเท่าที่มี |
| 4\. มีเฉพาะบทความจังหวัด | รวมชุดล่าสุดของ N จังหวัดแล้ว Shuffle โดยไม่มีเงื่อนไขต้องมีส่วนกลาง |
| 5\. สองจังหวัดมีบทความเนื้อหาเดียวกันคนละ ID | ทั้งสองมีสิทธิ์ติด 5 การ์ดพร้อมกัน แต่แสดงแท็กจังหวัดคนละชื่อ |
| 6\. การดึงข้อมูลคืน article_id เดิมสองแถว | ให้เข้าสุ่มครั้งเดียว |
| 7\. กดแท็บ “รีวิว” | กรองเฉพาะหมวดรีวิว แล้วคัดล่าสุดแยกตามจังหวัดและส่วนกลางใหม่ |
| 8\. บทความปักหมุดเก่ากว่าอันดับ 5 ของแหล่งนั้น | ไม่เข้าสุ่มจากสิทธิ์ปักหมุดตามกฎ Section ฉบับนี้ |

## **7) รูปแบบการแสดงผล PC / Mobile**

### **PC**

แสดงตามภาพอ้างอิง **1 การ์ดใหญ่ + 4 การ์ดเล็ก** เมื่อมีครบ 5 เรื่อง การ์ดจังหวัดแสดงแท็กหมวดและจังหวัดหนึ่งชื่อ เช่น สาระเรื่องบ้าน · ขอนแก่น หากเป็นรีวิวและมีประเภทรีวิว ให้แสดงตามลำดับ รีวิว · โครงการใหม่ · ขอนแก่น บทความส่วนกลางไม่แสดงแท็กจังหวัด

ข้อมูลรูปปก วันที่อัปเดต และยอดเข้าชมใช้กฎการ์ดบทความเดิมใน<u>[เอกสารบทความ Center](https://docs.google.com/document/d/1O33sILX5ThieZiphydZt1g40IxKGKCsF_sgyev-vSCA/edit?tab=t.qg99bt7usen1)</u> โดยวันที่ที่ใช้คัด “ล่าสุด” ต้องตรงกับหลักวันที่อัปเดตที่แสดงให้ผู้ใช้เห็น

### **Mobile**

ใช้ **ชุดบทความ 5 เรื่องเดียวกับ PC สำหรับการโหลดครั้งนั้น** เปลี่ยนเฉพาะวิธีจัดวางตาม UI Mobile เดิม เลื่อนไปจนสุด 5 การ์ดแล้วชน ไม่วนลูป และไม่ Shuffle ใหม่เพียงเพราะหน้าจอปรับขนาด

## **8) Acceptance Criteria สำหรับ QA**

| **รหัส** | **เงื่อนไขทดสอบ** | **ผลที่ต้องได้** |
|------|---------------|--------------|
| ART-AC01 | บทความจังหวัดเลือกแท็กจังหวัด 0 หรือ 2 จังหวัด | ไม่ผ่านกฎการเผยแพร่ของบทความจังหวัด |
| ART-AC02 | บทความส่วนกลางไม่มีแท็กจังหวัด | เข้าชุดส่วนกลางได้เมื่อมีประเภทข้อมูลส่วนกลางชัดเจน |
| ART-AC03 | จังหวัดมีมากกว่า 5 บทความในหมวดที่เลือก | บทความอันดับ 6 ลงไปไม่เข้าสู่ชุด Shuffle |
| ART-AC04 | ส่วนกลางมีมากกว่า 5 บทความ | เฉพาะ 5 เรื่องล่าสุดของส่วนกลางเข้าสุ่ม |
| ART-AC05 | เปลี่ยนแท็บจาก “บทความแนะนำ” เป็น “รีวิว” | กรองหมวดรีวิวก่อนคัด 5 ล่าสุดของแต่ละแหล่ง |
| ART-AC06 | สองจังหวัดมีบทความเนื้อหาเดียวกันคนละ article_id | ทั้งสองอยู่ในชุดผู้สมัครได้ และมีโอกาสแสดงพร้อมกัน |
| ART-AC07 | ข้อมูลคืน article_id เดิมซ้ำ | ผลลัพธ์แสดง ID นั้นได้ไม่เกินหนึ่งการ์ด |
| ART-AC08 | ชุดผู้สมัครมีมากกว่า 5 ID | แสดง 5 การ์ด โดยลำดับแรกเป็นการ์ดใหญ่ |
| ART-AC09 | ชุดผู้สมัครมี 3 ID | แสดง 3 การ์ด ไม่เติมเรื่องเก่าหรือทำซ้ำ |
| ART-AC10 | การ์ดจังหวัดและการ์ดส่วนกลางแสดงพร้อมกัน | การ์ดจังหวัดมีแท็กจังหวัดหนึ่งชื่อ; การ์ดส่วนกลางไม่มีแท็กจังหวัด |
| ART-AC11 | โหลด Section แล้วเปลี่ยนขนาดหน้าจอ | ชุดบทความไม่สุ่มเปลี่ยนระหว่างการแสดงครั้งนั้น |
| ART-AC12 | กดการ์ดจังหวัด / ส่วนกลาง | เปิดรายละเอียดด้วยบริบทจังหวัดที่ตรงกับการ์ด / คงส่วนกลาง ตามลำดับ |
| ART-AC13 | กด “ดูทั้งหมด” | ไปหน้า รวมบทความ Center ที่เรียงล่าสุดและแบ่งหน้า ไม่ส่งลำดับ Shuffle 5 การ์ดไปเป็นลำดับผลค้นหา |
