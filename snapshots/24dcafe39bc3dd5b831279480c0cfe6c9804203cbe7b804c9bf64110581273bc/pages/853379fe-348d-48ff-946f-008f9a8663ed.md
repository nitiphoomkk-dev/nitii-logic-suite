> ข้อมูลจากโค้ด FE ณ 2026-10-16 (repo `next-frontend-console-service` branch `develop` commit `9bbc0e5c`)

**Route:** `/home-builder/create` (ลงประกาศ) และ `/home-builder/update/{post_id}` (แก้ไข)

**ไฟล์หน้า:** `app/(dashboard)/home-builder/create/page.tsx`, `app/(dashboard)/home-builder/update/[id]/page.tsx`

**TrackingProvider:** ไม่มีของหน้าเอง ใช้แค่ส่วนกลาง (`category`, `source_type` ว่าง)

เข้าได้เฉพาะ `user_type` = `home_builder` ทั้ง 2 route ใช้ `PostHomeBuilderStepForm` (`components/form/post-home-builder/StepForm.tsx`) ตัวเดียวกับฟอร์มรับสร้างบ้านใน "หน้าสร้างใบประกาศ"

* `/home-builder/create` เข้าจากปุ่มสร้างประกาศใน Navbar และปุ่มในหน้าจัดการแบบบ้าน (`/home-builder`)
* `/home-builder/update/{post_id}` เข้าจากปุ่มแก้ไขในตารางหน้าจัดการแบบบ้าน

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
