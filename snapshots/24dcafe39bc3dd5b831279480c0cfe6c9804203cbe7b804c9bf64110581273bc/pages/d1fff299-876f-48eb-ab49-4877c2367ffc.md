# **EP-02 Top Banner — หน้า Center**

## **Solution รองรับ 3 ภาษา + Shuffle ระดับ Slot ต้นทาง + เลือก A/B เพียง 1 ภาพต่อ Slot**

**ฉบับปรับปรุง: เลือกสูงสุด 8 Slot ต้นทาง และแสดง Slot ละ 1 ภาพ โดยไม่สุ่มใหม่ทุกครั้งที่เลื่อนสไลด์**

**กฎหลักของ Solution ฉบับนี้**

ตรวจสอบภาษาและไฟล์ของอุปกรณ์ปัจจุบันให้แต่ละ Slot ผ่านเงื่อนไขก่อน จากนั้นนำ **Slot ต้นทาง** ไป Shuffle และเลือกสูงสุด **8 Slot** แล้วจึงเลือกกราฟฟิก **A หรือ B เพียง 1 ภาพ** ภายในแต่ละ Slot ที่ได้รับเลือก

**1 Slot ต้นทางที่ได้รับเลือก = 1 ภาพในชุดแสดงผล**

ภาพ A และ B ของ Slot เดียวกันจะไม่กินสองตำแหน่งในชุดแสดงผลเดียวกัน และเมื่อเลื่อนสไลด์หรือวน Loop ต้องยังใช้ภาพที่เลือกไว้ ไม่สุ่มเปลี่ยนภาพภายใน Slot ใหม่

### **หลักการทำงาน**

**ดึง Top Banner ที่ผ่านเงื่อนไขเดิมจากทุกจังหวัด → ตรวจภาษาและอุปกรณ์แยกแต่ละ Slot → ตัด Slot ที่ไม่มีภาพใช้ได้ → Shuffle Slot ต้นทางที่เหลือ → เลือกสูงสุด 8 Slot → เลือก A/B เพียง 1 ภาพต่อ Slot → แสดงตามลำดับ Slot ที่ได้**

ตัวอย่างตาม Flow ใหม่:

**A[A1, A2] + B[B1, B2] + C[C1]\n**→ Shuffle Slot ได้ **B → A → C\n**→ เลือกภาพภายในแต่ละ Slot ได้ **B2 → A1 → C1\n**→ **3 Slot ต้นทาง = 3 ภาพแสดง ไม่ใช่ 5 ภาพ**

# **1) ขอบเขตและนิยาม**

## **1.1 นิยามที่ใช้ใน Solution**

| **คำเรียก** | **ความหมาย** |
|---------|----------|
| **Slot ต้นทาง** | รายการโฆษณา Top Banner หนึ่งรายการ ซึ่งเก็บชุดกราฟฟิกไทย จีน และอังกฤษ โดยแต่ละภาษามี A/B ของตนเอง |
| **ภาษาหลัก** | ภาษาของกราฟฟิกที่ตรงกับภาษาปัจจุบันที่ User เลือกบนเว็บไซต์ |
| **ภาษาสำรอง** | **ภาษาไทยเท่านั้น** ใช้เมื่อไม่มีกราฟฟิกของภาษาหลักตามกฎภาษา |
| **ชุดภาพทางเลือกของ Slot** | ภาพ 1 หรือ 2 ภาพของภาษาที่เลือกได้ ซึ่งมีไฟล์ใช้ได้สำหรับอุปกรณ์ปัจจุบัน เก็บไว้ภายใน Slot เพื่อเลือกภายหลัง |
| **Slot ที่ผ่านเงื่อนไข** | Slot ที่ผ่านเงื่อนไขโฆษณาเดิม และมีภาพที่ใช้ได้ตามกฎภาษาและอุปกรณ์อย่างน้อย 1 ภาพ |
| **ชุด Slot ก่อน Shuffle** | รายการ Slot ต้นทางที่ผ่านเงื่อนไขทั้งหมด โดยแต่ละ Slot อยู่ในชุดเพียงครั้งเดียว |
| **ชุด Slot ที่ได้รับเลือก** | Slot สูงสุด 8 รายการแรกจากลำดับหลัง Shuffle |
| **ภาพที่ได้รับเลือกของ Slot** | ภาพ A หรือ B เพียง 1 ภาพ ซึ่งเลือกจากชุดภาพทางเลือกของ Slot ที่ได้รับเลือก |
| **ชุดแสดงผล** | รายการภาพที่ได้จาก Slot ที่ได้รับเลือก เรียงตามลำดับ Slot หลัง Shuffle และมีสูงสุด 8 ภาพ |
| **การจัดชุดหนึ่งครั้ง** | กระบวนการตั้งแต่ตรวจ Slot, Shuffle, เลือกสูงสุด 8 Slot และเลือกภาพให้แต่ละ Slot จนได้ชุดแสดงผลหนึ่งชุด ไม่ใช่การเลื่อนสไลด์หนึ่งครั้ง |

**ภาพทางเลือก 2 ภาพภายใน Slot ไม่ใช่ 2 รายการในชุด Shuffle** เช่น Slot A มี A1 และ A2 ก็ยังนับเป็น Slot A เพียงหนึ่งรายการ

# **2) โครงสร้างกราฟฟิก การเลือกภาษา และการเลือก A/B**

## **2.1 โครงสร้างภายใน 1 Slot ต้นทาง**

คงโครงสร้าง 3 ภาษา แต่ละภาษามีกราฟฟิกได้สูงสุด 2 ภาพ และ A/B แยกจากกันตามภาษา ไม่จำเป็นต้องมีจำนวนภาพเท่ากัน NaYoo Center (16)

| **ภาษา** | **กราฟฟิก A** | **กราฟฟิก B** | **จำนวนสูงสุดต่อภาษา** |
|------|-----------|-----------|--------------------|
| ไทย  | TH-A      | TH-B      | 2 ภาพ              |
| จีน  | ZH-A      | ZH-B      | 2 ภาพ              |
| อังกฤษ | EN-A      | EN-B      | 2 ภาพ              |
| **รวมต่อ Slot ต้นทาง** |           |           | **สูงสุด 6 กราฟฟิกตามชุดภาษา** |

ความสัมพันธ์ของจำนวนใน Flow ใหม่คือ:

**เก็บได้สูงสุด 6 กราฟฟิก → เลือกได้ 1 ชุดภาษา → เหลือภาพทางเลือก 1–2 ภาพ → Slot เข้าชุด Shuffle 1 ครั้ง → หาก Slot ได้รับเลือก แสดงเพียง 1 ภาพ**

## 

## **2.2 ลำดับการเลือกภาษา — คงกฎเดิม**

ตรวจสอบแยกแต่ละ Slot โดยใช้ลำดับ **ภาษาที่ User เลือก → ภาษาไทย → ตัด Slot ออก** และไม่ใช้จีนหรืออังกฤษเป็นภาษาสำรองตามกฎที่ยืนยันไว้ NaYoo Center (16)

| **ภาษาที่ User เลือก** | **ลำดับตรวจสอบ** | **ผลเมื่อไม่มีภาพตามภาษาที่อนุญาต** |
|--------------------|--------------|---------------------------------|
| **ไทย**            | ไทย          | ตัด Slot ออก                    |
| **จีน**            | จีน → ไทย    | หากไม่มีทั้งจีนและไทย ตัด Slot ออก |
| **อังกฤษ**         | อังกฤษ → ไทย | หากไม่มีทั้งอังกฤษและไทย ตัด Slot ออก |

เมื่อเลือกภาษาได้แล้ว ให้เก็บภาพของภาษานั้นไว้เป็น **ชุดภาพทางเลือกภายใน Slot** ยังไม่แยก A/B ออกเป็นสมาชิกของชุด Shuffle

**\*\*\*ตัวอย่าง User เลือกจีน แต่ Slot มีไทยและอังกฤษ ให้เลือกชุดไทย แม้มีอังกฤษอยู่ด้วย โดยห้ามเลือกอังกฤษมาทดแทน**

### **ตารางเลือกภาษา ครบทุกกรณี**

ตารางนี้สมมติว่ามีไฟล์สำหรับอุปกรณ์ที่ใช้งานครบถ้วน กรณีขาดไฟล์เฉพาะอุปกรณ์แยกไว้ในข้อ 2.3 และหัวข้อ 7

| **ชุดภาษาที่มีใน Slot ต้นทาง** | **User เลือกไทย** | **User เลือกจีน** | **User เลือกอังกฤษ** |
|----------------------------|---------------|---------------|------------------|
| ไทย + จีน + อังกฤษ         | เลือกชุดไทย   | เลือกชุดจีน   | เลือกชุดอังกฤษ   |
| ไทย + อังกฤษ               | เลือกชุดไทย   | **เลือกชุดไทยสำรอง** | เลือกชุดอังกฤษ   |
| ไทย + จีน                  | เลือกชุดไทย   | เลือกชุดจีน   | **เลือกชุดไทยสำรอง** |
| จีน + อังกฤษ               | **ตัด Slot ออก** | เลือกชุดจีน   | เลือกชุดอังกฤษ   |
| ไทยเท่านั้น                | เลือกชุดไทย   | เลือกชุดไทยสำรอง | เลือกชุดไทยสำรอง |
| จีนเท่านั้น                | ตัด Slot ออก  | เลือกชุดจีน   | ตัด Slot ออก     |
| อังกฤษเท่านั้น             | ตัด Slot ออก  | ตัด Slot ออก  | เลือกชุดอังกฤษ   |
| ไม่มีทั้ง 3 ภาษา           | ตัด Slot ออก  | ตัด Slot ออก  | ตัด Slot ออก     |

**การเลือกชุดภาษาได้ยังไม่เท่ากับได้รับเลือกแสดง** Slot นั้นต้องผ่านเงื่อนไขอุปกรณ์ และผ่านการเลือกสูงสุด 8 Slot อีกขั้นหนึ่ง

## **2.3 ตรวจไฟล์อุปกรณ์ก่อนนำ Slot เข้า Shuffle**

ใช้เฉพาะไฟล์ของอุปกรณ์ปัจจุบัน ไม่ใช้ภาพข้าม Desktop / Mobile ตามข้อกำหนดเดิม NaYoo Center (16)

| **สถานการณ์หลังเลือกชุดภาษา** | **ผลต่อชุดภาพทางเลือกและ Slot** |
|---------------------------|-----------------------------|
| A และ B มีไฟล์สำหรับอุปกรณ์ปัจจุบันทั้งคู่ | เก็บไว้เป็นภาพทางเลือก 2 ภาพ แต่ Slot เข้าชุด Shuffle เพียง 1 ครั้ง |
| มีเพียง A ที่มีไฟล์สำหรับอุปกรณ์ปัจจุบัน | เก็บ A เป็นภาพทางเลือกเพียงภาพเดียว |
| มีเพียง B ที่มีไฟล์สำหรับอุปกรณ์ปัจจุบัน | เก็บ B เป็นภาพทางเลือกเพียงภาพเดียว ไม่สร้าง A เพิ่ม |
| ไม่มีภาพที่ใช้ได้ตามกฎภาษาและอุปกรณ์ | ตัด Slot ออก **ก่อน Shuffle และก่อนเลือกสูงสุด 8 Slot** |

* มีภาษาที่ User เลือก → ใช้ภาษานั้น
* ไม่มี → ใช้ **ภาษาไทยบนอุปกรณ์เดียวกันเท่านั้น**
* ไม่มีไทยด้วย → **ตัด Slot ออกก่อน Shuffle** ไม่ใช้ภาษาอื่นสำรองและไม่ข้ามอุปกรณ์

**ตัวอย่าง:** User ใช้ Mobile ภาษาอังกฤษ แต่มีอังกฤษเฉพาะ Desktop และมีไทย Mobile → **ใช้ไทย Mobile**

จากนั้น **Shuffle Slot → เลือกตามจำนวนที่แต่ละ Product กำหนด → เลือก 1 ภาพ/รูปแบบต่อ Slot** โดยเงื่อนไขอื่นคงเดิม

## **2.4 การเลือก A/B — ทำหลังเลือก Slot**

เมื่อ Shuffle Slot และเลือกสูงสุด 8 Slot แล้ว จึงเลือกภาพภายใน **เฉพาะ Slot ที่ได้รับเลือก** ดังนี้

| **จำนวนภาพทางเลือกของ Slot ที่ได้รับเลือก** | **การทำงาน** | **จำนวนภาพแสดงจาก Slot นั้น** |
|-----------------------------------------|----------|---------------------------|
| **2 ภาพ**                               | เลือก A หรือ B **เพียง 1 ภาพ** | **1**                     |
| **1 ภาพ**                               | ใช้ภาพที่มีเพียงภาพเดียว | **1**                     |
| **0 ภาพ**                               | ต้องไม่เข้ามาถึงขั้นตอนนี้ เพราะต้องถูกตัดออกก่อน Shuffle | **0**                     |

ตัวอย่างผลลัพธ์เมื่อ Slot ได้รับเลือก:

| **ภาษาที่ User เลือก** | **ข้อมูลกราฟฟิก** | **ชุดภาพทางเลือกที่อนุญาต** | **ภาพแสดงจริง** |
|--------------------|---------------|-------------------------|-------------|
| จีน                | จีน 2 / ไทย 2 / อังกฤษ 2 | ZH-A, ZH-B              | **ZH-A หรือ ZH-B เพียง 1 ภาพ** |
| จีน                | จีน 1 / ไทย 2 / อังกฤษ 2 | ภาพจีนที่มี             | **จีน 1 ภาพ** |
| จีน                | จีน 0 / ไทย 2 / อังกฤษ 2 | TH-A, TH-B              | **TH-A หรือ TH-B เพียง 1 ภาพ** |
| อังกฤษ             | อังกฤษ 0 / ไทย 1 / จีน 2 | ภาพไทยที่มี             | **ไทย 1 ภาพ** |
| อังกฤษ             | อังกฤษ 0 / ไทย 0 / จีน 2 | ไม่มี                   | **Slot ถูกตัดออกก่อน Shuffle** |

**ภาพ A/B ที่ไม่ได้รับเลือกไม่กลายเป็นสไลด์เพิ่มเติม ไม่ถูกนำไปเติมตำแหน่งว่าง และไม่ถูกแสดงสลับแทนภาพที่เลือกไว้เมื่อวน Loop**

## **2.5 การคงชุดแสดงผลระหว่างเลื่อนสไลด์**

หลังจัดชุดสำเร็จ ให้คงทั้ง **ลำดับ Slot** และ **ภาพที่เลือกให้แต่ละ Slot** ไว้ตลอดการใช้งานชุดนั้น

| **เหตุการณ์** | **ลำดับ Slot** | **ภาพ A/B ที่เลือกไว้** |
|-----------|------------|---------------------|

| User กดเลื่อนขวา | ใช้ลำดับเดิม | ใช้ภาพเดิม          |

# **4) กฎจำนวนแสดงผล — สูงสุด 8 Slot ต้นทาง**

กำหนดให้:

**S = จำนวน Slot ต้นทางที่ผ่านเงื่อนไขโฆษณา ภาษา และอุปกรณ์แล้ว**

**จำนวน Slot ที่ได้รับเลือก = min(S, 8)\nจำนวนภาพในชุดแสดงผล = จำนวน Slot ที่ได้รับเลือก**

## **4.1 ตารางจำนวนแสดงผล**

| **Slot ต้นทางที่ผ่านเงื่อนไข** | **ภาพทางเลือกรวมที่อาจมี** | **Slot ที่ได้รับเลือก** | **ภาพแสดงจริง** |
|----------------------------|------------------------|---------------------|-------------|
| 0                          | 0                      | 0                   | **0**       |
| 1                          | 1–2                    | 1                   | **1**       |
| 2                          | 2–4                    | 2                   | **2**       |
| 3                          | 3–6                    | 3                   | **3**       |
| 7                          | 7–14                   | 7                   | **7**       |
| 8                          | 8–16                   | 8                   | **8**       |
| 9                          | 9–18                   | 8                   | **8**       |
| 10                         | 10–20                  | 8                   | **8**       |
| 20                         | 20–40                  | 8                   | **8**       |

**กรณีมี 7 Slot และแต่ละ Slot มี A/B ครบ 2 ภาพ ต้องแสดงเพียง 7 ภาพ** ห้ามหยิบภาพที่สองของ Slot ใดมาเติมให้ครบ 8

## **4.2 Slot ที่ไม่ได้รับเลือกและภาพ A/B ที่ไม่ได้ใช้**

| **รายการที่ไม่ได้รับเลือก** | **การทำงาน** |
|-------------------------|----------|
| Slot ที่อยู่ลำดับหลัง 8 หลัง Shuffle | ไม่อยู่ในชุดแสดงผลครั้งนี้ |
| ภาพอีกใบของ Slot ที่ได้รับเลือก | ยังคงเป็นภาพทางเลือกในข้อมูลต้นทาง แต่ไม่อยู่ในชุดแสดงผลครั้งนี้ |
| User เลื่อนครบภาพสุดท้าย | วนกลับภาพแรกในชุดเดิม ไม่ดึง Slot ลำดับที่ 9 มาเพิ่ม |
| User วนกลับมาเจอ Slot เดิม | ใช้ภาพเดิมของ Slot นั้น ไม่เปลี่ยนจาก A เป็น B |
| รีเฟรชและจัดชุดใหม่     | Slot หรือภาพที่ไม่ได้ใช้ครั้งก่อนมีโอกาสถูกเลือกในชุดใหม่ แต่ไม่รับประกันว่าจะได้รับเลือก |

## **5.1 ตัวอย่างหลัก — 3 Slot มีภาพทางเลือกรวม 5 ภาพ**

สมมติว่าเลือกภาษาและตรวจอุปกรณ์เรียบร้อยแล้ว:

**B → A → C**

## **5.4 ผลเมื่อเปลี่ยนภาษาและจำนวน A/B**

สมมติ Slot เดียวมีจีน 1 ภาพ และอังกฤษ 2 ภาพ:

| **ภาษาที่ User เลือก** | **ภาพทางเลือกภายใน Slot** | **ภาพแสดงจาก Slot นี้เมื่อได้รับเลือก** |
|--------------------|-----------------------|-------------------------------------|
| จีน                | ZH-A                  | **1 ภาพ**                           |
| อังกฤษ             | EN-A, EN-B            | **1 ภาพ**                           |

เมื่อเปลี่ยนจีน → อังกฤษ จำนวนภาพทางเลือกเปลี่ยนจาก 1 เป็น 2 แต่ **จำนวนตำแหน่งที่ Slot นี้ใช้ยังเป็น 1**

การเปลี่ยนภาษาอาจทำให้จำนวน Slot ที่ผ่านเงื่อนไขเปลี่ยน เช่น Slot ที่มีเฉพาะอังกฤษจะไม่ผ่านเมื่อ User เปลี่ยนเป็นจีน เพราะไม่มีทั้งจีนและไทย จึงต้องประเมินชุดใหม่ตามภาษา ไม่คงภาพอังกฤษไว้เติมจำนวน
