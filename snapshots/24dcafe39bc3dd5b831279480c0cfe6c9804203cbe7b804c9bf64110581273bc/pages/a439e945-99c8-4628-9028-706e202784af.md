## **EP-01 Solution Insert Card หน้า Center — ฉบับรวมข้อสรุปล่าสุด**

**ฉบับปรับปรุง 18 ตุลาคม 2569 · โหลดหน้าใหม่ = Refresh = Shuffle ใหม่ · ผู้จัดทำ นิติ๊**

รวมกฎการเลือกภาษา การ Shuffle ระดับ Slot การเลือก A/B และการแบ่งหน้า พร้อมตัวอย่าง Free Text, Video, Promotion, ซีรี่ย์ใหม่ และยอดนิยมต่างภาษา

**หลักการทุกครั้งที่โหลดหน้า:** ตรวจภาษาของแต่ละ Slot ก่อน → Shuffle Slot ที่ผ่านเงื่อนไขทั้งหมด → เลือก Slot ตามจำนวน Insert → เลือก A/B หนึ่งรูปแบบในภาษานั้น → แสดงหนึ่งการ์ดต่อ Slot การโหลดหน้าถัดไปหรือย้อนกลับแล้วโหลดใหม่เท่ากับ Refresh ส่วนการเปลี่ยนภาษาอย่างเดียวใช้ข้อ 3.4

## **1 วัตถุประสงค์และขอบเขต**

กำหนดให้ Insert Card จากทุกจังหวัดแสดงในหน้า Center ด้วยกฎเดียวกัน Slot ต้นทางหนึ่งรายการมีช่องไทย อังกฤษ และจีน โดยแต่ละภาษามี A/B ของตัวเอง ก่อน Shuffle ให้คัดภาษาที่ผู้ใช้เลือกก่อน หากไม่มีจึงใช้ชุดไทยสำรองของ Slot เดียวกัน จำนวนภาษาและรูปแบบ A/B ไม่เพิ่มรายการเข้า Shuffle

ใช้ตำแหน่งตามผัง Insert Card เดิมของแต่ละหน้า ตั้งแต่หน้า 2 ถึงหน้าสุดท้ายให้แสดง Insert จริงเท่าจำนวนหน้า 1 โดยทุกครั้งที่โหลดหน้าให้ Shuffle ใหม่จาก Slot ทั้งหมดที่ผ่านเงื่อนไข Slot เดิมจึงแสดงซ้ำข้ามหน้าได้

การแสดง Top Ads, Super Top Ads, Banner และจำนวนการ์ดรวมของแต่ละหน้าใช้กฎของส่วนนั้น ส่วน Insert ไม่ใช้การ์ดธรรมดาทดแทนเพียงเพราะ Slot เคยแสดงในหน้าอื่นแล้ว

EP-02 ในแท็บ “การแสดงผล” หมายถึง Insert Card หมวด “น่าอยู่” เพิ่มคำอธิบายไว้ในข้อ 3.5 เพื่อให้ทราบความหมายของเอกสารอ้างอิง โดยหมวดนี้ยังถูกคัดออกจากชุด Center ตาม IC-C02

## **3 เงื่อนไขการทำงาน**

### **3.1 แหล่งข้อมูลและการคัดออก**

* ดึง Insert Card ที่ผ่านเงื่อนไขเดิมจากทุกจังหวัดตามจำนวน N จังหวัดที่มีจริง
* ตัด Insert Card ประเภท “น่าอยู่” ออกจากชุด Center
* รวมหมวดที่เอกสารเดิมกำหนดให้อยู่ในชุดเดียวกัน แล้วตรวจภาษาและความพร้อมราย Slot ก่อน Shuffle

### **3.2 การเลือกภาษาและความพร้อม**

แต่ละ Slot ต้นทางมีช่องภาษาไทย อังกฤษ และจีน แต่ละช่องมี A/B สูงสุด 2 รูปแบบของตัวเอง A และ B เลือก Type ได้จาก Free Text, Video, Promotion, ซีรี่ย์ใหม่ และยอดนิยม โดย A/B ต่างภาษาไม่จำเป็นต้องเป็น Type เดียวกัน

ทุกครั้งที่โหลดหน้าให้ตรวจภาษาก่อน Shuffle ตามขั้นตอนนี้ ส่วนการเปลี่ยนภาษาอย่างเดียวให้ตรวจภาษาใหม่ภายใต้ลำดับ Slot เดิมตามข้อ 3.4

* ถ้า Slot มีอย่างน้อยหนึ่งรูปแบบพร้อมแสดงในภาษาที่ผู้ใช้เลือก ให้ใช้ภาษานั้น
* ถ้าไม่มีภาษาที่เลือก แต่มีรูปแบบพร้อมแสดงภาษาไทยใน Slot เดียวกัน ให้ใช้ไทยสำรอง
* ถ้าไม่มีทั้งภาษาที่เลือกและไทย ให้ตัด Slot ก่อน Shuffle และก่อนนับจำนวน Slot ที่แสดงได้

| **ภาษาที่พร้อมใน Slot** | **ผู้ใช้เลือกไทย** | **ผู้ใช้เลือกจีน** | **ผู้ใช้เลือกอังกฤษ** |
|---------------------|----------------|----------------|-------------------|
| ไทย จีน อังกฤษ      | ไทย            | จีน            | อังกฤษ            |
| ไทย อังกฤษ          | ไทย            | ไทยสำรอง       | อังกฤษ            |
| ไทย จีน             | ไทย            | จีน            | ไทยสำรอง          |
| จีน อังกฤษ          | ตัด Slot       | จีน            | อังกฤษ            |
| ไทยอย่างเดียว       | ไทย            | ไทยสำรอง       | ไทยสำรอง          |
| จีนอย่างเดียว       | ตัด Slot       | จีน            | ตัด Slot          |
| อังกฤษอย่างเดียว    | ตัด Slot       | ตัด Slot       | อังกฤษ            |
| ไม่มีชิ้นงานพร้อม   | ตัด Slot       | ตัด Slot       | ตัด Slot          |

เมื่อตัดสินภาษาให้ Slot แล้ว ให้ใช้ A/B ของช่องภาษานั้นเท่านั้น หากอังกฤษมี A พร้อมเพียงรูปแบบเดียว แม้ไทยมี A และ B ให้ใช้ A อังกฤษเพียงรูปแบบเดียว ไม่เอา B ไทยมารวม การใช้ชุดไทยสำรองไม่เปลี่ยนภาษาของเว็บไซต์

Mobile และ Desktop ใช้ภาพและ URL ที่บันทึกไว้ชุดเดียวกันของรูปแบบและภาษานั้น ไม่แยกไฟล์หรือ URL ตามอุปกรณ์ ส่วนรูปแบบที่ไม่ได้ใช้ภาพให้ตรวจข้อมูลตามการแสดงผลเดิมของประเภทนั้น หากไฟล์มีอยู่แต่โหลดล้มเหลว ให้ใช้การจัดการข้อผิดพลาดเดิม ไม่สลับเป็นภาษาไทยโดยอัตโนมัติ

### **3.3 การ Shuffle และ A/B Test**

ขั้นตอนจัดลำดับ Slot ด้านล่างใช้ทุกครั้งที่โหลดหน้า รวมเปิดครั้งแรก ไปหน้าถัดไป ย้อนกลับแล้วโหลดหน้านั้นใหม่ และ Refresh หากเปลี่ยนภาษาอย่างเดียวให้ใช้ข้อ 3.4

* **รวม Slot ที่ผ่านเงื่อนไขทั้งหมดเข้าสุ่ม** โดย 1 Slot นับเป็น 1 รายการ ไม่ว่าจะมีหลายภาษา หลายภาพ หรือหลายรูปแบบ A/B
* **Slot ที่ตรงภาษาผู้ใช้และ Slot ที่ใช้ไทยสำรอง สุ่มรวมกันได้** ไม่แยกโควตาตามภาษา และไม่บังคับให้ไทยสำรองอยู่ท้าย
* **ทุกครั้งที่โหลดหน้า ให้สุ่มลำดับ Slot ใหม่จากทั้งหมด** แล้วเลือกมาแสดงตามจำนวน Insert ของหน้านั้น โดยหน้า 2 ถึงหน้าสุดท้ายแสดงจำนวนเท่ากับหน้า 1
* **เมื่อ Slot ได้แสดง ให้เลือก A หรือ B ของภาษาที่คัดไว้เพียง 1 รูปแบบ** ตาม A/B Test เดิม หากมีพร้อมเพียงรูปแบบเดียว ให้ใช้รูปแบบนั้น
* **A/B ที่ไม่ถูกเลือกจะไม่แสดงเพิ่มหรือใช้เติมตำแหน่งอื่น** แม้มีหลายรูปแบบ Slot นั้นก็ยังเข้าสุ่มเพียง 1 รายการ
* **Slot เดิมแสดงซ้ำข้ามหน้าได้ เพราะแต่ละหน้าสุ่มใหม่** แต่ภายในหน้าเดียวกัน Slot นั้นแสดงได้เพียง 1 การ์ด

### **3.4 การคงชุดและการจัดชุดใหม่**

การโหลดหน้าใหม่เท่ากับ Refresh จึงจัดชุดและ Shuffle ใหม่ ส่วนการเปลี่ยนภาษาอย่างเดียวให้ตรวจชิ้นงานตามภาษาใหม่ โดยคงลำดับ Slot ที่มีผล Shuffle อยู่ ไม่ Shuffle ใหม่เพียงเพราะเปลี่ยนภาษา

| **เหตุการณ์** | **การทำงาน** |
|-----------|----------|
| เปิดแสดงผลครั้งแรก | คัด Slot ที่มีสิทธิ์และพร้อมแสดง ใช้ภาษาที่ผู้ใช้เลือกก่อน หากไม่มีให้ใช้ไทยสำรอง แล้วสุ่มลำดับ Slot เมื่อ Slot ได้ตำแหน่ง ให้เลือก A หรือ B ของภาษานั้นมาแสดง โดย Mobile และ Desktop ใช้ภาพและ URL ชุดเดียวกัน |
| ไปหน้าถัดไปแล้วโหลดหน้าใหม่ | Shuffle Slot ที่ผ่านเงื่อนไขทั้งหมดใหม่ แล้วเลือก Insert ให้ครบจำนวนตามหน้า 1 |
| ย้อนกลับแล้วโหลดหน้าเดิมใหม่ | ถือเป็น Refresh จึง Shuffle ใหม่ ผลอาจเหมือนเดิมได้ ไม่บังคับใช้ชุดเก่าของหน้านั้น |
| Refresh   | ประเมิน Source Slots และจัดชุดใหม่ได้ ผล Shuffle และ A/B อาจซ้ำเดิม |
| เปลี่ยนภาษา | มื่อผู้ใช้เปลี่ยนภาษา ระบบจะทำดังนี้:<br>-**ตรวจภาษาของทุก Slot ใหม่**ใช้ภาษาที่ผู้ใช้เลือกก่อน หากไม่มีให้ใช้ไทยของ Slot เดียวกัน<br>-**ถ้าไม่มีทั้งภาษาที่เลือกและไทย ให้ไม่แสดง Slot นั้น**<br>-**คงลำดับ Slot เดิม ไม่ Shuffle ใหม่**<br>-**เลือก A หรือ B ของภาษาที่คัดไว้มาแสดง 1 รูปแบบ** ตาม A/B Test เดิม หากมีพร้อมเพียงรูปแบบเดียว ให้ใช้รูปแบบนั้น |

กรณี Slot ที่เดิมถูกคัดออก แต่เพิ่งผ่านเงื่อนไขเมื่อเปลี่ยนภาษาอย่างเดียวโดยยังไม่โหลดหน้าใหม่ ต้องกำหนดว่าจะเพิ่ม Slot นั้นตรงไหนในลำดับที่แสดงอยู่ตามหัวข้อ 8 การเปลี่ยนภาษาอย่างเดียวยังไม่ใช่เหตุให้ Shuffle ใหม่

### **3.5 ข้อมูลอ้างอิง EP-02 น่าอยู่ (คัดออกจากชุด Center)**

**EP-02 = น่าอยู่** เป็นหัวข้อในแท็บ “การแสดงผล” ของ Insert Card ต้นทาง ครอบคลุมการแสดงข้อความ Free Text และ Video ของหมวดน่าอยู่ รายละเอียดด้านล่างเป็นข้อมูลอ้างอิงของหมวดนี้ ซึ่งยังไม่เข้าสุ่มใน Center ตาม IC-C02

### **4.2 จำนวน Insert และการ Shuffle เมื่อโหลดหน้า**

**ตั้งแต่หน้า 2 ถึงหน้าสุดท้าย ต้องแสดง Insert จริงเท่ากับจำนวนที่แสดงในหน้า 1 ทุกหน้า โดยทุกครั้งที่โหลดหน้าให้ Shuffle ใหม่จาก Slot ทั้งหมดที่ผ่านเงื่อนไข ไม่ใช้เฉพาะ Slot ที่ยังไม่เคยแสดง**

ตัวอย่าง มี Slot ผ่านเงื่อนไข 3 รายการ หน้า 1 แสดง Insert จริง 3 ใบ แม้ผังรองรับสูงสุด 6 เมื่อโหลดหน้า 2 หรือหน้า 3 ให้ Shuffle ทั้ง 3 Slot ใหม่แล้วแสดง Insert จริง 3 ใบ ไม่ลดจำนวนเป็นศูนย์และไม่ขยายเป็น 6

### **6.2 แต่ละภาษาใน Slot มี A/B ของตัวเอง**

ตัวอย่างนี้แยกช่องภาษาให้ชัดเจน ภายใน Slot ต้นทาง S1 ช่องไทยมี A/B ของไทย ช่องอังกฤษมี A/B ของอังกฤษ และช่องจีนมี A/B ของจีน รวมได้ 6 ทางเลือก แต่ S1 ยังเป็นหนึ่งรายการเข้า Shuffle แต่ละ A/B เลือก Type ได้จากทั้ง 5 ประเภท

สมมติทุกชิ้นงานพร้อมแสดง ทุก Slot ผ่านสิทธิ์ และมีตำแหน่งเพียงพอสำหรับ 4 Slot ภาพและ URL ของแต่ละรูปแบบและภาษาใช้ร่วมกันบน Mobile และ Desktop

| **Slot ต้นทาง** | **ช่องภาษา** | **รูปแบบ A** | **รูปแบบ B** |
|-------------|----------|----------|----------|
| S1          | ไทย      | Free Text | Video    |
| S1          | อังกฤษ   | Promotion | ซีรี่ย์ใหม่ |
| S1          | จีน      | ยอดนิยม  | Free Text |
| S2          | ไทย      | Video    | Promotion |
| S2          | อังกฤษ   | Free Text | ยอดนิยม  |

| S3          | ไทย      | ยอดนิยม  | ซีรี่ย์ใหม่ |
| S3          | อังกฤษ   | ไม่มี    | ไม่มี    |
| S3          | จีน      | Video    | Promotion |
| S4          | ไทย      | ไม่มี    | ไม่มี    |
| S4          | อังกฤษ   | ซีรี่ย์ใหม่ | Video    |
| S4          | จีน      | Promotion | ไม่มี    |

| **Slot** | **ผู้ใช้เลือกอังกฤษ** | **ผู้ใช้เลือกจีน** | **ผู้ใช้เลือกไทย** |
|------|-------------------|----------------|----------------|
| S1   | เลือก A Promotion หรือ B ซีรี่ย์ใหม่ จากชุดอังกฤษ | เลือก A ยอดนิยมหรือ B Free Text จากชุดจีน | เลือก A Free Text หรือ B Video จากชุดไทย |
| S2   | เลือก A Free Text หรือ B ยอดนิยม จากชุดอังกฤษ | เลือก A Video หรือ B Promotion จากชุดไทยสำรอง | เลือก A Video หรือ B Promotion จากชุดไทย |
| S3   | เลือก A ยอดนิยมหรือ B ซีรี่ย์ใหม่ จากชุดไทยสำรอง | เลือก A Video หรือ B Promotion จากชุดจีน | เลือก A ยอดนิยมหรือ B ซีรี่ย์ใหม่ จากชุดไทย |

**กรณี S1 เมื่อเลือกอังกฤษ:** คัดชุดอังกฤษไว้ก่อน Shuffle เมื่อ S1 ได้ตำแหน่งจึงเลือก A Promotion หรือ B ซีรี่ย์ใหม่ ไม่ใช้ A/B ไทยหรือจีน และไม่แยก S1 เป็นหลายรายการเพราะเตรียมไว้ 6 ทางเลือก

**กรณี S3 เมื่อเลือกอังกฤษ:** ไม่มีชุดอังกฤษ จึงคัดชุดไทยสำรองไว้ แล้วเลือก A ยอดนิยมหรือ B ซีรี่ย์ใหม่หนึ่งรูปแบบเมื่อได้ตำแหน่ง ไม่ใช้ A/B จีนแทนอังกฤษ

**กรณี S4 เมื่อเลือกจีน:** มีเพียง A Promotion ในช่องจีน จึงใช้รูปแบบนี้เมื่อได้ตำแหน่ง ไม่เอา B Video อังกฤษมาเติม

**ตัวอย่าง Shuffle ข้าม Slot หลังคัดภาษา:** ผู้ใช้เลือกอังกฤษแล้วได้ S1 อังกฤษ, S2 อังกฤษ, S3 ไทยสำรอง และ S4 อังกฤษ หาก Shuffle ได้ S3 → S1 → S4 → S2 ก็แสดงตามลำดับนี้ ชุดไทยสำรองไม่ถูกบังคับให้อยู่ท้าย ส่วนชุดจีนที่ไม่ได้คัดไม่เข้ามาปนในการสุ่มรอบนี้

จำนวน Slot ที่ผ่านเงื่อนไขภาษาในตัวอย่างคือ อังกฤษ 4 Slot จีน 4 Slot และไทย 3 Slot ตารางผลลัพธ์แสดงผลราย Slot ส่วนลำดับใช้ผล Shuffle ของรอบนั้น การเปลี่ยนภาษาไม่เริ่ม Shuffle ใหม่

### **6.3 เปลี่ยนภาษาโดยไม่ Refresh**

สมมติเปิดครั้งแรกเป็นอังกฤษ และได้ลำดับ S4 → S1 → S3 → S2 ตามตัวอย่างข้อ 6.2 เมื่อเปลี่ยนเป็นจีน ทั้งสี่ Slot ยังผ่านเงื่อนไข จึงคงลำดับ S4 → S1 → S3 → S2 แล้วใช้ชิ้นงานจีนหรือไทยสำรองตามกฎภาษา ไม่ Shuffle ใหม่

ตัวอย่างนี้ใช้ Slot ที่มีลำดับ Shuffle อยู่แล้ว ส่วน Slot ที่เดิมถูกคัดออกและเพิ่งผ่านเงื่อนไขหลังเปลี่ยนภาษาอย่างเดียว ยังต้องกำหนดว่าจะเพิ่มตรงไหนในลำดับเดิมตามหัวข้อ 8

## **9 ข้อกำหนดสำหรับส่งต่อทีมพัฒนา**

ทุกครั้งที่โหลดหน้า รวมการไปหน้าถัดไป ย้อนกลับแล้วโหลดใหม่ และ Refresh ให้ดึง Insert Card ทุกจังหวัดที่ผ่านเงื่อนไข ตัดประเภท “น่าอยู่” แล้วประเมินภาษาและความพร้อมของทุก Slot โดยเลือกภาษาผู้ใช้ก่อน ใช้ไทยของ Slot เดียวกันเมื่อไม่มีภาษาที่เลือก และตัด Slot เมื่อไม่มีทั้งสองภาษา

ข้อมูล Slot ต้นทางต้องแยกช่องไทย อังกฤษ และจีน โดยแต่ละช่องมี A/B สูงสุด 2 รูปแบบของตัวเอง ทั้ง A และ B เลือก Type ได้จากทั้ง 5 ประเภท ภาพและ URL ผูกกับทางเลือกและภาษานั้น ไม่บังคับให้ A ข้ามภาษาเป็น Type เดียวกัน

ในการโหลดหน้าแต่ละครั้งให้คัดช่องภาษาก่อน แล้ว Shuffle ที่ระดับ Slot ต้นทางจากทั้งชุดที่ผ่านเงื่อนไข Slot หนึ่งเป็นหนึ่งรายการ เมื่อ Slot ได้ตำแหน่งให้เลือก A/B เพียงหนึ่งรูปแบบจากช่องภาษาที่คัดไว้ตามกลไกเดิม ขณะอยู่หน้าเดิมไม่ Shuffle หรือเปลี่ยนผล A/B ซ้ำเอง

หน้า 1 ใช้ Insert ไม่เกินความจุ 6 หรือ 4 ตามผังของหน้า จำนวน Insert จริงในหน้า 1 เป็นจำนวน Insert ที่ต้องแสดงจริงของหน้า 2 ถึงหน้าสุดท้าย แต่ละหน้าเลือกจากผล Shuffle ใหม่ ไม่ใช้เฉพาะ Slot ที่ยังไม่เคยแสดง และไม่เพิ่มการ์ดจาก A/B ที่เหลือ

Mobile และ Desktop ใช้ภาพและ URL ชุดเดียวกันของรูปแบบและภาษาเดียวกัน ไม่ใช้อุปกรณ์เป็นเงื่อนไขเลือกไฟล์หรือ URL อีกชุด

การโหลดหน้าใหม่เท่ากับ Refresh ให้ประเมินข้อมูลและจัดชุดใหม่ ผลที่สุ่มอาจซ้ำเดิม ส่วนการเปลี่ยนภาษาอย่างเดียวให้ตรวจ Source Slots ทั้งหมดตามภาษาใหม่ คงลำดับ Slot ที่มีผล Shuffle อยู่ และใช้รูปแบบที่พร้อมตามกลไก A/B เดิม ไม่ Shuffle Slot ใหม่เพียงเพราะเปลี่ยนภาษา ตำแหน่งของ Slot ที่เพิ่งผ่านภาษาใหม่แต่ไม่เคยมีผล Shuffle ให้รอข้อสรุปในหัวข้อ 8
