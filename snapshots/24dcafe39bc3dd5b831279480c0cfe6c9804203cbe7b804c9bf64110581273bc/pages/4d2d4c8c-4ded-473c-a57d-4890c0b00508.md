**Route:** `/manage-post/update/{post_id}` (ประกาศ coming soon มี `?coming_soon_id=` ต่อท้าย)

**ไฟล์หน้า:** `app/(dashboard)/manage-post/update/[id]/page.tsx`, `UpdatePostClient.tsx`

**TrackingProvider:** ไม่มีของหน้าเอง ใช้แค่ส่วนกลาง (`category`, `source_type` ว่าง)

เข้าจากปุ่มแก้ไขในหน้าจัดการใบประกาศ (`/manage-post`) ใช้ฟอร์มชุดเดียวกับ "หน้าสร้างใบประกาศ" แต่เลือกฟอร์มจาก `user_type` อย่างเดียว (ไม่รับ `?type=`)

| ฟอร์ม | user_type |
|-------|-----------|
| ประกาศโครงการ | `project` (และ default) |
| ประกาศมือสอง | `general`, `agent`, `apartment`, `npa` |
| ประกาศรับสร้างบ้าน | `home_builder` |

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
