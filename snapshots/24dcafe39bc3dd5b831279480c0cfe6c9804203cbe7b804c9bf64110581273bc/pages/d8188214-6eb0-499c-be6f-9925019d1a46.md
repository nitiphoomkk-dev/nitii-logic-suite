> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/property-project/{ประเภท}-detail/{จังหวัด}/{uuid}` เช่น `/property-project/house-detail/khonkaen/{uuid}` (ประเภท: house, house-townhome, condo, townhome, shophouse, land, apartment, other)

**ไฟล์หน้า:** `app/(interface)/(post-and-profile)/detail/property-project/[property]/[location]/[uuid]/page.tsx`

**TrackingProvider:** `source_type: project`, `source_id` = id ประกาศ และตั้ง `entity_id` = id ประกาศ ให้ทุก event ที่ไม่ได้ส่ง entity_id มาเอง

ประกาศ premium ที่ปิดโฆษณา (block ads) จะไม่แสดงข้อ 15, 24, 25, 28 ส่วนข้อ 26 ไม่แสดงกับประกาศ premium ทุกแบบ และข้อ 22, 29 อาจซ่อนปุ่ม Line / Facebook

โมดูลแคมเปญ (ข้อ 5, 7, 12, 26) แสดงตามสถานะแคมเปญของประกาศ จังหวัด khonkaen, ubon, phitsanulok มีปุ่ม "รับสิทธิพิเศษ" เพิ่ม ส่วน buriram ใช้ปุ่มลงทะเบียนแบบเดิม

เปิดจาก BO preview (`?preview_from_bo`) จะไม่ยิง event ใดเลย

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
