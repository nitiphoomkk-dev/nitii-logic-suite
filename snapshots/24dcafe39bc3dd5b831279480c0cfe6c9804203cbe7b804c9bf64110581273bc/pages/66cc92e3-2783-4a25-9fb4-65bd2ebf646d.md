> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/post-listing` และ `/post-listing/{จังหวัด}` เช่น `/post-listing/khonkaen`

**ไฟล์หน้า:** `app/(interface)/(other)/post-listing/page.tsx`, `app/(interface)/(other)/post-listing/[location]/page.tsx`

**TrackingProvider:** `source_type: create_post` (route จังหวัดมี `province` = slug จังหวัด เพิ่ม)

ทั้ง 2 route ใช้ `CreatePostLanding` ตัวเดียวกัน ต่างกันแค่ `province` ใน pageMeta, ชื่อจังหวัดใน breadcrumb / หัวข้อ และ FAQ ท้ายหน้าที่มีเฉพาะ route จังหวัด

หน้านี้เป็นฟอร์มตัวอย่าง ยังไม่ login → เปิด modal login เองหลัง 2 วินาที, login แล้วแต่โปรไฟล์ไม่ครบ → เปิด modal กรอกข้อมูล, login แล้วและโปรไฟล์ครบ → ส่งต่อไป Nayoo Console ทันที

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
