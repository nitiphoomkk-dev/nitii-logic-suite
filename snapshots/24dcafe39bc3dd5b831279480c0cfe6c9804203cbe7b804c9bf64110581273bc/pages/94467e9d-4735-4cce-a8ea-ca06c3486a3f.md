 **กรณีพิเศษ**

2\. **การ์ดใบประกาศ Top ads  มี tag new ถ้าซื้อตอน เป็น tag new แต่จะแสดงแค่ตำแหน่ง การ์ดใบประกาศที่่ตำแหน่งของ top ads และไม่แสดงใน section ใบประกาศ tag new แต่ยังแสดง tag new**

```
 **3\.	ใบประกาศ tag new** 	
```

ใบประกาศที่ลงมาใหม่จะมีอายุ 3 วันและติด tag new ไม่จำกัดจำนวนการ์ดใบประกาศ สามารถแสดงทะลุไปถึงหน้า 2 ถึงหน้าสุดท้ายได้

* tag new สามารถดันใบประกาศได้ตอนที่ติด tag new
* tag new จะไม่อยู่ในระดับเดียวกับใบประกาศธรรมดาที่ลงมาแล้ว 3 วัน
* เมื่อหมด tag new แล้วใบประกาศนั้นจะตกลงมาลำดับแรก ของใบประกาศธรรมดา
* ใบประกาศ tag new เรียงตามเวลาที่สร้างในครั้งแรก และ เรียงตามการดันใบประกาศ
  * เมื่อลงครั้งแรกจะอยุ่ในลำดับที่ 1 ของใบประกาศ tag new
  * ถ้ามีใบอื่นดันมาก็จะสูญเสียตำแหน่งเดิมที่เคยอยู่
  * เมื่อหมดอายุจะตกลงไปอยู่ที่ตำแหน่งแรกของการ์ดใบประกาศธรรมดา
* กรณี tag new โดน reject
  * ผ่านตรวจ → กลับมาออนไลน์ → re-insert ท้ายสุดของชนชั้น tag new → นับเวลาที่เหลือต่อ (ค่าที่ freeze ไว้) ไม่รีเซ็ต ไม่ชดเชย
