## **1.2 Features ค้นหาและคัดกรอง**

##  ![](/api/attachments.redirect?id=73e7311c-0ed3-4ef0-85a6-60282bec859f)

## แบ่งเป็น 2 ส่วนหลัก: (A) ค้นหาด้วย Filter และ (B) ค้นหาด้วยชื่อ/ID ใบประกาศ

Logics:

* Features ในการค้นหาด้วย Filter default คือทั้งหมด

\-Filter กดแบบ Drop Down เพื่อ\*\* เลือกเฉพาะได้ \*\*โดยเลือกอย่างใดอย่างหนึ่งในการค้นหาและแสดงผลได้เลย \*\*ไม่จำเป็นต้องเลือก ทั้งหมด \*\*รายการที่แสดงจะขึ้นตาม Filter ที่กรองไว้

\-Filter ค้นหาวันที่สร้าง เป็นตัวเลือกแบบ Calendar เลือกเป็นวันเดียว โดยให้ขึ้นเฉพาะวันที่สร้าง ไม่ใช่วันที่ Update

\-Calendar ให้แสดงแค่ 1 เดือน สามารถกดซ้ายและขวาได้ **แต่ไม่สามารถกดวันที่ในอนาคตได้**

ปุ่ม Today เมื่อ User กด ให้เลือกเป็นวันที่ปัจจุบันเท่านั้น

```
    - ปุ่ม Clear ให้ยกเลิกการเลือกวันทั้งหมด
    - กดไปทางซ้าย ← จะแสดง เดือนที่ n\-1, และเดือน n Ex\. จากตุลาคมไปกันยายน 
    - กดไปทางขวา → จะแสดงเป็น เดือนที่ n\+1 Ex\. ตุลาคม ไป พฤศจิกายน
    - กดคลิกเลือกวันครั้งแรกจะเป็นวันที่เลือกเลยทันทีในรูปแบบ DD/MM/YYYY  คลิกวันที่ 19 เมษายน → Output ขึ้นช่องค้นหาวันที่สร้าง 19/09/2026 
    - ถ้ากดอีกครั้งที่ตรงกับวันที่เลือกครั้งแรกจะทำการยกเลิก **เลือกวันเดียวกันสองครั้งไม่ได้**
    - กดคลิกหลายวัน คือคลิกครั้งแรกวันที่ต้องการและลากคลุมวันที่ต้องการอีกวัน ขึ้นในช่องค้นหาวันที่สร้าง ในรูปแบบ DD/MM/YYYY \-   DD/MM/YYYY
- Filter ประเภทอสังหา เป็นตัวเลือกแบบ Drop Down โดยมีตัวเลือก 4 ตัวเลือก คือ บ้านเดี่ยว,บ้านแฝด,คอนโด,ทาวน์โฮม,อาคารพานิชญ์
```

* Features ทำเล สามารถพิมพ์ค้นหาและดูรายการแบบ Drop Downได้ ด้ชื่อใบประกาศ สามารถพิมพ์ค้นหาโดยการเขียนได้ทั้ง TH/EN และ ตัวเลข (พิมพ์ค้นหาได้ไม่เกิน 100 ตัวอักษร)

* **Logic รวม Filter**

เงื่อนไขพิเศษ:ชื่อเดิม เบอร์เดิม ไม่ส่งรายชื่อผู้สนใจซ้ำ

* นับ 24 ชั่วโมงจากเวลาลงครั้งแรก
* จะส่งซ้ำได้ถ้าเป็นข้อมูลเดิม ลงได้ถ้าลงก่อน 24 ชม. ไม่นับลีด ไม่ส่งไลน์
* case ลงตอนแรก 9 โมง รายชื่อที่สองหมดไม่พร้อมกัน ตัดจบไม่เท่ากันเพราะเป็น 24 ชั่วโมง
* กรณีส่งไป 1 ครั้งแล้ว ถ้ากดส่งซ้ำจะไม่ส่งไลน์ลูกค้ามาแล้วและรายชื่อผู้สนใจ
* มีการดักเบอร์โทร แพทเทิร์นเบอร์โทรของจริง เช่น 09 08 06
