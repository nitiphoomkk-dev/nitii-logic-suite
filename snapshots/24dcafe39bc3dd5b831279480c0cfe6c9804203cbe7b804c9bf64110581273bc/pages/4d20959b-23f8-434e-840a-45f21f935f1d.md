**การวางตำแน่งการแสดงผลให้ยึด ui figma เป็นหลัก**

**การแสดงผลใบประกาศที่ไม่เข้าร่วม แต่หมวดนั้นเข้าร่วม แบ่งออกเป็น 2 กรณีดังต่อไปนี้ ได้แก่**

1\.แสดงทางเข้าอีเว้นท์ กรณีที่ยังไม่มีการเลือกใบประกาศที่เข้าร่วมหรือใบประกาศ top event มาแสดงใน section นั้น

2\.แสดงผลใบประกาศ top event และใบประกาศที่เข้าร่วมใน

| **กรณี** | **เงื่อนไข** | **สิ่งที่แสดงใน section** |
|------|----------|-----------------------|
| **1** | ยังไม่มีการเลือกใบประกาศ top event หรือใบประกาศที่เข้าร่วม มาแสดงใน section นี้ | แสดง **"ทางเข้าอีเว้นท์"** แทน (เป็น fallback) |
| **2** | มีการเลือกใบประกาศ top event หรือใบประกาศที่เข้าร่วมไว้แล้ว | แสดง **ใบประกาศ top event และใบประกาศที่เข้าร่วม** ใน section นั้นตามที่เลือกไว้ |

**Logic การแสดงผลกรณีที่ 2**

ใบประกาศที่เข้าร่วม/บริษัทที่เข้าร่วม (เป็น Top Event และแสดงแบบสุ่ม หากแต่ละหมวดมีไม่ถึง 4 การ์ด จะดึงใบประกาศทั่วไปที่เข้าร่วม  แสดงสูงสุด 12 slot

  a. การวางสนใจแต่ top event ไม่มีการคำนึงถึง top ads ranking model

  b. ดึงใบประกาศที่เข้าร่วมแคมเปญมาแสดงด้วยหากไม่เต็ม slot

  c. ถ้าใบประกาศ 1-2 ใบจะแสดงกึ่งกลาง , ใบประกาศ =<4 ใบประกาศจะชิดซ้าย

  d. จะมีปุ่มเลื่อนซ้าย ขวา เลื่อนซ้ายได้เมื่อเลื่อนขวา เลื่อนเป็นชุด

  e. กดแล้วเปิด new tab ไปหน้าใบประกาศนั้น

| **หัวข้อ** | **รายละเอียด** |
|--------|------------|
| **ประเภทการ์ด** | ใบประกาศ/บริษัทที่เข้าร่วม โดยเป็น Top Event แสดงแบบสุ่ม |
| **เงื่อนไขเติมการ์ด** | หากแต่ละหมวดมีการ์ดไม่ถึง 4 ใบ จะดึง "ใบประกาศทั่วไปที่เข้าร่วม" มาเติม |
| **จำนวน slot สูงสุด** | แสดงสูงสุด 12 slot |
| **โมเดลจัดอันดับ** | คำนึงถึงเฉพาะ Top Event เท่านั้น **ไม่** คำนึงถึง Top Ads Ranking Model |
| **การจัดวาง: 1–2 ใบ** | แสดงกึ่งกลาง (center) |
| **การจัดวาง: ≤ 4 ใบ** | ชิดซ้าย (left-aligned) |
| **ปุ่มเลื่อน** | จะมีปุ่มเลื่อนซ้าย ขวา เลื่อนซ้ายได้เมื่อเลื่อนขวา เลื่อนเป็นชุด |

| **#** | **ชั้น** | **จำนวนในชั้น (N)** | **กฎต่อ 1 refresh** | **ผลลัพธ์** |
|-----|------|-----------------|-----------------|---------|
| 1   | Top event | 1               | ไม่สลับ เพราะมีรายการเดียว | คงที่ตำแหน่งเดิม |
|     | Top event | 2+              | วนตำแหน่งเฉพาะภายในกลุ่ม Top event แบบเก้าอี้ดนตรี | Top event ยังอยู่ด้านหน้าก่อนเสมอ และรายการในกลุ่ม Top event จะค่อย ๆ วนตำแหน่งกันจนครบทุกตำแหน่ง |

|     | ใบประกาศ | 2+              | วนตำแหน่งเฉพาะภายในกลุ่มใบประกาศแบบเก้าอี้ดนตรี | ใบประกาศยังอยู่หลัง Top event เสมอ และรายการในกลุ่มใบประกาศจะค่อย ๆ วนตำแหน่งกันจนครบทุกตำแหน่ง |
