> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/reviews/all/{จังหวัด}` เช่น `/reviews/all/khonkaen` (หน้าเดียว ไม่มี `/page/{N}`, หน้า 2 ขึ้นไปเป็น 404)

**ไฟล์หน้า:** `app/(interface)/(other)/reviews/[category]/[location]/page.tsx` (ใช้ `review-listing.tsx`), layout `app/(interface)/(other)/reviews/layout.tsx`

**TrackingProvider:** `source_type: review` (อยู่ใน layout ใช้ร่วมกับหน้ารีวิวทุกแบบ)

แต่ละ section แสดงเมื่อมีรีวิวในส่วนนั้น ถ้าไม่มีรีวิวเลยแสดงแค่ "ยังไม่มีรีวิว"

หน้ารีวิวมีอีก 2 แบบที่ใช้ component ต่างกัน ดูเอกสาร "หน้ารีวิว (ทั้งประเทศ)" และ "หน้ารีวิว (ตามหมวด)"

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
