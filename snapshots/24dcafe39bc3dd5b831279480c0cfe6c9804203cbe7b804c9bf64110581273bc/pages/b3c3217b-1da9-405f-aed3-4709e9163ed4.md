# **EP-02 Solution —  การแสดงวิดีโอแนะนำ**

## **หน้ารวมรีวิว Center**

**เลือกวิดีโอปักหมุด/ติดดาวจากทุกจังหวัดก่อน → หากไม่ครบ 3 ให้เติมวิดีโอล่าสุด → สุ่มสลับตำแหน่งร่วมกัน → วิดีโอที่ขึ้นส่วนแนะนำแล้วต้องไม่ซ้ำกับรายการรีวิวด้านล่าง**

## **1) แนวคิดและขอบเขต**

**หน้ารีวิว Center แบ่งพื้นที่แสดงรีวิวเป็น 2 ส่วน โดยใช้ข้อมูลจากทุกจังหวัดมารวมกัน**

| **ส่วนแสดงผล** | **หน้าที่** | **จำนวนสูงสุด** |
|------------|---------|-------------|
| **รีวิวแนะนำด้านบน** | **นำวิดีโอปักหมุด/ติดดาวมาแนะนำ และใช้วิดีโอล่าสุดเติมเมื่อไม่ครบ** | **3 การ์ด** |
| **รายการรีวิวด้านล่าง** | **แสดงรีวิวที่ตรงกับตัวกรอง โดยเรียงจากอัปเดตใหม่ไปเก่า และไม่ซ้ำกับส่วนแนะนำ** | **24 การ์ดต่อหน้า** |

**การดึงรีวิวจากทุกจังหวัด การใช้ตัวกรอง และจำนวน 24 การ์ดด้านล่างเป็นเงื่อนไขของหน้า Center ใน BRD ส่วนกฎเลือกวิดีโอแนะนำและไม่แสดงซ้ำ**

**ความหมายของ N จังหวัด**

**N หมายถึงจำนวนจังหวัดทั้งหมดที่นำข้อมูลมาแสดงร่วมกัน**

ตัวอย่าง N = 15 จังหวัด หมายถึงรวมรีวิวจากทั้ง 15 จังหวัดก่อน แล้วจึงเลือกวิดีโอแนะนำ ไม่ใช่เลือกจังหวัดละ 3 รายการ

ไม่ว่าจะมีจังหวัดกี่แห่ง ส่วนแนะนำยังแสดงสูงสุด 3 การ์ด และรายการด้านล่างยังแสดงสูงสุด 24 การ์ดต่อหน้า

### **คำที่ใช้ใน Solution**

| **คำ** | **ความหมาย** |
|-----|----------|
| **ปักหมุด/ติดดาว** | **วิดีโอที่ปักหมุด หรือติดดาว หรือมีทั้งสองสถานะ** |
| **ล่าสุด** | **วิดีโอที่อัปเดตใหม่ที่สุด โดยดูจากข้อมูลรวมทุกจังหวัด** |
| **Shuffle** | **การสุ่มสลับตำแหน่งของรายการ เช่น A–B–C อาจเปลี่ยนเป็น C–A–B** |
| **ไม่แสดงซ้ำด้านล่าง** | **ไม่นำวิดีโอที่เลือกขึ้นแนะนำมาแสดงซ้ำในรายการรีวิวด้านล่าง ไม่ใช่ลบวิดีโอออกจากระบบ** |

**ประเด็นที่ต้องแยกให้ชัด: ปักหมุด/ติดดาวได้รับการ เลือกเข้ามาในส่วนแนะนำก่อน แต่ไม่ได้หมายความว่าต้องอยู่การ์ดใหญ่เสมอ เพราะเมื่อเลือกครบแล้วจะ Shuffle ตำแหน่งร่วมกัน**

## **2) ตารางสรุป Logic การทำงาน**

### **2.1 การเลือกวิดีโอแนะนำ**

**จำนวนปักหมุด/ติดดาวทุกข้อ ให้นับรวมจากทั้ง N จังหวัด และไม่นับวิดีโอเดียวกันซ้ำ**

| **รหัส** | **หัวข้อ** | **เงื่อนไขการทำงาน** |
|------|--------|------------------|
| **RV-C01** | แหล่งข้อมูล | รวมวิดีโอรีวิวที่เข้าเงื่อนไขจากทุกจังหวัด ตั้งแต่จังหวัดที่ 1 ถึงจังหวัดที่ N |
| **RV-C02** | วิธีนับวิดีโอ | วิดีโอเดียวที่มีทั้งปักหมุดและติดดาว ให้นับเป็น 1 รายการ |
| **RV-C03** | มีปักหมุด/ติดดาว 1 รายการ | เลือกรายการนั้น แล้วเติมวิดีโอล่าสุดอีก 2 รายการ ที่ไม่ซ้ำ เมื่อมีข้อมูลเพียงพอ |
| **RV-C04** | มีปักหมุด/ติดดาว 2 รายการ | เลือกทั้ง 2 รายการ แล้วเติมวิดีโอล่าสุดอีก 1 รายการ ที่ไม่ซ้ำ เมื่อมีข้อมูลเพียงพอ |
| **RV-C05** | มีปักหมุด/ติดดาว 3 รายการ | ใช้ทั้ง 3 รายการ ไม่ต้องเติมล่าสุด |
| **RV-C06** | มีปักหมุด/ติดดาวมากกว่า 3 รายการ | Shuffle ปักหมุด/ติดดาวทั้งหมดจาก N จังหวัด แล้วเลือก 3 รายการ |
| **RV-C07** | วิธีเลือกล่าสุดมาเติม | เลือกจากเวลาอัปเดตใหม่ที่สุดของข้อมูลรวม N จังหวัด โดยข้ามวิดีโอที่เลือกไว้แล้ว |
| **RV-C08** | การสลับตำแหน่ง | นำปักหมุด ติดดาว และล่าสุดที่เติมมา Shuffle ร่วมกัน ไม่แยกกลุ่มแสดงก่อน–หลัง |
| **RV-C09** | ตำแหน่งการ์ดใหญ่ | ใช้วิดีโอลำดับแรกหลัง Shuffle จึงเป็นได้ทั้งปักหมุด ติดดาว หรือล่าสุดที่เติม |
| **RV-C10** | ไม่มีปักหมุด/ติดดาวเลย | เลือกวิดีโออัปเดตล่าสุดสูงสุด 3 รายการจากทุกจังหวัด แล้ว Shuffle ตำแหน่งของรายการที่เลือก |

**การเลือกล่าสุดในฉบับนี้ยังใช้ “เลือก 3 ล่าสุดก่อน แล้ว Shuffle” ไม่เปลี่ยนเป็นสุ่มจากวิดีโอทั้งหมด เช่น มี 50 รายการ ให้เลือก 3 ที่อัปเดตใหม่ที่สุดก่อน ไม่ใช่สุ่มเลือก 3 จากทั้ง 50 รายการ วิธีนี้คงตามฐาน Logic รีวิวเดิมครับ NAYOO V2 BRD (100)**

### **2.2 การไม่แสดงซ้ำกับรายการรีวิวด้านล่าง**

| **รหัส** | **หัวข้อ** | **เงื่อนไขการทำงาน** |
|------|--------|------------------|
| **RV-C11** | รายการที่ห้ามซ้ำ | ทุกวิดีโอที่เลือกขึ้นส่วนแนะนำแล้ว ต้องไม่แสดงซ้ำด้านล่าง |
| **RV-C12** | การเติมรายการด้านล่าง | ข้ามวิดีโอที่ขึ้นแนะนำ แล้วใช้รีวิวลำดับถัดไปที่ตรงกับตัวกรองมาเติมสูงสุด 24 การ์ด |
| **RV-C13** | การเรียงด้านล่าง | เรียงตามเวลาอัปเดตจากใหม่ไปเก่า ไม่ Shuffle ตามส่วนแนะนำ |
| **RV-C14** | กรณีมีปักหมุด/ติดดาวผสมกับล่าสุด | ต้องไม่แสดงซ้ำด้านล่าง ทุกรายการที่เลือก ทั้งปักหมุด ติดดาว และล่าสุดที่เติม |
| **RV-C15** | วิธีตรวจรายการซ้ำ | ตรวจจากรหัสของรีวิว/วิดีโอเดียวกัน ไม่ตรวจจากเลขช่อง ชื่อโครงการ หรือภาพปก |
| **RV-C16** | จำนวนการ์ด | ส่วนแนะนำสูงสุด 3 การ์ด และด้านล่างสูงสุด 24 การ์ดต่อหน้า นับแยกกัน |
| **RV-C17** | ปักหมุด/ติดดาวที่ไม่ได้ขึ้นแนะนำ | ยังแสดงด้านล่างได้ตามตัวกรองและลำดับล่าสุด ไม่ตัดรายการปักหมุด/ติดดาวทั้งหมดออก |
| **RV-C18** | ข้อมูลด้านล่างไม่ครบ 24 | แสดงเท่าที่เหลือจริง ไม่วนวิดีโอแนะนำกลับมาเติม และไม่สร้างการ์ดซ้ำ |
| **RV-C19** | รายการด้านบนและด้านล่างต้องตรงกัน | ระบบต้องข้ามวิดีโอชุดเดียวกับที่แสดงด้านบนจริง |

## **3) ตารางเงื่อนไขตามจำนวนวิดีโอ**

**ตารางนี้สมมติว่ามีวิดีโอล่าสุดเพียงพอสำหรับเติมให้ครบ 3 รายการ**

| **ปักหมุด/ติดดาวรวมจาก N จังหวัด** | **เลือกปักหมุด/ติดดาว** | **เติมล่าสุด** | **วิธีแสดงส่วนแนะนำ** | **รายการที่ห้ามซ้ำด้านล่าง** |
|--------------------------------|---------------------|------------|-------------------|--------------------------|
| **0 รายการ**                   | 0                   | 3          | เลือก 3 ล่าสุด แล้ว Shuffle | ล่าสุดทั้ง 3 ที่เลือก    |
| **1 รายการ**                   | 1                   | 2          | Shuffle ทั้ง 3 ร่วมกัน | ทั้ง 3 รายการ            |
| **2 รายการ**                   | 2                   | 1          | Shuffle ทั้ง 3 ร่วมกัน | ทั้ง 3 รายการ            |
| **3 รายการ**                   | 3                   | 0          | Shuffle ทั้ง 3    | ทั้ง 3 รายการ            |
| **มากกว่า 3 รายการ\***         | เลือก 3             | 0          | Shuffle กลุ่มปักหมุด/ติดดาวก่อนเลือก | เฉพาะ 3 รายการที่เลือกจริง |

**ตัวอย่างการนับ: จังหวัด A มีปักหมุด 1 รายการ และจังหวัด B มีติดดาว 2 รายการ → รวมเป็น 3 รายการแล้ว ไม่ต้องเติมล่าสุดแยกให้แต่ละจังหวัด**

## **4) ตัวอย่างการแสดงผล**

### **4.1 มีปักหมุด 1 รายการ และติดดาว 1 รายการ**

**สมมติรวมข้อมูลจาก N = 5 จังหวัด แล้วพบรายการดังนี้**

| **วิดีโอ** | **จังหวัด** | **สถานะ** |
|--------|---------|-------|
| **A**  | **จังหวัดที่ 1** | **ปักหมุด** |
| **B**  | **จังหวัดที่ 2** | **ติดดาว** |
| **C**  | **จังหวัดที่ 4** | **ล่าสุดอันดับ 1 ที่ยังไม่ได้เลือก** |
| **D, E, F…** | **จากทั้ง 5 จังหวัด** | **ล่าสุดลำดับถัดไป** |

**ระบบเลือก A และ B ก่อน แล้วเติม C ให้ครบ 3 จากนั้น Shuffle ร่วมกัน**

**ก่อน Shuffle**

**A → B → C**

**ตัวอย่างหลัง Shuffle**

**C → A → B**

| **ส่วนแสดงผล** | **รายการที่ใช้** |
|------------|--------------|
| **แนะนำช่อง 1 — การ์ดใหญ่** | **C — ล่าสุดที่เติม** |
| **แนะนำช่อง 2** | **A — ปักหมุด** |
| **แนะนำช่อง 3** | **B — ติดดาว** |
| **รายการรีวิวด้านล่าง** | **ใช้ D, E, F… ตามลำดับล่าสุด และเติมสูงสุด 24 การ์ด** |

**A, B และ C ต้องไม่ซ้ำด้านล่างทั้งหมด ไม่ใช่ตัดเฉพาะ C ซึ่งเป็นล่าสุด**

### **4.2 ไม่มีปักหมุด/ติดดาว และมีล่าสุดรวม 50 รายการ**

**สมมติวิดีโอจากทุกจังหวัดเรียงตามอัปเดตล่าสุดเป็น 01–50**

**เลือก 3 ล่าสุด**

01 → 02 → 03

**ตัวอย่างการแสดงส่วนแนะนำหลัง Shuffle**

[03] [01] [02]

รายการรีวิวด้านล่าง

[04] [05] [06] … [27] รวม 24 การ์ด

ส่วนแนะนำ 3 การ์ด + ด้านล่าง 24 การ์ด = แสดงวิดีโอไม่ซ้ำกัน 27 รายการ ในตัวอย่างนี้ ซึ่งมีข้อมูลเพียงพอและทุกรายการตรงกับตัวกรองเดียวกัน

### **4.3 ปักหมุด/ติดดาวที่ไม่ได้รับเลือก ยังแสดงด้านล่างได้**

**สมมติมีปักหมุด/ติดดาว 8 รายการ A–H และเลือกขึ้นแนะนำ B, D, H**

| **รายการ** | **การแสดงด้านล่าง** |
|--------|-----------------|
| **B, D, H** | ไม่แสดงซ้ำ เพราะขึ้นส่วนแนะนำแล้ว |
| **A, C, E, F, G** | ยังมีสิทธิ์แสดงตามตัวกรองและลำดับอัปเดตล่าสุด |
| **รีวิวอื่น** | แสดงได้ตามเงื่อนไขเดิม |

**ตัวอย่างนี้อธิบายผลหลังเลือกแล้ว ส่วนวิธีเลือก 3 จาก 8 ยังคงอ้างอิงข้อเสนอใน RV-C06**

**ห้ามตัดรายการปักหมุด/ติดดาวทั้งหมดออกจากด้านล่าง ให้ตัดเฉพาะรายการที่ขึ้นแนะนำจริง**

## **5) ตารางจำลองทั้ง 8 กรณี**

|------|--------------|-------------------|-----------------|-------------------|---------------------|---------------------|
| 1    | 1            | 0                 | 0               | ไม่มีรายการ       | 0                   | 0                   |
| 2    | 3            | 0                 | 2               | ล่าสุด 2\*        | 0                   | 0                   |
| 3    | 5            | 0                 | 24              | ล่าสุด 3          | 21                  | 21                  |
| 4    | 10           | 0                 | 50              | ล่าสุด 3          | 47                  | 24                  |
| 5    | 15           | 1                 | 50              | ปักหมุด/ติดดาว 1 + ล่าสุด 2 | 48                  | 24                  |
