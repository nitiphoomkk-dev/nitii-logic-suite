> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/property-project/new-opening/{จังหวัด}/{id}` เช่น `/property-project/new-opening/khonkaen/{id}`

**ไฟล์หน้า:** `app/(interface)/(post-and-profile)/detail/property-project/new-opening/[location]/[uuid]/page.tsx`

**TrackingProvider:** `source_type: project`, `source_id` = id ในลิงก์ (id โครงการเปิดตัวใหม่) และตั้ง `entity_id` = id ในลิงก์ ให้ทุก event ที่ไม่ได้ส่ง entity_id มาเอง

⚠️ id ในลิงก์ไม่ใช่ id ประกาศ ส่วนหลาย section ส่ง id ประกาศ (`post_id`) เป็น entity_id ถ้าโครงการยังไม่มี `post_id` event ที่ผูกกับ id ประกาศจะไม่ยิงหรือไม่มี entity_id

โมดูลแคมเปญ (ข้อ 4, 5, 9, 25) แสดงตามสถานะแคมเปญของประกาศ จังหวัด khonkaen, ubon, phitsanulok มีปุ่ม "รับสิทธิพิเศษ" เพิ่ม ส่วน buriram ใช้ปุ่มลงทะเบียนแบบเดิม

เปิดจาก BO preview (`?preview_from_bo`) จะไม่ยิง event ใดเลย

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
