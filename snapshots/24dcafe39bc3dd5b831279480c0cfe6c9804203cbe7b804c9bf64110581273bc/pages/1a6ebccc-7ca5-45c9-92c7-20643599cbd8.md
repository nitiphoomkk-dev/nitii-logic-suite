> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/rent/{ประเภท}/{จังหวัด}` เช่น `/rent/properties/khonkaen` (ต่อท้ายด้วยตัวกรองใน path และ `/page/{N}` ได้)

**ไฟล์หน้า:** `app/(interface)/(search)/search/[main_service]/[property]/[location]/[[...options]]/page.tsx` → `components/pages/search/rent/SearchRentPage.tsx`

**TrackingProvider:** `source_type: search` (ตั้งใน `[[...options]]/layout.tsx`, ไม่มี `category`)

`proxy.ts` rewrite URL นี้ไปที่ `/search/rent/...` route เดียวกันนี้ใช้กับหน้าค้นหาโครงการ มือสอง รับสร้างบ้าน และแบบบ้าน ทุกหน้าจึงได้ `source_type: search` เหมือนกัน แยกหน้าได้จาก `page.source` (path) เท่านั้น

ExcellentPropertySection (ทรัพย์ดีทรัพย์เด็ด) และ FindPopularRentSection (หาเช่า/หอพักยอดนิยม) ถูก comment ไว้ระหว่างรอ API จึงไม่แสดง

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
