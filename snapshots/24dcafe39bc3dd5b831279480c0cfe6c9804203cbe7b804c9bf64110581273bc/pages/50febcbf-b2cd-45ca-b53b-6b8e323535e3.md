**การเลือกช่วงเวลาที่จัดแคมเปญมี 2 กรณี**

1\. ช่วงเวลาที่จัดแคมเปญบน online

2\. ช่วงเวลาที่จัดแคมเปญ onsite

**ช่วงเวลาที่จัดแคมเปญบน online แบ่งออกเป็น 3 กรณี**

* Pre event
* Event
* End event

**โดยมี logic ในการเลือกวันดังต่อไปนี้**

**EP-02.5การเลือก pre event การเลือกช่วงเวลา จะเลือกแบบ 1:1 ในการเลือก**

 ![](/api/attachments.redirect?id=b81df65d-b456-48f2-af47-f5f2ea185b4d)

* ปุ่ม Today เมื่อ User กด ให้เลือกเป็นวันที่ปัจจุบันเท่านั้น
* ไม่สามารถเลือกวันที่ในอดีตได้
* ปุ่ม Clear ให้ยกเลิกการเลือกวันทั้งหมด
* กดไปทางซ้าย ← จะแสดง เดือนที่ n-1 <u>Ex</u>. จากตุลาคมไปกันยายน
* กดไปทางขวา → จะแสดงเป็นเดือน n+1 <u>Ex</u>. ตุลาคม ไป พฤศจิกายน
* <u><strong>กรณีเลือก วันเดียว</strong></u> กดคลิกเลือก doble วันครั้งแรก จะเป็นวันที่เลือกเลยทันทีในรูปแบบ DD/MM/YYYY  คลิกวันที่ 19 เมษายน → Output ขึ้นช่องค้นหาวันที่ 19/09/2026
* ถ้ากดอีกครั้งที่ตรงกับวันที่เลือกครั้งแรกจะทำการยกเลิก **เลือกวันเดียวกันสองครั้งไม่ได้**
* เมื่อหลังวันที่ 31 ธันวาคม ให้เริ่มปี ค.ศ.ใหม่
* การเลือก pre-event ช่วงเวลาห้ามทับซ้อนกับช่วง event และ end of event
* ถ้ากลับไปแก้วันที่ pre event ใหม่จะล้างค่า ของช่องอื่นๆ ที่ได้กรอก และ user ต้องทำการกรอกใหม่
* **วันที่ที่ถูกบล็อคจะต้องแสดงว่ามันกดไม่ได้แบบ disable**

**EP-02.6 ช่วง** Event ไม่สามารถเลือกวันที่ในอดีตได้ และ ไม่สามรถเลือกช่วงเวลาที่ทับซ้อนกันกับ ช่วง pre event หรือ end event ได้  logic การเลือก ปฎิทินใช้แบบ EP-02.5

**EP-02.7ช่วง  End** Event ไม่สามารถเลือกวันที่ในอดีตได้ และ ไม่สามรถเลือกช่วงเวลาที่ทับซ้อนกันกับ ช่วง pre event หรือ event ได้  logic การเลือก ปฎิทินใช้แบบ EP-02.5
