**EP-02 Banner — หน้า Center**

**Solution รองรับ 3 ภาษา + Shuffle Slot ต้นทาง + เลือก A/B หนึ่งภาพต่อ Slot**

**รหัสงาน:** EP-01 Banner — หน้า Center

**ฉบับ:** 1.0 สำหรับส่งทบทวน

**วันที่:** 8 ตุลาคม 2569

**เอกสารอ้างอิง:** NaYoo Center (24).pdf หน้า 1–5 สำหรับ Banner เดิม และ NaYoo Center (22).pdf หน้า 2–11 สำหรับกฎภาษาและการเลือกภาพของ Top Banner

**1. วัตถุประสงค์และขอบเขต**

เอกสารนี้กำหนดวิธีเลือกภาษากราฟิกและวิธีจัดชุดภาพของ **Banner บนหน้า Center** ให้ใช้หลักเดียวกับ Top Banner: ตรวจภาษาและไฟล์ของอุปกรณ์แยกแต่ละ Slot ก่อน จากนั้น Shuffle **Slot ต้นทาง** แล้วเลือกภาพ A หรือ B หนึ่งภาพภายใน Slot ที่ได้รับตำแหน่ง

**ผลที่ต้องได้:** ภายในชุดแสดงผลหนึ่งชุด Banner Slot ต้นทางหนึ่งรายการต้องครองได้ไม่เกินหนึ่งช่อง และต้องแสดงภาพของภาษาที่อนุญาตเพียงหนึ่งภาพ

**2. นิยาม**

| **คำ** | **ความหมายในเอกสารนี้** |
|-----|---------------------|
| Banner Slot ต้นทาง | รายการ Banner หนึ่งรายการจากจังหวัดต้นทาง เป็นหน่วยที่ใช้ในการ Shuffle; ภาพ A/B ไม่ทำให้เกิด Slot ใหม่ |
| ภาพ A/B | กราฟิกทางเลือกภายในภาษาเดียวของ Banner Slot ต้นทาง ไม่ใช่รายการ Banner เพิ่ม |
| จุดวาง Banner | ตำแหน่งแสดง Banner หนึ่งตำแหน่งบนหน้า เช่น บน กลาง หรือล่าง |
| Slot แสดงผล | ช่องหนึ่งในจุดวาง Banner ซึ่งแสดงภาพหนึ่งภาพจาก Banner Slot ต้นทางหนึ่งรายการ |
| ชุดแสดงผล | ลำดับ Slot และภาพที่เลือกไว้สำหรับจุดวาง Banner หนึ่งรอบ; Auto Slide เลื่อนชุดนี้โดยไม่เลือกภาพใหม่ |

**3. เงื่อนไขการทำงาน**

**3.1 แหล่งข้อมูลและการคัดออก**

1\. ระบบต้องดึง Banner ที่ผ่านเงื่อนไขเดิมจากทุกจังหวัดที่มีรายการ โดยรองรับจำนวนจังหวัด N ที่เปลี่ยนแปลงได้

2\. ระบบต้องไม่นำ Banner ประเภท **“น่าอยู่”** เข้าชุดแสดงผล Center

3\. ระบบต้องตรวจภาษาและภาพที่ใช้ได้ของแต่ละ Slot หลังคัดประเภท และตัด Slot ที่ไม่ผ่านเงื่อนไขก่อนเริ่ม Shuffle

**3.2 การเลือกภาษากราฟิก**

ในเชิงการเลือกภาพ Banner หนึ่ง Slot ต้องแยกชุดกราฟิกตามภาษา **ไทย จีน อังกฤษ** เช่นเดียวกับ Top Banner โดยแต่ละภาษามีภาพทางเลือก A/B ได้ไม่เกินสองภาพ และจำนวนภาพของแต่ละภาษาไม่จำเป็นต้องเท่ากัน

| **ภาษา** | **ภาพทางเลือกในภาษาเดียวกัน** | **เมื่อ Slot ได้ตำแหน่ง** |
|------|---------------------------|-----------------------|
| ไทย  | TH-A, TH-B ตามจำนวนที่มีจริง | เลือกหนึ่งภาพ         |
| จีน  | ZH-A, ZH-B ตามจำนวนที่มีจริง | เลือกหนึ่งภาพ         |
| อังกฤษ | EN-A, EN-B ตามจำนวนที่มีจริง | เลือกหนึ่งภาพ         |

**ข้อจำกัดข้อมูล:** Banner เดิมระบุสูงสุดสองภาพต่อ Slot ขณะที่ A/B ครบทั้งสามภาษาอาจต้องเก็บได้สูงสุดหกภาพต่อ Slot จำนวนหกเป็นความจุของข้อมูล

**แยกแต่ละ Banner Slot ต้นทาง** ตามลำดับต่อไปนี้

1\. หาก Slot มีภาพที่ใช้ได้ตรงกับภาษาที่ผู้ใช้เลือก ให้ใช้ภาพของภาษานั้น

2\. หากไม่มีภาพที่ใช้ได้ตรงภาษา แต่มีภาพภาษาไทยที่ใช้ได้ใน Slot เดียวกัน ให้ใช้ภาพภาษาไทย

3\. หากไม่มีทั้งภาพตรงภาษาและภาพภาษาไทยที่ใช้ได้ ให้ตัด Slot ออกจากชุดก่อน Shuffle

ห้ามใช้ภาพภาษาอังกฤษแทนภาษาจีน หรือภาพภาษาจีนแทนภาษาอังกฤษ ห้ามนำภาพต่างภาษามาเติมจำนวนภาพ A/B การใช้กราฟิกภาษาไทยสำรองไม่เปลี่ยนภาษาของเว็บไซต์และไม่แปลข้อความในภาพ

| **ภาษาของภาพที่ใช้ได้ใน Slot** | **ผู้ใช้เลือกไทย** | **ผู้ใช้เลือกจีน** | **ผู้ใช้เลือกอังกฤษ** |
|----------------------------|----------------|----------------|-------------------|
| ไทย จีน อังกฤษ             | ไทย            | จีน            | อังกฤษ            |
| ไทย อังกฤษ                 | ไทย            | ไทย            | อังกฤษ            |
| ไทย จีน                    | ไทย            | จีน            | ไทย               |
| จีน อังกฤษ                 | ตัด Slot       | จีน            | อังกฤษ            |
| ไทยอย่างเดียว              | ไทย            | ไทย            | ไทย               |
| จีนอย่างเดียว              | ตัด Slot       | จีน            | ตัด Slot          |
| อังกฤษอย่างเดียว           | ตัด Slot       | ตัด Slot       | อังกฤษ            |
| ไม่มีภาพที่ใช้ได้          | ตัด Slot       | ตัด Slot       | ตัด Slot          |

**กรณีมีภาพไม่ครบ A/B:** หากภาษาที่เลือกมีภาพที่ใช้ได้เพียงหนึ่งภาพ ให้ใช้ภาพนั้นเพียงภาพเดียว แม้ภาษาไทยจะมีสองภาพก็ตาม

**3.3 การ Shuffle และการเลือกภาพ**

1\. ระบบต้องนำ **Banner Slot ต้นทาง** ที่ผ่านเงื่อนไขเข้า Shuffle โดยให้หนึ่ง Slot เป็นหนึ่งรายการ ไม่แยก Slot ตามจำนวนภาพ A/B หรือจำนวนภาษา

2\. ภาพ A/B ของภาษาที่ผ่านการเลือกต้องคงเป็นภาพทางเลือกภายใน Slot นั้น ภาพไทยที่ใช้เป็น fallback ต้องร่วม Shuffle กับ Slot อื่นตามปกติ

3\. เมื่อ Slot ได้รับเลือกเข้าจุดวางแล้ว ระบบต้องเลือกภาพ A หรือ B ของภาษาที่กำหนดไว้ **เพียงหนึ่งภาพ** หากมีภาพเดียวให้ใช้ภาพนั้น ตัวอย่าง Shuffle ได้ B → A → C โดย B มีภาพ B1/B2, A มี A1/A2 และ C มี C1 ผลที่แสดงอาจเป็น B2 → A1 → C1 รวม **3 Slot, 3 ภาพ** ส่วน C มีภาพเดียวก็ใช้ C1 เลย

4\. ภายในชุดแสดงผลของจุดวางเดียวกัน ห้ามให้ภาพ A และ B ของ Slot ต้นทางเดียวกันครองคนละช่อง และห้ามนำภาพที่ไม่ได้เลือกมาเติมช่องที่ว่าง **Slot ต้นทางเดียวกันแสดงซ้ำข้ามจุดวางในหน้าเดียวกันได้ แต่ภายในแต่ละจุดวาง Slot นั้นแสดงได้เพียงหนึ่งครั้ง**

5\. ลำดับภาพที่แสดงต้องเป็นลำดับเดียวกับ Slot หลัง Shuffle โดยไม่ Shuffle ภาพซ้ำอีกครั้ง

6\. จำนวนภาพ A/B ไม่เพิ่มน้ำหนักของ Slot ในการ Shuffle: Slot ที่มีสองภาพและ Slot ที่มีภาพเดียวต่างเข้า Shuffle อย่างละหนึ่งรายการ การเลือก A/B ภายใน Slot ให้ใช้กลไกเดิม

7\. การจัดลำดับ Banner Center ไม่ใช้ Ranking Model

**ตัวอย่าง:** Slot A มี A1/A2, Slot B มี B1/B2 และ Slot C มี C1 หลังตรวจภาษาและอุปกรณ์แล้ว หาก Shuffle Slot ได้ B → A → C และเลือกภาพได้ B2 → A1 → C1 ผลคือ **3 Slot ต้นทาง และ 3 ภาพแสดง** แม้มีภาพทางเลือกรวม 5 ภาพ

**3.4 การเลื่อนและการจัดชุดใหม่**

• Banner ต้องเลื่อนอัตโนมัติทุก **4 วินาที** ด้วยชุด Slot และภาพที่เลือกไว้ในรอบนั้น

• การเลื่อนหรือวนกลับมาที่ Slot เดิมต้องไม่ Shuffle Slot และไม่เปลี่ยนภาพ A/B ระหว่างรอบการแสดงผล

• เมื่อผู้ใช้ Refresh หน้า ระบบต้องประเมินข้อมูลและจัดชุดใหม่ ผลที่ได้อาจเหมือนชุดก่อนหน้าได้

• เมื่อผู้ใช้เปลี่ยนภาษา ระบบต้องประเมินภาพที่ใช้ได้ของทุก Slot ตามภาษาล่าสุดอีกครั้ง และไม่ให้ผลจากภาษาก่อนหน้าทับผลล่าสุด

• การเปลี่ยนภาษาต้องไม่ดึงภาพจากเฉพาะ Slot ที่กำลังแสดง เพราะ Slot ที่เคยถูกตัดอาจมีภาพในภาษาใหม่; จังหวะและวิธีคงลำดับ Shuffle ระหว่างเปลี่ยนภาษาให้ยึดกฎที่ยืนยันสำหรับ Banner

**9. Requirement สำหรับส่งต่อทีมพัฒนา**

ระบบต้องดึง Banner ที่ผ่านเงื่อนไขเดิมจากทุกจังหวัด และตัด Banner ประเภท “น่าอยู่” ก่อนจัดชุด สำหรับ Banner Slot แต่ละรายการ ให้ตรวจภาพที่มีไฟล์ใช้ได้บนอุปกรณ์ปัจจุบัน โดยเลือกภาษาที่ผู้ใช้ใช้งานก่อน หากไม่มีให้ใช้ภาพภาษาไทยของ Slot เดียวกัน หากไม่มีทั้งสองภาษาให้ตัด Slot ก่อน Shuffle ห้ามใช้ภาพจีนแทนอังกฤษหรืออังกฤษแทนจีน และห้ามผสมภาพต่างภาษาเพื่อเติม A/B

นำ Slot ที่ผ่านเงื่อนไขมา Shuffle โดย **หนึ่ง Slot ต้นทางเข้าชุดเพียงหนึ่งรายการ** ภาพ A/B และจำนวนภาษาไม่มีผลเพิ่มน้ำหนักหรือจำนวน Slot หลัง Slot ได้ตำแหน่ง ให้เลือกภาพ A หรือ B เพียงหนึ่งภาพในภาษาที่กำหนดไว้ และคงภาพนั้นตลอดการ Auto Slide/วนกลับในชุดเดิม ไม่ทำซ้ำภาพหรือ Slot เพื่อเติมช่อง การ Refresh จึงจัดชุดใหม่ได้

หนึ่งจุดวาง Banner แสดงสูงสุดสาม Slot ขนาด Desktop 2,544 × 636 px, Mobile 900 × 378 px, Auto Slide ทุก 4 วินาที, การจัดวางกรณีมีหนึ่งถึงสามภาพ, จำนวนจุดวางของแต่ละหน้า และการเปิดลิงก์ในแท็บใหม่ ให้คงตาม Banner เดิม ส่วนความจุข้อมูลหลายภาษา การจัดสรร Slot ข้ามจุดวาง และวิธีจัดชุดเมื่อเปลี่ยนภาษาโดยไม่ Refresh ต้องปิดข้อ 8 ก่อนกำหนดรายละเอียดให้ Dev
