**Route:** `/blogs/{จังหวัด}` เช่น `/blogs/khonkaen` และหน้าถัดไป `/blogs/{จังหวัด}/page/{N}` (กรองแท็กด้วย `?tag=`)

**ไฟล์หน้า:** `app/(interface)/(other)/blogs/[location]/page.tsx` และ `page/[page]/page.tsx` (ทั้งคู่ใช้ `blog-listing.tsx`)

**TrackingProvider:** `source_type: blog`

`/blogs/center` เป็นหน้ารวมบทความทั้งประเทศ ใช้ component คนละชุด ดูเอกสาร "หน้ารวมบทความ (ทั้งประเทศ)"

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
