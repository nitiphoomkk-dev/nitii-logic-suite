> ข้อมูลจากโค้ด FE ณ 2026-10-16 (repo `next-frontend-console-service` branch `develop` commit `9bbc0e5c`)

**Route:** ทุกหน้าใน Console (`app/(dashboard)/*` และ `/admins`)

**ไฟล์:** `components/providers/AppTrackingProvider.tsx`, `components/system/tracking/DeepLinkTracker.tsx`, `utils/tracker/*`

**TrackingProvider:** `AppTrackingProvider` ห่อทุกหน้า ใส่ `user_id`, `user_role`, `is_logged_in` จาก Redux ให้ทุก event ไม่มี pageMeta (`category`, `source_type` ว่าง) หน้าไหนต้องการต้องห่อ `TrackingProvider` ของตัวเองเพิ่ม

ทุก event ส่งไป `/api/track` (sendBeacon) → server ใส่ `context.ip` → ส่งต่อ `TRACKING_BACKEND_URL` ถ้าไม่ได้ตั้ง env นี้ event จะถูกทิ้ง

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก

| Component | Event | ประเภท | ยิงเมื่อ | section_name | หมายเหตุ |
|-----------|-------|--------|----------|--------------|----------|
| DeepLinkTracker | `campaign_link_entry` | \-     | เข้าหน้าจากลิงก์ที่มี link key ใน hash (`#lk_xxx` หรือ `#anchor~lk_xxx`) | \-           | ยิงครั้งเดียวต่อ session ต่อ link key, ลบ hash ออกจาก URL หลังยิง |

## ฟิลด์ที่ทุก event ได้อัตโนมัติ

| กลุ่ม | ฟิลด์ | ที่มา |
|-------|-------|-------|
| context | `trace_id` | สุ่มใหม่ต่อ path, ค่าเดิมตลอดใน tab เดียวกัน |
| context | `session_id`, `client_id` | cookie |
| context | `request_id` | สุ่มใหม่ทุก event |
| context | `referrer`, `ip` | `document.referrer`, `ip` ใส่ฝั่ง server |
| user  | `user_id`, `user_role`, `is_logged_in` | Redux `user` |
| page  | `source`, `canonical_url`, `page_title` | pathname, URL เต็ม, `document.title` |
| device | `device_type`, `os`, `os_version`, `browser`, `browser_version`, `screen_width`, `screen_height`, `language` | user agent / browser |
| utm   | `source`, `medium`, `campaign`, `term`, `content` | query `utm_*` |
| data  | `marketing.link_key`, `marketing.anchor_id` | campaign link ล่าสุด |
| route | \-    | pathname |

## กรณีที่ไม่ยิง event

* URL มี `?preview_from_bo=1` (BO เปิด preview ใน iframe) → ทิ้งทุก event
* ไม่ได้ตั้ง `TRACKING_BACKEND_URL` → `/api/track` ตอบ 204 แล้วทิ้ง
