\*\*EP-02 การเพิ่มวิดีโอรีวิว แสดงหน้า UI ดังต่อไปนี้ \*\*

 ![](/api/attachments.redirect?id=3a1e85f0-ca87-4c16-ba0a-833a68c8d845)

* **การเพิ่มหัวข้อรีวิว (require)**
  * จำกัดข้อความที่ 500 ตัวอักษร
    * ใส่ได้ทั้งทุกตัวอักษร อักขระ และตัวเลข
    * ถ้าใส่ชื่อวิดีโอีไว้ก่อนที่จะวาง link จะยังคงชื่อวิดีโอไว้ที่ user ตั้ง
    * ถ้าใส่ link โดยยังไม่ใส่ ชื่อหัวข้อรีวิว จะดึงชื่อวิดีโอมาใส่ที่หัวข้อให้ auto
* **แท็ก(require)**
  * โครงการใหม่
  * รับสร้างบ้าน
  * อสังหามือสอง
  * ไลฟ์สไตล์
  * เมื่อเลือก tag การเชื่อมต่อจึงจะปรากฎ section นี้ขึ้นมา
* **Link URL (ต้องใส่ link 3 ประเภทนี้เท่านั้น)**
  * Youtube
  * Tiktok (ถ้าอัพโหลดรูปใหม่ รูปที่แสดงจะแสดงตรง section รีวิวที่เป็นการ์ดแนวนอนเท่านั้นแต่ตรง section แนวตั้งวิดีโอจะดึง cover ของปกวิดีโอนั้นมาแสดง)
  * Short video (ถ้าอัพโหลดรูปใหม่ รูปที่แสดงจะแสดงตรง section รีวิวที่เป็นการ์ดแนวนอนเท่านั้นแต่ตรง section แนวตั้งวิดีโอจะดึง cover ของปกวิดีโอนั้นมาแสดง)
  * เมื่อวาง link url แล้วระบบจะต้องดึงรูปปก cover ของวิดีโอนั้นมาทันที และแสดงรูปนั้นที่กรอบตัวอย่างรูปภาพ
  * โดย user สามารถที่จะลบภาพปกที่ดึงมาเผื่ออัพภาพใหม่ได้ ถ้า user อยากได้ภาพปกวิดีโอเดิมหลังลบไปแล้ว ให้วาง link ใหม่

  * อัพได้ไม่เกิน 3 mb jpg jpeg png เท่านั้น
  * ขนาด 1920 \* 1080 px

  * **เชื่อมใบประกาศเชื่อมได้ทีละ 1 เท่านั้น depend on แหล่งที่มาของวิดีโอ เชื่อมได้เฉพาะของจังหวัดนั้นเท่านั้น**

\*\*การกดปุ่มเปลี่ยนหน้า จะเป็นดังต่อไปนี้ \*\*

* กดต่อไป เท่ากับไปทีละหน้า
* กดก่อนหน้า เท่ากับ กลับไปทีละหน้า
* กดเลข 2 ตัวเลขเพจจิเนทจะเปลี่ยนเป็น 2 3 4 เป็นต้น
* ถ้ามีแค่ 3 หน้า เลข 4 จะไม่ปรากฎ
