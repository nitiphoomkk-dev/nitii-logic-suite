> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/property-project/developers/{จังหวัด}` เช่น `/property-project/developers/khonkaen`, หน้า 2 ขึ้นไป `/property-project/developers/{จังหวัด}/page/{N}`

**ไฟล์หน้า:** `app/(interface)/(search)/search/[main_service]/developers/[location]/page.tsx` และ `.../developers/[location]/page/[page]/page.tsx` (ทั้งคู่ render ผ่าน `developers-listing.tsx` → `ProfileCompanySearchPage`)

**TrackingProvider:** `source_type: search`

`{main_service}` ใช้ได้ทั้ง 5 ค่า (`property-project`, `property-for-sale`, `rent`, `home-builder`, `home-design`) component และ tracking เหมือนกันทุกค่า (รายการแบรนด์โครงการชุดเดียวกัน, แคมเปญใช้ variant `developer` เสมอ) ลิงก์ในเว็บใช้ `property-project`

หน้า 2 ขึ้นไปใช้ component และ tracking ชุดเดียวกัน position นับใหม่จาก 1 ทุกหน้า (ไม่บวก offset ตามเลขหน้า)

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
