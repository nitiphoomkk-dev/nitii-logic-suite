**EP-01 การเพิ่มวิดีโอโปรโมทและโปรแคมเปญของใบประกาศแต่ละหมวด มี logic ดังต่อไปนี้**

1\. ปุ่มเพิ่มวิดีโอโปรโมทและโปรแคมเปญ จะเริ่มแสดงให้ input เมื่อเพิ่มใบประกาศเหล่านั้นเข้ารวมแคมเปญ user ฝั่ง console สามารถเข้ามา input ได้ เมื่อ แคมเปญนั้นสร้างสำเร็จ แต่โปรโมชั่นและวิดีโอจะแสดงเมื่อถึงช่วง pre event —> end เมื่อหมดแล้วจะไม่แสดง ทั้งการแสดงผลฝั่งหน้าบ้านและฝั่ง console (แสดงเฉพาะใบประกาศ/โปรไฟล์บริษัทที่เข้าร่วม)

3\. สร้าง= ยังไม่มีโปรโมชั่นหรือวิดีโอนั้น

**EP-07 เงื่อนไขด้านช่วงเวลาสำหรับ เปิดใหม่เฟดใหม่ ที่เข้าร่วมแคมเปญแล้ว ใบประกาศนั้นสิ้นสุดระยะเวลาการเป็นเปิดใหม่ เฟดใหม่ก่อนจบแคมเปญ แบ่งออกเป็น 2 กรณี**

**กรณี 1** ใบประกาศเปิดใหม่ เฟดใหม่นั้น transfer เป็นใบประกาศปรกติได้ก่อนครบ ระยะเวลาสิ้นสุด จะยังแสดงผลเป็นการ์ดใบประกาศปรกติในช่วง walk-in  และแสดงผลในช่วงของ walk-in แบบปรกติ

**กรณีที่ 2**  ใบประกาศเปิดใหม่ เฟดใหม่นั้น transfer เป็นใบประกาศปรกจติไม่ได้ก่อนครบ ระยะเวลาสิ้นสุด จะยังไม่แสดงผลเป็นการ์ดใบประกาศปรกติในช่วง walk-in  จนกว่า User จะทำการเผยแพร่ใบประกาศนั้นใหม่ เนื่องจาก หากข้อมูลไม่ครบใบประกาศนั้นจะคงสถานะแบบร่างที่หน้าจัดการใบประกาศปรกติในฝั่ง BO และ CS  เมื่อเผยแพร่สำเร็จจะกลับมาออนไลน์ใบประกาศนั้น และยังคงแสดงผลในช่วงของ walk-in นั้น

**เงื่อนไขสร้างคูปอง walk-in**

**เนื่องจากเปิดใหม่ เฟดใหม่ยังไม่มีการแสดงผลฝั่งหน้าบ้าน console ที่หน้าจัดการใบประกาศ จะสร้างคูปองได้จากฝั่งทาง Bo เท่านั้น**

* เมื่อ transfer ใบประกาศสำเร็จข้อมูลที่เคยใส่ไว้   backoffice จะไปแสดงผลที่หน้าจัดการใบประกาศ console และ backoffice ด้วย
* โดย cossole จะเห้นการสร้างคูปองที่ถูกทำไว้ทั้งหมด
