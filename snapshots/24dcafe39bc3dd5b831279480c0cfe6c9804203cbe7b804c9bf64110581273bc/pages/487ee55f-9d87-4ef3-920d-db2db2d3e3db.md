**EP-01.1 การรับลิงก์สำหรับสร้าง QR Code สำหรับรับสิทธิ์ Walk-in**

ลิงก์สำหรับสร้าง QR Code จะถูกจัดเตรียมจากระบบหลังบ้านของแอดมินน่าอยู่ โดยแอดมินสามารถเข้าไปที่หน้า **ใบประกาศที่เข้าร่วม** เลือกเมนู **"ลิงก์สร้าง QR Code"** เพื่อคัดลอกลิงก์สำหรับการรับสิทธิ์ Walk-in ของแต่ละใบประกาศ

หลังจากคัดลอกลิงก์แล้ว แอดมินจะดำเนินการส่งลิงก์ดังกล่าวให้กับโครงการผ่าน **LINE กลุ่มของโครงการ** เพื่อให้โครงการนำลิงก์ไปสร้าง QR Code และนำไปใช้สำหรับการรับสิทธิ์โปรโมชั่น Walk-in ภายในโครงการ

เงื่อนไข

* ลิงก์สำหรับสร้าง QR Code จะถูกสร้างจากฝั่งหลังบ้านของแอดมินน่าอยู่เท่านั้น
* โครงการจะไม่ได้สร้างลิงก์ด้วยตนเองผ่านระบบ
* QR Code ที่สร้างจากลิงก์ดังกล่าวจะเชื่อมโยงกับใบประกาศและโปรโมชั่น Walk-in ที่กำหนดไว้ในระบบโดยอัตโนมัติ
* โครงการสามารถนำ QR Code ไปติดตั้งหรือแสดงภายในพื้นที่โครงการ เพื่อให้ผู้ใช้งานสแกนสำหรับรับสิทธิ์โปรโมชั่น Walk-in

| **ที่ตั้ง** | แสดงได้สูงสุด **1 บรรทัด** | แสดงเป็นจังหวัด |

**การสร้าง QR Code**

* ผู้ใช้งานสามารถกดปุ่ม **"สร้าง QR Code"** เพื่อสร้าง QR Code สำหรับให้ลูกค้าใช้รับสิทธิ์โปรโมชัน Walk-in
* เมื่อกดปุ่ม ระบบจะดำเนินการดังนี้
  * สร้าง QR Code ที่อ้างอิงกับโครงการนั้นโดยเฉพาะ
  * กำหนดข้อมูลอ้างอิงของโครงการและสิทธิ์โปรโมชันที่เกี่ยวข้อง
  * แสดง QR Code ที่สามารถนำไปให้ลูกค้าสแกนเพื่อรับสิทธิ์ได้
* **เงื่อนไขการใช้งาน**
  * ลิงก์สร้าง QR Code เป็นลิงก์เฉพาะของแต่ละโครงการ ไม่สามารถใช้ข้ามโครงการได้
  * ผู้ที่มีลิงก์เท่านั้นจึงจะสามารถเข้าถึงหน้าสร้าง QR Code ได้
  * หากลิงก์หมดอายุ ถูกยกเลิก หรือไม่ถูกต้อง ระบบจะแสดงข้อความแจ้งเตือนว่าไม่สามารถสร้าง QR Code ได้
  * QR Code ที่สร้างขึ้นสามารถนำไปแสดงหน้าจุดขายหรือให้ลูกค้าสแกน ณ โครงการ เพื่อดำเนินการรับสิทธิ์โปรโมชัน Walk-in
  * หน้านี้สำหรับเจ้าหน้าที่หรือผู้ดูแลโครงการเท่านั้น ไม่รองรับการเข้าถึงจากผู้ใช้งานทั่วไป
  * การสร้าง QR Code ไม่ถือเป็นการรับสิทธิ์ของลูกค้า จนกว่าลูกค้าจะทำการสแกนและยืนยันรับสิทธิ์สำเร็จตามขั้นตอนของระบบต่อไป

**EP-03.3 แสดง QR Code สำหรับรับสิทธิ์ Walk-in**

เมื่อเจ้าหน้าที่โครงการกดปุ่ม "สร้าง QR Code" ระบบจะสร้าง QR Code สำหรับใช้รับสิทธิ์โปรโมชัน Walk-in และแสดงหน้าจอ QR Code พร้อมข้อมูลการใช้งาน ดังนี้

**การแสดงผล QR Code**

| **ข้อมูล** | **การแสดงผล** |
|--------|-----------|
| **QR Code** | แสดง QR Code สำหรับให้ลูกค้าสแกนรับสิทธิ์ |
| **ชื่อโครงการ** | แสดงชื่อโครงการสูงสุด 1 บรรทัด หากยาวเกินจะแสดงเป็น (...) |
| **ราคาเริ่มต้น** | แสดงในรูปแบบตัวเลขพร้อมหน่วย ล้าน ดึงข้อมูลจากราคาเริ่มต้นของใบประกาศนั้นๆ และแสดงผลตามนั้น |
| **ที่ตั้งโครงการ** | แสดงเป็นโซน ถ้าไม่อยู่ในโซนแสดงอำเภอ-ตำบล |
| **เวลาหมดอายุ** | แสดงเวลานับถอยหลังของ QR Code ระบบจะแสดงเวลานับถอยหลังแบบ Real-time เริ่มต้นที่ **10:00 นาที และจะนับถอยหลัง**<br>เมื่อครบกำหนด 10 นาที ระบบจะเปลี่ยนสถานะ QR Code เป็น**"หมดอายุ"** โดยอัตโนมัติ และไม่สามารถใช้รับสิทธิ์ได้ |

**เงื่อนไข**

* สามารถใช้งาน QR Code ได้เฉพาะในช่วงเวลาที่ QR Code ยังไม่หมดอายุ
* ลูกค้าที่สแกน QR Code หลังหมดอายุ จะไม่สามารถดำเนินการรับสิทธิ์ได้ และระบบจะแจ้งว่า QR Code หมดอายุ
* การกดปุ่ม **“ย้อนกลับ”** จะไม่ยกเลิก QR Code ที่ถูกสร้างไว้ หาก QR Code ยังไม่หมดอายุจะยังคงสามารถใช้งานได้
* หากต้องการใช้งานหลัง QR Code หมดอายุ เจ้าหน้าที่โครงการจะต้องกด สร้าง QR Code ใหม่ เพื่อรับ QR Code ชุดใหม่สำหรับให้ลูกค้าสแกนรับสิทธิ์ต่อไป และเริ่มนับเวลาหมดอายุใหม่

กรณีที่ QR Code ใกล้หมดอายุ โดยนับเวลาถอยหลังถึง 1 นาทีสุดท้าย จะแสดงแจ้งเตือนดังต่อไปนี้

หมดเวลาแล้วจะแสดง 00.00 และเมื่อ user สแกนลิ้งค์นั้นจะไม่สามารถเข้าถึงได้

**การกรอกหมายเลขโทรศัพท์**

เงื่อนไขการกรอก

* ผู้ใช้งานสามารถกรอกหมายเลขโทรศัพท์มือถือได้เฉพาะตัวเลข 0-9
* รองรับหมายเลขโทรศัพท์ความยาว 10 หลัก เท่านั้น
* กรอกข้อมูลไม่ถูกต้อง ข้อมูลฟีลต้องขึ้นสีแดงที่ช่องกรอกนั้น แสดงดังต่อไปนี้
  * ระบุเบอร์โทรศัพท์:-ข้อมูลไม่ถูกต้อง
* **ไม่กรอกข้อมูลแล้วกดยืนยัน ต้องขึ้นฟีลกรอบสีแดง และข้อความแจ้งเตือน “กรุณากรอกข้อมูล” ในช่องที่กรอกผิดและไม่กรอกข้อมูล**
* ดักเบอร์โทรแปลกได้  เอาแค่เบอร์ที่ เป็น 06 08 09 ที่ไม่ดักที่เหลือดักหมด

**EP-04.2 การตรวจสอบสิทธิ์รับโปรโมชั่น**

เมื่อผู้ใช้งานกดยืนยัน ระบบจะตรวจสอบสิทธิ์จาก **หมายเลขโทรศัพท์เพียงอย่างเดียว** โดยไม่พิจารณาจากชื่อ-นามสกุลหรือสถานะการล็อกอิน

เงื่อนไขการตรวจสอบ

* หากหมายเลขโทรศัพท์ดังกล่าว **ยังไม่เคยรับสิทธิ์โปรโมชั่นนี้**
  * ระบบจะบันทึกข้อมูลการ Walk-in
  * ระบบอนุญาตให้รับสิทธิ์โปรโมชั่นได้ แสดงต่อไปนี้

 ![](/api/attachments.redirect?id=6d512f87-c3ca-493d-9181-1eb780e8e836)

* หากหมายเลขโทรศัพท์ดังกล่าว **เคยรับสิทธิ์โปรโมชั่นนี้แล้ว**
  * ระบบจะไม่อนุญาตให้รับสิทธิ์ซ้ำ
  * ระบบจะแสดงข้อความ “หมายเลขโทรศัพท์นี้ได้รับสิทธิ์โปรโมชั่นแล้ว”
  * แสดงต่อไปนี้

 ![](/api/attachments.redirect?id=a4212efe-a94d-429c-9714-a28b937acb61)

เงื่อนไข

* การตรวจสอบสิทธิ์จะอ้างอิงจาก หมายเลขโทรศัพท์ เท่านั้น
* กรณีผู้ใช้งานกรอก ชื่อ-นามสกุลแตกต่างกัน แต่ใช้หมายเลขโทรศัพท์เดียวกัน ระบบจะถือเป็น ผู้ใช้งานรายเดียวกัน
* สถานะการล็อกอินหรือไม่ล็อกอิน ไม่มีผลต่อการตรวจสอบสิทธิ์รับโปรโมชั่น Walk-in
* หมายเลขโทรศัพท์ 1 หมายเลข สามารถรับสิทธิ์โปรโมชั่นเดียวกันได้เพียง 1 ครั้ง ตามเงื่อนไขของแต่ละโครงการเท่านั้น

**เงื่อนไขการส่ง SMS**

เมื่อผู้ใช้งานรับสิทธิ์สำเร็จ ระบบจะดำเนินการดังนี้

* บันทึกข้อมูลการรับสิทธิ์โปรโมชั่น (Walk-in)
* เปลี่ยนสถานะคูปองเป็น "ได้รับแล้ว"
* ส่ง SMS ยืนยันการรับสิทธิ์ไปยังหมายเลขโทรศัพท์ที่ผู้ใช้งานระบุ
* SMS จะถูกส่งเพียง 1 ครั้งต่อการรับสิทธิ์ 1 รายการ

**EP-05 การเข้าถึงหน้า "โปรโมชั่น Walk-in ของฉัน" ผ่าน SMS**
