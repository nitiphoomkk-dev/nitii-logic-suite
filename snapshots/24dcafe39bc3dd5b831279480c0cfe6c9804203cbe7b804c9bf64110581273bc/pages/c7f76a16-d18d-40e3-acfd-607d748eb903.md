> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/mortgage-calculator/{จังหวัด}` เช่น `/mortgage-calculator/khonkaen` และหน้าถัดไปของรายการโครงการ `/mortgage-calculator/{จังหวัด}/page/{N}`

**ไฟล์หน้า:** `app/(interface)/(other)/mortgage-calculator/[location]/page.tsx` และ `page/[page]/page.tsx` (ทั้งคู่ใช้ `mortgage-calculator-route.tsx`)

**TrackingProvider:** `source_type: loan`

`/mortgage-calculator/center` และ `/mortgage-calculator/thailand` เป็น 404 (ยังไม่มีหน้าส่วนกลาง)

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
