> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/blogs/{จังหวัด}/{slug}` เช่น `/blogs/khonkaen/{slug}` (จังหวัดรวม `center`)

**ไฟล์หน้า:** `app/(interface)/(other)/blogs/[location]/[slug]/page.tsx`

**TrackingProvider:** `source_type: blog`, `source_id` = `id` บทความ, และ `entity_id` = `api_id` บทความ เป็นค่าเริ่มต้น (event ที่ไม่ได้ส่ง entity_id เอง เช่น `page_view`, `all_post`, click ของ `breadcrumb` จะได้ค่านี้)

บทความแบ่ง 2 กลุ่ม ทำให้ส่วนล่างต่างกัน: กลุ่ม B = หมวด `material`, `design` หรือรีวิวบริษัทรับสร้างบ้าน, กลุ่ม A = ที่เหลือ

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
