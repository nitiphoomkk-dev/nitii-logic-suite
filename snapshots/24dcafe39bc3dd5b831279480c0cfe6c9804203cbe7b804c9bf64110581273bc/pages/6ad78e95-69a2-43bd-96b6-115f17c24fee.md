> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/home-builder/company-detail/{บริษัท}/{จังหวัด}` เช่น `/home-builder/company-detail/{ชื่อบริษัท}-{id}/khonkaen`

**ไฟล์หน้า:** `app/(interface)/(post-and-profile)/detail/home-builder/company-detail/[brand_id]/[location]/page.tsx`

**TrackingProvider:** `source_type: builder`, `source_id` = company_home_builder_id และตั้ง `entity_id` = company_home_builder_id เป็นค่าเริ่มต้นของทุก event ที่ไม่ได้ใส่ entity_id เอง

* `/thailand` = หน้าหลักบริษัท, จังหวัดอื่น = หน้าสาขา ต่างกันตามวงเล็บในตารางสรุป
* บริษัท premium ไม่มี #23 และถ้าปิดโฆษณา (`blockAds`) จะไม่มี #24–#26, ถ้าปิด Line / Facebook ปุ่มนั้นใน #3 และ #4 จะไม่แสดง
* แคมเปญ: แสดง #6 เมื่อบริษัทร่วมแคมเปญและมีเนื้อหา ถ้าไม่มีจะแสดง #7 (hero) หรือ #12 (Walk-in) แทน และ #8 ซ่อนเมื่อมี #6 (ยกเว้นช่วงก่อนเริ่มงาน)
* Pop-up โฆษณาไม่แสดงเมื่อหน้ามีแคมเปญหรือโปร Walk-in (`AdPopupGate`)
* `/page/{N}` = หน้าถัดไปของรายการแบบบ้าน (#22) tracking เหมือนหน้าหลัก ต่างแค่ position ของการ์ดนับต่อจากหน้าก่อน
* `/portfolio` (และ `/portfolio/page/{N}`) = หน้าผลงานทั้งหมด ⚠️ ไม่มี TrackingProvider และ PageViewTracker ของหน้า จึงไม่มี `page_view` และทุก event ในหน้าไม่มี `source_type` / `source_id`. แสดง #1 (มีลำดับที่ 3 "ผลงานทั้งหมด", action_id 2 = ลิงก์โปรไฟล์บริษัท), #2, #3, #4, รายการผลงาน (ไม่มี tracking) และ #27. ⚠️ #3 ซ่อนปุ่มแชร์แต่ยังยิง impression `share`, ⚠️ ปุ่มแชร์ผลงานทั้งหมดไม่ยิง event

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
