ปุ่ม Filter ในการกรองข้อมูลมีทั้งหมด 4 ประเภท ประกอบไปด้วย โครงการ/บทความ, การลงทะเบียน, ประเมินลูกค้า และการติดตาม หากไม่กดตัวกรองทั้ง 4 ประเภท ข้อมูลจะขึ้นข้อมูลล่าสุดของผู้ลงทะเบียนเข้ามาทั้งหมด ตัวเลขทั้งหมดอัปเดตอัตโนมัติตาม Filter ที่เลือก ไม่ใช่ตัวเลขคงที่ หากยังไม่กด Filter ใด รายการแสดงข้อมูลทั้งหมดเรียงตามวันที่ล่าสุด

 ![](/api/attachments.redirect?id=98194f44-f7a3-4cc0-a2fe-083f309ad203)  ![](/api/attachments.redirect?id=199edb75-6471-418f-b429-d9d0dc364d32)

#### **ระบบจะแสดง Dropdown รายชื่อโครงการและบทความที่มีในระบบ โดยมีรายละเอียดดังนี้**

**กรณีเปิด Dropdown**

* ตัวเลือกแรกสุดคือ "ทั้งหมด" ซึ่งเป็นค่า Default ที่ถูกเลือกไว้อยู่แล้ว
* แสดง 5 ตัวเลือกหลักก่อน ได้แก่
  * ทั้งหมด
  * โครงการ ทั้งหมด
  * โครงการ (ระบุเอง) → เมื่อเลือกตัวนี้จะขยายแสดง Search Box และรายชื่อโครงการให้เลือก
  * ทรัพย์ทั้งหมด →
  * ทรัพย์ (ระบุเอง) → เมื่อเลือกจะขยายแสดง Search Box และรายชื่อทรัพย์ให้เลือก
  * บทความทั้งหมด
* ผู้ใช้สามารถเลือกได้มากกว่า 1 ตัวเลือกพร้อมกัน (Multi-select) โดยตัวที่เลือกจะแสดงเครื่องหมายถูกและพื้นหลังเป็นสีฟ้า
* หากเลือก "ทั้งหมด" จะเป็นการยกเลิกตัวเลือกอื่นทั้งหมดและกลับสู่ค่า Default
* ด้านล่าง Dropdown มีปุ่ม 2 ปุ่มคือ
  * "ล้างข้อมูล" → ยกเลิกตัวเลือกทั้งหมด กลับเป็น "ทั้งหมด"
  * "ค้นหา" → ยืนยันการเลือกและกรองข้อมูลในตารางทันที
* ข้อมูลในตาราง จะยังไม่ถูกกรองจนกว่าจะกดปุ่ม "ค้นหา"

**เมื่อเลือก "โครงการ (ระบุเอง)"**

* มี Search Box พิมพ์ค้นหาชื่อโครงการได้
* แสดงรายชื่อโครงการตามจังหวัดที่เลือกไว้ (ถ้ามี)
* เลือกได้ 1 โครงการต่อครั้ง (Single-select)

**เมื่อเลือก "ทรัพย์ (ระบุเอง)"**

* มี Search Box พิมพ์ค้นหาชื่อโครงการได้
* แสดงรายชื่อทรัพย์ตามจังหวัดที่เลือกไว้ (ถ้ามี)
* เลือกได้ 1 โครงการต่อครั้ง (Single-select)

**กรณีเลือกแล้ว**

* แสดงชื่อโครงการหรือบทความบนปุ่ม
* ถ้าเลือกหลายรายการ แสดงจำนวน เช่น "3 รายการ"
* กรองตารางเฉพาะ Lead ของโครงการ/บทความนั้น
* กด "ล้างข้อมูล" → กลับ Default
* กด "ค้นหา" → ตารางอัปเดตทันที

ค่าเริ่มต้นจะติ๊กถูกทั้งหมด หากต้องการเลือกเพียงอย่างใดอย่างหนึ่ง ให้กดที่ทั้งหมดซ้ำ แล้วเลือกตัวเลือกที่ต้องการกรอง หรือติ๊กออกให้เป็นวงกลมเปล่าทีละอันได้

### **Edge Cases ที่ต้องจัดการ**

| **กรณี** | **การจัดการ** |
|------|-----------|
| ไม่มีข้อมูลในตาราง | แสดงสถานะว่าง "ไม่พบรายชื่อผู้สนใจ" |
| ค้นหาแล้วไม่พบ | แสดง "ไม่พบรายชื่อที่ค้นหา" พร้อมปุ่ม "ล้างการค้นหา" |
| ข้อผิดพลาดเครือข่าย | แสดง Toast แจ้งเตือน "เกิดข้อผิดพลาด กรุณาลองใหม่" |
| กด "บันทึก" สำเร็จ | แสดง Popup สีเขียว ✔ พร้อมข้อความยืนยัน แล้วปิดอัตโนมัติ |
| Note เกิน 200 ตัวอักษร | ไม่สามารถพิมพ์เพิ่มได้ แสดง Counter สีแดง |
| กด "ยกเลิก" ใน Popup | ปิด Popup ทันที ไม่บันทึกการเปลี่ยนแปลงใด ๆ |
| ราคาต่ำสุด > ราคาสูงสุด | แสดงข้อผิดพลาด "ราคาต่ำสุดต้องเผชิญราคาสูงสุด" บันทึกบันทึก Disabled |
