> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/map-events`

**ไฟล์หน้า:** `app/(interface)/(other)/map-events/page.tsx`

**TrackingProvider:** ไม่มีของหน้า (มีแค่ของ layout ที่ใส่ข้อมูล user) event ในหน้านี้จึงไม่มี `source_type` / `category`

หมุดและการ์ดมาจากข้อมูลคงที่ในโค้ด (`MAP_EVENT_PROJECTS` ใน `map-events-data.ts`, ขอนแก่น 6 รายการ id 8801–8806) ไม่ได้ดึงจาก API

`MapEventsSection` ตัวเดียวกันใช้ในหน้าแคมเปญ event-online ซึ่งยิง `campaign_map_*` ผ่าน callback แต่หน้านี้ไม่ได้ส่ง callback จึงไม่ยิง

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก

## 3. MapEventProjectCard

การ์ดแสดงด้านซ้ายแผนที่ (desktop) หรือ bottom sheet (mobile) หลังกดหมุด

| Component | Event | ประเภท | ยิงเมื่อ | section_name | section_number | หมายเหตุ |
|-----------|-------|--------|----------|--------------|----------------|----------|
| PostTileCard | `post_new_project` (โครงการใหม่ / มือสอง / เช่า), `post_style` (รับสร้างบ้าน) | impression, click | การ์ดเข้าจอ / กดการ์ด | `posts_first_section` | 1              | position = 1, action_id = `1`, entity_id = id ในข้อมูลคงที่, impression ยิงใหม่ทุกครั้งที่เลือกหมุด |

ชื่อ event มาจากข้อมูลคงที่ตอนนี้ (ทุกรายการ `is_new` = true, ไม่มี top ad)
