> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/register-interest/{จังหวัด}` เช่น `/register-interest/khonkaen`

**ไฟล์หน้า:** `app/(interface)/register-interest/[location]/page.tsx`

**TrackingProvider:** `source: register_interest`, `source_type: campaign`, `source_id` = id แคมเปญ, `province` = slug จังหวัด, `province_id`

ค่าที่ติดไปกับทุก event ในหน้า (actionMeta): entity_id = `deal_id` (ไม่มีดีล = ว่าง), extra_data = query `from`, `campaign_id`, `deal_type`, `deal_id` ที่มีใน URL

`source_id` มาจาก `?campaign_id=` → แคมเปญของ landing ที่ส่งมา (referrer) → แคมเปญที่เปิดในหน้า search ของจังหวัดตามหมวด

เข้าจากการ์ดดีล (`deal_type` + `deal_id`) → ฟอร์มแสดงการ์ดดีล ส่งแล้วไปข้อ 4 เลย, ไม่มีดีล → ส่งแล้วไปข้อ 2 → 3 → 4

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก

| Component | Event | ประเภท | ยิงเมื่อ | section_name | หมายเหตุ |
|-----------|-------|--------|----------|--------------|----------|
| PageViewTracker | `page_view` | view   | เปิดหน้า / เปลี่ยน path | `page_section` | 1 ครั้งต่อหน้า, มี entity_id / extra_data จาก actionMeta |

⚠️ `source_id` เลือกหมวดจาก `?category=` อย่างเดียว (ไม่มี = project) แต่ฟอร์มเลือกจาก `?category=` → `?from=` → referrer ถ้าไม่มี `category` และหมวดจริงเป็นมือสอง `source_id` กับ `campaign_id` ในฟอร์มอาจเป็นคนละแคมเปญ

## 1. CentralRegisterInterestForm

| Event | ประเภท | ยิงเมื่อ | section_name | section_number | หมายเหตุ |
|-------|--------|----------|--------------|----------------|----------|
| `campaign_registration_form` | impression | ฟอร์มเข้าจอ | `register_interest_lead_section` | 1              | ยิงซ้ำได้ทุกครั้งที่กลับเข้าจอ |
| `campaign_registration_start` | click  | เริ่มพิมพ์ชื่อ / เบอร์ หรือกด checkbox ครั้งแรก | `register_interest_lead_section` | 1              | 1 ครั้งต่อฟอร์ม, extra_data: `form_id` = `register_interest_lead_form` |
| `campaign_registration_consent` | click  | กด checkbox ยอมรับเงื่อนไข | `register_interest_lead_section` | 1              | extra_data: `consent` (true / false) |
| `campaign_registration_submit` | click  | กด "รับสิทธิพิเศษ" | `register_interest_lead_section` | 1              | ยิงก่อนตรวจฟอร์ม, extra_data: `form_id` |
| `campaign_registration_success` | view   | ส่งสำเร็จ (API ส่ง registration id กลับ) | `register_interest_lead_section` | 1              | extra_data: `result_status`, `registration_id` |
| `campaign_registration_error` | view   | ส่งไม่ผ่าน | `register_interest_lead_section` | 1              | extra_data: `error_code` = `validation_error` (+ `failed_field_name`), `turnstile_required`, `missing_interest_context` (ไม่มีแคมเปญ), `http_{status}`, `network_error` |

ทุก event ในตารางนี้: entity_id = `deal_id` (ไม่มีดีล = ว่าง), extra_data มี `campaign_id` (เมื่อมีแคมเปญ) และ query จาก URL
