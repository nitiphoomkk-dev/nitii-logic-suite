**Route:** `/{จังหวัด}/enroll/{slug}` เช่น `/khonkaen/enroll/{slug}`

**ไฟล์หน้า:** `app/(interface)/[location]/enroll/[slug]/page.tsx`

**TrackingProvider:** ไม่มีของหน้า (มีแค่ของ layout ที่ใส่ข้อมูล user)

หัวข้อ รูป และช่องในฟอร์มมาจาก API ตาม `slug` (ช่องอีเมล, LINE, โซน, ประเภททรัพย์, ช่วงราคา แสดงตามที่หน้าตั้งค่าไว้) ไม่มีหน้า → 404

`enroll_form_section` ในฟอร์มส่งไปกับข้อมูลลงทะเบียน (lead attribution) เท่านั้น ไม่ใช่ tracking event

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
