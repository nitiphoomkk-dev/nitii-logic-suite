  * ถ้าเลขเป็น <3.5 จะแสดงเป็นดาว 3 ในแนว column
  * ดึงตัวเลขใบประกาศขาย และเช่า ในจังหวัดที่ user อยู่มาแสดง ตัวเลขดึงเฉพาะใบประกาศที่ออนไลน์อยู่ฟีลเตอร์ตัวเลขตามจังหวัด

  * 4.00 - 4.49 -> แสดง 4.0 ดาว

  * **การแสดงผลแสดง ดังต่อไปนี้  ทั้ง PC และ mobile**
    * 1-999 ใบ แสดงตามตัวเลขจริง
    * > =1000ใบ-9999ใบ แสดงตามตัวเลขจริง

**Trigger**  เมื่อ  User กดปุ่ม **เพิ่ม** ให้มี Pop up ขึ้นมาทันที รูปแบบการ

เป็นตัวเลือกแบบ Calendar ให้เลือกวันที่เริ่มต้น→วันที่สิ้นสุด ตามลำดับ หลังเลือกระบบจะต้องคำนวณระยะเวลาทั้งหมดและแสดง จำนวนวันทั้งหมด พร้อมกับวันที่เริ่มต้น-วันที่สิ้นสุด ในรูปแบบ DD/MM/YYYY ทั้งคู่

```
- ตัวเลือกแบบ Calendar **ไม่สามารถเลือกวันที่ในอดีตได้**
- การแสดง Calendar จะแสดงเดือนสองเดือนคู่กันเสมอ
- กดไปทางซ้าย ← จะแสดง เดือนที่ n\-1, และเดือน n <u>Ex</u>\. กันยายน และ ตุลาคม 
- กดไปทางขวา → จะแสดงเป็น เดือนที่ n และเดือน n\+1 <u>Ex</u>\. ตุลาคม ไป พฤศจิกายน
- กดคลิกเลือกวันครั้งแรกจะเป็นวันที่เลือกเลยทันทีในรูปแบบ DD/MM/YYYY และเมื่อคลิกครั้งที่ 2 จะกำหนดเป็น วันที่สิ้นสุดทันที 
- เมื่อครบเดือนธันวาคม ให้เริ่มปีค\.ศ\.ใหม่ 
- สามารถเลือกซ้ำได้กับที่มีอยู่
```
