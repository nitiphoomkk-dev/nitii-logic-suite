* **ดันเมื่อ สักครู่** (ภายใน 5 นาที)----> ดันเมื่อ 6-59 นาทีที่แล้ว—> ดันเมื่อ1..2..3…23ชั่วโมงที่แล้ว—>ครบ24ชม =ดันเมื่อ1 วันที่แล้ว จะนับเป็นวัน จนกว่าจะ ครบ 1 เดือน ถ้าครบ 1 เดือนจะแสดงเป็น ดันเมื่อ dd/mm/year(คศ.) ของวันที่ดันล่าสุด เมื่อครบจะหายไปเมื่ออัพเดทไปประกาศ
* **อัปเดตเมื่อสักครู่**(ภายใน 5 นาที)---->**อัปเดต** 6-59 นาทีที่แล้ว—>**อัปเดต** 1..2..3…23ชั่วโมงที่แล้ว— ครบ24ชม =**อัปเดต** 1 วันที่แล้ว จะนับเป็นวัน จนกว่าจะ ครบ 1 เดือน ถ้าครบ 1 เดือนจะแสดงเป็น **อัปเดต** เมื่อ  dd/mm/year(คศ.) จะหายไปเมื่อเกิดการดันใบประกาศ
  * \*\*\***อัปเดต**ใบประกาศโปรไฟล์เท่ากับการแก้ไขข้อมูลโปรไฟล์หรือใบประกาศของบริษัทนั้นนั้นทั้งหมด นับเป็นอัพเดท  (แก้ไขใบประกาศ สร้างใบประกาศ ลบใบประกาศ เปิดขาย ปิดขาย ออนไลน์ ออฟไลน์ และการแก้ไขข้อมูลโปรไฟล์ทุกอย่าง)
  * **สำหรับการ์ด top ads** เมื่อซื้อ top ads คำจะถูก fix ไว้ที่อัพเดท จะนับเวลาที่ขึ้น top asd เป็น อัพเดทตาม logic อัพเดท และจะนับเวลาใหม่ การแก้ไขข้อมูลโปรไฟล์หรือใบประกาศของบริษัทนั้นนั้นทั้งหมด นับเป็นอัพเดท

**Logic การแสดงผล**

* ดึงชื่อโปรไฟล์นนายหน้าในช่องกรอกภาษาไทยมาแสดง ถ้าเปลี่ยนภาษาเป็นอังกฤษแล้วจึงดึงชื่ออังกฤษมาแสดง
* แสดงโล่สีฟ้าข้างชื่อและแสดงแท็กบ้านพร้อม
* ตัวเลข 4.8 หมายถึง นับการรีวิวทั้งหมดที่เกิดจาก ผลรวมของเลขรีวิว/5 user มาคำนวณหาให้ได้ตัวเลข โดยคะแนนสูงสุดเท่ากับ 5
  * ถ้าเลขเป็น >=3.5 จะแสดงเป็นดาว 3.5 ในแนว column และ ถ้ามากว่า3.5 แต่อยู่ในน 4จะแสดงเป็นดาว 3.5 ดาว ใช้กับทุกช่วงเรชที่เกิดขึ้น
  * ถ้าเลขเป็น <3.5 จะแสดงเป็นดาว 3 ในแนว column
  * ดึงตัวเลขใบประกาศขาย และเช่า ในจังหวัดที่ user อยู่มาแสดง ตัวเลขดึงเฉพาะใบประกาศที่ออนไลน์อยู่ฟีลเตอร์ตัวเลขตามจังหวัด
  * 0.00 - 0.49 -> แสดง 0 ดาว
  * 0.50 - 0.99 -> แสดง 0.5 ดาว

  * 3.00 - 3.49 -> แสดง 3.0 ดาว
  * 3.50 - 3.99 -> แสดง 3.5 ดาว
  * 4.00 - 4.49 -> แสดง 4.0 ดาว
  * 4.50 - 4.99 -> แสดง 4.5 ดาว
  * 5.00 =แสดง 5 ดาว
