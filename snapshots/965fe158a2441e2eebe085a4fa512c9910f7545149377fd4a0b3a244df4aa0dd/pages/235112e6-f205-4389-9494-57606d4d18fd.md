## section_number

* ค่า default ของ component = 19 (`positionTracking?: number` ใน `SpecialPropertySection` และ `SpecialPropertySearchSection`) หน้ารายละเอียดทั้งสองหน้าไม่ได้ส่งค่า จึงใช้ 19
* หน้าค้นหาเช่า / มือสอง ส่ง `positionTracking={4}` เพราะ 4 ไม่ซ้ำกับ section อื่นในหน้าค้นหา (หน้าค้นหาใช้ 1–3, 5–10, 12, 23)
* 19 ไม่ซ้ำกับ section อื่นในหน้ารายละเอียด (หน้ารายละเอียดใช้ 1–4, 8, 10, 13–18, 23) และไม่ใช้ 4 บนหน้ารายละเอียด เพราะซ้ำกับ NayooReview, Contact, ContactBar
* ทั้ง 4 และ 19 ไม่ได้มาจาก spec ทีม analytics ถ้า spec กำหนดเลขอื่น ให้เปลี่ยนตาม

## extra_data.placement

ใช้กับ event `all_special_property` เท่านั้น (การ์ด `special_property` ไม่มี) ปุ่ม "ดูทั้งหมด" มี 2 จุดใน section เดียว ทั้งสองไปที่ URL เดียวกัน (หน้าโปรไฟล์เอเจนท์) และยิง event เดียวกัน ค่า `placement` จึงเป็นตัวเดียวที่แยกว่ากดจุดไหน

| ค่า | จุดที่กด | ตำแหน่งบนหน้า |
|-----|----------|---------------|
| `header` | ลิงก์ "ดูทั้งหมด" | มุมขวาของแถบหัว section ข้างชื่อ "ทรัพย์เด็ดคัดพิเศษ" |
| `card` | การ์ด "ดูทรัพย์เด็ดคัดพิเศษ ทั้งหมด" | ท้ายแถวการ์ด (แสดงเมื่อการ์ดไม่เต็มแถว หรือหน้าสุดท้ายของ desktop ที่การ์ดไม่เต็มหน้า) |

* ฟิลด์อื่นของ payload (`action_id` = 0, `destination`, `section_name`, `section_number`) เหมือนกันทั้งสองจุด
* อยู่ใน `action.extra_data` เป็น object `{ "placement": "header" }` หรือ `{ "placement": "card" }`
* ไม่ได้มาจาก spec ทีม analytics เป็นมิติที่ FE เพิ่มเอง ถ้าไม่ต้องการแยกจุด ตัดออกได้โดยไม่กระทบ event อื่น
* ไม่ยิงเลย (ทั้งสองค่า) เมื่อจังหวัดไม่มีโปรไฟล์เอเจนท์ เพราะปุ่มกดไม่ได้

## หมายเหตุ

* จังหวัดที่ยังไม่มีโปรไฟล์เอเจนท์ ปุ่ม "ดูทั้งหมด" และการ์ดท้ายแถวกดไม่ได้ จึงไม่ยิง event
* การ์ดที่อยู่หน้าถัดไปของ desktop (เลื่อนด้วยลูกศร) ไม่ยิง impression จนกว่าจะเลื่อนมาถึง
* การ์ดท้ายแถวไม่ยิง impression ลูกศรเลื่อนไม่มี event
* ไม่มีรูปแบบ `_ad` เพราะการ์ดไม่มี flag โฆษณา
