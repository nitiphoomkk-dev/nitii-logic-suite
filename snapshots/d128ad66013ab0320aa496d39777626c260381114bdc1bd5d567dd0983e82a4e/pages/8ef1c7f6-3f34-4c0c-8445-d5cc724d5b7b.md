**Solution Pop-up จังหวัด — แบบที่1 รวมน้ำหนัก A/B ทุกภาษา**

ฉบับ1.0 · 4 พฤศจิกายน2569 · ผู้จัดทำ: นิติ๊ · สถานะ: Solution ตามคำตัดสินผู้ใช้ สำหรับ Dev/Tester · ตัวเลขเป็นข้อมูลสมมติ ไม่ใช่ผลทดสอบระบบจริง

**เป้าหมาย:** รวมClickและImpressionของไทย จีน อังกฤษ และการใช้งานDesktop/Mobileก่อนคำนวณ เพื่อใช้น้ำหนักA/Bเพียงชุดเดียวต่อSource Slot ทุกภาษาใช้โอกาสร่วมกัน แต่ยังดูCTRแยกภาษาได้

คำสั่งล่าสุดให้ใช้ **แบบที่1** จากภาพเปรียบเทียบ แทนวิธีแยกน้ำหนักรายภาษาใน [Solution Pop-up จังหวัดฉบับอ้างอิง](https://wiki.infonayoo.co/doc/solution-pop-up-3-ab-ctr-shuffle-slot-OIULEZeCv3) ส่วนภาษา ไทยสำรอง ภาพร่วมอุปกรณ์ คิวไม่จำกัด เปิดทีละหนึ่ง เวลาและSessionคงเดิม

**ปรับปรุง 6 พฤศจิกายน 2569: ใช้กฎจัดคิวตาม Pop-up Center เฉพาะเหตุการณ์เปลี่ยนหน้า เปลี่ยนภาษา และเปิดแท็บใหม่ — เปลี่ยนหน้าคงคิวไม่ Shuffle; เปลี่ยนภาษา Shuffle ใหม่โดยไม่ล้างประวัติของแท็บเดิม; แท็บใหม่แยกประวัติและคิว คงกฎจังหวัด สูตรน้ำหนักแบบที่ 1 และกฎภาพ/ภาษาเดิมทั้งหมด**

**หนึ่งSource = หนึ่งน้ำหนักร่วม A/B** ไม่ใช่หนึ่งน้ำหนักทั้งProduct ไม่รวมข้ามSource จังหวัด หรือProductอื่น

**คำตัดสินล่าสุด 10 พฤศจิกายน 2569: การเปลี่ยนหน้าผลลัพธ์ในแท็บเดิมไม่เปิด Pop-up และไม่ Shuffle แม้มีรายการรอ ส่วนการเปิดเว็บไซต์ในแท็บใหม่ให้ตรวจเวลาและสิทธิ์ จัดคิวและประวัติแยกจากแท็บเดิม แล้วเปิดครั้งละหนึ่งรายการเมื่อผ่านเงื่อนไข กฎนี้แทนข้อความเดิมที่ให้เปิดรายการถัดไปเมื่อเปลี่ยนหน้า โดยไม่เปลี่ยนสูตรน้ำหนักและกฎภาษา**

## EP-01 ขอบเขตและเงื่อนไขการแสดงผล

**หลักการทำงาน:** ดึง Pop-up ของจังหวัดปัจจุบัน รวมหมวดน่าอยู่ → ตรวจสถานะ ระยะเวลา สิทธิ์ และไทยบังคับ → Shuffle Slot ต้นทางทั้งหมดโดยไม่ตัดจำนวน → เลือกภาษาหลักหรือไทยสำรองและเลือกA/Bหนึ่งภาพด้วยน้ำหนักร่วมของแต่ละSlot → เก็บเป็นคิว → เมื่อหน้า เวลา ความถี่ และ Session อนุญาต จึงเปิดรายการถัดไปที่ยังมีสิทธิ์ครั้งละหนึ่ง Pop-up

| รหัส | หัวข้อ | เงื่อนไข / การกระทำ | Logic การแสดงผล / การทำงาน |
|------|--------|---------------------|----------------------------|
| PP1-01 | จังหวัด | ผู้ใช้อยู่จังหวัดขอนแก่น | ดึงเฉพาะ Pop-up ที่มีสิทธิ์ของขอนแก่น ไม่ดึงจังหวัดอื่นมาเติม |
| PP1-02 | หมวด   | โครงการใหม่ รับสร้างบ้าน น่าอยู่ หรือหมวดอื่นผ่านเงื่อนไข | รวมใน Candidate จังหวัดเดียวกัน หมวดน่าอยู่ไม่ถูกตัดด้วยกฎ Center |
| PP1-03 | เงื่อนไขต้นทาง | สถานะ ช่วงเวลา สิทธิ์ของรายการและภาพ A/B | ตรวจเงื่อนไขเดิมก่อนเลือก และตรวจอีกครั้งก่อนเปิดจริง |
| PP1-04 | ไม่จำกัด Slot | มี Candidate S รายการ | ใช้ทั้งหมด M=S ไม่ตัดเหลือ 8, 3 หรือ K รายการ และไม่กำหนดจำนวนตายตัวใหม่ |
| PP1-05 | หน่วยนับ | รายการเดียวมีหลายภาษาและ A/B | นับ Source Slot เดียว เข้า Shuffle หนึ่งครั้ง ไม่แตกเป็นหลายรายการ |
| PP1-06 | การเปิดจริง | มีคิวแล้ว แต่กฎเปิดยังไม่อนุญาต | ยังไม่เปิด ไม่ถือว่าผู้ใช้เห็น และไม่บันทึก Impression เพียงเพราะอยู่ในคิว |
| PP1-07 | จำนวนหน้าต่าง | กฎอนุญาตเปิดรายการถัดไป | เปิดครั้งละหนึ่ง Pop-up ไม่เปิดหลายรายการซ้อนหรือพร้อมกัน |
| PP1-08 | ขอบเขต Product | มี Pop-up โฆษณาและ Pop-up โปร Walk-in/แคมเปญ | Solution นี้เป็น Product โฆษณา โปร Walk-in/โปรจองยังใช้ flow ของตน ไม่ถูกนำมาต่อท้ายคิวนี้อัตโนมัติ |

**ไม่จำกัด Slot หมายถึงคิวมีได้ตามจำนวนรายการที่ผ่านเงื่อนไขจริง** ผู้ใช้อาจเห็นไม่ครบทั้งหมด เพราะยังต้องผ่านหน้า เวลา และสิทธิ์การเปิด ไม่ใช่สัญญาว่าจะเปิดทุกตัวในการเข้าหน้าครั้งเดียว

## EP-03 การเลือกภาษาและไทยสำรอง

**ภาษาที่ผู้ใช้เลือก → หากไม่มีภาพใช้ได้ ให้ใช้ไทยของ Source เดิม** ไม่ใช้จีนแทนอังกฤษหรืออังกฤษแทนจีน และไม่ผสมภาษาเพื่อทำให้มี A/B ครบ

### 5.2 Gate ของหน้า Walk-in / แคมเปญ / พรีเมี่ยม

คง [EP-change จังหวัด](https://wiki.infonayoo.co/doc/ep-change-ab2LaeyD3b) และ [Pop-up พรีเมี่ยม](https://wiki.infonayoo.co/doc/pop-up-vEZRjm9Dqo) เฉพาะหน้าที่ตารางต้นทางกำหนด ไม่ขยายเป็นการห้ามโฆษณาทุกหน้าทั้งเว็บ

| เงื่อนไขในหน้าที่ต้นทางระบุ | Pop-up โฆษณา | Flow ที่คงแยกต่างหาก |
|-----------------------------|--------------|----------------------|
| เข้าร่วม Walk-in            | ไม่เปิดโฆษณาในหน้าโครงการปกติ/เฟดใหม่/เปิดใหม่ หน้าแบบบ้าน และโปรไฟล์บริษัทรับสร้างบ้านตามตาราง | โปร Walk-in ใช้กฎของตน |
| เข้าร่วมแคมเปญ              | ไม่เปิดโฆษณาในหน้าโครงการ แบบบ้าน มือสอง/เช่า และโปรไฟล์บริษัทรับสร้างบ้านตาม EP-change | โปรจองในช่วงแคมเปญตามกฎเดิม |
| เข้าร่วม Walk-in และแคมเปญ  | ไม่เปิดโฆษณาในหน้าที่กำหนด | คงลำดับเงื่อนไขโปรตามต้นทาง ไม่รวมเป็นหลายโฆษณาซ้อน |
| พรีเมี่ยมที่เข้าร่วมแคมเปญหรือ Walk-in | ไม่เปิดโฆษณาตามตารางพรีเมี่ยม | คงโปรที่มีสิทธิ์ ไม่เพิ่มกฎห้ามโฆษณาทุกหน้าจากคำว่าพรีเมี่ยมอย่างเดียว |
| ไม่มีเงื่อนไขห้ามและยังมีสิทธิ์เปิด | พิจารณาคิว Pop-up จังหวัดตามปกติ | ยังต้องผ่านเวลา/Session |

ตัวเลข **4 วินาทีในต้นทางเป็นของ Pop-up โปร Walk-in** ไม่ใช่เวลาสลับ Pop-up โฆษณา ไม่ใช้แทนเวลารอของจังหวัด และหน้าตัวอย่าง Center ที่เป็นข้อยกเว้นไม่ใช่กฎขยายให้จังหวัด

กำหนดLเป็นไทย จีน อังกฤษ แต่ละภาษาใช้ยอดหลังresetของตน เหตุการณ์จากทั้งสองอุปกรณ์อยู่ในภาษานั้น ไม่มีคู่ภาษา–อุปกรณ์ที่คงinputเก่าไว้เมื่อแก้ภาพ

```text
CLICK_A_TOTAL = SUM(CLICK_A[TH], CLICK_A[ZH], CLICK_A[EN])
IMP_A_TOTAL   = SUM(IMP_A[TH], IMP_A[ZH], IMP_A[EN])
CLICK_B_TOTAL = SUM(CLICK_B[TH], CLICK_B[ZH], CLICK_B[EN])
IMP_B_TOTAL   = SUM(IMP_B[TH], IMP_B[ZH], IMP_B[EN])

CTR_A_TOTAL = CLICK_A_TOTAL / IMP_A_TOTAL × 100
CTR_B_TOTAL = CLICK_B_TOTAL / IMP_B_TOTAL × 100

RAW_A = CTR_A_TOTAL / (CTR_A_TOTAL + CTR_B_TOTAL) × 100
P_A = MAX(30, MIN(70, RAW_A))
P_B = 100 - P_A
```

ใช้สูตรเมื่อIMPรวมทั้งAและBมากกว่า0 และCTR_A_TOTAL+CTR_B_TOTALมากกว่า0 มิฉะนั้นใช้50:50ทั้งSource ใช้ความละเอียดจริงก่อนย่อทศนิยมแสดงผล

| CTRรวมA | CTRรวมB | ดิบA:B | น้ำหนักร่วม |
|---------|---------|--------|-------------|
| 3%      | 2%      | 60:40  | 60:40       |
| 9%      | 1%      | 90:10  | 70:30       |
| 1%      | 9%      | 10:90  | 30:70       |
| 2%      | 2%      | 50:50  | 50:50       |
| 0%แต่มีIMPรวม | 2%      | 0:100  | 30:70       |
| 2%      | 0%แต่มีIMPรวม | 100:0  | 70:30       |
| 0%      | 0%      | หารศูนย์ไม่ได้ | 50:50       |
| IMPรวมฝั่งใด0 | —       | ข้อมูลรวมยังไม่ครบ | 50:50       |

ตัวอย่างจำกัดช่วง: ดิบA90 → MIN(70,90)=70 → MAX(30,70)=70; ดิบA10 → MIN(70,10)=10 → MAX(30,10)=30; ดิบA60ใช้60ตามจริง

น้ำหนักเป็นโอกาส ไม่ใช่โควตา7ต่อ3ในทุก10ครั้ง ไม่กำหนดให้Aชนะเสมอ ไม่เพิ่มIMPขั้นต่ำหรือเกณฑ์นัยสำคัญทางสถิติที่ยังไม่ได้ตัดสิน

## EP-11 จำลองรวมสามภาษาแล้วใช้หนึ่งน้ำหนัก

### 11.2 คำนวณน้ำหนักร่วม

| ขั้นตอน | ผล  |
|---------|-----|

| น้ำหนักร่วมแสดงในตัวอย่าง | **A61.11:B38.89** |

ใช้ค่าจริงคำนวณ ไม่ปัดCTRเป็น3.67/2.33ก่อน และไม่เฉลี่ยเปอร์เซ็นต์รายภาษา

## EP-12 เปลี่ยนภาพ — resetเฉพาะภาษา แต่น้ำหนักร่วมทั้งSource

ใช้SourceSXตามEP-11 สมมติแก้ภาพจีนAไฟล์ร่วมDesktop/Mobile

### 12.1 สิ่งที่เกิดทันที

| รายการ | ก่อนแก้ | หลังแก้สำเร็จ |
|--------|---------|---------------|
| inputจีนA | 10Click/1,000IMP | เริ่มใหม่0/0  |
| inputจีนB | 50Click/1,000IMP | เริ่มใหม่0/0ด้วย แม้ไม่แก้B |
| inputไทย | A400/10,000 B200/10,000 | คงเดิม        |
| inputอังกฤษ | A30/1,000 B30/1,000 | คงเดิม        |
| weightร่วมSource | 61\.11:38.89 | **50:50ทุกภาษา**ถึงรอบรายวันถัดไปเมื่อมีA/B |
| Performance/รุ่นภาพเดิม | สะสมก่อนแก้ | เก็บประวัติ ไม่ล้าง |
| SourceหรือProductอื่น | ข้อมูลของตน | คงเดิม        |
| ภาพPop-upที่เปิด | ภาพที่เลือก | ไม่สลับA/Bอัตโนมัติเพราะresetweight |

Pop-upมีinput3ภาษา ไม่ใช่6คู่device จึงไม่มีจีนDesktopเก่าเหลือไว้รวม การคงinputไทย/อังกฤษไม่ได้แปลว่าคงweightแยกสองภาษา เพราะทุกภาษาใช้weightร่วมชุดเดียว

### 12.2 รอบรายวันถัดไป — จีนไม่มีข้อมูลใหม่

| inputหลังresetล่าสุดของแต่ละภาษา | A Click/IMP | B Click/IMP |
|----------------------------------|-------------|-------------|
| ไทยเดิม                          | 400/10,000  | 200/10,000  |
| อังกฤษเดิม                       | 30/1,000    | 30/1,000    |
| จีนใหม่ยังว่าง                   | 0/0         | 0/0         |
| รวมใช้คำนวณ                      | 430/11,000  | 230/11,000  |

CTRรวมA=3.909091%, CTRรวมB=2.090909% → น้ำหนักร่วม **65.15:34.85** โดยประมาณ ใช้ทุกภาษาเมื่อมีA/B

ไม่คง50:50เพียงเพราะจีนว่าง เพราะยอดรวมSourceคำนวณได้ ไม่รอครบ3ภาษา ผลนี้ใช้เมื่อถึงรอบรายวัน ไม่ใช่ทันทีหลังแก้ภาพ

### 12.3 มีข้อมูลจีนใหม่ก่อนรอบรายวัน

| inputสะสมหลังresetล่าสุด | A Click/IMP | B Click/IMP |
|--------------------------|-------------|-------------|
| ไทย                      | 400/10,000  | 200/10,000  |
| อังกฤษ                   | 30/1,000    | 30/1,000    |
| จีนใหม่                  | 12/200      | 2/200       |
| รวมคำนวณ                 | 442/11,200  | 232/11,200  |

| ขั้นตอน | ผล  |
|---------|-----|
| CTRรวมA | 442÷11,200×100 = 3.946429% |
| CTRรวมB | 232÷11,200×100 = 2.071429% |
| น้ำหนักดิบA | ประมาณ65.578635% |
| หลังจำกัดช่วง | **65.58:34.42** ทุกภาษาใช้ร่วม |

CTRเฉพาะจีนหลังresetเป็น6%กับ1%ยังดูรายงานได้ แต่ไม่ใช้ผล70:30ของจีนเฉพาะภาษาเป็นweightในแบบที่1

### 12.4 Performanceไม่ใช่inputหลังreset

Performanceรวมก่อนแก้ยังอยู่ และมีข้อมูลใหม่ข้างต้น จะได้A452/12,200 กับB282/12,200 หากเอามาแทนinputใหม่จะได้61.58:38.42 ซึ่งไม่ใช่65.58:34.42ที่ต้องใช้

| เหตุการณ์ | ผล  |
|-----------|-----|
| แก้จีนอีกครั้งก่อนdaily | เริ่มinputจีนA/Bใหม่อีกครั้ง และweightร่วม50:50ถึงdailyถัดไป |
| แก้ไทยและจีนพร้อมกัน | Resetสองภาษา เก็บอังกฤษ ตั้งweightร่วม50:50 |
| แก้ครบ3ภาษา | inputSourceเริ่มใหม่ทั้งหมด ใช้50:50จนยอดรวมคำนวณได้ตามรอบ |
| Refresh/เปลี่ยนภาษาเว็บไซต์ | ไม่ใช่แก้ไฟล์ ไม่resetinput ไม่คำนวณทันที |
| ผ่าน00:00ไม่มีแก้ภาพ | ใช้สะสมตั้งแต่resetแต่ละภาษา ไม่ล้างinputทุกวัน |

| **PP1-AC47** | **SX มีข้อมูลคำนวณและ Performance อยู่แล้ว** | **เปิดแท็บใหม่ เปลี่ยนภาษา หรือเปลี่ยนหน้าโดยไม่แก้สื่อ** | **ไม่ reset input หรือ Performance ไม่คำนวณน้ำหนักทันที ทุกแท็บใช้กฎน้ำหนักรวมล่าสุดของ Source ตาม EP-10–12 เดิม เหตุการณ์จริงเก็บตามเกณฑ์เดิม** |

### **EP-13.1 AC เพิ่มเติม — การกดเปลี่ยนหน้าผลลัพธ์**

**การเปลี่ยนหน้าผลลัพธ์ในจังหวัดและแท็บเดิมใช้คิวเดิมตาม PP1-O08 และ EP-06 ไม่เรียก Shuffle ใหม่ แม้กลับหน้าที่เคยเปิด การ Refresh และการเปลี่ยนภาษาในแท็บเดิมไม่ล้างประวัติ ส่วนการเปิดแท็บใหม่แยกประวัติและคิวของตนตาม EP-06 การจัดคิวและประวัติไม่เปลี่ยนสูตรน้ำหนักหรือกฎภาษาเดิมของจังหวัด**

| **AC ID** | **เงื่อนไข / การกระทำ** | **ผลลัพธ์ที่ต้องได้** |
|-------|---------------------|-------------------|
| **PP1-PG01** | **หน้า 1 → 2 → 3 → 4 → 5 → 4 → 3 → 2 → 1 ในจังหวัดและแท็บเดิม ขณะมีรายการรอและเงื่อนไขเปิดผ่าน** | **ไม่เปิด Pop-up จากการเปลี่ยนหน้าทั้งไปข้างหน้าและย้อนกลับ ไม่ Shuffle ไม่สุ่มภาพใหม่ คงคิวและประวัติเดิม** |
| **PP1-PG02** | **กดเปลี่ยนหน้า แต่หน้าปลายทางไม่อนุญาตหรือเวลารอ/ความถี่ยังไม่ผ่าน** | **ไม่เปิด Pop-up ไม่บันทึก seen หรือ Impression จากการเปลี่ยนหน้า/การเตรียมคิวล้วน ไม่ข้าม Gate และไม่ล้าง Session เพื่อให้เปิดได้** |
| **PP1-PG03** | **ทุก Source เคยเปิดแล้วในขอบเขตกันซ้ำเดิม แล้วเปลี่ยนหน้าหรือกลับหน้า 1** | **ไม่วนเปิด Source เดิม ไม่สร้างสิทธิ์จากอีกภาษา/อีกภาพ A/B และไม่ reset input หรือ Performance เพียงเพราะเปลี่ยนหน้า** |

**ตัวอย่างตามคำตัดสินล่าสุด: แท็บ A หน้า 1 เปิด S3 แล้วปิด → ไปหน้า 2 และหน้า 3 ไม่เปิด S1/S2 → เปิดเว็บไซต์ในแท็บ B ใหม่ ให้ B ตรวจและ Shuffle คิวของตน แล้วเปิดหนึ่งรายการเมื่อผ่านเวลาและสิทธิ์ของ B ผลสุ่มอาจเป็น S3 ซ้ำได้ ไม่ใช่การเปิด S1 ต่อจากแท็บ A**
