## วิธีอ่านตาราง

* ✅ **แปลแล้ว** — ข้อความทั้งหน้ามาจาก catalog `messages/th` / `messages/en`
* ⬜ **ยังไม่แปล** — ตัวหน้าเอง หรือ component / schema / constant ที่หน้านั้นใช้ ยังมีข้อความไทย hardcode
* — **ไม่มีข้อความ** — หน้า redirect หรือ `notFound()`
* Navbar, sidebar, avatar menu และ `components/ui` (ปุ่ม, modal, popup, …) **แปลแล้วในทุกหน้า** สถานะในตารางดูเฉพาะเนื้อหาของหน้า

* หน้าที่ตั้ง `title` / `description` (metadata) เอง ยังเป็นไทย hardcode ทุกหน้าที่เป็น ⬜ — นับรวมในสถานะแล้ว
