ใช้กับ section **ประกาศเช่าล่าสุด** บนหน้า Home รวมจังหวัด (Home Center, EP-06) เป็น public ไม่ต้องใช้ token ใช้แค่ apikey ตามปกติ **ไม่ต้องส่ง header** `**province**` เพราะดึงจากทุกจังหวัดเสมอ

```cs
GET /api/listing/home-page/thailand/rent-posts
```

shape เดียวกับ `/api/listing/home-page/rent-posts` (ของหน้า Home แยกจังหวัด) ใช้ component การ์ดเดิมได้เลย

## ตัวอย่าง response

```json
{
  "success": true,
  "message": "get thailand rent posts successfully",
  "data": {
    "rent_posts": [

        "id": 90369,
        "slug": "ให้เช่าบ้านเดี่ยว-...-90369",
        "project_name": { "th": "บ้านเดี่ยว ...", "en": "..." },
        "post_type": "secondhand",
        "listing_types": ["rent"],
        "is_new": false,
        "update": "อัพเดท 1 วันที่แล้ว",
        "...": "field อื่นเหมือนการ์ดหน้า Home แยกจังหวัด"
      }
    ]
  }
}
```

> ข้อมูลข้างบนเป็นตัวอย่าง ไม่ใช่ข้อมูลจริง

## Field

| Field | ความหมาย |
|-------|----------|
| `rent_posts` | การ์ดใบประกาศ สูงสุด **12 ใบ** เรียงมาให้แล้ว FE แสดงตามลำดับได้เลย (ซ้าย → ขวา) |
| `rent_posts[].is_new` | `true` = ติดป้าย NEW (ลงประกาศมาไม่เกิน 6 ชั่วโมง) |
| `rent_posts[].listing_types` | section นี้เป็น `["rent"]` เสมอ |

## วิธีเลือกและเรียงการ์ด

เหมือน section ประกาศขายอสังหาฯ มือสองล่าสุด


1. ใบประกาศที่ติด **NEW** มาก่อน
2. ถ้ายังไม่ครบ 12 ใบ เติมด้วยใบประกาศธรรมดา
3. ในแต่ละกลุ่ม เรียงจาก **ลงใหม่ / ดันล่าสุด** ก่อน (ดูเวลาที่ใหม่กว่าระหว่างวันลงกับวันดัน) กลุ่มธรรมดาไม่แทรกขึ้นก่อนกลุ่ม NEW

* แสดงเฉพาะใบประกาศมือสองที่ **ลงเช่า** ออนไลน์ ไม่หมดอายุ ไม่ใช่ฉบับร่าง และ **ไม่รวม NPA**
* ใบประกาศที่ลง **ทั้งขายและเช่า** ขึ้นได้ทั้ง section นี้ (เป็นการ์ดเช่า) และ section มือสอง (เป็นการ์ดขาย) ตามสเปก EP-06 จึงอาจเห็นใบเดียวกันทั้ง 2 section
* ถ้าไม่มีใบประกาศเลย `rent_posts` จะเป็น `[]` (ไม่เป็น `null`)
* ปุ่ม "ดูทั้งหมด" → หน้าค้นหาเช่า center (FE กำหนด URL เอง)
* ไม่มี cache ข้อมูลเป็นปัจจุบันทุกครั้งที่เรียก
