**EP-01 บทความน่าสนใจ (การปักหมุดบทความ ณ ที่ตรงนี้เทียบเท่ากับการปักหมุดน่า home จังหวัดที่ตำแหน่งการแสดงผล)**

* บทความที่น่าสนใจ
* ถ้ามีบทความที่ปักหมุด =5 slot (นับของจังหวัดนั้น) จะสลับกันขึ้นตำแหน่งที่ 1  แบบ random
* ปักหมุด 1-5 slot บทความที่ปักหมุดจะสลับกันแสดงที่ตำแหน่งที่ 1 แบบ random และบทความที่เหลือจะดึงมาจากอัพเดทล่าสุดและจะต่อท้ายของบทความที่ปักหมด
  * มีปักหมุด 1 บทความ -> บทความล่าสุดจะอยู่ตำแหน่งที่ 2,3,4,5
  * มีปักหมุด 2 บทความ -> บทความล่าสุดจะอยู่ตำแหน่งที่ 3,4,5
* ถ้าไม่มีปักหมุดเลย จะดึงจากอัพเดทล่าสุดทั้งหมดตาม(จาก 5อันล่าสุด )  slot ที่เหลือ เช่นเหลือ 5 ก็หยิบ5 อันล่าสุด และ random การแสดงผล
* ติดดาวได้ 1 slot ตำแหน่งใหญ่สุด ติดดาวเท่ากับล็อคตำแหน่ง
* แสดงเป็น dd/mm/year(คศ.)

**รายละเอียดบทความ แสดงบทความตาม tag ที่มี บทความจะมี 1 tag ยกเว้นรีวิว**

\*\*แสดงชื่อบทความ สูงสุด 2 บรรทัด พร้อมเนื้อหาบทความ 2 บรรทัดแรก \*\*

**BIO ผู้เขียน**

* รูป (ถ้าดึงได้)
* ชื่อผู้เขียน

**วันที่อัปเดต= วันที่สร้าง หลังจากนั้นถ้าแก้ไขก็นับเป็นอัพเดท**

**ภาพปก แสดงภาพปกบทความยกเว้นกรณีของรีวิว**

\*\* เข้าชม\*\*

```
- **ช่วง 0 \- 999:** ให้แสดงตัวเลขจริงทั้งหมด \(เช่น 123, 999\)
- **ช่วง 1,000 ขึ้นไป \(K\):** หารด้วย 1,000 และแสดงทศนิยม 1 ตำแหน่งเสมอ
- **ช่วง 1,000,000 ขึ้นไป \(M\):** หารด้วย 1,000,000 และแสดงทศนิยม 1 ตำแหน่งเสมอ
- **การปัดเศษ:** ห้ามปัดขึ้น \(Floor\) หรือตัดเศษทศนิยมทิ้งจนกว่าจะถึงตำแหน่งที่กำหนด **\(No rounding until 1 decimal place\)**
```

**EP-02 Filter เลือกอ่านบทความจากน่าอยู่**

* มีช่องค้นหา
  * ค้นหาชื่อบทความ
  * ช่องค้นหาจำกัด 200 ตัวอักษร
  * พิมพ์มากกว่า 1 ตัวอักษรแล้วค้นหาเลย
  * ถ้าผู้ใช้เลือก tag "สาระเรื่องบ้าน" แล้วพิมพ์ค้นหา "ผนัง" แสดงเฉพาะบทความที่ **เป็น tag สาระเรื่องบ้าน และ ชื่อมีคำว่าผนัง** เท่านั้น
    * search "ผนัง" + tag "บทความล่าสุด" → แสดงบทความทุก tag ที่มีคำว่าผนัง
    * แล้วกด switch ไป tag "สาระเรื่องบ้าน" → ไม่แสดงเฉพาะบทความ tag สาระเรื่องบ้าน **ที่มีคำว่าผนัง** (search text ยังอยู่ใน input box)
* มี tag ให้สามารถ กด filter ตาม หมวดหมู่ได้
  * **บทความล่าสุด, สาระเรื่องบ้าน, ไลฟ์สไตล์, อัปเดตข่าวสาร, รีวิว, Trend อสังหา, วัสดุและนวัตกรรมบ้าน, ไอเดียวแบบบ้านและฟังก์ชัน**

 ![](/api/attachments.redirect?id=c7e1ca20-3e01-4fc6-9331-721cb6a846ae)

* โดยจะ Default บทความล่าสุด
  * ดึงบทความทุก tag เรียงตามล่าสุด
* คลิกที่ tag อื่นๆ จะ filter บทความตามหมวดนั้นๆมา
  * เรียงตามล่าสุด การเปลี่ยนแท็บจะไม่เปลี่ยนบทความที่น่าสนใจด้านบน จะตามไปทุกหน้าที่เปลี่ยนฟีลเตอร์

**EP-03 การ์ดบทความ**

**ถ้าบทความนั้นล่าสุดและปักหมุดหรือติดดาว จะแสดงตำแหน่งทั้งหมดและล่าง**

**ถ้าบทความนั้นโดนดึงไปอัพเดทล่าสุด ก็จะยังคงแสดงล่าสุด ทั้งบนและล่าง**

* แสดง 24 slot ตาม tag ที่ filter ไว้
* Logic การดึงบทความ ดึงตามอัพเดทล่าสุด
* คลิกแล้วไปหน้ารายละเอียดบทความไปหน้ารายละเอียดบทความ
* มี banner 2 ตำแหน่ง แสดงแถวที่ 4, 8
  * ขนาดของ Banner มี 2 ขนาด ของ Desktop กับ Mobile มีขนาดต่างกัน
    * Desktop 848x212 px
    * Mobile 300x126 px
  * จำนวนกราฟิก
    * รองรับ สูงสุด 2 กราฟิก ต่อ 1 Banner Slot
    * แสดงผล ครั้งละ 1 กราฟิก
  * Logic การแสดง คำนวณตาม [Ranking Model](https://docs.google.com/document/d/1vkTt5j-xxEV60V2V-k0j--mNcPNaHZPwf1rSGHvtceM/edit?pli=1&tab=t.jpl10e71jymp)

 ![](/api/attachments.redirect?id=2ebf612f-e516-4e3e-819d-de39dc4ea36b)

  * มีรูปปก
    * ถ้าเป็น tag รีวิว และ บทความนั้นมีวิดีโอ รูปปกจะต้องดึงรูปปกจากวิดีโิอมา
    * ถ้าไม่มีวิดีโอ รูปปกจะดึงจากภาพปกบทความ
  * Logic การดึง จะดึงบทความที่มี tag รีวิวมาทั้งหมด ตามอัพเดทล่าสุด
