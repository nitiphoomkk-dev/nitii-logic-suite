> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/home-design/{สไตล์}-detail/{จังหวัด}/{slug}` เช่น `/home-design/modern-detail/khonkaen/{slug}`

**ไฟล์หน้า:** `app/(interface)/(post-and-profile)/detail/home-design/[style]/[location]/[uuid]/page.tsx`

**TrackingProvider:** `source_type: builder`, `source_id` = id ประกาศแบบบ้าน (post_id) และตั้ง `entity_id` = id ประกาศ เป็นค่าเริ่มต้นของทุก event ที่ไม่ได้ใส่ entity_id เอง. ⚠️ `source_type` เดียวกับหน้าโปรไฟล์บริษัทรับสร้างบ้าน แยกสองหน้าได้จาก route / source_id เท่านั้น

* ประกาศ premium ที่ปิดโฆษณา (`blockAds`) ไม่มี #12, #19, #23 และประกาศ premium ไม่มี #20, #22, ถ้าปิด Line / Facebook ปุ่มนั้นใน #18 และ #24 จะไม่แสดง
* แคมเปญ: #5 แสดงเมื่อบริษัทมีโปรแคมเปญหรือโปร Walk-in ถ้าไม่มีโปรแต่มีข้อมูลแคมเปญจะแสดง #6 แทน, #7 ซ่อนเมื่อแคมเปญมีโปรจองของตัวเองแล้ว (ยกเว้นช่วงก่อนเริ่มงาน)
* Pop-up โฆษณาไม่แสดงเมื่อหน้ามีแคมเปญหรือโปร Walk-in (`AdPopupGate`)
* เปิดจาก BO preview (`?preview_from_bo=1`) จะไม่มี #1, #5, #6, #20 และ event ทั้งหมดถูกตัดทิ้งไม่ส่ง

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
