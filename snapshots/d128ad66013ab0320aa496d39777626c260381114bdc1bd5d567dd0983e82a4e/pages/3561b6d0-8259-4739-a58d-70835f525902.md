> ข้อมูลจากโค้ด FE ณ 2026-10-16 (branch `develop` commit `4c73f5e`)

**Route:** `/property-for-sale/{ประเภท}-detail/{จังหวัด}/{id ประกาศ}` เช่น `/property-for-sale/house-detail/khonkaen/{id ประกาศ}` (ประกาศที่ขายและเช่าใช้ `/sale-or-rent/{ประเภท}-detail/...` ซึ่งเปิดหน้าเดียวกัน)

**ไฟล์หน้า:** `app/(interface)/(post-and-profile)/detail/property-for-sale/[property]/[location]/[uuid]/page.tsx`

**TrackingProvider:** `source_type: secondhand`, `source_id: {id ประกาศ}`, `entity_id: {id ประกาศ}` (event ที่ไม่ได้ส่ง entity_id เองจะได้ id ประกาศนี้)

บล็อกแคมเปญแสดงเฉพาะเมื่อจังหวัดนั้นมีแคมเปญที่เปิดอยู่ ขอนแก่น / อุบล / พิษณุโลก ไม่แสดงบล็อกแคมเปญด้านบน (#5, #6) แต่ยังมีบล็อกแคมเปญด้านล่าง (#22) เปิดจาก BO preview จะไม่ยิง event ใดเลย

## วิธีอ่านตาราง

* **impression** = การ์ดหรือบล็อกเข้ามาในจอ, **click** = กด, **view** = เปิด modal หรือหน้า
* **section_number** = ลำดับ section บนหน้า, **position** = ลำดับการ์ดใน section (เริ่มที่ 1)
* **entity_id** = id ของสิ่งที่ถูกดูหรือกด เช่น id ประกาศ, id แบนเนอร์
* ⚠️ = ค่าไม่ตรงกับ convention ของส่วนอื่น ควรเช็ก
