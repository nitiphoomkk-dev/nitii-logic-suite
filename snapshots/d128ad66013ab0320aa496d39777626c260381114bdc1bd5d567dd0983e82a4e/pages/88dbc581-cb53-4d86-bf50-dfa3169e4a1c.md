**Logic หน้าเพิ่มผู้ใช้คือ** 

1⁠. ต้องกรอกข้อมูล require ให้ถูกต้องครบถ้วน  

Require ประกอบด้วย

1\.เพศ ไม่มี default 

2\.ชื่อ

3\.นามสกุล

4\.เบอร์โทรศัพท์หลัก

5\.รหัสผ่าน มีปุ่มตาสามารถกดดูรหัสผ่านที่พิมพ์ไปได้

6\.ยืนยันรหัสผ่าน  มีปุ่มตาสามารถกดดูรหัสผ่านที่พิมพ์ไปได้

หากไม่ใส่ข้อมูลให้ครบถ้วนตาม require  เมื่อกดปุ่มบันทึกข้อมูล ระบบแสดงกรอบฟีลสีแดง และข้อความสื่อสาร กรุณาเติมข้อมูล

โดยเมื่อกรอกข้อมุลครบจะทำการบันทึกข้อมูล เท่ากับ มีบัญชีผู้ใช้งานทั่วไป

2⁠. ปุ่มรีเซ็ต

⁠ a⁠.   ถ้ากดปุ่มรีเซ็ต ข้อมุลที่ถูกกรอกจะหายไปจากระบบในขั้นตอนการกรอก

โดยปุ่มรีเซ็ตจะทำงานเฉพาะในหน้าการเพิ่มข้อมูลผู้ใช้งานเท่านั้น

3⁠. ปุ่มยกเลิก

⁠ a⁠. การกดปุ่มยกเลิกเท่ากับ ไม่ต้องการกรอกข้อมูลเพื่อสร้าง account นั้น

4⁠. ระบบต้องตรวจสอบ ชื่อ-นามสกุล ต้องรองรับภาษาไทย จีน อังกฤษ 

5⁠. เบอร์โทรศัพท์หลัก ต้องตรวจสอบตัวเลขให้ถูกต้อง ต้องมี10หลักและ logic แบบตัวเลขเบอร์โทรของประเทศไทย  หากกรอกตัวเลขไม่ครบระบบต้องแสดงฟีลกรอบสีแดง

พร้อมข้อความ กรุณากรอกเบอร์โทรศัพท์ให้ครบถ้วน

6⁠. สามารถเพิ่มรูปภาพโปรไฟล์ได้ รองรับไฟล์ประเภท

⁠ a⁠. คลิกเพื่ออัปโหลด หรือ ลากและวาง JPG, JPEG, PNG ขนาดไม่เกิน 3MB

7⁠. เบอร์โทรสำรองมี 2 ช่องกรอก

8⁠. ต้องสามารถตัวสอบ link facebook ตามที่ user นำ link มาวางไว้ได้ 

⁠ a⁠. หากไม่ถูกต้อง ให้แสดงฟีลกรอกสีแดง และขึ้นข้อความ กรุณาใส่ข้อมูลให้ถูกต้อง

**Logic หน้าแก้ไขข้อมูล**

1\. ข้อมูลRequire ประกอบด้วย

1\.เพศ ไม่มี default 

2\.ชื่อ

3\.นามสกุล

4\.เบอร์โทรศัพท์หลัก

5\.รหัสผ่าน มีปุ่มตาสามารถกดดูรหัสผ่านที่พิมพ์ไปได้ 

6\.ยืนยันรหัสผ่าน  มีปุ่มตาสามารถกดดูรหัสผ่านที่พิมพ์ไปได้

หากไม่ใส่ข้อมูลให้ครบถ้วนตาม require  เมื่อกดปุ่มบันทึกข้อมูล ระบบแสดงกรอบฟีลสีแดง และข้อความสื่อสาร กรุณาเติมข้อมูล

โดยเมื่อกรอกข้อมุลครบจะทำการบันทึกข้อมูล เท่ากับ มีบัญชีผู้ใช้งานทั่วไป

**2.สามารถแก้ไขข้อมูลได้ดังต่อไปนี้**

1⁠. เพศ สามารถแก้ไขได้

2⁠. อีเมลสามารถแก้ไขได้

3⁠. ชื่อสามารถแก้ไขได้

4⁠. นามสกุลแก้ไขได้

5⁠. กรณีเบอร์โทรหลัก 

⁠ a⁠. หากสมัครมาด้วยเบอร์จากฝั่งหลังบ้าน ช่องกรอกเบอร์โทรหลักจะ disable ไม่สามารถแก้ไขได้ ได้หาก

กรณีที่ 1 user นั้นได้ทำการ log-inเข้าเว็บน่าอยู่ และ verify ตัวตนเรียบร้อยแล้วช่องกรอกเบอร์โทรหลักจะ disable 

กรณีที่ 2 user นั้นยังไม่ได้ทำการlog-inเข้าเว็บน่าอยู่ สามารถแก้ไขเบอร์โทรหลักได้

⁠ b⁠. หากสมัครมาด้วยเบอร์โทรจากฝั่งหน้าบ้าน ช่องกรอกเบอร์โทรหลักจะ disable ไม่สามารถแก้ไขได้

6⁠. กรณีแก้ไขรหัสผ่านใหม่ สามารถพิมรหัสผ่านใหม่ในช่องรหัสผ่าน และช่องยืนยันรหัสผ่าน ตาม policy ที่ dev คิด 

7⁠. การแก้ไขจะสำเร็จเมื่อ กดปุ่มบันทึก จะถือว่า การแก้ไขข้อมูลนั้นสำเร็จ

**EP-05 การ export ข้อมูล** 

**เมื่อกดปุ่ม export  แสดง modal ดังต่อไปนี้**  

 ![](/api/attachments.redirect?id=c4cf9530-7559-47fd-ae77-81bf1801f133)

แสดงค่าเริ่มต้น เป็น ทั้งหมด disable ช่องเลือกวันที่เริ่มต้นและสิ้นสุด ไม่สามารถเลือกช่องเลขกำหนดวันในปฎิทินได้ 

⁠ user super admin,admin สามารถกดปุ่ม export ได้เลยเมื่อกดแล้วจะดาวน์โหลดอัตโนมัติ 

หากเลือกตามวันที่อัปเดต จะ default วันที่สิ้นสุดให้เป็นวันที่ปัจจุบัน ไม่สามารถเลือกเกินวันที่ปัจจุบันได้ จะ disable ปุ่มการเลือกวันที่เกินไว้  และ user กำหนดวันที่เริ่มต้นเอง

เงื่อนไข ถ้าไม่เลือกวันที่เริ่มต้นและสิ้นสุดจะไม่สามารถกดปุ่ม export ได้ disable ปุ่ม

**Export ข้อมูลเป็น.xlsx ชื่อไฟล์ตั้งตามหัวข้อฟีเจอร์นั้น พร้อมวันที่ดาวน์โหลด(DD/MM/YYYY)**
