ใช้กับ section บทความน่าสนใจบนหน้า Home รวมจังหวัด (Home Center, EP-09) logic ตาม wiki [บทความหน้าเสิร์ชและ home](/doc/home-OkZG8eRp8L) หัวข้อ EP-02 Solution (ต่างจาก wiki ตรงที่กลุ่มจังหวัดเอา 5 เรื่องล่าสุด **รวมทุกจังหวัด** ไม่ใช่จังหวัดละ 5 ตามที่ตกลงกับทีม) เป็น public ไม่ต้องใช้ token ใช้แค่ apikey ตามปกติ ไม่ต้องส่ง header `province`

```
GET /api/blog/interest/thailand
GET /api/blog/interest/thailand?tag=review
```

shape ของการ์ดเหมือน `/api/blog/interest/center` และ `/api/blog/interest/:province` ใช้ component เดิมได้ (`ArticlesInteresSection` / `ArticlesInteresClient`)

**สิ่งที่ FE ต้องเปลี่ยน:** หน้า Home รวมจังหวัดเปลี่ยนจาก `/api/blog/interest/center` เป็น `/api/blog/interest/thailand` เท่านั้น `/api/blog/interest/center` ยังใช้ logic เดิม (ปักหมุด/ติดดาว) สำหรับหน้ารายละเอียดบทความส่วนกลางและหน้าสินเชื่อ ไม่ต้องแก้ 2 หน้านี้

## Query

| Query | ความหมาย |
|-------|----------|
| `tag` | ไม่ส่ง = แท็บ "บทความแนะนำ" (ทุกหมวด) / ส่ง slug หมวดตามแท็บ: `saaraeruue-ngbaan`, `life-style`, `news-n-events-hotdeal-promotion`, `review`, `ethrnd-sanghaa`, `nwatkrrmbaan`, `aebbbaan` |

ส่ง `tag` ที่ไม่ใช่ 7 ค่านี้ (เช่น `recommended`) จะได้ error ให้ไม่ส่ง `tag` สำหรับแท็บบทความแนะนำ

## Field

| Field | ความหมาย |
|-------|----------|
| `id`  | Ghost post id |
| `slug` | slug ของบทความ |
| `title` | ชื่อบทความ |
| `feature_image` / `thumbnail_url` | รูปปก (ค่าเดียวกัน) |
| `excerpt` | คำโปรย   |
| `view_count` | จำนวนการเข้าชม |
| `tags` | แท็กของบทความ แท็กหมวดอยู่ตัวแรก (แท็บที่เลือก หรือหมวดแรกของบทความถ้าเป็นแท็บบทความแนะนำ) บทความจังหวัดมีแท็กจังหวัด 1 ตัว บทความส่วนกลางไม่มีแท็กจังหวัด (backend ตัดแท็ก `center` ออกให้แล้ว) |
| `featured` | flag featured จาก Ghost |
| `updated_at` / `updated_at_th` | วันที่อัปเดตล่าสุด (เวลาไทย) / แบบไทยสำหรับแสดงบนการ์ด |

ลำดับใน `data` = ลำดับการ์ด **ตัวแรก = การ์ดใหญ่** ตัวที่ 2–5 = การ์ดเล็ก

## วิธีเลือกการ์ด (ฝั่ง backend)


1. กรองหมวดตาม `tag` ก่อน (ไม่ส่ง = ทุกหมวด)
2. **กลุ่มจังหวัด:** บทความของทุกจังหวัดรวมกัน เรียงตามวันที่อัปเดต เอา 5 เรื่องล่าสุด (นับเฉพาะบทความที่ติดแท็กจังหวัดเดียว)
3. **กลุ่มส่วนกลาง:** บทความที่ติดแท็ก `center` และไม่มีแท็กจังหวัด เอา 5 เรื่องล่าสุด
4. รวม 2 กลุ่ม (สูงสุด 10 เรื่อง ไม่ซ้ำ id) สุ่มลำดับ แล้วเอา 5 เรื่องแรก
5. ไม่ใช้ปักหมุด/ติดดาว

## ข้อควรรู้

* **สุ่มใหม่ทุก request** ถ้า render ฝั่ง server แล้ว fetch ซ้ำฝั่ง client จะได้ชุดไม่ตรงกัน ให้ fetch ที่เดียว เปลี่ยนแท็บแล้ว fetch ใหม่ได้ตามปกติ
* ได้ **0–5 การ์ด** ถ้าหมวดนั้นมีบทความน้อยจะได้เท่าที่มี ถ้าไม่มีเลยได้ `data: []` ให้แสดง "ยังไม่มีบทความในหมวดนี้"
* รายการบทความจาก Ghost ถูก cache ฝั่ง backend สูงสุด 24 ชม. (เหมือนหน้าจังหวัด) บทความใหม่อาจใช้เวลาสักพักกว่าจะเข้ากลุ่มสุ่ม
* ถ้าดึงกลุ่มใดกลุ่มหนึ่งไม่ได้ backend จะส่งการ์ดจากอีกกลุ่มมาแทน error เฉพาะตอนดึงไม่ได้ทั้งสองกลุ่ม
* ปลายทาง backend: product-service `GET /system/blog/interest/thailand`
