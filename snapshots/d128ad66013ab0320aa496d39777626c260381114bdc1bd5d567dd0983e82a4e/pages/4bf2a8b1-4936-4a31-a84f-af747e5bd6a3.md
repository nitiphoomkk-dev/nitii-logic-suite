# **EP-1  หน้าจัดการเอกสารและการรับรอง**

**Condition:** หน้านี้แสดงรายการบริษัทรับสร้างบ้านทั้งหมด พร้อมสถานะเอกสารรับรองแต่ละประเภท (ISO / HBA / DBD) โดย Admin สามารถกรอง ค้นหา และเข้าจัดการเอกสารของแต่ละบริษัทได้

**Design:** การออกแบบเป็นไปตามการออกแบบใน Figma

**EP-1.1  Layout และโครงสร้างหน้า**

**Column การแสดงผล**

* ชื่อบริษัท ดึงภาษาไทย มาแสดง
* ไอดี ดึงไอดีบริษัท - ไอดีจังหวัด
* วันที่สร้าง บริษัท
* วันที่อัพเดทข้อมูลบริษัท

### **Default State เมื่อเปิดหน้า**

* แสดงรายการบริษัททั้งหมด (ไม่มีการกรอง)
* เรียงลำดับตาม: วันที่อัปเดตล่าสุด (ใหม่สุดขึ้นก่อน)
* แสดง 10 รายการต่อหน้า (Pagination)
* Header ตาราง: "รายการทั้งหมด (N)" — N = จำนวนรายการจริงหลังกรอง

### **Filter Bar (แถบกรองด้านบน)**

* \*\*ช่องค้นหา: \*\*ค้นหาตามชื่อบริษัท (real-time หรือ กด Enter)
* \*\*Dropdown "ประเภทเอกสาร"  \*\*ค่าเริ่มต้น = "ทั้งหมด" — กรองแสดงเฉพาะบริษัทที่มีเอกสารประเภทนั้น
* \*\*Dropdown "สถานะ": \*\*ค่าเริ่มต้น = "ทั้งหมด"
* ตัวเลือก: ทั้งหมด รออนุมัติ (Pending) / อนุมัติแล้ว / ปฏิเสธ

### **Logic การกรองข้อมูล (Filter)**

◦      Filter ทำงานแบบ AND — เลือกหลาย Filter พร้อมกันได้

◦      ค้นหาชื่อ + กรองประเภทเอกสาร + กรองสถานะ ทำงานพร้อมกัน

◦      เมื่อกรองแล้วไม่มีผลลัพธ์ ให้แสดงข้อความ "ไม่พบข้อมูล"

◦      Reset filter: เลือก "ทั้งหมด" ใน Dropdown ทั้งสองตัว + ล้างช่องค้นหา

### **ตารางรายการบริษัท**

แต่ละแถวแสดง:

◦      รูปภาพบริษัท / ชื่อบริษัท / ไอดี / วันที่สร้าง / วันที่อัปเดต

◦      ปุ่มสถานะเอกสาร 3 ปุ่ม: ISO | HBA | DBD

### **Logic สีปุ่มเอกสาร**

สีของแต่ละปุ่มสะท้อนสถานะเอกสารนั้น ๆ ดังนี้:

 ![](/api/attachments.redirect?id=7616fe9d-0861-4db2-8665-82e1e63d1fa3)  ![](/api/attachments.redirect?id=7616fe9d-0861-4db2-8665-82e1e63d1fa3)  ![](/api/attachments.redirect?id=7616fe9d-0861-4db2-8665-82e1e63d1fa3)  ![](/api/attachments.redirect?id=7616fe9d-0861-4db2-8665-82e1e63d1fa3)

| **สี** | **สถานะ** | **ความหมาย** |
|-----|-------|----------|
| 🟢 เขียว | อนุมัติแล้ว | **เอกสารถูกแนบ** และ Admin **อนุมัติแล้ว** |
| 🟠 ส้ม/เหลือง | รออนุมัติ (Pending) | **เอกสารถูกแนบแล้ว รอ Admin ตรวจสอบ** |
| 🔴 แดง | ปฏิเสธ | Admin ปฏิเสธเอกสาร — ต้องอัปโหลดใหม่ |
| เทา | ยังไม่มีเอกสาร | **ยังไม่มีการแนบไฟล์ใด ๆ** |

**Logic การนับสถานะ (Badge Count)**

แต่ละบริษัทมีเอกสาร 3 ประเภท แต่ละประเภทมีสถานะอิสระ กฎ:

◦      ปุ่มแต่ละปุ่มแสดงสถานะของเอกสารประเภทนั้นเท่านั้น

◦      ปุ่มที่คลิกได้ = ปุ่มที่ไม่ใช่สีเทา (มีไฟล์แนบ)

◦      ปุ่มสีเทา (ไม่มีไฟล์) = ไม่สามารถคลิกเข้าดูรายละเอียดได้

## **เงื่อนไขอื่นๆ**

* ปุ่มนำทาง = ก่อนหน้า / หน้าที่ (1,2,3...) / ต่อไป
* Reset หน้า เมื่อ Filter เปลี่ยน ให้ reset กลับหน้า 1 เสมอ

**EP-2  จัดการเอกสาร อนุมัติ / ปฏิเสธ**

เมื่อ Admin คลิกปุ่มเอกสารที่มีสี (ไม่ใช่สีเทา) ระบบจะเปิดหน้า/modal จัดการเอกสารนั้น Admin สามารถดูไฟล์ อนุมัติ หรือปฏิเสธเอกสารได้

\*\*เงื่อนไขการเข้าถึง \*\*ปุ่มเอกสารแต่ละปุ่ม (ISO / HBA / DBD) คลิกได้เฉพาะเมื่อมีสี (ไม่ใช่สีเทา)
