#  logic ใส่รูปหลายภาษา

**สรุป:** ตัวสลับภาษาคือปุ่มแคปซูลมีธง TH / EN / CN ไทยบังคับ อังกฤษและจีนไม่บังคับ ถ้าเว้นว่างจะใช้รูปไทยแทน สถานะบนปุ่มบอกว่าภาษาไหนครบหรือมีปัญหา ข้อนี้ใช้กับ 2 ช่อง คือ รูปปกโครงการ และ รูปภาพเพิ่มเติมของพื้นที่โฆษณาพิเศษ

### 1) หน้าตาของตัวสลับ

| สิ่งที่เห็น | ความหมาย |
|-------------|----------|
| ปุ่มสีฟ้าอ่อน | ภาษาที่กำลังแก้อยู่ |
| ปุ่มพื้นขาวมีเส้นขอบ | ภาษาอื่น กดเพื่อสลับ |
| เครื่องหมายถูกสีเขียวที่มุมปุ่ม | ภาษานั้นมีรูปครบ |
| จุดเตือนสีแดงที่มุมปุ่ม | ภาษานั้นมีปัญหา ต้องแก้ |
| ไม่มีเครื่องหมาย | ยังไม่มีรูป (และไม่ผิด ถ้าเป็นอังกฤษหรือจีน) |

ปกกับรูปเพิ่มเติมมีตัวสลับแยกกัน 2 ตัว ใต้ปุ่มของอังกฤษและจีนมีข้อความ "ถ้าไม่ใส่รูป ระบบจะใช้รูปภาษาไทยแทน" และไม่มี `*`

### 2) Logic หลัก


1. **เปิดหน้า:** เลือกภาษาไทยเสมอ ทั้งหน้าเพิ่มและหน้าแก้ไข ไม่จำภาษาที่ใช้ครั้งก่อน
2. **สลับภาษา:** รูปที่อัปโหลดแล้วไม่หาย ตัวนับ “(x/3 รูป)” แยกกันต่อภาษา
3. **ไทยบังคับ:** ต้องมีรูปอย่างน้อย 1 รูป ไม่มีแล้วกดบันทึกจะขึ้นจุดเตือนที่ปุ่ม TH และกรอบแดงที่ช่อง
4. **อังกฤษและจีนไม่บังคับ:** เว้นว่างไม่ถือว่า error จุดเตือนขึ้นเฉพาะรูปผิดเงื่อนไข เช่น ขนาดเกิน 3 MB หรือรูปแบบไฟล์ไม่ถูก
5. **เครื่องหมายถูก:** ขึ้นเมื่อภาษานั้นมีรูปและผ่านเงื่อนไขทั้งหมด

### 3) ตอนกดบันทึก


1. ตรวจทุกภาษาของทั้งสองช่อง
2. ถ้ามีปัญหา ระบบสลับไปภาษาที่ผิดตัวแรกของช่องที่อยู่บนสุดของหน้า แล้วเลื่อนไปที่ช่อง
3. แสดงข้อความสรุป เช่น "ภาษาไทย: ยังไม่ได้เพิ่มรูปปก"
4. ผู้ใช้แก้แล้ว จุดเตือนของภาษานั้นหายทันที ไม่ต้องรอกดบันทึกอีกรอบ
5. ถ้าผ่านทั้งหมด บันทึกและขึ้น popup "บันทึกข้อมูลสำเร็จ"

### 4) กรณีพิเศษ

* **พื้นที่โฆษณาถูกปิด** (บริษัทลูกธรรมดา): ตัวสลับยังแสดงและสลับดูได้ แต่แก้ไขไม่ได้ และไม่ตรวจเงื่อนไขจนกว่าจะกด "เปิดใช้งาน" พอเปิดแล้วกฎไทยบังคับเริ่มใช้
* **สวิตช์ "ใช้ข้อมูลกับบริษัทแม่" เปิดอยู่:** ทุกภาษาใช้รูปของบริษัทแม่ตามภาษาเดียวกัน แท็บอ่านอย่างเดียว ปิดสวิตช์แล้วจึงแก้ได้ ถ้าบริษัทแม่ไม่มีรูปอังกฤษ ใช้รูปไทยของบริษัทแม่แทน
* **ลบรูปไทยทั้งหมดตอนแก้ไข:** ไทยกลับมาเป็นบังคับ บันทึกไม่ได้จนกว่าจะใส่ใหม่ อังกฤษและจีนไม่กระทบ
* **ออกจากหน้าโดยไม่บันทึก:** ถ้ามีรูปใหม่ในภาษาใดก็ตาม ขึ้นป๊อปอัปยืนยันก่อน
* **การเข้าถึง:** ปุ่มมีข้อความ TH/EN/CN กำกับ ไม่พึ่งธงอย่างเดียว กดสลับด้วยปุ่มลูกศรได้ และมีกรอบโฟกัส

### 5) ที่ต้องยืนยันกับทีมหลังบ้าน (ผมสมมติไว้)

* เว็บฝั่งผู้ใช้แสดงรูปภาษาไทยแทนจริงเมื่อภาษาอื่นว่าง
* จำนวนสูงสุด 3 รูปต่อภาษาสำหรับปก และรูปภาพเพิ่มเติม 1 รูปต่อภาษา (ตามที่หน้าแสดงอยู่)
* ข้อมูลที่บันทึกต้องแยกตามภาษา ไม่ใช่รูปชุดเดียว
