* สามารถกดเวลาที่ set ค่าในการบวกวัน จากวันที่ปัจจุบัน โดยแบ่งออกเป็น 30 วัน, 60 วัน, 90 วัน
  * กรณีไม่กดเลือกวันที่เริ่มต้น ถ้ากด +30 +60 +90 จะบวกวันเริ่มต้นและวันที่สิ้นสุดจากวันที่ปัจจุบัน
  * กรณีเลือกวันที่เริ่มต้นแล้ว ถ้ากด +30 +60 +90 จะบวกไปจากวันที่เลือกไปถึงวันที่สิ้นสุด
  * สามารถเลือกวันที่ในอดีตได้
  * เงื่อนไขเวลาไม่มีผลต่อ สถานะนายหน้าโล่เขียวคอมมู เท่ากับว่าวันที่เริ่มต้นและสิ้นสุดจบลง สถานะโล่เขียวคอมมูยังคงอยู่
* **การแสดง Calendar จะแสดงเดือนสองเดือนคู่กันเสมอ**
* กดไปทางซ้าย ← จะแสดง เดือนที่ n-1, และเดือน n <u>Ex</u>. กันยายน และ ตุลาคม
* กดไปทางขวา → จะแสดงเป็น เดือนที่ n และเดือน n+1 <u>Ex</u>. ตุลาคม ไป พฤศจิกายน
* <u><strong>กรณีเลือก วันเดียว</strong></u> กดคลิกเลือก doble วันครั้งแรกที่เลือกเลยทันทีในรูปแบบ DD/MM/YYYY  คลิกวันที่ 19 เมษายน → Output ขึ้นช่องค้นหาวันที่สร้าง 19/09/2026
* ถ้ากดอีกครั้งที่ตรงกับวันที่เลือกครั้งแรกจะทำการยกเลิก **เลือกวันเดียวกันสองครั้งไม่ได้**
* **Calendar ไม่สามารถสร้างช่วงเวลา ได้มากกว่า 2 ช่วงเวลา**
* **แถบสีเขียวด้านล่างปฏิทิน (ระยะเวลาทั้งหมด): ต้อง Auto-calculate ตัวเลขจำนวนวัน และอัปเดตวันที่ในวงเล็บให้ตรงกับ Start Date - End Date ที่ User เพิ่งเลือกใหม่เสมอ**
* **กดบันทึกแล้วแสดง modal ดังต่อไปนี้ 2 วินาทีแล้วไปหายอัตโนมัติ**
