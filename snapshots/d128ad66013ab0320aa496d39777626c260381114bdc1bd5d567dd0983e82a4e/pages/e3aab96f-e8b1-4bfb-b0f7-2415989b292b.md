**เมื่อ select แล้วแสดงดังต่อไปนี้**

* **ฟิลเตอร์สถานะใบประกาศ**

  **กฎหลัก:** แท็บ “เหลือขาย / เปิดใหม่–เฟสใหม่ / ขายหมด” เป็น **ฟิลเตอร์สถานะแบบเลือกได้หลายค่า** การกดแท็บจะเปลี่ยนผลการค้นหา ไม่ใช่การสลับโฟกัสไปดูทีละส่วน 

  
  1.  **แท็บด้านนอกและ Full Filter ใช้ค่าสถานะที่มีผลต่อการค้นหาชุดเดียวกัน** เมื่อเลือกหรือยกเลิกที่แท็บด้านนอก ให้ปรับผลค้นหาและค่าที่แสดงใน Full Filter ทันที ส่วนการเปลี่ยนค่าใน Full Filter ให้ปรับผลค้นหาและแท็บด้านนอกเมื่อกด **“ค้นหา”** เท่านั้น ก่อนกด “ค้นหา” ค่าที่เปลี่ยนใน Full Filter ยังเป็นค่าที่กำลังเลือกอยู่ ไม่ใช่ค่าที่ใช้ค้นหาจริง
  2. **เลือกหลายสถานะได้** รายการที่ตรงกับสถานะใดสถานะหนึ่งที่เลือกให้แสดงผล เช่น เลือก “เหลือขาย” และ “ขายหมด” จะแสดงทั้งสองกลุ่ม หากไม่เลือกสถานะเลย ให้แสดงทุกสถานะที่ผ่านฟิลเตอร์อื่น
  3. **ประเภททรัพย์ใช้ร่วมกับสถานะ** เลือกบ้านและคอนโด = บ้าน *หรือ* คอนโด; เลือกเหลือขายและขายหมด = เหลือขาย *หรือ* ขายหมด แต่ผลลัพธ์ต้องผ่าน **ทั้งกลุ่มประเภททรัพย์และกลุ่มสถานะ**
  4. **หนึ่งโครงการมีสถานะเดียวในขณะนั้น** จึงไม่นำโครงการเดียวกันไปนับข้ามกลุ่มสถานะ ตัวเลขข้างแต่ละสถานะคำนวณใหม่ตามจังหวัด ประเภททรัพย์ และฟิลเตอร์อื่นที่เลือก โดยยังแสดงจำนวนของสถานะอื่นให้เปรียบเทียบและเลือกเพิ่มได้

  **ตัวอย่าง:** มี A = บ้านเหลือขาย, B = บ้านเปิดใหม่, C = คอนโดขายหมด เมื่อเลือกประเภท “บ้าน” จะได้ A และ B; กด “เหลือขาย” จะเหลือ A; กด “เปิดใหม่/เฟสใหม่” เพิ่ม จะได้ A และ B พร้อมกัน และ Full Filter ต้องแสดงว่าทั้งสองสถานะถูกเลือก
  * **ตัวเลขข้างแต่ละสถานะ:** นับจำนวนใบประกาศที่มีสถานะนั้นหลังใช้ตัวกรองประเภททรัพย์และเงื่อนไขอื่น โดยไม่ใช้สถานะที่เลือกอยู่มาทำให้ตัวเลขของสถานะอื่นเป็น 0
  * **สถานะที่ไม่มีใบประกาศจริงหลังใช้เงื่อนไขอื่น**: แสดง 0 และเลือกเพิ่มไม่ได้ ตัวอย่าง: เลือก “เปิดใหม่/เฟสใหม่” ใน Full Filter → แท็บด้านนอกแสดงว่าเลือกสถานะนี้อยู่ หากกด “เหลือขาย” ด้านนอก ระบบเพิ่ม “เหลือขาย” เป็นสถานะที่สองใน Full Filter และแสดงใบที่ตรงกับสถานะใดสถานะหนึ่ง โดยคงตัวกรองอื่นไว้


  * * **เหลือขาย** (ตัวเลข ไดนามิกตามจำนวนใบประกาศที่มีสถานะนี้ และไดนามิกตามตัวเลือกประเภทฟีลเตอร์) (เลือกได้มากกว่า 1)
    * **เปิดใหม่/เฟสใหม่** (ตัวเลขไดนามิกตามจำนวนใบประกาศที่มีสถานะนี้ และไดนามิกตามตัวเลือกประเภทฟีลเตอร์) (เลือกได้มากกว่า 1)
    * **ขายหมด** (ตัวเลขไดนามิกตามจำนวนใบประกาศที่มีสถานะนี้ และไดนามิกตามตัวเลือกประเภทฟีลเตอร์) (เลือกได้มากกว่า 1)

**ตารางเหตุการณ์ใช้ Walk-in เป็นตัวอย่าง โดยกฎเดียวกันนี้ใช้กับตัวเลือกพิเศษอื่นทั้งหมดที่หน้าปัจจุบันรองรับ เช่น แคมเปญ รีวิวจากน่าอยู่ และ VDO 360 ดังนี้**

* เมื่ออยู่ขอบเขตเดิม ให้คงค่าที่ผู้ใช้เลือกไว้ หากตัวเลือกพิเศษมีใบประกาศเข้าร่วม แต่ไม่มีใบที่ตรงกับประเภททรัพย์และเงื่อนไขอื่นที่เลือก ให้ ไม่แสดงผลลัพธ์การค้นหา โดยไม่ล้างตัวกรองให้อัตโนมัติ

ขอบเขตเฟสนี้: เมื่อเปลี่ยนระหว่าง Center กับจังหวัด หรือข้ามจังหวัด ให้ล้างตัวกรองทั้งหมดและกลับค่าเริ่มต้นของหน้าปลายทาง
