**EP-03 หน้าเพิ่ม Pop up  กรณีเลือก 4 หมวดที่ไม่ใช่** **Campaign**


 ![](/api/attachments.redirect?id=9e616cea-eb17-472a-ba1c-118e3894b65c)


\*\*Trigger  \*\*เมื่อ  User กดปุ่ม เพิ่ม  Pop up ให้มีการพา user 

\*\*Conditions: \*\*การแสดงในหน้านี้ เป็นไปตามที่ออกแบบ ให้มี 4 หัวข้อในการเพิ่มรายละเอียด คือ

1\. ประเภท 2.ชื่อ pop up 3. ระยะเวลาแสดงผล 4. Slot A/ Slot B

\*\*Logic: \*\*

* **Default การแสดงผลไว้ที่เฉพาะ slot A slot B จะเป็นไม่แสดงผล ในค่าเริ่มแรกของการเพิ่ม**
* **หัวข้อประเภท pop up** เป็นตัวเลือกแบบ Single Choice และ มีตัวเลือกให้เลือก 5 หมวดหมู่ คือ 1.โครงการใหม่ 2. บริษัทรับสร้างบ้าน 3.น่าอยู่ 4.อื่นๆ 5.Campaign เป็น require  default เป็น โครงการใหม่
* **หัวข้อชื่อของ pop up**สามารถพิมพ์ได้ทั้ง TH/EN ตัวเลขและเครื่องหมาย เป็น require
* \*\*หัวข้อ ระยะเวลาแสดงผล \*\*ให้เลือกวันที่เริ่มต้น - วันที่สิ้นสุด เป็นตัวเลือกแบบ Calendar ให้เลือกวันที่เริ่มต้น→วันที่สิ้นสุด ตามลำดับ หลังเลือกระบบจะต้องคำนวณระยะเวลาทั้งหมดและแสดง จำนวนวันทั้งหมด พร้อมกับวันที่เริ่มต้น-วันที่สิ้นสุด ในรูปแบบ DD/MM/YYYY ทั้งคู่ เป็น require
  * ตัวเลือกแบบ Calendar **ไม่สามารถเลือกวันที่ในอดีตได้  สำหรับวันที่เริ่มต้น**

###  **logic ปฎิทินนี้ใช้กับ  1.โครงการใหม่ 2. บริษัทรับสร้างบ้าน 3.น่าอยู่ 4.อื่นๆ แคมเปญจะเป็นอีก logic นึง**

```
- การแสดง Calendar จะแสดงเดือนสองเดือนคู่กันเสมอ
- กดไปทางซ้าย ← จะแสดง เดือนที่ n\-1, และเดือน n <u>Ex</u>\. กันยายน และ ตุลาคม 
- กดไปทางขวา → จะแสดงเป็น เดือนที่ n และเดือน n\+1 <u>Ex</u>\. ตุลาคม ไป พฤศจิกายน
- กดคลิกเลือกวันครั้งแรกจะเป็นวันที่เลือกเลยทันทีในรูปแบบ DD/MM/YYYY และเมื่อคลิกครั้งที่ 2 จะกำหนดเป็น วันที่สิ้นสุดทันที 
- เมื่อหมดเดือนธันวาคม ให้เริ่มปี ค\.ศ\.ใหม่

```

**เงื่อนไข ปิดการแสดงจะ disable ช่องกรอกข้อมูลด้านล่างไว้**

* **หัวข้อ Slot A และ B** สามารถเลือกได้ว่าจะแสดงผลหรือไม่ โดยสามารถ ปิดการแสดงผล Slot ใด Slot นึงได้
* ถ้าเลือกปิด Slot A หรือ B ให้ทำการปิดช่องกรอกข้อมูลของ Slot นั้นไป ให้เหลือเพียงช่องหัวข้อเท่านั้น
* การปิดการแสดงผลทั้ง 2 slot เท่ากับออฟไลน์ Pop up นั้น

### **EP-03.1 กรณีเลือก แคมเปญ  (เมื่อเลือก แคมเปญ)**

* ### Logic การทำงาน
  
  | รหัส | หัวข้อ | เงื่อนไข / การกระทำ | Logic การทำงาน |
  |------|--------|---------------------|----------------|
  | POP-CAMP-01 | เลือกประเภท | ผู้ใช้เลือกประเภท **แคมเปญ** | แสดงช่องสำหรับเลือกแคมเปญ |
  | POP-CAMP-02 | รายการแคมเปญ | เปิดช่องเลือกแคมเปญ | แสดงเฉพาะแคมเปญของจังหวัดที่กำลังจัดการ และมีสถานะ **กำลังแสดง** |
  | POP-CAMP-03 | ไม่มีแคมเปญ | จังหวัดนั้นไม่มีแคมเปญที่กำลังแสดง | ไม่มีรายการให้เลือก และยังบันทึก Pop-up ประเภทแคมเปญไม่ได้จนกว่าจะเลือกแคมเปญ |
  | POP-CAMP-04 | เลือกแคมเปญ | เลือกแคมเปญสำเร็จ   | ดึงวันเริ่มต้น วันสิ้นสุด และ URL ของแคมเปญมาแสดง |
  | POP-CAMP-05 | ระยะเวลาเริ่มต้น | เลือกแคมเปญสำเร็จ   | ใช้วันเริ่มต้นและสิ้นสุดแคมเปญเป็นค่าเริ่มต้นในช่องระยะเวลา Pop-up  |
  | POP-CAMP-06 | แก้ระยะเวลา | ผู้ใช้เปลี่ยนวันที่ Pop-up | แก้วันที่ได้ โดยวันสิ้นสุด Pop-up เลือกได้ **ไม่เกินวันสิ้นสุดแคมเปญ** |
  | POP-CAMP-07 | วันที่เกินแคมเปญ | เปิดปฏิทินเลือกวันที่ | วันที่หลังวันสิ้นสุดแคมเปญเป็น **Disable** และเลือกไม่ได้ |
  | POP-CAMP-08 | คำนวณจำนวนวัน | เปลี่ยนช่วงวันที่ Pop-up | อัปเดตวันที่และจำนวนวันแสดงผลให้ตรงกับช่วงที่เลือก |
  | POP-CAMP-09 | URL แคมเปญ | เลือกแคมเปญแล้ว     | ดึง URL ของแคมเปญมาแสดงและใช้กับ Pop-up |
  | POP-CAMP-10 | ช่อง URL ของ Slot | เลือกประเภทแคมเปญ   | **Disable ช่อง URL ของ Slot A และ B** ผู้ใช้กรอกหรือแก้ไขผ่านช่องดังกล่าวไม่ได้ |
  | POP-CAMP-11 | ภาพไทย | Slot A หรือ B เปิดแสดงผล | บังคับใส่ภาพไทยใน Slot ที่เปิด |
  | POP-CAMP-12 | ปิด Slot | ปิดการแสดงผล Slot A หรือ B | ไม่ตรวจภาพบังคับของ Slot ที่ปิด และบันทึกได้เมื่อข้อมูลบังคับอื่นครบ |
  | POP-CAMP-13 | ปิดทั้งสอง Slot | ปิดการแสดงผล A และ B | บันทึกได้เมื่อข้อมูลบังคับอื่นครบ โดย Pop-up อยู่ในสถานะออฟไลน์ |
  | POP-CAMP-14 | ภาพอังกฤษ / จีน | ไม่อัปโหลดภาพภาษาดังกล่าว | บันทึกได้เมื่อข้อมูลบังคับอื่นครบ และใช้ภาพไทยสำรองเมื่อไม่มีภาพภาษาที่เลือกใช้ได้ |
  | POP-CAMP-15 | อุปกรณ์ | อัปโหลดภาพแต่ละภาษา | ใช้ภาพไฟล์เดียวกันทั้ง Desktop และ Mobile |
  | POP-CAMP-16 | แคมเปญถูกปิดก่อน Pop-up หมดอายุ | Pop-up เริ่มแสดงแล้ว ต่อมาแคมเปญถูกปิด | Pop-up ยังแสดงต่อได้จนถึงวันสิ้นสุดของ Pop-up เมื่อผ่านเงื่อนไขแสดงผลอื่นเดิม |
  | POP-CAMP-17 | Pop-up หมดอายุ | ถึงวันสิ้นสุดและรายการเข้าสถานะหมดอายุ | **หยุดแสดง Pop-up** และคงรายการไว้ใน Backoffice |
  | POP-CAMP-18 | จัดการรายการหมดอายุ | เปิดรายการ Pop-up ที่หมดอายุใน Backoffice | **ไม่สามารถแก้ไขหรือลบ** รายการนั้นได้ |

  | เหตุการณ์ | ผลการทำงาน |
  |-----------|------------|

  | แก้วันสิ้นสุด Pop-up | เลือกได้ถึงวันที่ 30 มิถุนายน ส่วนวันที่ 1 กรกฎาคมเป็นต้นไปถูก Disable |
  | เปิด Slot A และปิด Slot B | บังคับภาพไทยของ A และไม่ตรวจภาพของ B |

## EP-05 การนับสถิติของ Slot A และ Slot B — Pop-up

ระบบเก็บสถิติ 2 ระดับ ได้แก่ **ยอดสะสมของแต่ละ Slot** และ **สถิติรายกราฟิก** โดยใช้เหตุการณ์ Click และ Impression ชุดเดียวกันมาสรุปผล

### 05.1 สถิติภาพรวมของ Slot ที่หน้าจัดการ Pop-up

| หัวข้อ | Logic การทำงาน |
|--------|----------------|
| ขอบเขต | แสดงสถิติ Slot A และ Slot B แยกกัน โดยแต่ละ Slot รวมทุกภาษา ทุกอุปกรณ์ และทุกเวอร์ชันภาพของ Slot นั้น |
| Click  | รวม Click ที่ผ่านเงื่อนไขทั้งหมดของ Slot และนับสะสมต่อเมื่อเปลี่ยนหรือเพิ่มกราฟิก |
| Impression — IMP | รวม IMP ที่ผ่านเงื่อนไขทั้งหมดของ Slot และนับสะสมต่อเมื่อเปลี่ยนหรือเพิ่มกราฟิก |
| CTR    | คำนวณจาก **Click สะสม ÷ IMP สะสม × 100** โดยไม่บวกหรือเฉลี่ย CTR ของแต่ละภาพ |
| เปลี่ยนกราฟิก | ไม่รีเซ็ตยอดสะสมของ Slot แต่ภาพใหม่เริ่มสถิติรายกราฟิกของตนเอง |
| รอเริ่มแสดงผล | ยังไม่นับสถิติ |
| ปิดแสดงผล / ออฟไลน์ | ไม่นับสถิติใหม่ เมื่อเปิดอีกครั้งและยังอยู่ในช่วงแสดงผล ให้นับต่อจากยอดเดิม |
| หมดอายุ | ไม่นับเหตุการณ์ที่เกิดหลังสิ้นสุดการแสดงผล และเก็บสถิติที่ผ่านมาไว้ดูย้อนหลัง |

### 05.2 สถิติรายกราฟิก แยกภาษา อุปกรณ์ และเวอร์ชัน

**ภาพ Pop-up 1 ภาษาใน 1 Slot ใช้ไฟล์เดียวกันทั้ง Desktop และ Mobile** โดยบันทึกอุปกรณ์ที่เกิดเหตุการณ์แยกไว้สำหรับดูรายงาน

| หัวข้อ | Logic การทำงาน |
|--------|----------------|
| การเปลี่ยนภาพ | บันทึกภาพใหม่เป็น Record หรือ Version ใหม่ ไม่เขียนทับภาพและสถิติเดิม |
| การผูกสถิติ | แต่ละเหตุการณ์ระบุรายการ Pop-up, Slot A/B, Graphic_ID หรือ Version, ภาษาของภาพ และอุปกรณ์ที่เกิดเหตุการณ์ |
| แยกภาษา | เก็บสถิติภาพภาษาไทย `TH` อังกฤษ `EN` และจีน `CN` แยกกัน |
| แยกอุปกรณ์ | เก็บ Click และ IMP จาก Desktop และ Mobile แยกกันได้ **แม้ใช้ Graphic_ID ของภาพเดียวกัน** |
| ภาพใหม่ | เริ่ม Click และ IMP ของภาพเวอร์ชันใหม่ที่ 0 แล้วนับเมื่อภาพนั้นเกิดเหตุการณ์จริง |
| ภาพเดิม | เก็บ Record และสถิติเดิมไว้เรียกดูย้อนหลัง |
| เปลี่ยนภาพหนึ่งภาษา | เช่น เปลี่ยนภาพ EN ของ Slot A ให้สร้างเวอร์ชันใหม่สำหรับภาพ EN นั้น ซึ่งใช้ทั้ง Desktop และ Mobile ส่วนภาพไทยและจีนคง Record และสถิติเดิม |
| CTR รายกราฟิก | คำนวณจาก Click และ IMP ของ **Graphic_ID/Version นั้น** โดยรวมอุปกรณ์ตามขอบเขตรายงานที่เลือก |
| สรุปรายภาษา | รวม Click และ IMP ของภาษานั้นตามขอบเขตรายงาน แล้วคำนวณ CTR ใหม่ ไม่เฉลี่ย CTR ของแต่ละอุปกรณ์หรือเวอร์ชัน |
| ใช้ไทยสำรอง | นับตาม **ภาษาของภาพที่แสดงจริง** เช่น เว็บอังกฤษแสดงภาพไทยสำรอง ให้นับเข้า Graphic_ID ภาษาไทย ไม่เพิ่มยอดให้ภาพอังกฤษ |

หากต้องการวิเคราะห์ว่าภาพไทยถูกแสดงบนเว็บไซต์ภาษาใด ให้เก็บ **ภาษาหน้าเว็บ** แยกจาก **ภาษาของภาพที่แสดงจริง**

### 05.3 เงื่อนไขการนับ ใช้ร่วมกันทั้งสองระดับ

| เหตุการณ์ | Logic การนับ |
|-----------|--------------|
| ผู้ใช้คลิกจริง | นับ 1 การคลิกเป็น 1 Click ทันที โดยไม่ต้องรอหน้าเป้าหมายโหลดเสร็จ |
| คลิกซ้ำตำแหน่งเดิม | หากเป็นการคลิกจริงคนละครั้ง ให้นับแต่ละครั้ง ไม่ตัดทิ้งเพียงเพราะคลิกพิกัดเดิมซ้ำกัน 10 ครั้ง |
| ส่งเหตุการณ์ซ้ำ | เหตุการณ์เดียวกันต้องใช้ Event_ID เดิม เมื่อส่งซ้ำหรือ Retry ให้นับเพียงครั้งเดียว |
| ภาพปรากฏบนหน้าจอ | นับ 1 IMP เมื่อมีส่วนใดส่วนหนึ่งของกราฟิกปรากฏในพื้นที่หน้าจอ และหน้าเว็บกำลังแสดงอยู่ |
| ภาพอยู่ในจอต่อเนื่อง | ไม่เพิ่ม IMP ซ้ำทุกวินาทีหรือทุกครั้งที่หน้าเว็บอัปเดต |
| ภาพออกจากจอแล้วกลับมา | เมื่อภาพกลับมาปรากฏอีกครั้งและผ่านเงื่อนไข ให้นับ IMP ใหม่ |
| Refresh / กลับเข้ามาดูใหม่ | เมื่อภาพปรากฏและผ่านเงื่อนไข ให้นับ IMP ใหม่ แม้เป็นผู้ใช้คนเดิม |
| สลับไปแท็บอื่น / ย่อหน้าต่าง | **ไม่นับ IMP ขณะที่หน้าเว็บไม่แสดงอยู่** |
| กลับมาเปิดแท็บหรือหน้าต่าง | หากภาพกลับมาปรากฏบนหน้าจอและผ่านเงื่อนไข ให้นับ IMP ใหม่ |
| ภาพไม่ได้แสดง | ไม่เพิ่ม IMP ให้ภาพภาษาอื่น หรือทางเลือก A/B ที่ไม่ได้แสดง |

### 05.4 สูตรและรูปแบบการแสดงตัวเลข

ฐานข้อมูลเก็บ **จำนวนจริงเต็มจำนวน** และย่อเฉพาะตอนแสดงผล

| จำนวนจริงของ Click / IMP | วิธีแสดง | ตัวอย่าง |
|--------------------------|----------|----------|
| 0–999                    | แสดงจำนวนเต็มตามจริง | `0`, `123`, `999` |
| 1,000–999,999            | หาร 1,000 แสดงทศนิยม 1 ตำแหน่ง ตัดเศษไม่ปัดขึ้น | `1,000 → 1.0K`, `1,999 → 1.9K` |
| ตั้งแต่ 1,000,000        | หาร 1,000,000 แสดงทศนิยม 1 ตำแหน่ง ตัดเศษไม่ปัดขึ้น | `1,000,000 → 1.0M`, `1,299,999 → 1.2M` |

**สูตร CTR**

`CTR = (Click จริง ÷ IMP จริง) × 100`

* คำนวณจากจำนวนจริงก่อนย่อเป็น K/M
* แสดงทศนิยม 1 ตำแหน่ง โดยตัดเศษไม่ปัดขึ้น เช่น `3.39% → 3.3%`
* หาก IMP เท่ากับ 0 ให้แสดง `—` เพราะยังคำนวณ CTR ไม่ได้
