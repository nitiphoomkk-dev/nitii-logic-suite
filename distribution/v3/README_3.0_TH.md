# นิติ๊ Logic Suite 3.0.0

ชุดนี้รวม 11 สกิลและตัวอัปเดต Wiki ไว้ด้วยกัน สำหรับ Codex ที่ติดตั้งสกิลในโปรเจกต์ ให้แตก ZIP แล้วเปิด Terminal ในโฟลเดอร์ที่มีไฟล์ `install_nitii.py` ระบุพาธโปรเจกต์ที่จะใช้ถามนิติ๊

```sh
python install_nitii.py --project "C:/path/to/project"
```

ใช้คำสั่งเดียวกันกับโปรเจกต์ใหม่และโปรเจกต์ที่ติดตั้ง 1.2 หรือ 1.2 พร้อมแพตช์ 1.2.1 ไว้แล้ว บน Windows ใช้ `py -3` แทน `python` ได้ เมื่อเสร็จแล้วให้เปิดแชทใหม่ในโปรเจกต์นั้น ลองถามว่า “นิติ๊ ตาม Wiki ล่าสุด Pop-up จังหวัดเมื่อเปลี่ยนหน้าแสดงอย่างไร ขอหน้าที่มาและ revision ด้วย”

**การใช้ข้อมูลล่าสุด** เมื่อนิติ๊ค้นหรืออ่าน Wiki ตัวสกิลจะตรวจชุดข้อมูลที่ GitHub เผยแพร่ล่าสุดก่อนตอบ ถ้ามีชุดใหม่จะดาวน์โหลดและตรวจไฟล์ให้เอง เครื่องต้องรัน Python 3.9 ขึ้นไป เชื่อมต่อ GitHub และเขียนแคชได้ ผู้รับใช้บัญชีได้ตามปกติโดยไม่ต้องใส่ Wiki API key [วิธีดูวันที่ของข้อมูล](AUTO_UPDATE_TH.md)

| สกิล | งานที่ใช้ |
|---|---|
| nitii-logic | วิเคราะห์ Logic และประสานการตรวจตามบทบาท |
| nitii-knowledge | ค้นและอ่านหลักฐาน Wiki พร้อม URL และ revision |
| nitii-solution | เขียน Solution และถอด Requirement |
| nitii-qa | เขียน AC และ Test Case |
| nitii-sa | ตรวจขอบเขตข้อมูลและการเชื่อมต่อระบบ |
| nitii-po | เตรียมตัวเลือกให้ผู้ตัดสินใจด้านธุรกิจ |
| nitii-pm | วางแผนงานและตรวจลำดับงานที่พึ่งกัน |
| nitii-uxui | ตรวจการใช้งานและหน้าจอ |
| nitii-backend | ตรวจฝั่งระบบและการจัดเก็บข้อมูล |
| nitii-frontend | ตรวจฝั่งหน้าจอและการรับส่งข้อมูล |
| nitii-explain | อธิบายผลให้ผู้ฟังแต่ละกลุ่มเข้าใจ |

สำหรับ Codex Marketplace, Claude Code, Gemini CLI หรือการอัปโหลดไฟล์ ให้ดู [วิธีติดตั้งตามแพลตฟอร์ม](INSTALL_TH.md) ไฟล์ ZIP ย่อยสำหรับ Plugin และ Standalone อยู่ใน `packages/` ของชุดนี้

สำเนาสำรองที่บรรจุใน ZIP เป็นข้อความและตาราง Wiki 281 หน้าจากวันที่ 19 ตุลาคม 2569 จำนวนหน้าและเวลาของข้อมูลออนไลน์อ่านได้จาก [สถานะการเผยแพร่บน GitHub](https://raw.githubusercontent.com/nitiphoomkk-dev/nitii-logic-suite/knowledge/latest.json) การอัปโหลดไฟล์อย่างเดียวใน ChatGPT Project หรือ Gemini Gem ต้องเปลี่ยนไฟล์เองเมื่อต้องการข้อมูลชุดใหม่
