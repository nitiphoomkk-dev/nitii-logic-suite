# ข้อมูล Wiki ที่นิติ๊ใช้ตอบ

เมื่อนิติ๊ใช้ตัวค้นหรือตัวอ่านของสกิล `nitii-knowledge` สกิลจะตรวจรายการเผยแพร่บน GitHub ก่อนใช้งาน ถ้ามีข้อมูลชุดใหม่จะดาวน์โหลด ตรวจสอบ hash แล้วสลับไปใช้ชุดนั้น เมื่อมีชุดล่าสุดอยู่แล้วจะใช้ข้อมูลในแคชต่อ การเปิดแชทใหม่ในโปรเจกต์เดิมใช้การติดตั้งเดิมได้

ตัวค้นและตัวอ่านต้องรันด้วย Python 3.9 ขึ้นไป มีสิทธิ์เชื่อมต่อ GitHub และเขียนแคชได้ เครื่องของผู้รับไม่ต้องมี Wiki API key งานตรวจ Wiki ของ GitHub ตั้งไว้ทุกวันเวลา 20:00 น. ตามเวลาไทย งานอาจเริ่มช้ากว่ากำหนดได้ การแก้ Wiki ระหว่างรอบจะปรากฏหลังการเผยแพร่รอบที่รวมการแก้นั้นสำเร็จ

| สถานะจากตัวค้นและตัวอ่าน | ข้อมูลที่ใช้ตอบ |
|---|---|
| `updated` | ตรวจและรับชุดที่เผยแพร่ใหม่แล้ว |
| `current` | ตรวจแล้วว่าชุดที่มีตรงกับ GitHub |
| `stale` | ตรวจ GitHub ครั้งนี้ไม่สำเร็จ ใช้แคชที่เคยตรวจผ่านและแจ้งวันที่สำเนา |
| `error` พร้อม `source: bundle` | ใช้สำเนาที่มากับชุดติดตั้งและแจ้งวันที่สำเนา |

`checkedAtUtc` ใน `knowledge_update` คือเวลาที่ฝั่ง GitHub ตรวจ Wiki สำเร็จ หากเป็นค่าว่างให้ระบุวันที่สำเนาจาก `snapshotCapturedAtUtc` ถ้ามี ผู้ใช้ถามนิติ๊ได้ว่า “คำตอบนี้ใช้ข้อมูลวันที่เท่าไร และหน้า Wiki revision ไหน” [สถานะรอบเผยแพร่](https://raw.githubusercontent.com/nitiphoomkk-dev/nitii-logic-suite/knowledge/latest.json)

## สำหรับผู้ใช้ไฟล์อัปโหลดใน Project หรือ Gem

ผู้ที่ใช้เฉพาะไฟล์อัปโหลดให้เปิด [รายการชุดล่าสุด](https://raw.githubusercontent.com/nitiphoomkk-dev/nitii-logic-suite/knowledge/latest.json) แล้วดาวน์โหลดไฟล์ที่ระบุใน `archivePath` ใต้ `https://raw.githubusercontent.com/nitiphoomkk-dev/nitii-logic-suite/knowledge/` แตก ZIP แล้วใช้ไฟล์ `web/NAYOO_WIKI_*.txt` และ `web/UPLOAD_INDEX.txt` แทนชุดเก่าใน Project หรือ Gem นั้น การอัปโหลดเพียงอย่างเดียวใช้ข้อมูลตามวันที่ของไฟล์ที่อัปโหลด
