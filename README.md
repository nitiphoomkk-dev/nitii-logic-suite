# Nitii Logic Suite — v1.2 + แพตช์อัปเดตอัตโนมัติ 1.2.1

## ผู้ติดตั้งเดิม: รับแพตช์ครั้งเดียว

[ดาวน์โหลดแพตช์ 1.2.1](https://github.com/nitiphoomkk-dev/nitii-logic-suite/releases/download/v1.2.1/Nitii_Auto_Update_Patch_1.2.1.zip) · [วิธีติดตั้งและตรวจผล](AUTO_UPDATE_PATCH_TH.md)

ผู้ใช้รุ่น 1.2 ที่รัน Python/network ได้ รับแพตช์ครั้งเดียว จากนั้นตัวค้นและตัวอ่านจะตรวจและรับข้อมูล Wiki ที่เผยแพร่ล่าสุดก่อนใช้งานเอง ไม่ต้องรัน updater ทุกครั้ง แพตช์สำรองไฟล์เดิมและไม่ต้องติดตั้งสกิลทั้งชุดใหม่ ไม่ใช่การส่งแพตช์ลงเครื่องทุกคนอัตโนมัติ และไม่รองรับไฟล์อัปโหลดอย่างเดียวใน Project/Gem

## ชุดบิ๊กบอสภูมิ — 3 พฤศจิกายน 2569

เพิ่มชุดติดตั้งบิ๊กบอสภูมิพร้อมบทบาท QA, SA, PO, PM, UX/UI, Backend และ Frontend รวม 8 สกิลและคำสั่งเอเจน 8 ไฟล์ เริ่มประสานทีมเฉพาะเมื่อมนุษย์สั่งสำหรับ task นั้น ไม่เปิดทีมจากการติดตั้งหรืออัปเดต

[ดาวน์โหลดชุดบิ๊กบอสภูมิ 1.0.0](nitii-bigboss-phum-1.0.0.zip) · [คู่มือใช้งาน](BIGBOSS_PHUM_TH.md) · [รายการไฟล์และ SHA-256](BIGBOSS_MANIFEST.json)

ไฟล์บทบาทและสกิลอยู่ภายใน ZIP ให้ดาวน์โหลดแล้วแตกลง workspace ที่ต้องการใช้ การ clone รีโปอย่างเดียวยังไม่ติดตั้งชุดนี้ และ ZIP Release v1.2.0 เดิมไม่ได้เปลี่ยนตาม ไม่มีการติดตั้ง MCP หรือคัดลอก credential อัตโนมัติ

ชุดทักษะ “นิติ๊” สำหรับค้น Business Logic, ทำ Solution, AC, Test Case และส่งต่องาน Dev มี 11 ทักษะ พร้อมฐานข้อความ NaYoo Wiki เดิม 281 หน้า และตัวรับข้อมูลรุ่นใหม่

## การรับข้อมูลใหม่

- AI ที่รัน Python และออกอินเทอร์เน็ตได้: รับแพตช์ 1.2.1 ครั้งเดียว จากนั้นใช้ตัวค้น/อ่านเดิม ซึ่งเรียกอัปเดตก่อนอ่านทุกครั้ง ข้อมูลใหม่ผ่าน hash และสลับทั้งชุด หากตรวจไม่ได้จะใช้สำเนาสำเร็จเดิมพร้อมแจ้ง stale ผู้รับไม่ต้องมี Wiki key
- AI ที่ใช้เว็บได้: ตรวจ public feed และอ่านหน้าที่เกี่ยวข้องตามสิทธิ์เครื่องมือ
- AI ที่ใช้เฉพาะไฟล์อัปโหลด: ดาวน์โหลด knowledge.zip รุ่นล่าสุด แล้วเปลี่ยนไฟล์ `web/*.txt` เอง ไฟล์ใน Project/Gem/Skill ไม่ถูกแทนที่อัตโนมัติ

ตัวรับอัปเดตเฉพาะข้อมูล ไม่ดาวน์โหลดหรือรันโค้ดจาก Wiki ไม่โหลด corpus ทั้งชุดเข้า context ของ AI เพื่อเช็กสถานะ ผู้รับควรค้นก่อนอ่านและอ่านเฉพาะหลักฐานที่เกี่ยวข้อง

## ขอบเขต

ฐานเริ่มต้นคัดข้อความจาก Wiki วันที่ 19 ตุลาคม 2026 ส่วนเวลาตรวจครั้งต่อไปอยู่ใน feed เนื้อหาอาจมีร่าง ข้อเสนอ กฎเก่า และข้อขัดแย้ง ต้องแยกสถานะหลักฐานก่อนสรุป ไม่ตามอ่าน Google Docs/Figma/Canva ภายนอก ไม่รวมไฟล์ภาพจากลิงก์ ไม่ส่ง credential หรือประวัติแชต ไม่มีการให้สัญญาอนุญาตแบบ Open Source แก่ข้อมูลภายใน

โค้ด sync/updater อยู่ใน repository นี้ แต่ชุดสกิลครบยังดาวน์โหลดจาก Release Assets การ clone source อย่างเดียวไม่ติดตั้งสกิลลง AI
